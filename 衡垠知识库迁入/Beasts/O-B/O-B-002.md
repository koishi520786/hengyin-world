### 一、物种概述

隧锈鼠是特殊能量叠加血脉变异后定居地下管廊的小型群居啮齿型异化动物，单只 0.25m／0.6kg、数十只成群。威胁「低」由机制推出：单只输出只在肉体层，群体带来的是多点浅伤与消耗，非绕防手段；契约明载其**伴生低转土／金道蛊、独立活动、不受控**。含铁锈质门齿与硬毛最强，腹部最弱，怕干燥与高频震动。本档把啃矿锈归食性代谢、门齿硬毛归肉体结构，伴生蛊单列第八节，**绝不因携蛊而给它空窍、真元、炼蛊或催动能力**【原创设定】。

### 二、形态与生理结构

| 部位／系统 | 结构与比例 | 防御层级与差异 |
|---|---|---|
| 体型体重 | 0.25m／0.6kg；头躯尾≈1:1.6:1.1，尾近裸 | 质量小、群居分散使单发收益低 |
| 皮肤外皮 | 薄、少脂，背部真皮含铁质沉积 | 首道屏障，破之「仅表面伤」 |
| 锈质硬毛 | 背与体侧硬毛掺氧化铁屑，顺向叠生 | **最强**：挡低转切割与擦划、耐磨 |
| 腹部 | 无硬毛、皮薄毛稀 | **最弱**：穿刺命中升「伤及内脏」 |
| 门齿 | 终身生长、釉质富铁锈质，可啃矿锈层 | 攻击结构：穿刺＋啃咬挤压 |
| 肌肉骨骼 | 四肢短肌、脊柱柔韧，骨细 | 吸能弱；挤压可骨折 |
| 感官 | 触须发达、视觉退化、听高频灵敏 | 感官弱点：怕高频震动（契约锚） |
| 特殊器官 | 无毒性腺；颊囊暂存矿屑；盲肠发酵菌膜 | 分泌物≠蛊毒，不指向任何蛊编号 |
| 运动／内部 | 四足钻缝、可倒挂管顶；耐湿、代谢依赖潮湿菌膜 | 怕干燥：干燥致硬毛锈层脆裂【原创设定】 |

**prose**：梯度「锈质硬毛→薄肌→细骨→内脏」，腹部无硬毛是唯一可直达内脏的开口；群居使「单只被挡」不等于「群体被处理」，是低威胁仍须范围手段的机制原因【原创设定】＋【合理推测】。

### 九、仙蛊档案

| 项 | 内容 |
|---|---|
| 是否携仙蛊 | **否** |
| 理由 | ①契约只标「伴生低转土／金道蛊」，明确低转、无仙蛊；②仙蛊六转以上同名天下唯一、有意志、需特定食物，野生附体属「极高」级稳定机制须有证据，本种「低」且无证据；③第八节明细全为凡蛊（一～三转）与转数不明凡蛊，无六转以上条目；④纪律 5 禁止无依据硬塞高转仙蛊，O-G-110 起为预留段不得借用；⑤本组六种均不携仙蛊，O-B-012 阈鹿仙蛊登记属承接档案，不引用不类比。 |

**prose**：「否」是确定结论；C-G-160 乌七蛊「封禁六转以下蛊虫」对伴生凡蛊有效、对宿主肉身无效，这一区分是第十节判定依据，不能倒推成「携仙蛊」【原创设定】。

| 二转（①普通） | 势均力敌：单发被硬毛挡回 | 同左（伴生蛊不叠加） | 输出不对口＋范围不足 | C-G-087 刀光蛊／C-G-169 覆盖群体 |
| 三转（⑦真元不足负伤） | 取决于搭配：看是否带范围音道或改地形蛊 | 同左 | 缺件蛊不可用、低转催高转打折 | 保 C-G-169；缺则撤 |
| 四转（②攻伐） | 优势明显：C-G-100 单只可破甲重伤 | 同左 | 攻伐配置防御薄，拐角被绕后 | C-G-100 点杀＋C-G-018 兜底 |
| 五转（③防御恢复） | 较大胜算：C-G-133 挡群涌但难清群 | 同左 | C-G-133 自困；生机叶冷却 | 固守＋C-G-169 驱散 |
| 六转（④专门针对） | 轻松击杀：先知「怕干燥／高频震动」 | 同左，且 C-G-160 可封禁伴生凡蛊 | 依赖情报正确性；封禁只及蛊不及宿主 | C-G-169＋C-G-460＋C-G-160 |
| 七转（⑤完整准备） | 轻松击杀：组件齐、真元足 | 同左 | 组件兼容与同催须逐条核 | C-K-217 范围输出＋C-K-221 封视线 |
| 八转（④＋⑤） | 轻松击杀：情报正确且组件齐 | 同左 | 仍须核杀招消耗 | 对口范围杀招＋C-G-206 护装备 |
| 九转（⑤） | 轻松击杀：全前置成立 | 同左 | 真元效率不经济 | 建议驱散代替全歼 |

**prose（七配置差异）**：①普通→势均力敌；②攻伐→优势明显但防御薄；③防御恢复→较大胜算非全歼；④专门针对→轻松击杀；⑤完整准备→轻松击杀且容错高；⑥情报不足遭突袭→明显劣势；⑦真元不足／负伤／缺蛊→取决于搭配。携蛊后结果**不高于本体**，因伴生蛊独立活动、不受控、不成组合（评估体系 3.2）【合理推测】。

### 十七、现代社会与秘境分布

| 主体 | 处置口径 |
|---|---|
| 官方机构 | 市政／地铁按「管廊害兽」登记，清淤、干燥、封堵缝隙为常规处置；检修前报备振动时段 |
| 蛊师协会登记 | 列「低威胁·群居·伴生蛊独立活动·不携仙蛊」；驯养不适用（普通动物智慧、无协同） |
| 秘境公司捕获评估 | 「低单体价值、伴生蛊为凡蛊且不可控」，通常不立项活捉，仅作矿道秘境伴生指示 |
| 企业资源开发 | 粪砂金属屑与锈质硬毛低强度回收；禁以「取蛊」名义批量清群 |
| 黑市 | 偶以「锈齿磨料」「野生土金蛊」名义兜售，后者多为【未识别野生蛊虫】，不得比定已知蛊名 |
| 普通人识别避险 | 识别「管廊锈色硬毛小群、啃金属声」；勿徒手探箱涵、勿在废弃区间久留 |

**prose**：**不随意出现在市中心**是三条件同时不成立——①需稳定潮湿菌膜与金属氧化层，核心区管廊定期清淤干燥；②需可钻缝隙与少人扰动，核心区人流振动持续；③「怕干燥／怕高频震动」弱点在照明、通风、列车振动下被持续触发。故稳定分布于地下管廊／地铁／矿道，仅随废弃管段短时外溢【原创设定】。
