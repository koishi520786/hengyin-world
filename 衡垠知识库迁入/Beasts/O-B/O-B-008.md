### 一、物种概述

泥囊螈是本项目**「携蛊 ≠ 可控」的头号案例**，也是全库最容易被写坏的一头妖兽。它体内与体表寄生着大量野生蛊——肠腔、腐食囊、皮肤褶皱、黏液囊内壁、口腔隐窝里都有，数量以百千计，绝大多数根本无法鉴定到具体蛊名。直觉会把它读成「一身蛊、战力爆表」，而本档案要论证的恰好相反：**它一头蛊也指挥不了**。

它是普通动物智慧的巨型两栖兽：2.4 米、260 公斤，全部本事是伏在腐泥里、靠湿皮挨打、把黏液囊外翻糊住猎物、张口吞腐肉。它没有空窍、没有真元／仙元、没有炼化能力，也不具备"催动"这个动作所需的能量与意志。身上那些蛊是自发吸收天地元气、被动释放单体效果的住客，彼此之间没有配合、没有连锁、更谈不上杀招。按《妖兽携蛊与野生蛊虫档案》六项分析清单，它在「智慧／催动条件／指挥多蛊／配合／杀招」五项上全部不成立，第六项「自主保护机制」也【原著未明确】。

因此它的中威胁来自**本体**（钝击体量、黏裹控制、腐液刺激）＋**一项可改变战局的被动机制**（携大量被动寄生野生蛊，令"击杀≠安全取蛊"、令封蛊类比打本体更管用），而**不是**来自把蛊能力加起来。它真正麻烦的地方是卫生与取蛊：杀了它，满身蛊可能逃逸、反噬、随腐气散入沼泽；想拿样本，得先封、再捕、再沉眠。这一点在第十四、十六、十七节会反复落地。

泥囊螈的分布几乎由"能不能保住那层湿皮"画出边界：它需要淤泥做基质、腐殖质做食源、高湿维持胶质层，还需要静水让外翻的黏液囊不被冲散。城市对它不友好不是因为人多，而是三样东西同时存在——硬化地面不给淤泥、冬季融雪盐与干燥空气让皮开裂、路面高温与明火直接越过它最薄的黏膜。它偶尔出现在城郊湿地边缘，已是分布上限；再往里一步就是生理意义上的死区。

### 六、本体实力与威胁

> **本节不计算任何携带蛊虫**；被动寄生蛊单列第八节，按规则**不计入**本体，也不得与本体相加。

**本体战力**（评估体系 3.1 模板）：常态下，泥囊螈凭 260 kg 体量扑压与钝咬，对配置①普通蛊师可稳定造成「中伤」（钝击震荡），配合黏液囊外翻可追加「特殊控制」（束缚 2～4 息）；对已开 C-G-018 玉皮蛊／C-G-037 青丝蛊的目标，钝击降为「轻伤」。防御侧：厚韧湿皮把钝击「中伤」降为「轻伤」，但**抗切割一般**——C-G-056 月芒蛊、C-G-100 水钻蛊可稳定造成「重伤」；黏液囊外翻内壁被命中则由「中伤」升为「致命」。恢复为湿皮自然愈合（**须保湿**，干燥下伤口不闭合），无特殊器官再生。

**实际携蛊战力**：**≈ 本体战力，不追加有效项**。体内＋体表大量【未识别野生蛊虫】＋少量真实低转 C-G（第八节），全部为「被动寄生」、无一条有发动记载、无宿主催动、无配合、无杀招；按《妖兽携蛊与野生蛊虫档案》6.2 与《仙蛊唯一性登记表》第六节，仅"未被封禁且确有自发单体效果"者可计入，本物种此类效果最弱判「微弱」（如 C-G-096 敛息蛊被动隐气息），且**不得把身上所有蛊能力简单相加计入战力**。因此实际携蛊战力与本体战力在同一量级，不因"蛊多"抬升。

**理论最大战力**：仅当"全部携带蛊虫均可发挥 + 由有智慧施术方组织成杀招"时成立的上限，单列为存档估值；本物种智慧不足、无催动条件、无组织者，标【理论上限·不可实现】（携蛊档案 6.3 第 5 条、评估体系 3.2）。**不得当日常战力**。

**威胁等级机制复核**：中＝具备「一项」可改变战局的机制（携大量被动寄生野生蛊 → 取蛊风险／封蛊判定），但前置明显、可被对口蛊或情报克制（评估体系 2.1）。它的"中"不来自单体强度，也不来自蛊的加总；契约等级不改写。

### 九、仙蛊档案

**否。** 三层理由：① 契约只批准「体内＋体表大量被动寄生野生蛊，以【未识别野生蛊虫】为主＋少量真实低转 C-G」，明确限定低转、未批准仙蛊；② 本物种是**全库「携蛊≠可控」典型案例**，若硬塞一只六转仙蛊，会直接把「携带≠能催动」的教学结论冲掉，与第八节六项清单自相矛盾；③ 《仙蛊唯一性登记表》R1（同名天下唯一、天地不自然产生）、R5（不得认定为新生野生仙蛊），且本轮 C 组**只新增一只野生仙蛊 O-G-110「界隙蛊」、宿主固定为 O-B-012 阈鹿**，不得复用、不得重新安排。因此本物种**无依据**携任何仙蛊；野外若检出高转气息，一律【未识别野生蛊虫】／【待考证】，交登记表复核，本档案不据此抬级、不给阈鹿以外的任何物种分派 O-G-110。

### 十四、战斗方式与应对

泥囊螈不"打"，它**压、糊、喷、泡**：

1. **接敌前**：先判场地湿度与基质。把战场引到干燥、硬化、有盐或可明火的地带，T1 会自行失效——这比任何破防蛊都省事（配置④「专门针对」的核心）。
2. **接敌中**：它扑压（钝击）、外翻黏液囊（特殊控制 2～4 息）、喷腐液（微弱刺激）。**不要用钝击蛊和它比力气**（C-G-107 被压到微弱）；用切割／钻破（C-G-056／C-G-100）走"抗切割一般"这条路，或趁外翻窗口钻 1～2 mm 内壁直取致命。
3. **关于满身蛊**：**先封再打**。C-G-160 乌七蛊一封，百千只低转野生蛊整批失效，战斗立刻退化成"打一头 260 kg 的湿皮兽"，难度降一档。这一步是本案区别于其他妖兽的关键。
4. **收尾（最容易翻车）**：**击杀 ≠ 安全取蛊**。宿主死亡后蛊可能逃逸、反噬取蛊者、自毁或随腐气消散（7.1）。须先 C-G-143 皓珠蛊／C-G-683 龟息蛊封印沉眠，或 C-G-454 水笼蛊专捕，并核对是否有主动攻伐蛊；【未识别野生蛊虫】一律不徒手接触、不定价、不流通。
5. **不建议的打法**：纯钝击流、对视类魂道（C-G-204 前置不成立）、驭犬蛊（C-G-040 限犬类）、误用 C-G-133 水幕天华蛊把自己困在沼泽里。

配⑥「情报不足遭突袭」是主要翻车点：不知它抗钝击、没带封蛊蛊、被黏液囊先手裹住，结果可落到「明显劣势」；但只要撤到干燥硬化地面或一封了之，威胁迅速回落。

| 肉材 | 全体 | **不建议**：腐胺与未识别蛊污染风险 | — | 禁售 |

**风险提示**：资源价值的大头是"蛊样本"，但**样本价值 ≠ 宿主战力**，也不得因"身上蛊多"抬价；黑市常见把【未识别野生蛊虫】冒充 C-G-063 爱生离等高价蛊，协会要求逐只编号鉴定，无证书不交易。

### 十七、现代社会与秘境分布

| 主体 | 处置 |
|---|---|
| 官方机构 | 湿地管理／疾控部门列为「腐食性大型两栖 + 野生蛊携带体」双属性：既纳入湿地有机消纳，也纳入**生物安全**管理；捕获、转运、剖检须报备，禁止活体跨区运输 |
| 蛊师协会登记 | 登记为「中威胁·被动携大量野生蛊·**不可控不可催动**」；协会明文写入本案结论：「携带蛊≠可控，身上蛊能力不得简单相加计入战力」；取蛊须持「野生蛊封捕」专项许可，禁止以驯蛊／奴兽名义申报 |
| 秘境公司捕获评估 | 评估结论：**"高成本、中收益、高风险"**——肉材无价值、蛊样本价值高但封捕与登记成本更高，且逃逸／反噬风险显著；仅接受科研机构委托的小规模活体采样，不设商业捕获队 |
| 企业资源开发 | 湿地原位腐废消纳服务、湿皮仿生衬层、黏液阻尼材料；均须在封蛊前置下取料，不得整群捕杀、不得把蛊群带入生产线 |
| 黑市 | 「泥囊螈带蛊活体」被炒成"一身仙蛊"，实际绝大多数为【未识别野生蛊虫】与低转 C-G；交易常伴随逃逸与反噬事故，协会持续查处 |
| 普通人识别避险 | 识别：2.4 m 湿皮、贴地伏泥、腐臭味、雨后夜间活动、受惊时腹侧翻出黏囊。避险：不靠近腐沼边缘、不徒手触碰、不投盐或明火戏弄（会激化外翻与喷吐）、发现即报湿地管理方；它不追人，缓步退到干燥硬化地面即可 |

**为何不随意出现在市中心**：三条生理硬约束叠加——① 硬化地面与排水渠无淤泥基质，无法伏泥与筑隐窝；② 干燥空气、冬季融雪盐、路面高温使湿皮胶质层开裂、黏液凝固（T1 失效）；③ 260 kg 体型无法进入管渠与楼梯、电梯等城市构筑物。城市对它不是"危险"，是"物理上待不住"。偶有个体随暴雨旧河道误入城郊湿地边缘，即为分布上限。

### 十八、设计来源与原创说明

本物种由以下**抽象设计方向**独立推演，不借鉴任何既有作品的特定怪物：

- **共生代价与"培养基"思路**：把"满身是蛊"设计成**生理分泌物招来的住客**，而不是军备库；宿主得到零收益或极微收益，却承担全部取蛊与生物安全风险。代价方向先于战力方向，从根上堵死"蛊多 ⇒ 强"。
- **抗性的不对等**：只给一层"抗钝击、不抗切割"的湿皮，让最强防御自带最直白的破解口，避免"防御极高"式模糊话；再把最弱部位（外翻黏液囊内壁）绑定到唯一主动动作上——它一出手就露破绽。
- **渗透压边界**：以变温、皮肤呼吸、胶质层保湿这套生理，把"怕干燥／盐／火"从设定台词变成可判定的结构失效，使环境成为能被蛊师主动选择的克制手段。
- **群体节律的缺席**：刻意不给它群体、首领、节律协同，独居＋反射，保证「普通动物智慧」在行为学上自洽，天然不满足指挥多蛊与杀招门槛。

独立创造的部分：厚韧湿皮的纤维—胶质双层与抗钝击／抗切割不对等、黏液囊外翻窗口的"出手即露弱"、腐食腔腐液喷吐、隐窝滞蛊的生理化解释、六项清单逐项论证、以及"先封蛊再打本体"的应对链，均为本档案【原创设定】。所引蛊虫／杀招编号全部为 v3.0 既有真实条目，仅作机制引用；【未识别野生蛊虫】为守纪律的留白，不是遗漏。

### 十九、战力平衡检查

| 检查项 | 结论 |
|---|---|
| 能力是否过强 | **否，且这是本案重点**。五项天赋全部带弱点与克制；**满身蛊不产生任何加总战力**——六项清单逐项判定「智慧不足／无催动条件／不能指挥多蛊／无配合／不能形成杀招」，实际携蛊战力 ≈ 本体战力。若有人把百千只蛊相加，会得到与《妖兽携蛊与野生蛊虫档案》6.1「数量堆叠不等于组合」直接矛盾的结论 |
| 是否存在无法应对的机制 | **否，且有专用平衡阀**。C-G-160 乌七蛊「一封即废」把最大变量清成零；此外干燥／盐／火废 T1、切割钻破破防、趁外翻窗口直取致命、C-G-133 隔绝腐液、C-G-107／O-G-008 撤离，路径齐全 |
| 战斗判定是否合理 | 是。第十节每格给机制原因、钝击与切割结果分开、毒按「对大型猛兽效较慢」降级、魂道按「须对视」判无效、驭兽蛊按适用范围判无效、封印按「对蛊不对肉」判特殊控制；第十二节八级结果随配置①／④／⑥／⑦翻转 |
| 是否违规给妖兽蛊师能力 | 否。无空窍、无真元／仙元、无炼化、无杀招催动；第九节明确不携仙蛊；使用状态只取「被动寄生」 |
| 是否把蛊虫能力写成天赋／让携带＝可控 | 否。第五节 T5 明确标「生理，非蛊技」并禁读作"会放蛊"；第八节以「编号＋照录能力＋被动状态」单列，8.3／8.4 两次成文"不得简单相加" |
| O-B-008 特有的判定风险 | ① 主持人易把「整支蛊群」误当配合或杀招，须朗读 8.3 第 3～5 项；② 易把 C-G-063 爱生离「二转第一毒」误算成宿主毒攻击，实际「发动方式未明、无催动记载」；③ 易忽略 7.1「击杀≠安全取蛊」，须在收尾阶段强制走封捕链 |

**结论**：本物种的威胁密度来自**生物安全与判定复杂度**，不来自数值。它是对"携蛊即强"这一直觉的定向反例，战力平衡上安全且可逐条拆解。
