# 外部扩展名录（临时键区）

本目录只放**未能匹配正式 C-G／O-G 编号**的外部目录条目，共 45 条。

- 正式蛊虫档案在 `Gu/C-G/`、`Gu/O-G/`；本目录不是正式实体区。
- 临时键沿用原表 `G-<转>-<流派码>-<序号>`，只作导入管理，不是世界正式编号。
- 已匹配的 219 条不另建档案，仅在 `Indexes/gu-index.json` 对应正式条目里挂 `alternate_keys`。
- 未匹配条目不推断能力、不补写转数、不占用正式编号；核实后再合并或由编号管理员分配。
