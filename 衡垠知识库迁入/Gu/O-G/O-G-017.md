**基本资料**

### 一、外观

- 外观：一只极小的竹簸箕，簸沿磨得圆润，箕底编着细密篾纹。
- 大小：掌心大。
- 颜色：竹黄，篾纹深褐。
- 形态特征：近了散落之物，簸箕会自行微微一倾，像等人往里扫。
- 特殊视觉效果：催动时，地面上针尖大的碎屑会「顺篾纹」轻轻滑拢，归成一小堆，不扬灰。

### 二、核心能力

- 基础能力：把一片地面上散落、细碎、无主的「小物」拾拢归堆——落穗、碎料、散元石屑、药籽皆可，便于收取。
- 作用机制：土道「归堆」——只拢「已落地、无主、细碎」之物，靠篾纹顺其势轻扫，不掘地、不夺人手中物、不取已归属之物。
- 作用对象：地面散落细碎无主之物。
- 能力范围：数步内一片地面。
- 效果强度：归堆整齐、不扬灰、不混类（同类自成一堆）；但不辨贵贱、不识毒、不会替蛊师挑拣「值不值得捡」。
- 使用限制：只拾「落地无主」者；正在被催动的蛊、他人持握之物、嵌入物表的浊气一概不动；湿黏、生根之物拾不起。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 一转蛊师即可 |
| 炼化难度 | 极低 |
| 特殊要求 | 无 |
| 炼化风险 | 无 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 即其所拾的一撮碎屑（自给） |
| 辅助食物 | 无 |
| 频率 | 无需专门喂养 |
| 成本 | 无 |
| 特殊环境 | 须地面干燥平整，泥泞与草丛中篾纹易塞 |
| 断食后果 | 无（靠环境碎屑为生；地面绝对洁净则无物可拾，但不死） |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 落地、无主、细碎、干燥之物 |
| 消耗 | 一转青铜真元，几乎不耗 |
| 范围 | 数步内一片地面 |
| 持续 | 一次一扫 |
| 缺陷 | 不掘地、不夺持握物、不辨贵贱、不识毒、湿黏生根之物无效；无战斗能力 |
| 克制 | 无直接克制；被「无尘净地」「泥泞草丛」废掉效力 |
| 优势 | 零成本、不扬灰、自动归类，是采收与清场的省力底子 |
| 适用场景 | 收割后拾穗、炼材场收碎料、矿场收屑、废墟清场归堆 |
| 不适用场景 | 战斗；需鉴别 / 挑拣 / 去毒（宜配 O-G-019 砥砺蛊、O-G-020 牙筹蛊） |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一只用了整季秋收、从未散篾的旧竹簸箕 |
| 辅助材料 | 一撮落穗、一根旧篾条 |
| 过程 | 以真元把「顺纹归拢」之意炼入篾纹 |
| 难度 | 极低 |
| 成功率或风险 | 极低 |
| 替代材料 | 可用柳条簸箕替代，但遇湿更易变形 |
