# 【原创设定】敛痕蛊

**基本资料**

| 项目 | 内容 |

| 编号 | O-G-109 |
| 名称 | 敛痕蛊 |
| 品阶 | 六转 |
| 凡蛊或仙蛊 | 仙蛊（同名天下唯一） |
| 所属流派 | 炼道 |
| 核心用途 | 道痕相关：收拢游离道痕凝成痕砂 |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一枚极薄的空蚌壳，壳内不积物，只浮着一层会自己聚拢的细砂。
- 大小：两指长。
- 颜色：壳白泛青，砂灰。
- 形态特征：近了「有痕将散」之处，细砂会顺壳纹缓缓聚成一小撮。
- 特殊视觉效果：收痕时，壳内细砂会按流派泛出极淡的不同色泽，随即褪成一律的灰。

### 二、核心能力

- 基础能力：收拢「自然逸散的游离道痕」——杀招余波、炼蛊废渣、器物崩解时散出、道痕将散未散者——凝成一撮可辨、可封存的「痕砂」，供辨识佐证或作低阶炼材引子。
- 作用机制：炼道「敛屑」——只收「已散、无主、游离」之痕，不夺他人 / 他物身上「尚在生效」的道痕；不凭空生痕、不把痕炼成修为、不补全仙蛊道痕。
- 作用对象：一小片「痕场」内游离将散之痕。
- 能力范围：身边一小片痕场。
- 效果强度：痕砂可看出「属何流派、约何时散」，仅此；不能转化为蛊仙修为、不能反推完整杀招、不能当仙材使。
- 使用限制：只收游离将散之痕；活跃 / 有主道痕收不得（强收反被痕伤）；产出极淡、只堪佐证；一处痕场收一次即尽。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 六转蛊仙，炼道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 须在「一次炼蛊散痕未尽」之际收齐一撮作引 |
| 炼化风险 | 中；收错（碰到有主痕）则反噬蛊仙 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 仙元（低频） |
| 辅助食物 | 炼蛊时散逸的废渣道痕（自给） |
| 频率 | 每收一痕场补；空置则每月一次 |
| 成本 | 中 |
| 特殊环境 | 须近「有痕可敛」之地，净室无痕则空转 |
| 断食后果 | 蚌壳内细砂散尽，敛痕失效 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 只收游离将散、无主之痕 |
| 消耗 | 六转青提仙元 + 心力 |
| 范围 | 一小片痕场 |
| 持续 | 一次一收 |
| 缺陷 | 不生痕、不增益修为、不补仙蛊道痕、不夺有主痕、产出极淡只堪佐证、无战斗力 |
| 克制 | 被道痕探测 / 真伪辨类仙蛊看穿「只是痕砂」、被「净痕」手段清场；多流派痕砂混杂时受「道痕互斥」硬约束，须调和否则自冲 |
| 优势 | 唯一能把「必然散掉、本无从查证」的游离痕留作佐证的经营 / 考据型仙蛊，不触碰任何「造痕 / 增修为」红线 |
| 适用场景 | 战后辨招、炼蛊复盘、道痕考据、佐证归属、收拢壶天内逸散痕 |
| 不适用场景 | 实战、增益修为、补全仙蛊、夺有主之痕 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一枚在某次大炼蛊散痕时「只敛屑、不沾主痕」的空蚌壳 |
| 辅助材料 | 仙材「澄痕砂」一撮、一缕炼蛊废渣道痕 |
| 过程 | 以仙元把「只敛游离」之意炼入蚌壳，令其分辨有主 / 无主 |
| 难度 | 高 |
| 成功率或风险 | 中；分辨炼偏则成品会误沾有主痕、反伤蛊仙 |
| 替代材料 | 无 |

> **硬约束**：本蛊受分析报告第 5 节第 10 条与 2 节「道痕互斥」约束——绝不「凭空生道痕、把痕炼成修为、补全仙蛊道痕、夺有主道痕」；痕砂只作辨识 / 低端炼材引子，不作增益。
