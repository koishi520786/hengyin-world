# 【原创设定】问路石蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-006 |
| 名称 | 问路石蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 土道 |
| 核心用途 | 移动/侦查（记录并指引用走过的路径） |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一颗圆润的鹅卵石，石上生着细如发丝的纹路。
- 大小：鸽卵大小。
- 颜色：青灰，纹路银白。
- 形态特征：走过之处，石纹会自行「长」出一条新的细线，对应走过的路。
- 特殊视觉效果：问路时，石上会亮起一条淡光，顺着该走的纹路流动。

### 二、核心能力

- 基础能力：自动记录蛊师走过的路径（以石纹刻画），问路时以微光指引回溯；也能「擦去」某段不想被记住的路。
- 作用机制：问路石以土道道痕「记住」大地的起伏与自身移动，形成一份只有蛊师能读的私密路图。
- 作用对象：本人走过的路（以自身足迹为限）。
- 能力范围：记录无上限，但只记「走过的」，不记「没走过的」。
- 效果强度：能精确回溯走过的路径；但只记录经过，不记录沿途变化后的现状。
- 使用限制：必须本人亲自走过；被外力抹去足迹（如水冲、翻土）不会影响石纹，但若蛊师刻意「忘路」，石纹也会淡去。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，土道或兼修土道者更易 |
| 炼化难度 | 低 |
| 特殊要求 | 无 |
| 炼化风险 | 无 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 路上的一撮浮土 |
| 辅助食物 | 无 |
| 频率 | 每行一段路可顺带喂一次 |
| 成本 | 极低 |
| 特殊环境 | 无 |
| 断食后果 | 石纹渐淡，路图渐失 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 必须本人亲自走过；他人夺石亦读不懂（私密路图） |
| 消耗 | 二转赤铁真元；无需持续耗真元 |
| 范围 | 只记「走过的」路，不探未知 |
| 持续 | 石纹长期留存，久不喂则淡去 |
| 缺陷 | 只记走过之路，不探未知；无战斗能力；记录的是「过去的路」，不反映实时变化 |
| 克制 | 几乎无直接克制；被「夺走蛊虫」可读石无用（私密性） |
| 优势 | 低成本、无需持续耗真元；在迷宫、密林、雾中、沙丘等易迷路之处极实用；路图私密，他人夺石也读不懂 |
| 适用场景 | 探险、追踪回撤、送货、勘探 |
| 不适用场景 | 正面战斗；完全未知、需即时探测之地（应配合回声蛊） |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一块在岔路口被无数人踩过、磨得圆润的鹅卵石 |
| 辅助材料 | 一位老向导的一句指路之言（声入石中） |
| 过程 | 以真元将石纹「刻」入，全程不可离手 |
| 难度 | 低 |
| 成功率或风险 | 低 |
| 替代材料 | 可用河滩卵石替代，但成品路图更易散 |

### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | O-G-001 回声蛊、O-G-003 倒影蛊、O-G-012 雁书蛊（把路图作递信底图） |
| 可参与杀招 | O-K-003「静夜图」（辅助：记录地形作警戒底图） |
| 蛊虫组合 | 与回声蛊、倒影蛊、守更蛊共织「声、影、时、地」四维警戒网，问路石蛊专司「地」这一维，令四者信息落在同一张图上互参（见 O-K-003） |
| 进阶方向 | 可升炼为四转「旧路重走蛊」：以问路石蛊为主蛊，合炼一只宇道定位类凡蛊，可重演一次「走过的路径上」的旧时情景（仅成像、不改现实）；代价是每重演一次便擦去一段真实石纹，重演越多路图越残，且仍不记录任何未走过之地 |
| 其他关联资料 | 见《原创杀招图鉴.md》O-K-003 |
