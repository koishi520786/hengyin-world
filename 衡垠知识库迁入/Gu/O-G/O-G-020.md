# 【原创设定】牙筹蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-020 |
| 名称 | 牙筹蛊 |
| 品阶 | 三转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 智道 |
| 核心用途 | 商业交易 / 资源管理：清点、核价、记账、防缺漏 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一小把象牙色的细算筹，捆在一根旧绳里，筹头磨得发亮。
- 大小：一握。
- 颜色：牙白，绳褐。
- 形态特征：清点之物一多，算筹会自行在绳间挪位，筹头朝外者即「已点」。
- 特殊视觉效果：核账时，算筹会轻轻磕碰出细响；数目对得上，响止于一声；数目有缺，便多出一声空磕。

### 二、核心能力

- 基础能力：对一批货物 / 元石 / 账目做清点、核数、按既定单价核价，并把结果记成一份不易漏的「筹账」，可防缺漏、防调包导致的数目不对。
- 作用机制：智道「核数」——只认「数」与「已定的价」，不识物之好坏（验质归 O-G-019 砥砺蛊）、不测人心真伪（测谎归竹君子【原著蛊虫】）、不议价、不预言盈亏。
- 作用对象：一批可数、且已有定价的货 / 钱 / 账。
- 能力范围：一批，数越大越耗心力。
- 效果强度：点数准、核价准、缺一件即「空磕」示警；但只核「数与价」，不核「质与真伪」。
- 使用限制：须「物已定价、且可逐件点数」；散装难计、活物乱窜、价目未定者核不了；一次只理一批，混批则乱；市集嘈杂、清点被打断则须从头再点。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 三转蛊师，智道或兼修智道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 须亲手核平过一笔「分毫不差」的账作引 |
| 炼化风险 | 低；心浮气躁强炼，则算筹自乱、不成蛊 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 一小把细砂般的谷粒 / 元石屑（「可数之物」） |
| 辅助食物 | 无 |
| 频率 | 每核一批喂一次；闲时每半月一小撮 |
| 成本 | 低 |
| 特殊环境 | 须静处理账，嘈杂处筹响易乱 |
| 断食后果 | 筹头黯淡、挪位迟钝，点数渐生漏 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 物已定价、可逐件点数、一批一理、须静 |
| 消耗 | 三转白银真元 + 心力（数越大越耗神，久核精神萎靡，对应原著「心力」消耗形态） |
| 范围 | 一批货 / 钱 / 账 |
| 持续 | 一次一账 |
| 缺陷 | 只核数不核质、不测真伪、不议价、不预言；散装 / 活物 / 未定价者无效；混批则乱、被打断须重头 |
| 克制 | 被「调包不改数」「抹去价目」类手段绕过；被心力耗竭、嘈杂打断所限；需砥砺蛊 / 竹君子补「质 / 真」两维 |
| 优势 | 把「易漏、易被做手脚」的清点核价变成可复验的一步，是商队与库房的账房底子 |
| 适用场景 | 商队盘点、库房记账、集市收付、辎重核数 |
| 不适用场景 | 验货质、测人谎、议价、散装 / 活物清点、混乱战场 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一把核过万笔账、从未错一根的旧牙筹 |
| 辅助材料 | 一根未断过的捆绳、一枚磨平的旧筹码 |
| 过程 | 以真元把「不漏一声」之意炼入筹头，令数目不合时自出空磕 |
| 难度 | 中 |
| 成功率或风险 | 中；若引账本就有错，成品终生多磕一声（误报） |
| 替代材料 | 可用竹筹替代，但数大时更易乱 |
