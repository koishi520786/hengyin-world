# 【原创设定】砥砺蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-019 |
| 名称 | 砥砺蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 金道 |
| 核心用途 | 物品加工：打磨器物、去毛刺、验材质 |
| 稀有程度 | 常见 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一块微缩的青磨石，石面被磨出一道浅浅的凹弧，触手温凉。
- 大小：掌心大。
- 颜色：青灰，凹弧处泛细亮。
- 形态特征：贴上器物，石面会顺着物形微微起伏，像在「记」它的轮廓。
- 特殊视觉效果：打磨时不见火星，只落下一层极细的粉末；粉落得匀，便知材质纯，粉忽粗忽细，便知内里夹了杂。

### 二、核心能力

- 基础能力：把器物表面的毛刺、糙口磨去、磨出合用的刃 / 面；磨时落粉的匀细，可顺带验出材质是否纯、有无夹层。
- 作用机制：金道「砥砺」——只「去余、显形」，不增材、不改形、不赋能力；「验材质」是打磨落粉的自然副产，并非第二能力。
- 作用对象：一件可磨的实物（器、料、刃、坯）。
- 能力范围：单件，手持可及。
- 效果强度：去毛刺、磨合用面、以落粉辨纯杂；但不能把凡铁磨成仙材、不能补裂（补裂属 O-G-018 弥缝蛊）、不能赋道痕。
- 使用限制：只磨「可磨」之物；过软（腐木、湿泥）、过脆（薄瓷）、含活跃道痕之仙材一概磨不得；一件磨到「形定」即止，过磨反损器。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，金道或兼修金道者更易 |
| 炼化难度 | 低 |
| 特殊要求 | 须亲手磨出过一件「不偏不亏」的器物作引 |
| 炼化风险 | 低 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 打磨落下的一撮细粉（自给） |
| 辅助食物 | 几滴清水（润石） |
| 频率 | 每磨一件喂一次；闲时每半月润一次水 |
| 成本 | 极低 |
| 特殊环境 | 石面须常润，干磨则落粉失真、验材不准 |
| 断食后果 | 石面涩滞，磨出的面起毛、落粉忽粗忽细，验材失效 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 可磨之物、石面常润、磨到形定即止 |
| 消耗 | 二转赤铁真元，低耗 |
| 范围 | 单件，手持可及 |
| 持续 | 一次一磨 |
| 缺陷 | 不增材、不改形、不赋道痕、不补裂；过软过脆及仙材磨不得；过磨损器；验材只辨纯杂、不辨具体为何物 |
| 克制 | 被炎道（退火）、水道（锈涩）、变化道「改形」类手段克制；与 O-G-020 牙筹蛊（核数不核质）互补 |
| 优势 | 一件蛊兼「加工」与「粗验」，是商队验货、匠作整坯的常备 |
| 适用场景 | 整坯去刺、磨刃合面、验料纯杂、交易前磨样 |
| 不适用场景 | 补裂、赋道痕、仙材加工、需精辨成分（宜竹君子 / 书虫一类） |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一块磨过千件器、凹弧始终不偏的老青磨石 |
| 辅助材料 | 一撮陈年磨粉、一滴无风之水 |
| 过程 | 以真元把「顺形去余」之意炼入石面凹弧 |
| 难度 | 低 |
| 成功率或风险 | 低；失败仅石面开裂，可再寻石 |
| 替代材料 | 可用细砂岩替代，但落粉更粗、验材更不准 |

### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | O-G-020 牙筹蛊（验质 + 核数）、O-G-013 束囊蛊（存样）、O-G-017 拾穗蛊（收磨粉）、书虫·竹君子【原著蛊虫】 |
| 可参与杀招 | O-K-012「牙筹清账」（辅助：磨样验货，辨材质真伪，补牙筹蛊「只核数不核质」之短） |
| 蛊虫组合 | 与牙筹蛊、结绳蛊、书虫、竹君子、元老蛊构成「录约—测谎—验货—核价—收付」的交易链，砥砺蛊专司「验质」一环（见 O-K-012） |
| 进阶方向 | 可升炼为三转「淬砺蛊」：把「去余显形」提升为「磨时可顺带逼出器内隐裂」；代价是每逼一次隐裂便须多磨去一层、器物随之变薄，且对薄器可能「未验先废」，验深以「耗料与损器风险」为代价 |
| 其他关联资料 | 见《原创杀招图鉴.md》O-K-012 |
