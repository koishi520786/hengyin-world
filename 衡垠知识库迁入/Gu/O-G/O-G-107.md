# 【原创设定】存息蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-107 |
| 名称 | 存息蛊 |
| 品阶 | 六转 |
| 凡蛊或仙蛊 | 仙蛊（同名天下唯一） |
| 所属流派 | 魂道 |
| 核心用途 | 生命与魂魄：温养将散残息、延缓消散 |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一缕将断未断的游丝，尽头悬着一点比米粒还小的温光，光不亮却不肯灭。
- 大小：游丝寸许，光点如尘。
- 颜色：丝灰白，光暖黄。
- 形态特征：所托之息越弱，丝越细、光越垂；息一散，丝立断。
- 特殊视觉效果：托住一线残息时，光点会极缓地一涨一落，像替它接着最后一口气。

### 二、核心能力

- 基础能力：温养一缕「将散未散」的残息 / 残魂，延缓其消散，为招魂、辨认、超度留一段窗口。
- 作用机制：魂道「留息」——不造魂、不补魂、不复活、不延寿，只把「本就还在、正要散」的那一线托住，慢一点散。
- 作用对象：单缕尚存一线的残息 / 残魂，或壶天熟地中「将枯未枯」的一线微弱生机。
- 能力范围：单缕。
- 效果强度：可把「数息即散」延缓到「数日」，供从容辨认 / 超度；一旦散尽不可追，离体越久越难托。
- 使用限制：只托「尚存一线」者；散尽者无效；不能令其恢复神智、不能还魂附体、不能增寿；托养期间持续耗魂魄底蕴 / 心力。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 六转蛊仙，魂道或兼修魂道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 须亲守一缕「将熄未熄」之息直至天明不散 |
| 炼化风险 | 中；炼化失败残息立散且反噬心神 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 仙元（低频）+ 蛊仙一缕魂魄底蕴（托养时持续供） |
| 辅助食物 | 一炷安魂香 |
| 频率 | 托养期间每日一次；空置则每月一次 |
| 成本 | 高（耗魂魄底蕴，非单纯仙元） |
| 特殊环境 | 须静、避荡魂 / 扰神之地 |
| 断食后果 | 游丝断、所托残息立散，不可再续 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 只托「尚存一线」之残息；散尽不可追 |
| 消耗 | 六转青提仙元 + 魂魄底蕴 / 心力（持续，对应原著「鬼官衣不耗仙元但耗魂魄底蕴」一类消耗形态） |
| 范围 | 单缕 |
| 持续 | 数日（延缓，非复原） |
| 缺陷 | 不复活、不延寿、不还魂、不增魂；散尽不可追、离体久者难托、耗魂魄底蕴、无战斗力 |
| 克制 | 被魂道「吞魂 / 荡魂」、梦道「夺魂」、更高明魂道手段克制 |
| 优势 | 唯一能为「善后 / 辨认 / 超度」争到窗口的魂道仙蛊，绝不越界成「复活」 |
| 适用场景 | 战后收魂、辨残魂归属、超度留证、壶天熟地温养将枯之苗的一线生气 |
| 不适用场景 | 实战、复活、延寿、补全魂魄 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一缕在「荡魂之境」边缘自行凝住未散的残息 |
| 辅助材料 | 仙材「安魂露」一滴、一炷安魂香灰 |
| 过程 | 以仙元把「不令其散」之意炼入游丝 |
| 难度 | 高 |
| 成功率或风险 | 中；炼化失败残息立散且反噬心神 |
| 替代材料 | 无 |

> **硬约束**：本蛊受《原著蛊道体系分析报告》第 5 节第 10 条「禁无条件复活／无条件无限重生」约束——只「延缓消散」，绝不「复活 / 还魂 / 延寿 / 补魂」，任何搭配与进阶均不得突破此线。
