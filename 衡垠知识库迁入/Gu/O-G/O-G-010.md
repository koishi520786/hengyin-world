# 【原创设定】转灯蛊

**基本资料**

| 项目 | 内容 |

| 编号 | O-G-010 |
| 名称 | 转灯蛊 |

| 所属流派 | 光道 |
| 核心用途 | 控制/辅助（旋转光罩偏折攻击方向） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一盏缓慢自转的走马灯，灯罩镂空，光从镂孔漏出。
- 大小：拳头大。
- 颜色：灯罩米白，漏光金黄。
- 形态特征：灯罩上镂刻的图案会随「偏折」次数而悄然变换。
- 特殊视觉效果：催动时，灯罩飞转，漏出的光在蛊师身周拉成一层旋转的光幕。

### 二、核心能力

- 基础能力：在身周凝出一层旋转的光罩，凡「直线、有形、可反射」的攻击，都会被偏折方向，难以直取要害。
- 作用机制：光道「以旋偏折」——光罩不是硬接，而是借旋转把入射攻击的落点带偏。
- 作用对象：本人及身周一步。
- 能力范围：贴身光罩。
- 效果强度：可偏折箭矢、飞针、月刃一类直线攻击的方向（非完全弹开，是带偏落点）；对钝器重击、范围攻击效果大减。
- 使用限制：持续耗真元；只对「有形可偏」的攻击有效；对魂道、梦道、律道等无形手段无效；光罩旋转越快、真元耗越多。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 五转蛊师，光道或兼修光道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 无 |
| 炼化风险 | 中 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 烛光（或以真元凝成的光） |
| 辅助食物 | 无 |
| 频率 | 每七日一次 |
| 成本 | 低 |
| 特殊环境 | 无 |
| 断食后果 | 灯渐暗，光罩渐薄，最终不转 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 持续供真元；只对有形可偏的攻击生效 |
| 消耗 | 五转紫晶真元，持续耗；转越快耗越多 |
| 范围 | 贴身一步光罩 |
| 持续 | 随真元维持 |
| 缺陷 | 挡不住范围攻击与钝击；耗真元；夜间极显眼、易暴露位置 |
| 克制 | 克制直线远程（箭、刃、针）；被范围攻击、炎道燎原、暗道「熄光」克制 |
| 优势 | 以「巧」制「直」，对直线远程攻击有奇效；光罩自带照明，可反制隐形者显形 |
| 适用场景 | 对射、防冷箭、护身 |
| 不适用场景 | 隐身潜行；混战大范围覆盖 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一盏转过整整一万圈、灯芯未断的走马灯 |
| 辅助材料 | 灯罩镂孔上刮下的金粉 |
| 过程 | 于子夜以真元点亮灯芯，令其自转不熄 |
| 难度 | 高 |
| 成功率或风险 | 中；失败则灯毁 |
| 替代材料 | 可用铜灯替代，成品光罩更硬但更耗真元 |
