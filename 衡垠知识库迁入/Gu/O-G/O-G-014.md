# 【原创设定】扁担蛊

**基本资料**

| 项目 | 内容 |

| 编号 | O-G-014 |
| 名称 | 扁担蛊 |
| 品阶 | 二转 |

| 所属流派 | 力道 |
| 核心用途 | 运输：分担负重之「重」，令长途负重省力 |
| 稀有程度 | 常见 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一根微缩的扁担，两头各坠一枚小石砣，担身有一道磨得发亮的肩痕。
- 大小：一拃长。
- 颜色：竹黄泛褐，石砣青灰。
- 形态特征：蛊师负物越稳，担影越平；步子一乱，两头石砣便一高一低。
- 特殊视觉效果：催动时担身浮出一道淡影，虚虚搭在蛊师肩上，随人走而不落地。

### 二、核心能力

- 基础能力：把蛊师所负之物的「重」分一部分到担形虚影上，令长途负重省力、步履稳当。
- 作用机制：力道「分重」——不消物之重、不增蛊师之力，只把「压在人身上的那一份」匀到担影上；担影随人缓行，人停则影散。与原著「蛮力天牛蛊」一类「临时增力」是两回事，本蛊绝不越界增力。
- 作用对象：本人所负之重。
- 能力范围：本人肩挑 / 背负之物。
- 效果强度：可长途承重而气力不坠、少耗真元于「撑住」；但不增速、不增力、举不起原本举不动之物。
- 使用限制：须「肩挑/背负、缓行」之姿；一旦放下货物、改作奔袭或腾挪，分重即散；陡坡、湿滑处担影易歪，分重失衡。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，力道或兼修力道者更易 |
| 炼化难度 | 低 |
| 特殊要求 | 须亲自挑过一次「未换肩走完全程」的担 |
| 炼化风险 | 低 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 一小把粗盐（取汗渍之意） |
| 辅助食物 | 无 |
| 频率 | 每行一趟喂一次 |
| 成本 | 极低 |
| 特殊环境 | 无 |
| 断食后果 | 肩痕磨平，分重渐失，担影歪斜，负重反较不养时更累 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 肩挑 / 背负、缓行；不可奔袭 |
| 消耗 | 二转赤铁真元，低耗 |
| 范围 | 本人所负 |
| 持续 | 一趟路程 |
| 缺陷 | 不增速、不增力、只缓行有效、担影怕陡坡湿滑、放下货即散 |
| 克制 | 被力道「卸担」、地形陷足、阵道「定身」类手段克制；与肥甲虫蛊【原著蛊虫】（驮运商队货物）互补 |
| 优势 | 让低阶蛊师也能长途运货，省真元、省气力、步履稳 |
| 适用场景 | 商队、迁徙、送货、随军辎重 |
| 不适用场景 | 战斗冲锋、奔袭、举重物、腾挪闪避 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一根挑过千里货、从未断过的旧扁担 |
| 辅助材料 | 两枚河滩圆石、一缕旧汗巾抽出的线 |
| 过程 | 以真元把「匀重」之意炼入担身，令两头石砣自平不晃 |
| 难度 | 低 |
| 成功率或风险 | 低；失败仅担身开裂，材料可再寻 |
| 替代材料 | 可用竹杠替代，承重更小但更轻 |
