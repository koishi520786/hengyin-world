# 【原创设定】静息蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-011 |
| 名称 | 静息蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 气道 |
| 核心用途 | 修炼辅助：入定时平缓真元流转、镇定杂念 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一缕凝住不散的沉水香烟，盘成一枚小环，无火无热。
- 大小：铜钱大。
- 颜色：淡青灰，边缘几近透明。
- 形态特征：蛊师呼吸越匀，烟环越圆；心绪一乱，环上便起细毛边。
- 特殊视觉效果：催动时烟环不升不散，只在蛊师鼻息前极缓地转，像把一口气盘了起来。

### 二、核心能力

- 基础能力：入定（打坐行功）时，把蛊师的呼吸与真元流转调成同一匀律，压住杂念与躁动，使行功不被心绪起伏打岔。
- 作用机制：气道「匀息」——它不生真元、不提纯真元，只把「节拍」理顺；真元走得顺，岔气与走火便少。原著「精炼真元」另属酒虫一类，本蛊绝不越界。
- 作用对象：本人真元流转的节拍。
- 能力范围：本人。
- 效果强度：能压住轻微躁动、减少行功岔气、延长一次入定的稳定时长；不增真元总量、不提纯真元、不加快修为。
- 使用限制：只在「静止入定、且不催动其他蛊」时生效；一旦起身、开口或催动别蛊，匀律即破，当次入定前功尽弃。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，气道或兼修气道者更易 |
| 炼化难度 | 低；静息蛊几无意志，只认「一口气绵长不断」 |
| 特殊要求 | 须在「一息绵长未断」的状态下完成炼化，中途换气即须重来 |
| 炼化风险 | 低；失败仅烟散，不伤蛊师 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 一炷安神香燃尽后的香灰（或静室清晨第一口气息） |
| 辅助食物 | 无 |
| 频率 | 每七日一次 |
| 成本 | 低 |
| 特殊环境 | 须在无声、无穿堂风的静室喂养 |
| 断食后果 | 烟环松散、匀律不准，行功时反易引气岔走，故断食比不养更险 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 静止入定、不催动他蛊 |
| 消耗 | 二转赤铁真元，低耗、近乎不耗 |
| 范围 | 本人 |
| 持续 | 一炷香至一个时辰，起身即散 |
| 缺陷 | 入定时不能动、不能催他蛊、极易被袭；不增真元总量、不提纯；只对「心绪散乱」有效，对肉身伤势无用 |
| 克制 | 克制躁动、轻度惑乱所致的心绪散乱；被「强制打断入定」「噪声扰息」类手段克制；与水道「静水」环境相宜 |
| 优势 | 让低阶蛊师打坐少走岔、稳根基；零战斗负担，是少数「不占战力却抬修行下限」的蛊 |
| 适用场景 | 闭关、行功、伤后调息、长途休整 |
| 不适用场景 | 战斗；需随时应对的值守（那是守更蛊 O-G-004 之职） |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一段在无人打扰的静室里燃了整夜、烟柱始终不散的沉水香 |
| 辅助材料 | 一撮冷香灰、一滴檐下晨露 |
| 过程 | 以真元把「不散之烟」盘成环，令其记住那一夜的匀律，全程不可出声 |
| 难度 | 低 |
| 成功率或风险 | 低；受惊、出声则香断烟散，材料作废 |
| 替代材料 | 可用盘香替代，但成品匀律维持更短、更怕风 |
