### 一、杀招简介

「往复游」是一式四转凡道机动杀招。核心 O-G-008 洄游蛊在预先亲至的 A、B 两点间架起一条仅容本人、约三里内的成对宇道通路；再以敛息蛊隐去气息、悄步蛊掩去脚步，令对手眼中蛊师「忽在 A 忽在 B、又仿佛处处在」，无法锁定真身与下一步动向。它不伤人，靠「宇道提供转移本身、暗道抹去转移痕迹」制造判断混乱，用于诱敌扑空、掩护撤离或突然设伏贴身。代价是距离短、标记点须预置、每次往返耗元石补游力，且频繁往返反会暴露「存在两点标记」这一事实。

### 三、运行原理

> 原文「二、杀招原理」照录）

洄游蛊在 A、B 两点架起成对通路（O-G-008）。蛊师通过通路在两点间快速往返，配合敛息蛊隐去气息、悄步蛊掩去脚步，使对手眼中蛊师「忽在 A 忽在 B、又仿佛处处在」，无法锁定其真实位置与下一步动向。暗道的作用是「抹去转移痕迹」，宇道的作用是「提供转移本身」，二者协同构成「真假莫辨的机动」。

### 四、发动条件

> 原文「三、发动过程」照录）

- 发动条件：已提前在 A、B 两点埋下洄游蛊两半。
- 发动步骤：① 催洄游蛊通过通路；② 同时催敛息蛊、悄步蛊掩盖自身痕迹；③ 视需要往返数次。
- 发动速度：中（视两点距离）。
- 是否需要蓄力：否。
- 是否能够连续发动：可（但每次耗元石补游力，连续往返游力耗尽需恢复）。
- 发动失败的可能原因：标记点被毁、超距、游力耗尽。

### 五、消耗情况

> 原文「五、消耗与限制」照录）

- 真元或仙元消耗：中，耗四转黄金真元，不涉仙元。
- 蛊虫损耗：洄游蛊每次往返耗游力，需元石补。
- 材料成本：元石。
- 使用限制：距离三里、标记点须预置、游力有限。
- 副作用：频繁往返暴露「有两点标记」这一事实，聪明对手会转而搜标记点。
- 可被破解的方式：毁标记点、宇道封锁、阵道封印、或以范围攻击覆盖两点之间。

### 九、改良与进阶

- **加蛊改良**：可加入 O-G-006 问路石蛊，把 A、B 两点及沿途路径记成私密底图，使往返选点更准、撤离不迷；代价是多催一只蛊、且底图只记「走过的路」，对全新落点无益。
- **换蛊改良**：原著「蒙尘蛊」可替悄步蛊补「气息遮蔽」之一维，但会失了「掩脚步声」之专，属取舍而非纯增强；援引分析报告 3.5「冰刃风暴初代→二代换掉狂风蛊」之改良逻辑。
- **浓缩成蛊**：援引「杀招＝炼蛊残方」，理论上可把「往返 + 隐息 + 掩步」收成一只「游影蛊」；代价是须耗元石与一只宇道凡蛊作蛊材，且浓缩后「两点须预置、三里上限、耗游力」的条件不消失。
- **进阶上限锁死**：不得升级为「无标记瞬移 / 无限往返」——O-G-008 硬约束为「两点须亲至埋下、相距三里内、每次耗游力」，这是本招不可突破的天花板。

### 十一、设计理念

> 原文「七、设计说明」照录并补）

原著有洞地蛊（成对宇道通路，但年耗二十万元石、距离远）与神游蛊、定仙游（瞬移但门槛高）。洄游蛊是「低配成对通路」的原创补位：距离短、只容自身、耗元石，换取低门槛与可重复。本招把「往返」与「隐藏痕迹」组合，做出「机动诱敌」的战术价值，短板（短距、预置、耗资源）与机制直接相关。本版补：本招刻意不赋予任何直接攻击力，其价值全在「改变对手的判断与站位」，是「节奏控制 / 信息不对称」而非「攻伐」类设计。

### 十二、组合逻辑

- **核心 / 辅助**：核心 O-G-008 洄游蛊（定「宇道往返机动」之性质），辅助敛息蛊、悄步蛊【原著蛊虫】（补「抹去气息与脚步声」之条件）。
- **协同类型**：按分析报告 3.2，属「条件型」——敛息 / 悄步先抹去「转移留下的痕迹」，洄游蛊的「转移」才不被看破；若隐息一失效，往返即成「明着来回」，整招 tactical 价值归零。
- **为何不是「多蛊同用」反例**：三蛊同赴「真假动线」单一目标，核心缺位则无通路、辅助缺位则通路暴露，缺一即崩，符合「每只蛊都要有作用」。

### 十三、与原著体系的兼容性

> 逐条分析）

1. **品阶规则**：四转凡道杀招，转数取「初次出现时标注」、非强度刻度；核心洄游蛊四转、敛息蛊三转、悄步蛊品阶原文未明（标「—」），低转辅助蛊靠「隐息 / 掩声」的机制位参与，不靠数值，符合「高转不使低转失效」。
2. **真元仙元消耗**：耗四转黄金真元（中）+ 元石（每用必补游力），不涉仙元；符合「凡道杀招用真元、受真元总量限制、战斗通常不长久」，且「元石补给」正对应原著洞地蛊「年耗二十万元石」的资源门槛逻辑。
3. **道痕运行**：本招不新增、不消耗道痕层级设定；洄游蛊之「成对通路」为宇道凡蛊能力，标记点是「亲至埋下」的定位条件，不是道痕造物，不凭空生痕、不增益修为。
4. **流派规律**：杀招流派为宇道（辅以暗道），组成蛊虫含宇道（洄游蛊）与暗道（敛息、悄步）——「宇道提供转移、暗道抹去痕迹」在「机动诱敌」一目标上协同；跨流派援引「大宗师触类旁通」，非无条件混合。
5. **蛊虫唯一性**：三只组成蛊虫全为凡蛊，凡蛊可同名多只；本招不含仙蛊，不新增唯一性例外，也不改写洞地蛊 / 定仙游等原著仙蛊设定。
6. **杀招组合规则**：3 只蛊同时催动、核心 1 + 辅助 2 分工明确、每只都有作用；发动条件、消耗、效果范围、缺陷与破解方式齐备，且「标记点被毁 / 游力耗尽 / 宇道封锁」皆可落到具体组件，符合检查表第 7、8 条与「破解须落到具体组件」之要求。

### 十四、平衡性分析

- **强在何处**：机动性极强、真假难辨、可诱敌可设伏，能分散追击、掩护撤离、为 O-K-001 制造贴身爆发的机会。
- **代价与机制同源**：距离三里、只容自身、标记点须亲至预置、每次耗元石补游力、频繁往返反暴露「两点标记」——全从「低配成对通路 + 痕迹抹除」的机制里长出；尤其「暴露标记」是「用得越多越易被针对」的自限，不是外加缺点。
- **破解链清晰**：毁标记点 → 通路断；宇道封锁 / 阵道封印 → 转移被禁；范围覆盖两点之间 → 往返皆挨打；搜标记点 → 反制其预置依赖。
- **上限锁死**：非攻击型、无直接伤害、不放大转移距离、不涉仙元与道痕增益，故只是「战术机动」而非「万能逃遁」，不破坏平衡。
