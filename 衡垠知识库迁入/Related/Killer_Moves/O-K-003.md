### 一、杀招简介

「静夜图」是一式三转凡道布防杀招，四只低阶原创蛊各补一维：回声蛊「听」目不能视之处，倒影蛊借水面「看」，守更蛊「守时」定节律并抵御惑乱，问路石蛊「记地形」提供底图，四者信息落在同一张「图」上互参，织成覆盖「声、影、时、地」的守夜警戒网。它不伤人、不硬挡，却因「补掉单一感官的盲区」而在持久对峙中起决定作用。全招低耗、可整夜维持，但极度依赖静环境与静水面，且任一维被破即留盲区——是一张能被逐根拆掉的网，而非无死角护罩。

### 三、运行原理

> 原文「二、杀招原理」照录）

守夜最大的破绽在于「某一刻的松懈」与「单一感官的盲区」。本招以守更蛊把守夜时段划成固定更次（律道「守约」加持），保证心神不散；回声蛊补足目不能视之处的「听」；倒影蛊借水面之镜补「看」；问路石蛊提供地形底图，令四者信息能落在同一张「图」上互参。四蛊皆低耗、皆非战斗蛊，却因「各补一维」而构成一张无死角的静夜警戒网——这正是「多蛊协同」的价值所在，而非堆砌。

### 四、发动条件

> 原文「三、发动过程」照录）

- 发动条件：守夜、伏击、盯梢等需长时间警戒且环境偏静的场景。
- 发动步骤：① 先以问路石蛊记录周边地形；② 以守更蛊定更次（与蛊师定约）；③ 以回声蛊周期性扫听；④ 有水面处，以倒影蛊摄影比对。
- 发动速度：慢（布设需时间）。
- 是否需要蓄力：否（布设型）。
- 是否能够连续发动：可（整夜维持）。
- 发动失败的可能原因：节律被外力强断（守更蛊失效，全招警戒心散）；环境噪声过大（回声蛊失效）。

### 九、改良与进阶

- **加蛊改良**：可加入 O-G-202 应候蛊（依附守更蛊，择「交更」之候定约），使更次更准、少被「时辰不巧」拖累；代价是须与守更蛊同源炼化，且候纹一换旧约即不稳，反不如原招省心。
- **补通报维**：可加入 O-G-012 雁书蛊，令「发现异动」即刻递一句口信回据点，补上「警戒→通报」的一环；代价是多催一只蛊、须预置收信标记，且一次只递一句。
- **不宜单蛊化**：援引分析报告 1.5「合炼后新蛊通常只保留一只主蛊能力并强化，其余能力丧失」，若把四蛊硬浓缩为一只「静夜蛊」，须择定主蛊（如回声蛊），则影 / 时 / 地三维尽失，整张网塌成单维；故本招按原著「有的杀招只能收敛为数只仙蛊配合、无法单蛊化」之例，保留为多蛊协同更合理。
- **进阶上限锁死**：不得设计成「无死角、不可破、不依赖环境」——任一维被破即留盲区、依赖静环境静水面，是本招不可突破的天花板。

### 十一、设计理念

> 原文「七、设计说明」照录并补）

原著有大量「非战斗却决定战局」的低阶蛊（书虫、地听肉耳草、蛛丝马迹蛊）。本招把这类蛊的「多维度补盲」价值显式化，用四只低阶蛊各补一维，织成警戒网。它不强、不无敌，每只蛊都有明确作用、也各有明确破法，符合「杀招必须能被拆解、每只蛊必须有作用」的规范。本版补：「无死角」指「感官互补」而非「不可破解」——四维恰是四条可被分别拆掉的线，这正是它既好用又不破坏平衡的缘由。

### 十二、组合逻辑

- **核心 / 辅助**：核心 O-G-001 回声蛊（定「声之警戒」之性质），辅助 O-G-003 倒影蛊、O-G-004 守更蛊、O-G-006 问路石蛊（各补影 / 时 / 地一维）。
- **协同类型**：按分析报告 3.2，属「条件型 + 载体型」混合——守更蛊「定节律」是整夜维持的前置条件（节律一断全招心散），问路石蛊「地形底图」是令声 / 影 / 时三维信息得以互参的载体，回声与倒影则在此载体上各补一维。
- **为何不是「多蛊同用」反例**：四蛊同赴「守夜警戒」单一目标、各补一维、缺一即留盲区，符合「每只蛊都要有作用」，非堆名字。

### 十三、与原著体系的兼容性

> 逐条分析）

1. **品阶规则**：三转凡道杀招，转数取「初次出现时标注」、非强度刻度；组成蛊虫二转（回声、问路石）与三转（倒影、守更）混用，低转蛊靠「听 / 记地形」的机制位而非数值参与，符合「高转不使低转失效」。
2. **真元仙元消耗**：各蛊低耗、耗二至三转真元，整夜维持主要耗心神，不涉仙元；符合「凡道杀招用真元、受真元总量限制」与「心力」消耗形态（操纵蛊虫用久精神萎靡）。
3. **道痕运行**：本招不新增、不消耗道痕层级设定；守更蛊之「节律」为微弱律道道痕约束心神，属「守约」类既有逻辑，不凭空生痕、不增益修为。
4. **流派规律**：杀招流派为音道+水道+律道（复合），组成蛊虫实含音、水、律、土四道——「各补一维」在同一目标上协同；跨流派合法性援引「大宗师触类旁通 / 一个杀招可含六七个流派」，且本招四蛊皆低阶、无道痕互斥之虞，非无条件混合。
5. **蛊虫唯一性**：四只组成蛊虫全为凡蛊，凡蛊可同名多只；本招不含仙蛊，不新增唯一性例外。
6. **杀招组合规则**：4 只蛊同时催动、核心 1 + 辅助 3 分工明确、每只都有作用；发动条件、消耗、效果范围、缺陷与破解方式齐备，且破解（噪声 / 冻水面 / 断节律）各自落到具体组件，符合检查表第 7、8 条。

### 十四、平衡性分析

- **强在何处**：无死角（感官互补）、低耗、反潜行反惑乱，是「非战斗却决定战局」的典型，整夜维持可把偷袭方逼入明处。
- **代价与机制同源**：依赖静环境 / 静水面（回声、倒影的机制前提）、整夜耗心神（持续型通病）、单点被破即留盲区（多维网的结构性弱点）、节律被断全招心散（守更蛊定约之条件）——全从「四只低阶非战斗蛊各补一维」的机制里长出，非外加缺点。
- **破解链清晰**：持续噪声 → 废回声；冻 / 搅水面 → 废倒影；强攻打断节律 → 废守更；任一维破，网即不全。
- **上限锁死**：非攻击型、无直接伤害、不涉仙元与道痕增益、「无死角」不等于「不可破」，故只是「优质布防」而非「无敌护罩」。
