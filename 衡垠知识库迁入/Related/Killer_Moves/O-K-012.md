### 一、杀招简介

「牙筹清账」是 v3.0 新增的一式四转凡道经营杀招，专治交易里「漏数、调包、虚言、抵赖」。O-G-020 牙筹蛊清点核价记账、缺件即「空磕」示警，O-G-019 砥砺蛊磨样验材质纯杂（补「只核数不核质」之短），O-G-021 结绳蛊按序录约；原著书虫存契约底本、竹君子测对方言辞真伪、元老蛊存元石收付找赎。六蛊按「录约—测谎—验货—核价—收付」各补一维。它零战斗力、只把「一趟本就要做的交易」变得可复验；代价是竹君子「唯至诚君子可炼化喂养」、极难自有（多须借人），只测谎不测「记错 / 被蒙蔽」，须静、一批一理，且书虫 / 结绳一失则底本丢。

**分工说明**：牙筹蛊为**核心**，定「智道核数核价」之性质；结绳蛊 / 书虫司「录约存底」、竹君子司「测谎」、砥砺蛊司「验质」、元老蛊司「收付」。六蛊按「录约—测谎—验货—核价—收付」协同：牙筹只核数不核质（质归砥砺、真归竹君子、约归结绳 / 书虫），任何一只都不「全能」。**竹君子「唯至诚君子可炼化喂养」，故本招多借一位至诚君子之竹君子在场验谎、非蛊师自有**——这是本招最大的持有门槛。

### 三、运行原理

先以结绳蛊把契约条款按先后结绳存档、书虫喂记契约底本（双底本：一存「次序」、一存「不失」）；交易时以竹君子测对方言辞之真伪（原著「天生测谎」，但只测「说谎」，不测「记错 / 被蒙蔽」）；以砥砺蛊磨样验货、落粉辨材质纯杂，补牙筹蛊「只核数不核质」之短；牙筹蛊按既定单价逐件点数核价、记成筹账，缺一件即「空磕」示警；末以元老蛊存元石、收付找赎。六步皆「不议价、不预言盈亏、不改物之质」，只把「一趟本就要做的交易」变得可复验、防缺漏、防调包——对应分析报告第 6 节「非战斗用途（清算 / 质检 / 档案）」与「信息不对称（标记真伪）」。

### 四、发动条件

- 发动条件：物已定价、可逐件点数；契约条款已录（结绳 + 书虫）；竹君子须由一位至诚君子炼化喂养并在场；须静处理账。
- 发动步骤：① 结绳蛊录约、书虫存底；② 竹君子测谎；③ 砥砺蛊磨样验质；④ 牙筹蛊核数核价、记筹账；⑤ 元老蛊收付找赎。
- 发动速度：中（逐件点数 / 磨样需时间）。
- 是否需要蓄力：否。
- 是否能够连续发动：可（一批一账，逐批重理）。
- 发动失败的可能原因：价目未定 / 散装难计 / 活物乱窜、竹君子不在场或非至诚君子所养、市集嘈杂清点被打断、书虫失则契约底本丢、混批则乱。

### 五、消耗情况

- 真元仙元消耗：中（六蛊同催），耗四转黄金真元（取整招门槛），不涉仙元。
- 心力：牙筹蛊核数「数越大越耗神」、结绳回放、书虫回放耗心力（对应原著「操纵蛊虫用久精神萎靡」之心力形态）。
- 蛊虫损耗：无（持续 / 可反复型）。
- 材料成本：牙筹之谷粒 / 元石屑、砥砺之清水与磨粉、结绳之麻纤维、书虫所喂之契约底本、竹君子之「真诚」（原著食料）、元老蛊所存元石。
- 使用限制：只核数不核质（质归砥砺、真归竹君子）、不测「记错 / 被蒙蔽」、不议价、不预言；一批一理、须静；竹君子门槛极苛。
- 副作用：竹君子极难自有（须借至诚君子），借不到则「测谎」一维缺；书虫一失则底本丢；久核精神萎靡。
- 可被破解的方式：「调包不改数」「抹去价目」绕过核数、蒙蔽竹君子（使其不察「记错」而非「说谎」）、夺书虫 / 结绳（毁底本）、嘈杂打断清点、混批致乱。

### 六、杀招效果

- 核心效果：一趟「录约—测谎—验货—核价—收付」的可复验交易 / 资源管理。
- 作用范围：一批货 / 钱 / 账。
- 持续时间：一次一账。
- 攻击方式：非攻击型（商业交易 / 资源管理）。
- 对目标的影响：令缺漏、调包、虚言更难奏效；对己为「账可复验、约可回放、质可粗验」。
- 特殊效果：牙筹蛊「空磕」示警缺件；结绳 + 书虫双底本防「记岔 / 抵赖」。

### 七、优缺点

- 主要优势：把易漏、易被做手脚的清点核价变成可复验流程；质 / 真 / 数 / 约 / 收五维分工，防缺漏防调包。
- 主要缺陷：零战斗力；竹君子极难自有、只测谎不测「记错 / 被蒙蔽」；只核数不核质（须砥砺补）；不议价、不预言；须静、一批一理、底本怕失。
- 附带副作用：借不到竹君子则测谎一维缺；书虫 / 结绳失则底本丢；久核耗心力。
- 可被破解的方式：调包不改数、抹价目、蒙蔽竹君子、夺底本、嘈杂打断、混批。

### 八、实战表现

- 对目标的实际影响：令缺漏、调包、虚言更难奏效；对己「账可复验、约可回放、质可粗验」。
- 作用范围 / 持续 / 方式：一批货 / 钱 / 账 / 一次一账 / 非攻击型（商业交易 / 资源管理）。
- 最适合的场景：商队盘点、库房记账、集市收付、辎重核数、O-K-011 收成入账、O-K-010 到站核数。
- 被哪些类型的能力克制：智道「改单」、暗道「调包不改数」、心力耗竭、嘈杂打断、夺底本。
- 与哪些杀招存在配合：O-K-009「雁字回书」（约期 / 对账口信）、O-K-010「一囊担山」（到站核数）、O-K-011「春耕图」（收成清点核价）。

### 九、改良与进阶

- **换蛊改良**：可把「双底本」并为书虫一蛊承担、省下结绳蛊；代价是失「按序回放」一维、契约次序易被抵赖，属取舍而非纯增强。
- **加环（不新增 O-G 引用）**：可在「收付」前加一道「按成色分级计价」（由蛊师依砥砺蛊落粉粗定，不另设蛊）；代价是分级标准须事先定死、临时改标整账作废、耗心力倍增。
- **浓缩成蛊**：援引「杀招＝炼蛊残方」，可收成一只「权衡蛊」以减少蛊数与心力；代价是依「合炼只保留一只主蛊能力」，「测谎 / 验质 / 存约 / 收付」多维将失，且「物须定价、一批一理、竹君子门槛」不消失。
- **进阶上限锁死**：不得设计成「测『记错 / 被蒙蔽』 / 议价 / 预言盈亏 / 无竹君子亦验谎」——竹君子「天生测谎、唯至诚君子可炼化喂养」、牙筹蛊「只核数不核质」是硬约束。

### 十一、设计理念

对应分析报告第 6 节「非战斗用途（清算 / 质检 / 档案）」「信息不对称（标记真伪）」。本招一次覆盖物品加工（砥砺验质）、商业交易 / 资源管理（牙筹核账）、资质 / 记忆 / 推演（结绳录约）三个扩充方向。它刻意把「质 / 真 / 数」拆给三只不同蛊：牙筹只核数、砥砺只验质、竹君子只测谎，任何一只都不「全能」——这正是「一只蛊只有一个能力」与「缺陷须与机制相关」的体现。竹君子「唯至诚君子可炼化」是原著给的现成门槛，本卷直接拿来当本招最大持有成本，不另造限制。名字「牙筹」「空磕」取算筹与磕响之象，与全卷「日常器物 / 声响」取象一致。

### 十二、组合逻辑

- **核心 / 辅助**：核心 O-G-020 牙筹蛊（定「智道核数核价」性质），辅助 O-G-019 砥砺、O-G-021 结绳（质 / 约）+ 书虫 / 竹君子 / 元老蛊【原著蛊虫】（底本 / 测谎 / 收付）。
- **协同类型**：按分析报告 3.2，属「条件型 + 载体型」混合——结绳 / 书虫「双底本」是核账得以复验的载体，竹君子「测谎」与砥砺「验质」是补「真 / 质」的前置条件，元老蛊「存元石」是收付条件；任一缺则「约无凭 / 谎不察 / 质不辨 / 数无凭 / 钱无处收」。
- **为何不是「多蛊同用」反例**：六蛊同赴「一趟可复验交易」单一目标、各补一维、缺一即不全，符合「每只蛊都要有作用」；且严格不把「元老蛊存元石」这类蛊虫自身能力当作杀招。

### 十三、与原著体系的兼容性

> 逐条分析）

1. **品阶规则**：四转凡道杀招（取整招催动门槛：组成含四转竹君子；核心牙筹蛊为三转），转数取「初次出现时标注」、非强度刻度；组成蛊虫二转（砥砺 / 结绳）、三转（牙筹）、四转（竹君子）、品阶未标（书虫 / 元老）混用，低转 / 未标蛊靠「验质 / 录约 / 存底」机制位参与，不靠数值，符合「高转不使低转失效」。
2. **真元仙元消耗**：耗四转黄金真元（中，取整招门槛）+ 心力（核数、回放，数越大越耗神），不涉仙元；符合「凡道杀招用真元」与「心力」消耗形态。
3. **道痕运行**：本招不新增、不消耗道痕层级设定；牙筹「核数」、砥砺「去余显形」、结绳「结以存真」、竹君子「测谎」、书虫「永记」、元老「存元石」皆凡蛊能力，不凭空生痕、不增益修为、不补全仙蛊道痕。
4. **流派规律**：杀招流派为智道（主）辅以金道 / 律道，组成蛊虫含智道（牙筹 / 结绳）、金道（砥砺）、以及原著未明标流派的书虫 / 竹君子 / 元老——「录约—测谎—验货—核价—收付」在同一目标上协同；跨流派援引「大宗师触类旁通」，皆低阶无道痕互斥之虞，非无条件混合。
5. **蛊虫唯一性**：六只组成蛊虫全为凡蛊，凡蛊可同名多只；本招不含仙蛊，不新增唯一性例外。
6. **杀招组合规则**：6 只蛊同时催动、核心 1 + 辅助 5 分工明确、每只都有作用；发动条件、消耗、效果范围、缺陷与破解方式齐备，且「调包不改数 / 蒙蔽竹君子 / 夺底本 / 嘈杂打断」皆落到具体组件，符合检查表第 7、8 条。

### 十四、平衡性分析

- **强在何处**：把易漏、易被做手脚的清点核价变成可复验流程，质 / 真 / 数 / 约 / 收五维分工，防缺漏防调包，是商队与库房的账房底子。
- **代价与机制同源**：竹君子极难自有（原著门槛，借不到则测谎一维缺）、只测谎不测「记错 / 被蒙蔽」、牙筹只核数不核质（须砥砺补）、不议价不预言、须静一批一理、书虫 / 结绳一失则底本丢、久核耗心力——全从「把不同维度拆给不同单能力蛊」的机制里长出，非机械堆砌。
- **破解链清晰**：调包不改数、抹去价目、蒙蔽竹君子、夺书虫 / 结绳、嘈杂打断清点、混批致乱。
- **上限锁死**：非攻击型、无对敌伤害、不议价不预言、不涉仙元与道痕增益，故只是「清算流程」而非「万能辨真」，不破坏平衡。
