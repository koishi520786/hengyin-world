# 跑团剧本（非正式）

本目录存放《衡垠世界》的**非正式跑团剧本、战役提案与人生线框架**。

## 边界

- 不是世界正典，不进入核心 60 份正式库，不新增或改写任何正式编号。
- 世界事实以 `最终版/` 为准；剧本里的“默认值”只用于本战役，可被玩家确认或替换。
- 主角由玩家完全控制。剧本只安排时间表、制度截止日、NPC 的行动与可选机会，不写主角的台词、行动、内心和未确认记忆。
- 不把开窍结果、学校去向、第一只本命蛊、苏晞的资质写成“已经发生”；这些在开局点由玩家确认或按规则判定。
- 苏晞是第二主角，不是奖励、不是恋爱对象、不是等待主角的工具人；本剧本不安排她与主角的恋爱线。

## 读法

1. 先读 [`00_开窍大典之后_总纲.md`](00_开窍大典之后_总纲.md)，确认开局分支与状态。
2. 只读当前季节：第一季已细化到场景卡；第二至四季是模块化场景卡，按当前进度展开。
3. 每次只推进一个可感知场景，停在玩家可以回应的地方；不要一次跳完一个季节。
4. 场景卡里的“分支”是 GM 的准备，不是已经发生的事实；玩家选到卡外方向时，按 `00` 的压力时钟与 NPC 目标即兴，不强拉回原路线。
5. 每场景结束后更新本地状态台账；大段跳过时间必须结算金钱、伤势、蛊虫、学业、关系与系统任务。
