### 1.3 登记字段定义（12 项，逐只必填）

| 字段 | 定义 | 填写纪律 |
|---|---|---|
| 编号 | C-G／O-G 稳定编号 | 引用前打开 v3.0 文件核对真实存在；无独立编号写「—（本库无独立 C-G 编号）」 |
| 名称 | 原著／原创蛊名 | 保留原著名称与异写，不合并、不擅自正名 |
| 转数 | 品阶（六转及以上为仙蛊） | 只记原文／图鉴明确给出者；不明写【原著未明确】；两说并列标【存在争议】 |
| 来源 | 天地自然生成／人为炼制／【原创设定】／本轮新增 | 原著未写者【原著未明确】；原创一律标【原创设定】 |
| 原持有者 | 炼制者／首位持有者／首位降服者 | 【原著未明确】时留空，不推测；「在谁身上捕捉到」≠「由谁持有」 |
| 当前所在地 | 仙窍／福地／秘境／战场／宿主体表／去向不明 | **不清一律【位置或归属待核实】** |
| 是否炼化 | 是否被蛊师以真元／仙元炼化 | 野生＝未被炼化；不明写【原著未明确】 |
| 是否封印 | 是否被封禁／囚禁 | 「福地禁锢不住仙蛊」；不明写【原著未明确】 |
| 宿主关系 | 体表寄生／体内寄生／共生／伴生／独立活动／人工附加／不适用 | 见《妖兽携蛊与野生蛊虫档案.md》第二节六类；不足以判定写【原著未明确】 |
| 控制状态 | 能否控制／能否催动／是否自主活动／是否护主 | 见该档案第三节；资料不足逐项标【原著未明确】 |
| 状态变更记录 | 流转、获得、收入仙窍、预留段顺延等事件 | 按时间顺序记可考据者，不补写未记载事件 |
| 可信度 | 沿用 v3.0 七级标记 | 【原著明确】／【可靠资料佐证】／【原著未明确】／【存在争议】／【待考证】／【原创设定】 |

## 六、仙蛊战力计入规则（末尾）

1. **只有实际可发挥的效果计入「实际携蛊战力」**。判据（见《妖兽携蛊与野生蛊虫档案.md》第六节）：
   - 该仙蛊**未被封禁**（参照第三卷「渡地灾」：地灵天地伟力可禁锢一～五转凡蛊，但「**仙蛊唯一，超凡脱俗，福地根本禁锢不住仙蛊**」）；
   - 有明确记载由宿主／施术方**实际发动**；
   - 单体效果须与「指挥多蛊／配合／杀招」分开记。
2. **单纯「携带／寄生／藏有」不计入战力**。第七百三十九节「野生仙蛊」中，钻头鳖「智力不足」且无催动记载 → 其野生七转仙蛊**不自动折算为钻头鳖的战力**；该仙蛊被方源获得后的战力属**方源**，不回算给钻头鳖。
3. **「力量残留」「曾在其身上捕捉到」不计入宿主战力**。和稀泥仙蛊力量残留于泥浆持续侵蚀荡魂山属环境后续效果；行空「在一头天马身上捕捉到」属发现线索，二者均不计为宿主实际携蛊战力。
4. **理论最大战力单列，不得当日常战力**。假设全部携带蛊虫均可发挥、且由有智慧施术方组织成杀招时的上限，只作档案估值单列；星魔蝠「缺乏智慧，不能使用杀招」为原著明写的**反例**，其理论上限须标「不可实现」。
5. **不得把身上所有蛊能力简单相加**。C-G-247「许多蛊一起使用就是杀招」说明组合须有施术方组织；B站／ll.txt 中的「数量堆叠」不等于组合加成。本体战力／实际携蛊战力／理论最大战力**三层分列，不求和、不合并成一个总战力数字**。
6. **仙蛊属「例外项」而非常规叠加项**。「斩杀星魔蝠」章：「**若是荒兽身上寄生了仙蛊，那又另当别论了**」是条件句；不得默认每头荒兽都有仙蛊加成，也不得把「位置或归属待核实」的仙蛊计入任何妖兽战力。
7. **状态变更触发重算**：凡被炼化、被封印、被收入仙窍、宿主死亡、宿主被活捉等状态变更，须重新计算「实际携蛊战力」，并在「状态变更记录」栏留痕。
