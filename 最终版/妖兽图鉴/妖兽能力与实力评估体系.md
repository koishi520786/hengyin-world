## 一、能力来源分类

### 1.1 总原则

- **分别记录**：一只妖兽的每一项能力，必须且只能归入下列 12 类中的一类作为「主来源」；若确由多类共同构成，须**拆成多条**分别记录并注明耦合关系，不得把不同体系揉成一句「它很强」。
- **不同体系不混同**：肉体生理 ≠ 元素 ≠ 特殊能量 ≠ 蛊虫 ≠ 法则。尤其**蛊虫能力不得算作妖兽的肉体能力**，环境加成不得算作妖兽本体能力。
- **蛊道体系是蛊师的**：空窍、元海、真元／仙元、炼化／炼蛊、本命蛊、杀招催动、道痕修为属于**蛊师**（合集 7.1／第五节）。妖兽默认不具备；妖兽「携蛊」只能是被动寄生／共生／野生蛊附体，须单列在「蛊虫」类并核对蛊编号。

### 1.2 十二类来源（逐类判定口径）

| # | 来源类 | 定义 | 典型表现（机制句） | 判定要点 | 与蛊道的关系 | 可信度 |

### 1.3 混同禁令（成文规则）

1. 禁止「它皮糙肉厚又会放电，所以防御极高」——须拆成：肉体生理（鳞甲抗穿刺，到 X 层）+ 元素（带电体表，对接触类目标 Y 结果）+ 各自弱点。
2. 禁止把蛊虫能力写成妖兽的「天赋」；蛊只能以「编号 + 照录能力 + 被动/附体状态」单列。
3. 禁止把环境／主场加成计入「本体战力」（见第三节）。
4. 禁止以特殊能量、法则、道痕为妖兽补出空窍、真元、炼蛊、杀招催动能力（铁律 2／7）。

## 二、威胁等级定义（按机制，不按体型）

> 契约已为 12 种妖兽标注低／中／高／极高，**本节不改写契约等级**，只给出「等级应如何由机制推出」的统一口径，供补档与复核使用。

### 2.1 四级定义

| 等级 | 定义（机制句） | 典型机制特征 |
|---|---|---|
| 低 | 能力主要落在**肉体生理**单层，无绕过肉体防御的手段；对配置①普通蛊师，其攻防可被常规对口蛊逐条处理 | 单一爪击／咬合／冲撞；无魂／毒／空间／法则；弱点部位明确且易命中 |
| 中 | 具备**一项**可绕过普通肉体防御或改变战局的机制（毒入体、范围吐息、控制、特殊器官剥夺能力、携被动寄生野生蛊），但前置条件明显、可被对口蛊或情报克制 | 毒须入体；吐息限属性；控制有时长；寄生蛊被动、可被封印 |
| 高 | 具备**多项**互补机制，或一项机制稳定成立且难被常规手段覆盖（多层部位防御 + 恢复／再生 + 绕防攻击 + 大体型稀释毒），使配置①～③多数维度不占优 | 破甲门槛高；毒因体型「效较慢」；有明确但有代价的弱点 |
| 极高 | 机制**稳定成立且能压制蛊师判定链**：可绕过肉体防御、可破前置／断真元、或涉及空间时间／法则／野生仙蛊，使正面配置无解，只能靠撤退或窄窗口特殊克制 | 对应《匹配表》5.3「基本无法正面取胜／主要靠撤退或特殊克制」 |

### 2.2 升降级条件（不改契约，只作复核）

| 条件 | 影响 |
|---|---|
| 命中明确弱点且写成「部位＋条件＋后果」 | 实际交锋结果可低于契约等级 |
| 目标体型大且以毒为主要威胁 | 按 C-G-563「对大型猛兽效较慢」判起效延迟，威胁临时下调 |
| 目标体质克制某毒（蜂毒被 C-G-565「熊体克制」） | 该条攻击降级为「无效／微弱」 |
| 情报不足遭突袭（配置⑥） | 实际威胁临时上调，因无法对口布防 |
| 携蛊状态被核为【未识别野生蛊虫】／【待考证】 | 不得据「携仙蛊」直接抬级；须待考证后重评 |

### 2.3 体型口径

- 体型进入判定的**唯一合法方式**是机制：动能、受毒剂量与起效速度、部位层级厚度、可否被束缚／缠绕、可否被「只容自身」的位移蛊带走（O-G-008 洄游蛊）。
- **禁止**「体型大 ⇒ 威胁高」「体型小 ⇒ 威胁低」。反例：C-G-563 毒「对大型猛兽效较慢」说明大体型反而是毒的减益；C-G-565「蜂毒被熊体克制」说明体型／体质是具体克制而非泛化强弱。

## 三、三层战力

### 3.1 定义

| 层 | 定义 | 记什么 | 不记什么 |
|---|---|---|---|
| 本体战力 | 妖兽**仅凭自身肉体／器官／元素／血脉／精神／灵魂**能稳定达成的攻防结果 | 第 1～7、9 类来源；常态、无外部加成 | 环境加成、携蛊、假想满配 |
| 实际携蛊战力 | 本体战力 + **当前确实附着且状态可核**的蛊（被动寄生／共生／野生附体），按蛊的真实能力、发动条件、消耗逐条计入 | 已核对编号的蛊；其被动触发条件；蛊与宿主的耦合 | 未识别／待考证的蛊、假想「假如它有某蛊」 |
| 理论最大战力 | 在**最有利且全部条件同时满足**的极限假设下可能达成的上限（含环境、时机、潜在携蛊、对手失误） | 仅作边界标注 | **不得当日常战力使用** |

### 3.2 两条硬规则

1. **理论最大 ≠ 日常战力**：理论最大只在「全部前置同时成立」的极限情形成立，例如 C-G-228 定仙游须「脑海有地点具体印象且地点未巨变」、O-G-008 洄游蛊须「两点先亲自到达并埋标记、相距三里内」、C-G-133 水幕天华蛊「无法移动无法停止」。任一前置不满足即回落到实际层。判定默认用**实际携蛊战力**，理论最大只作「上限备注」。
2. **不得把身上所有蛊能力简单相加**：多蛊不等于能力叠加。须按《匹配表》第六节核对——组件兼容性、同时催动限制、真元／资源压力、发动条件。例：O-K-001「以牙还牙」是「燃恨印→连催自力更生蛊与蛮力天牛蛊」的固定顺序，且「不能连续发动」；O-G-011 静息蛊「静止入定、不催动他蛊」，与「连催多蛊」直接冲突。凡蛊组合须先过兼容检查，不能把 N 只蛊的效果做加法。

### 3.3 表述模板（禁模糊话）

> 「O-B-〈编号〉 本体战力：〔部位层级结论〕+〔可成立攻击机制与结果〕+〔恢复/抗性/弱点〕。实际携蛊战力：在〔编号〕〔蛊名〕以〔被动触发条件〕成立时，追加〔照录能力 + 结果〕；该蛊〔消耗／限制／弱点〕。理论最大战力：仅当〔全部前置〕同时成立时上限为〔机制结果〕，**不作日常战力**。缺失字段：〔逐项列『未知』〕。」

## 四、伤害七级

> 与《妖兽蛊虫战力匹配表》3.1 完全对齐，避免两文件口径漂移。

| 级别 | 定义（机制句） | 战力评估中的用途 |
|---|---|---|
| 无效 | 未满足发动条件，或机制被目标结构／抗性完全挡回，无任何状态改变 | 该条能力不计入有效输出 |
| 微弱 | 外皮级擦划／短暂干扰，不累积为有效伤势 | 可忽略，或累计触发阈值 |
| 轻伤 | 破外皮或浅入肌层，未及骨骼／内脏；可自愈 | 计入伤势累积，轻微削机动 |
| 中伤 | 深入肌层或破甲后稳定命中，或破骨未及内脏；影响机能 | 明显削机动／出力 |
| 重伤 | 伤及内脏、中枢、大血脉，或特殊器官被毁、能力被剥夺 | 战力大幅下降；可丧失某类能力 |
| 致命 | 摧毁生命维持机能或触发即死机制 | 「击杀」前提；仍须过第七节「能杀≠能安全取蛊」 |
| 特殊控制 | 不沿伤害层级，直接施加束缚／定身／催眠／封禁／位移／奴役等状态 | 单列；须写时长、解除条件、对催动的打断 |

**评估口径**：一只妖兽的「输出能力」应表述为「在〔条件〕下能对〔目标部位／承载〕稳定造成〔七级中的某一级〕，机制原因是〔…〕」；不得写「伤害很高」。防御能力同理表述为「能把〔某类攻击〕从〔级〕降到〔级〕，机制是〔哪一层、怎么挡〕」。

## 五、抗性与弱点的判定口径

### 5.1 抗性

| 项 | 口径 |
|---|---|
| 必须三要素 | 「对什么（攻击类型／属性）」+「通过什么机制」+「到什么程度（把七级中的哪级降到哪级）」 |
| 禁止写法 | 「抗性高」「几乎免疫」。改为「鳞甲矿化层把一转切割型月刃挡在甲面，结果由轻伤降为仅表面伤」 |
| 对口核对 | 五行抗性用 C-G-161 五行熊皮蛊（仅减免金木水火土五道**蛊虫效果**）；魂抗用壮魂／魂道防御；毒抗须核解毒蛊（C-G-060 清热蛊、C-G-157 雪洗蛊、C-G-476 濯洗蛊）与体型延迟（C-G-563） |
| 不对口即无效 | 以硬化皮蛊抗魂道、以五行熊皮蛊抗纯物理或音浪，均判「不对口＝无此抗性」 |
| 上限必写 | 抗性可承受上限无据写「未知」；不得写「无限／绝对」 |

### 5.2 弱点

| 项 | 口径 |
|---|---|
| 必须三要素 | 「弱点部位」+「触发条件」+「后果（七级结果或能力剥夺）」 |
| 禁止写法 | 「腹部较软」。改为「腹部无鳞甲覆盖，穿刺类命中即由『仅表面伤』升为『伤及内脏』」 |
| 部位候选 | 眼、囟门、甲缝／接缝、黏膜（口／鼻／创面）、特殊器官外露口、翼膜、关节缝 |
| 时间型弱点 | 换甲／蜕皮／产卵／进食／器官外露时段，须标窗口时长（无据写未知） |
| 成对出现 | 有抗性必查是否存在对应弱点；有弱点必查是否被某抗性抵消，二者在同一结论里并列写出 |

### 5.3 证据要求

- 抗性／弱点若由**蛊**提供，须给蛊编号并照录（如「C-G-565 蜂毒蛊被熊体克制」是克制关系的证据，不是该妖兽的抗性证据，除非设定明确绑定）。
- 抗性／弱点若由**设定**提供，须标【原创设定】并写明「来源＝《原创妖兽图鉴》O-B-〈编号〉 档案第〈节号〉节」；无出处写【待考证】。
- 任何「未知」字段不得用推测数值填补。

## 六、战力结论的证据标准

### 6.1 证据分级（与可信度标记对齐）

| 级别 | 可用证据 | 允许下的结论强度 |
|---|---|---|
| 强 | 权威文件正文逐字（蛊编号 + 能力 + 消耗 + 限制）、已核对的原创档案 | 可下确定性机制结论，标【原著明确】／【原创设定】 |
| 中 | 百科／考据整理、A 级杀招档案的组件字段 | 可下倾向性结论，标【可靠资料佐证】，须注明「未取到正文逐字」 |
| 弱 | 本项目机制推演、假想防御、组合测试 | 只能下标【合理推测】的判定框架，不得写成设定事实 |
| 无 | 查不到编号／字段缺失 | 写「未知」／【原著未明确】／【待考证】／【未识别野生蛊虫】，**不下战力结论** |

### 6.2 结论书写模板

> 「在〔配置／环境／情报〕下，〔蛊师转数 + 关键蛊编号〕对〔妖兽 O-B-〈编号〉〕的〔某部位／某承载〕可稳定造成〔七级结果〕，机制原因是〔发动条件→命中方式→部位层级→抗性核对→结果〕；消耗为〔真元品质/仙元/魂魄底蕴/其他〕；剩余威胁为〔…〕；结果归类为〔《匹配表》5.3 八级之一〕。证据：〔权威文件 + 编号/行〕。缺失字段：〔…〕。」

### 6.3 禁止句式（反例）

| 禁止 | 原因 | 改写方向 |
|---|---|---|
| 「实力强大／防御极高／普通蛊师难以对付」 | 无机制、无部位、无条件、无消耗、无结果 | 拆成七级结果 + 机制句 |
| 「三转蛊师打不过它」 | 把转数当固定战力 | 改「配置⑥情报不足遭突袭的三转蛊师，因〔某前置〕不成立，结果为〔八级之一〕」 |
| 「它身上有仙蛊所以极高威胁」 | 未核编号、把携蛊当本体 | 改「携蛊状态【待考证】／【未识别野生蛊虫】，不据此抬级」 |
| 「所有仙道杀招都耗仙元」 | 违反铁律 | 改「C-K-062 鬼官衣不耗仙元、耗魂魄底蕴；本招消耗逐条核对」 |
| 「道痕可以驱动任意能力」 | 道痕非万能能量 | 改「须同流派、达境界；多流派互斥；成功道痕一道至多用于六转仙蛊」 |

## 七、「转数／体型不等于战力」成文规则

### 7.1 规则条文（七条）

1. **转数不是强度刻度**：《蛊真人蛊虫合集》7.3「转数非强度刻度：一切蛊虫皆可升级，所谓转数不可尽信，只取文中初次出现时的转数」。
2. **转数只定档位**：转数决定真元／仙元品质与储量档位、可稳定催动的蛊转数上限，不直接决定胜负（7.1 品质表：青铜／赤铁／白银／黄金／紫晶；青提／红枣／白荔／黄杏）。
3. **低转催高转有额外限制**：第五节「低级蛊师用高级蛊如孩童挥重锤」；C-G-250 偃月仙蛊相关「七转只能催三到四指」（6.5 五指拳心剑）。须判真元不足、催动不稳、效果打折或反噬。
4. **凡蛊／仙蛊是品类不是强弱**：一至五转凡蛊、六转及以上仙蛊；凡蛊可同名多只、仙蛊同名天下唯一（7.3）。低转单蛊若有对口机制，可胜过高转不对口单蛊。
5. **体型只以机制入场**：动能、受毒剂量与起效速度、部位厚度、可否被束缚／位移。禁止「大⇒强」。
6. **体型是双刃**：C-G-563 蛇毒蛊、鸠毒蛊「对大型猛兽效较慢」、C-G-565 蜂毒蛊「被熊体克制」——大体型／特定体质反构成减益或克制。
7. **组合、杀招、道痕、经验、情报、环境均独立入场**：任一因子可翻转结果；须逐项写「如何进入判定」（见《匹配表》5.4 因子表）。

### 7.2 判定流程（评估一只妖兽／一名蛊师时）

1. 先列**能力来源**（12 类拆分，不混同）→ 2. 定**三层战力**（本体／实际携蛊／理论最大，理论最大不作日常）→ 3. 按**机制**定威胁等级（非体型）→ 4. 逐条过**抗性／弱点三要素** → 5. 用**七级伤害 + 八级结果**落结论 → 6. 按**证据分级**标注可信度、补齐「未知」清单 → 7. 最后才对照**转数与体型**作「是否影响某一具体机制」的复核，不得反过来用转数／体型直接给结论。

### 7.3 「三转蛊师」示例（说明非固定战力）

同为三转白银真元：配置④「专门针对」且带对口蛊、情报正确 → 可对低／中威胁妖兽达「优势明显」；配置⑥「情报不足遭突袭」且防御不对口 → 对同一妖兽可落「明显劣势」。差异来自配置、情报、对口与否，**不来自「三转」这个标签**。

## 八、能力类型与蛊道规则兼容检查表

### 8.1 检查表（逐能力必过）

| 能力来源类 | 与蛊道规则的关系 | 是否兼容（默认） | 处理方式 | 违规示例（禁止） |
|---|---|---|---|---|
| 肉体生理 | 蛊道无「肉体修为」体系 | 兼容（独立体系） | 按部位分级判；不与真元／道痕挂钩 | 给妖兽加「真元护体」解释鳞甲 |
| 特殊器官 | 分泌物 ≠ 蛊毒 | 兼容（独立体系） | 若确为蛊毒，须指向具体蛊编号并移入第 10 类 | 把毒囊分泌物直接当 C-G-063 爱生离 |
| 元素 | 五行减免蛊（C-G-161）只减免「五道蛊虫效果」 | 部分兼容 | 注明「减免对象＝蛊虫效果」；纯物理／音浪不在其列 | 用五行熊皮蛊减免纯物理冲撞 |
| 特殊能量 | 非真元／非仙元 | **不兼容真元体系** | 单列，写明可否被真元干涉；不与真元互相转换 | 用「能量」给妖兽补真元／催蛊 |
| 精神 | 心志类 ↔ C-G-132 正气蛊、O-G-009 记仇蛊 | 部分兼容 | 区分精神与灵魂；对症用蛊 | 用壮魂蛊治纯精神恐慌 |
| 灵魂 | 魂道绕过肉体防御 | 兼容（对口） | 先判「有无魂魄」；再核壮魂／魂道防御 | 对无魂目标判魂道有效 |
| 血脉 | 血亲追溯类蛊（C-G-199／571／573）作用于血 | 兼容（作为对象） | 血脉是被追溯对象，非主动施法 | 称妖兽「有血道修为」 |
| 空间时间 | 宇／宙道蛊有前置 | 部分兼容 | 逐条核前置（地点印象、预置标记、真元耗尽） | 让妖兽「随意瞬移」 |
| 法则 | 律／天／运道须境界与道痕 | **默认不兼容** | 妖兽默认无法则修为；带法则须给证据 | 凭空给妖兽加道痕／法则 |
| 蛊虫 | 蛊是独立个体；蛊道体系归蛊师 | 兼容但须隔离 | 单列编号、照录能力、标被动/附体；**不给妖兽空窍／真元／炼蛊／杀招催动** | 「妖兽自己炼了这只仙蛊」 |
| 环境 | 主场加成 ≠ 本体 | 兼容（记在环境） | 换场地即失效；不计入本体战力 | 把主场优势写成「本体战力」 |
| 人工改造 | 若用蛊改造仍归第 10 类 | 部分兼容 | 写明改造者／手段／可逆性／失效条件 | 默认改造使妖兽获得炼蛊能力 |

### 8.2 妖兽默认值（铁律 2／7 成文）

> 除非《原创妖兽图鉴》某档案**明确设定并标【原创设定】+ 给出证据**，否则妖兽一律按下列默认处理：

| 项 | 默认值 | 依据 |
|---|---|---|
| 空窍 | 无 | 空窍／元海是蛊师体系（合集 7.1） |
| 真元／仙元 | 无 | 同上；品质表仅对蛊师成立 |
| 炼化／炼蛊能力 | 无 | 蛊师三用「炼、养、用」（7.1）；炼蛊须秘方与失败率（第五节） |
| 本命蛊 | 无 | 本命蛊＝蛊师第一只炼化之蛊（7.1） |

### 8.3 两处必须随档携带的核对结论

1. **O-G-110 已登记，不是未启用预留段**：O-G-110 已由《仙蛊唯一性登记表》第四节登记为「界隙蛊」并在《原创蛊虫图鉴》卷末附录建立唯一实体记录；六转宇道、O-B-012 阈鹿体表被动寄生、未炼化未封印、妖兽不可催动、自主护主存疑、宿主死亡后留存未知。具体能力／消耗／炼制仍【待考证】，不据此抬升威胁等级，不加空窍／真元／炼蛊能力。
2. **仙道杀招不必耗仙元**：C-K-062 鬼官衣「不耗仙元、耗魂魄底蕴」（蛊虫合集 6.5）；O-G-107 存息蛊以「六转青提仙元 + 魂魄底蕴／心力」为消耗形态并明言对应「鬼官衣」一类。评估任何杀招消耗须逐招核对，不得默认仙元。
