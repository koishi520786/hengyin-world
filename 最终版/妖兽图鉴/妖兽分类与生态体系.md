# 第 5 章 五维分类体系

> **总原则**：五个维度互相独立、逐维分别记录，**不合并成一条等级线**，也不由某一维直接推出另一维。一只妖兽在每一维各取一个（可多选的候选标签除外）判定，五维结果并列写成一行档案，禁止以「它很强」一类模糊话代替。契約已固定的「类别／智慧／威胁」三列**本卷不改写**，只给出「该标签应如何由机制复核」的统一口径（沿用《妖兽能力与实力评估体系.md》第二节）。

## 5.1 维度一：生物本质（候选分类，不强行统一）

下列 15 项为**候选标签池**【原创设定·分类框架】，可多选、可并列、可标【其他】；它们描述「是什么」，**不表示强弱顺序**，也不与《蛊真人》原著兽类分类（见 5.5）等同。原著并未使用这套词，故不得把任一标签反引为【原著明确】。

| # | 候选标签 | 判定口径（机制句） | 本卷 12 种契约归此标签者 |
|---|---|---|---|
| 1 | 普通动物 | 未异化、结构符合常规动物生理，无超常器官／能量 | 无（12 种均非纯普通动物） |
| 2 | 异化动物 | 基础动物形态＋单项或多项环境性异化（食性、体表、栖境特化），无蛊道修为 | O-B-001 檐鸮、O-B-002 隧锈鼠、O-B-004 砾背驮兽、O-B-005 草潮羚、O-B-007 洄鳞鲮、O-B-010 悬丝鹞 |
| 3 | 妖兽 | 具稳定超常能力（伏击、甲壳、两栖掠食等）且能力主要来自本体，非蛊、非真元 | O-B-003 层藓兽、O-B-006 沉沙螯、O-B-008 泥囊螈 |
| 4 | 灵兽 | 与元气／灵机亲和、常作辅助或指示生物 | 契约未指定；O-B-007「滤食元气絮、水质指示」接近此描述但契约类别为「异化鱼类」，**按契约不归入**【原创设定·不并标签】 |
| 5 | 魔兽 | 具侵蚀性／污染性能力，对常规生物或环境有害 | 契约未指定，无归入 |
| 6 | 神兽 | 具信仰／仪式性地位或规则级位格 | 契约未指定，无归入 |
| 7 | 巨兽 | 体型远超常规、以体型进入动能／受毒剂量判定 | O-B-009 潮脊鲸（契约类别＝巨兽） |
| 8 | 亡灵 | 无活体生理、以魂／残息为存在载体 | 契约未指定，无归入 |
| 9 | 元素 | 本体主要由单一元素／能量凝结构成 | 无；O-B-011 为「元素-昆虫型生命」，见第 10／11 项 |
| 10 | 植物型 | 具植物性组织或光合／固着特征 | 无独立项；O-B-003 为「妖兽·动植物复合」，并列取第 3＋本项 |
| 11 | 昆虫型 | 具昆虫式体节／外骨骼／群体节律 | O-B-011 晶隙蛰（元素-昆虫型生命，并列取第 9＋本项） |
| 12 | 深海地下 | 以高压／无光／封闭地下或深海为常态栖境 | O-B-002（地下管廊／矿道）、O-B-009（海洋／深海）、O-B-011（洞窟） |
| 13 | 人工创造 | 由蛊师／机构炼制、改造或装配而成 | 契约未指定；O-B-004「被人类驯养运输」属**驯养**非**创造**，不归入 |
| 14 | 智慧型非人 | 智慧接近人类、有社会组织或边界感知等非人理性 | O-B-012 阈鹿 |

## 5.2 维度二：起源类型

描述「从哪里来」，与「生物本质」「能力来源」独立。除注明原著依据者外均为【原创设定】（本世界生态设定）。

| 起源类型 | 定义 | 判定要点 | 契约对应 |
|---|---|---|---|
| 自然野生繁育 | 在本世界常态生态中自行繁衍、有稳定种群 | 须有食物链位置与种群规模；O-B-005 群 200～2000 为契约明载规模 | O-B-001、O-B-005、O-B-007、O-B-009、O-B-010 |
| 环境异化 | 由栖地特殊条件（矿锈、流沙、沼泽、元气絮）长期作用而异化 | 须写明异化因子；异化 ≠ 获得真元／空窍 | O-B-002（矿锈）、O-B-004（岩菌矿液）、O-B-006（流沙）、O-B-008（沼泽腐食） |
| 特殊能量环境原产 | 依赖结晶渗出的能量凝结体等非常规能量场 | 能量**单列**，不与真元／仙元混同；道痕逸散仅【合理推测】 | O-B-011 |
| 森林／秘境顶级捕食者 | 由森林或秘境食物链顶层位演化 | 与「智慧」无关，只述生态位 | O-B-003（森林）、O-B-012（秘境／小世界） |
| 秘境／小世界原产 | 栖于秘境或边界裂隙，依赖界隙稳定 | 须核「边界裂隙」是否为人工／自然；契约未明确 → 【待考证】 | O-B-012 |
| 人工驯养（非创造） | 人类捕获后驯养利用，物种本身仍野生 | 驯养改变行为、不改变起源；不得据此给妖兽加空窍／真元 | O-B-004（运输）、O-B-001（侦查警戒）、O-B-010（侦查／通讯） |
| 【原著未明确】 | 契约未给起源线索者保留缺口 | 不推测补写 | 各条「跨近海迁徙」「洄游连接」属**行为**非**起源**，不据此改起源 |

## 5.3 维度三：智慧程度（实力强 ≠ 智慧高）

> **硬规则**：智慧是「能否组织多蛊、能否形成配合、能否施展复杂杀招」的门槛，不是战力刻度。《妖兽携蛊与野生蛊虫档案.md》第三节六项清单已判定：本轮考据**没有任何一个原著妖兽案例能同时通过「智慧／指挥多蛊／配合／杀招」四项**；星魔蝠（C-B-018）「缺乏智慧，不能使用杀招」是原著明写反例【原著明确】，钻头鳖（C-B-017）「智力不足」同【原著明确】。因此**高威胁、高智慧、携蛊三者互不推导**。

| 智慧档 | 定义（机制句） | 对蛊道判定的含义 | 契约对应（契约原词照录） |
|---|---|---|---|
| 普通动物 | 本能驱动，无工具／无组织／无多步计划 | 不能指挥多蛊、不能配合、不能组杀招；「携蛊」只能被动寄生 | O-B-002、O-B-005、O-B-007、O-B-008、O-B-010（高等动物者不在此档） |
| 普通动物偏高 | 略高于本能，有简单伏击／择时，仍无多蛊组织 | 同上，仅单体行为可更复杂 | O-B-006（普通动物偏高） |
| 高等动物 | 有领地、伏击、亲代照护、可驯养学习 | 可被驯养作侦查／通讯／运输，但驯养 ≠ 获得催蛊能力 | O-B-001、O-B-003、O-B-004、O-B-010 |
| 高等动物（群体节律） | 个体智慧有限，群体呈同步节律 | 群体行为不等于个体指挥；不得据「群体节律」判其能组杀招 | O-B-011 |
| 接近人类（无文明） | 有个体判断与记忆，未形成社会组织／技术 | 仍不自动获得空窍、真元、炼化蛊虫、流派境界 | O-B-009 |
| 接近人类、有简单社会组织 | 有简单群体结构、边界感知与稳定行为 | 可「感知并短暂稳定边界裂隙」，但这是**本体天赋**，不是蛊、不是杀招；携带 O-G-110 仍「妖兽不可催动」 | O-B-012 |

**反例对照（实力强 ≠ 智慧高，逐条可判定）**：

| 对照 | 威胁（契约） | 智慧（契约） | 结论 |
|---|---|---|---|
| O-B-009 潮脊鲸 | 高 | 接近人类（无文明） | 巨兽高威胁来自体型与本体，不来自「会组杀招」 |
| O-B-003 层藓兽 | 高 | 高等动物 | 森林顶级伏击捕食者靠本体伏击，非智慧型施术 |
| O-B-012 阈鹿 | 极高 | 接近人类、有简单社会组织 | 极高威胁来自边界裂隙感知＋秘境位格；其「共生低转蛊＋O-G-110 界隙蛊」为被动寄生、不可催动【原创设定】 |
| O-B-008 泥囊螈 | 中 | 普通动物 | 体内＋体表大量被动寄生野生蛊，是全库「携蛊≠可控≠可催动≠能组杀招」典型案例；蛊多 ≠ 智慧高 |
| O-B-005 草潮羚 | 低 | 普通动物 | 群 200～2000 的规模不构成「组织多蛊」能力 |

## 5.4 维度四：能力来源（12 类，不同体系不混同）

> 沿用《妖兽能力与实力评估体系.md》1.2 的十二类框架【合理推测·判定层】，本卷只作**分类登记口径**，不复制其逐类战力结论。**总原则**：每一项能力必须且只能归入一类作为主来源；多类共同构成则拆成多条并注明耦合关系；**蛊虫能力不得算作妖兽肉体能力，环境加成不得算作本体能力，特殊能量不得与真元／仙元混用**。

| # | 来源类 | 本卷登记判据（必须落到机制） | 与蛊道的关系 | 契约对应 |
|---|---|---|---|---|
| 1 | 肉体（肉体生理） | 爪、牙、甲、体型动能、厚肌吸能 | 与蛊道无关；「肉身强」不推定能催蛊 | O-B-003 伏击、O-B-006 流沙螯、O-B-009 巨兽体型、O-B-005 踩踏 |
| 2 | 器官（特殊器官） | 毒囊／腺体／滤食器官／发光器；破坏＝剥夺对应能力 | 分泌物 ≠ 蛊毒，除非指向具体 C-G 编号 | O-B-007 滤食器官（水质指示）、O-B-006 毒相关（契约写「伴生毒道低转蛊群」，故毒源归第 10 类蛊，不归器官） |
| 3 | 元素 | 炎／冰／雷／水／风／土亲和，须写属性＋外放方式＋范围＋消耗 | 元素抗性 ≠ 蛊抗性 | 契约未给稳定元素外放；O-B-006「流沙」属地形利用（归第 11 类环境），不归元素 |
| 4 | 特殊能量 | 非真元、非仙元、非元素；单列来源、可否被真元干涉 | **不兼容真元体系**，不得用来补真元／催蛊 | O-B-011「食结晶渗出的能量凝结体」 |
| 5 | 精神 | 威压、恐惧、惑乱、士气 | 精神 ≠ 灵魂；壮魂类不治纯精神恐慌 | 契约未指定，无归入 |
| 6 | 灵魂 | 有无魂魄、魂魄强弱、魂道承载 | 魂道绕过肉体防御，但须目标有魂 | 契约未指定，无归入 |
| 7 | 血脉 | 血亲追溯、种族传承、资质 | 血脉是「被追溯／被感应」对象，非主动施法 | 契约未指定，无归入 |
| 8 | 空间时间 | 宇道／宙道位移、定身、隔离；逐条核前置 | 妖兽若有空间能力仍须核前置，不得「随意瞬移」 | O-B-012「感知并短暂稳定边界裂隙」【原创设定】：属**界隙感知／稳定**的本体天赋，须与「宇道蛊的效果」分开登记；契约未给距离／时长／消耗 → 【原著未明确】／【待考证】 |

## 7.2 六个生态区域食物链示意

> 读法：`A → B` 表示「A 被 B 取食／能量由 A 流向 B」；`〔非 O-B〕` 为环境／资源项，不立编号。每行另注该区的关键限制条件。蛊群在该区的位置见第 14 章，**蛊不进入食物链箭头**（蛊是独立资源，不是营养级）。

### 区域一：城市边缘

```
〔非 O-B〕城市飞虫 → O-B-001 檐鸮 → O-B-003 层藓兽（幼体猎物，R-01）
〔非 O-B〕高空气流微粒 → O-B-010 悬丝鹞
O-B-001 ⇄ O-B-010（城市上空竞争，R-10，非取食）
```
**限制条件**：檐鸮／悬丝鹞依赖檐下结构／上升气流；建成区核心缺少檐下与飞虫密度，故两者止于「城市边缘」；层藓兽仅在森林—城市边缘交界带接触幼体，不进入建成区（契约明载 O-B-003 栖地为森林）。

### 区域二：地下管廊

```
〔非 O-B〕腐屑／矿锈 → O-B-002 隧锈鼠 → O-B-003 层藓兽（R-02）
                                     → O-B-008 泥囊螈（R-04）
                                     → O-B-006 沉沙螯（R-08，荒漠边缘矿道）
〔非 O-B〕结晶渗出的能量凝结体 → O-B-011 晶隙蛰（R-35）
O-B-002 ⇄ O-B-011（共存矿道 R-15，非取食）
O-B-004 砾背驮兽 ⇄ O-B-011（甲缝清理共生 R-13）
```

**限制条件**：管廊／地铁／矿道为封闭无光环境；O-B-011 必需能量凝结体，只出现在「洞窟／特殊能量环境」，与 O-B-002 的矿锈资源位不同，故判「共存」而非竞争同一食物。

### 区域三：森林

```
〔非 O-B〕草／林下植被 → O-B-005 草潮羚（草原侧，森林边缘取食）→ O-B-003 层藓兽（R-03）
O-B-001 檐鸮（幼体）→ O-B-003 层藓兽（R-01）
O-B-002 隧锈鼠 → O-B-003 层藓兽（R-02）
O-B-011 晶隙蛰 → O-B-003 层藓兽（偶食 R-09）
O-B-003 ⇄ O-B-012 阈鹿（秘境林缘竞争 R-11，非取食）
```
**限制条件**：层藓兽为「森林顶级伏击捕食者」，依赖林冠／藓层遮蔽；离开森林遮蔽后伏击机制不成立，故不跨区追猎至城市或荒漠腹地。

### 区域四：草原与荒漠

```
〔非 O-B〕草场 → O-B-005 草潮羚（群 200～2000）→ O-B-003 层藓兽（R-03）
                                            → O-B-006 沉沙螯（落单个体，R-07）
O-B-002 隧锈鼠 → O-B-006 沉沙螯（R-08）
O-B-005 踩踏／粪肥 →〔非 O-B〕草原（生态调节 R-24，非取食）
O-B-006 流沙伏击 →〔非 O-B〕荒漠微地形（R-30）
```
**限制条件**：沉沙螯仅取「落单 O-B-005」与进入流沙带的 O-B-002，群体正面对峙不触发伏击；草潮羚迁徙（R-25）决定草原侧捕食压力的季节性。

### 区域五：河湖与沼泽及近海

```
〔非 O-B〕元气絮与藻 → O-B-007 洄鳞鲮 → O-B-008 泥囊螈（R-05）
                                    → O-B-009 潮脊鲸（洄游群 R-06）
O-B-002 隧锈鼠 → O-B-008 泥囊螈（R-04）
O-B-007 洄游 ⇢ 河湖 ↔ 近海（迁徙连接 R-25）
O-B-009 跨近海迁徙 ⇢ 近海 ↔ 深海（R-25）
O-B-008 ⇄ O-B-009（河口个体竞争 R-12，非取食）
```
**限制条件**：洄鳞鲮是「水质指示」种（R-26），其种群状态可作该区观测指标；泥囊螈与潮脊鲸的竞争仅限**河口个体**（R-12），不扩为全种群竞争；潮脊鲸主体在海洋／深海。

### 区域六：高空与洞窟及秘境

```
〔非 O-B〕高空气流微粒 → O-B-010 悬丝鹞（R-33）
〔非 O-B〕结晶渗出的能量凝结体 → O-B-011 晶隙蛰（R-35）
O-B-011 → O-B-003 层藓兽（偶食 R-09）
〔非 O-B〕秘境边界裂隙 ⇄ O-B-012 阈鹿（感知并短暂稳定 R-23，非取食）
O-B-003 ⇄ O-B-012（秘境林缘竞争 R-11）
O-B-010 ⇄ O-B-001（城市上空竞争 R-10）
```
**限制条件**：O-B-011 的「道痕逸散」仅【合理推测】，不进食物链、不作能量转换；O-B-012 与边界裂隙的关系是**本体天赋调节**，不是捕食也不是蛊效；秘境／小世界蛊群单列于第 14 章「秘境特有蛊群」。

### 14.1.1 专条：巢穴中的蛊虫不算单只妖兽个人战力（硬性判定）

| 判项 | 结论 | 依据 |
|---|---|---|
| 巢穴／栖地伴生蛊归谁 | 归**区域／场景资源**，不归该区域内任何单只妖兽 | 14.1 第 4、5 类定义；野生蛊「成群生存／隐秘场所生存」【可靠资料佐证】 |
| 能否因「某妖兽的巢里有蛊」而给该兽加战力 | **不能**。须核三条件：①该蛊是否被明确记载由该兽实际发动；②是否未被封禁；③是否为单体效果而非「数量堆叠」。三条件缺一即不计 | 《仙蛊唯一性登记表.md》第六节「只有实际可发挥的效果计入实际携蛊战力」；《妖兽携蛊与野生蛊虫档案.md》6.2／6.3 |
| 数量堆叠是否等于战力 | **不等于**。星魔蝠（C-B-018）「身上寄生的野生蛊虫规模庞大，但只能单纯地凭借数量的堆叠」「不能使用杀招」【原著明确】 | 《原著兽类图鉴.md》C-B-018 条 |
| 击杀宿主是否自动获得巢蛊 | **否**。巢蛊为独立野生个体，可能逃逸／反噬／自毁；安全取蛊须专门手段（见 14.2「能否捕获」列与输出 3 第 15 章） | 《妖兽蛊虫战力匹配表.md》7.1「能杀≠能安全取蛊」 |
| 三层战力如何记 | ①本体战力／②实际携蛊战力／③理论最大战力**三层分列、不求和**；巢蛊只可能进入「区域资源」栏，不进入①或② | 《妖兽携蛊与野生蛊虫档案.md》第六节 |

| 国家/秘境关联 | 晏京旧城、临江老站、东陵外港、澜沧旧堤、阿什兰东炉城是“檐鸮—旧城改造”叙事的常用地点；与秘境无直接绑定，不把城市种群写成秘境物种。 |

**生态位一句话**：檐鸮是城市边缘的“低成本鼠害控制器”，不是战斗妖兽；它的故事价值在于旧城改造、灭鼠政策、电线防护与巢箱争议。

### 15.2 O-B-006 沉沙螯 · 荒漠商路的伏击者

| 项目 | 内容 |
|---|---|
| 分布（既有 39 国） | 赤砂：NAT-004 九庭城外围、NAT-026 苏哈沙缘、NAT-027 乌祖—白镜商道、NAT-028 白镜盐湖、NAT-029 焰脊荒漠；赫兰：NAT-025 南赫兰旱季沙地（边缘种群） |
| 分布（新增 81 国） | 赤砂 NAT-074 阿兹拉沙海北缘、NAT-076 达哈绿洲外缘、NAT-077 法里商道、NAT-079 伊玛山地沙谷、NAT-081 卡里盐邦、NAT-083 纳西绿洲、NAT-084 奥马尔；苍垠 NAT-056 赤岸沙地（边缘）；岛屿 NAT-112 赤渊火山灰地（亚种，待考证） |
| 栖息地 | 沙丘背风坡、盐壳裂隙、废弃井口、商路驼道旁的碎石带；白天埋沙，夜间伏击。不进入湿润草地与连续林带。 |
| 气候 | 热荒漠与盐漠；耐旱、耐盐，依赖夜间凝结水与猎物血液；连续降雨会迫使它向高处迁移。 |
| 食性 | 小型兽、蜥蜴、昆虫、腐肉；也会伏击驼队掉队牲畜。捕食以螯钳夹持与尾部刺击为主，毒液用于麻痹而非瞬间致死。 |
| 天敌/竞争 | 天敌为大型沙蟒、猛禽与沙地妖兽；竞争者是其他伏击型沙地节肢类。沉沙螯会避开绿洲核心，避免与人类常住区正面冲突。 |
| 繁殖/生命周期 | 每季 1 窝，卵生 20—40 枚，埋于沙下；孵化后同类相食率高。寿命 5—8 年；种群随驼队路线与弃井数量上升。 |
| 种群/迁徙 | 不迁徙；商路废弃后种群下降，新井与临时营地会形成新的局部高密度点。 |
| 环境与人类影响 | 驼队与散客的主要风险之一；螯壳、毒液与尾刺可做蛊材、药材与护具；过度捕杀会导致小型兽类泛滥，反过来破坏沙地植被。 |
| 材料/产业/蛊虫 | 螯壳可制轻甲片与滤沙器；毒液可制麻痹类蛊材；活体可作沙地蛊师的反面教材。相关蛊只用既有低转毒道/土道凡蛊叙事，**不新增编号**。 |
| 国家/秘境关联 | 阿兹拉的商路法庭、乌祖商团保险、白镜盐湖采盐队、卡里盐邦的盐壳路都与它有产业关系；与秘境无直接绑定，沙地秘境边缘另有独立种群（待考证）。 |

**生态位一句话**：沉沙螯把“沙路风险”变成可定价的保险与护具产业；它不是随机怪物，而是荒漠商路生态的一部分。

### 15.3 O-B-012 阈鹿 · 秘境林缘的界隙宿主

| 项目 | 内容 |
|---|---|
| 分布（既有 39 国） | 苍垠：NAT-001 天枢山间秘境林缘、NAT-005 临江雾谷外缘、NAT-016 万岭高山林带；霜栎：NAT-007 冰下秘境林缘、NAT-031 白栎寒林；玄溟：NAT-006 深渊门上层林带、NAT-038 北溟雾林 |
| 分布（新增 81 国） | 苍垠 NAT-041 云溪高谷、NAT-045 石门山口、NAT-049 江原峡谷；霜栎 NAT-086 北雪林带、NAT-090 极光林缘、NAT-092 白夜雾林；玄溟 NAT-105 极夜地下林窗、NAT-107 地热雾林；岛屿 NAT-113 霜洋冰林（边缘，待考证） |
| 栖息地 | 秘境入口外 3—10 km 的林缘、雾谷、冰裂隙与地热泉带；不进入无秘境背景的纯城市或纯荒漠。 |
| 气候 | 寒温带、亚寒带与高山雾林；依赖稳定水汽与地热/冰隙形成的“界隙窗口”。 |
| 食性 | 苔藓、地衣、灌木嫩枝、矿盐；偶尔食小型兽。不是主动猎杀型妖兽，攻击多由护域或受惊触发。 |
| 天敌/竞争 | 天敌极少；竞争者是其他大型林栖妖兽。阈鹿不组织群体，通常独居或成对。 |
| 繁殖/生命周期 | 繁殖周期长，每 2—3 年一胎；幼鹿随母鹿在秘境边缘活动。寿命【待考证】；种群密度极低，不能写成“成群出没”。 |
| 种群/迁徙 | 随界隙窗口开合做短距迁移；窗口关闭时留在林缘，不跨洲迁徙。具体窗口时长【待考证】。 |
| 环境与人类影响 | 界隙窗口会影响局部空间稳定、迷雾与失踪事件；阈鹿本身不是“门”，不能把它的天赋等同于 O-G-110 的效果。 |
| 材料/产业/蛊虫 | 鹿角、苔盐、界隙残留物可作研究材料；**O-G-110 界隙蛊只登记在 O-B-012 阈鹿身上，不复制、不替换、不新增宿主**。阈鹿不能像蛊师一样主动催动 O-G-110；携带≠控制≠炼化。 |
| 国家/秘境关联 | 临江雾谷、天枢山间秘境、北雪林带、极夜地下林窗是主要叙事点；与 12 座有名秘境中的临江雾谷、霜栎冰下城、北溟深渊门有边缘关联，但不把阈鹿写成秘境主人。 |

**不可改动边界（原样保留）**：O-B-012 阈鹿携带 O-G-110 界隙蛊；O-G-110 为唯一特殊登记仙蛊，不计入 O-G 44 只正式档案，不复制给其他妖兽；阈鹿的界隙感知是本体天赋，**不得强行解释成 O-G-110 的蛊效**；捕获≠炼化≠催动。
