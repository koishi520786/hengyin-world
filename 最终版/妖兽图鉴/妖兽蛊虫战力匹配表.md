### 0.3 字段定义与「未知」规则

基准库每条固定 14 列：**编号｜名称｜品阶转数｜流派｜具体能力｜作用距离｜攻击方式｜发动条件｜真元或仙元消耗｜持续时间｜使用限制｜已知弱点｜适用目标｜可信度**。

- 「具体能力」照录权威资料、可压缩不改义；「流派」仅在原文出现「某道／某类蛊虫」时照录，否则写「未知」。
- 作用距离／攻击方式／发动条件／消耗／持续／限制／弱点／适用目标：原著未写即写「未知」（＝【原著未明确】），**绝不虚构数值与章节**。原文有实据的（如月光蛊「攻击范围十米」、青丝蛊「一次性消耗三成青铜真元」、蛇毒蛊「对大型猛兽效较慢」）照录。
- 「品阶转数」：条目逐字标注者照录；仅由合集分转段位可推者写「X 转凡蛊／仙蛊（按段位）【合理推测】」；转数不明段写「仙蛊（转数不明）【原著未明确】」。

### 0.4 铁律 2／3 的成文对照（判定前必读）

1. **凡蛊／仙蛊分界**：一至五转为凡蛊，六转及以上为仙蛊（十转存疑，【原著未明确】）。蛊真人蛊虫合集 7.1：真元「一转青铜、二转赤铁、三转白银、四转黄金、五转紫晶」，仙元「六转青提、七转红枣、八转白荔、九转黄杏」。
2. **转数≠绝对战力**：合集 7.3「转数非强度刻度：一切蛊虫皆可升级，所谓转数不可尽信，只取文中初次出现时的转数」。判定看机制、部位、条件、消耗、结果，不按转数直接给胜负。
3. **单蛊能力与多蛊杀招分开**：第一节基准库只收**单只蛊虫**能力；多蛊协同只在第六节「蛊虫组合测试」以杀招（C-K／O-K）形式出现，且不把杀招威力倒推给组件蛊单独使用。
4. **不得假定所有仙道杀招必耗仙元**：蛊虫合集 6.5「鬼官衣（幽魂，魂道防御）：**不耗仙元、耗魂魄底蕴**」；原创 O-G-107 存息蛊限制表亦以「鬼官衣不耗仙元但耗魂魄底蕴」为消耗形态依据。仙道杀招的消耗须逐招核对，可能是仙元、魂魄底蕴、寿元、心力、气运、道痕等，也可能不耗仙元。
5. **低转催动高转蛊有额外限制**：合集第五节「蛊虫转数宜与蛊师修为匹配：高级蛊师用低级蛊如壮汉舞软剑，**低级蛊师用高级蛊如孩童挥重锤**」；C-G-250 偃月仙蛊「七转只能催三到四指」（见 6.5 五指拳心剑）。低转蛊师催高转蛊须判真元品质／储量不足、催动不稳、效果打折或反噬，不得按满效果判定。
6. **道痕不是万能能量**：道痕是流派修为的载体，须同流派、须境界（大宗师「直接利用自然界道痕」、道主「超脱仙元令杀招永存」）；多流派道痕互斥（C-G-539 纲：杀招天纲地常「让道痕不互斥」反证互斥是常态）；「成功道痕一道至多用于六转仙蛊，七转八转需更多道」（第五节三）；O-G-109 敛痕蛊「不生痕、不增益修为、多流派痕砂混杂时受道痕互斥硬约束」。不得把道痕当通用能量池随意驱动任意能力。
7. **不得给妖兽随意加空窍／真元／炼蛊能力**：空窍、元海、真元、炼化／炼蛊、杀招催动是**蛊师体系**；妖兽默认只有肉体／器官／元素／血脉／精神／灵魂等天然能力。妖兽「携蛊」只能是**被动寄生、共生或野生蛊附体**，不因此获得空窍、真元、主动炼蛊与随意催动杀招的能力（详见输出 2 第八节兼容检查表）。
8. **禁模糊话**：禁止「实力强大／防御极高／普通蛊师难以对付」。所有结论必须落到**机制、部位、条件、消耗、结果**；资料不足写「未知」／【原著未明确】，绝不虚构数值与章节。

## 二、妖兽身体防御与抗性的通用判定框架

> 本节为**通用框架**【合理推测：本项目为跑团判定所立的机制层，非原著逐字】；逐种妖兽的具体部位数值、专属抗性与弱点写在《原创妖兽图鉴》各档案第十节，本节不代替也不复制。

### 2.1 部位分级（9 类）

| 部位 | 结构特征 | 默认承伤职能 | 判定要点（须落到机制） |
|---|---|---|---|
| 外皮 | 表皮／毛发／黏膜 | 抵御擦划、浅表切割、接触类毒的**首道**屏障 | 破外皮仅计「仅表面伤」；黏膜（眼、口、鼻、创面）视为外皮缺口，毒／气／粉末可由此入体 |
| 鳞甲 | 角质／矿化／叠瓦状硬片 | 抵御穿刺、斩击、钝击的**硬质**层 | 须判「破甲」还是「弹开」；叠瓦缝隙、甲片接缝、换甲／蜕皮期为空隙；水系／钻刺类可能沿缝入内 |
| 肌肉 | 厚实肌层／脂肪 | 吸收动能、保护深部 | 厚肌可把「破甲」降级为「中伤」而非「伤及内脏」；但钝击震荡可越过肌层传至内脏 |
| 骨骼 | 骨板／肋骨／甲壳内骨架 | 保护内脏、支撑形体 | 破骨不等于伤内脏；骨折主要影响机动与结构；C-G-185 松骨蛊类「松软骨骼」属跨层打击 |
| 内脏 | 心肺／脏器／血脉 | 生命维持 | 「伤及内脏」为重伤以上门槛；须经穿甲、穿肌，或由毒／气／震荡／声波绕过前两层抵达 |
| 头骨 | 加厚颅骨 | 保护脑与感官 | 通常最硬；但眼、耳、囟门、鼻腔为天然开口；对头骨强攻多为「破甲／弹开」，致命中枢需命中开口或穿透 |
| 眼 | 眼球／瞬膜 | 视觉 | 显式弱点：无厚甲；强光、粉末、眩晕、对视类魂道（如 C-G-204 金刚怒目蛊须对视）由此进入 |
| 翅肢 | 翼膜／肢节／尾／触须 | 机动、平衡、攻击 | 翼膜薄、易撕裂；打断翅肢主要削机动而非致死；关节缝为结构弱点 |
| 特殊器官 | 毒囊／发光器／电感器／囊袋／腺体 | 能力来源 | 破坏该器官＝剥夺对应能力（吐息、毒液、电场、发光）；往往有外露开口或薄壁，是「绕过肉体防御」的指定入口 |

**通用规则**：判定必须逐级过「外皮→鳞甲→肌肉→骨骼→内脏」，每一层给出**通过／被阻／被绕**及原因；不得只写「防御高」。「绕过肉体防御」指攻击不经上述层级、直接作用于内脏／魂魄／状态（见 2.6）。

### 2.2 恢复能力（判定口径，不预设数值）

| 恢复类型 | 机制 | 判定要点 |
|---|---|---|
| 无恢复 | 伤口不闭合 | 轻伤可累积成重伤；持续伤势有意义 |
| 自然愈合 | 随时间闭合血肉伤 | 须给「速率／是否留疤／是否恢复器官功能」，无据写「未知」 |
| 再生 | 断肢／器官重长 | 须区分「能否再生特殊器官」「是否消耗储备」「再生期间是否更脆弱」 |
| 蛊／共生体代偿 | 身上被动寄生野生蛊替宿主挡伤或修补 | **须单独核对蛊的编号与能力**，不得把蛊能力算成妖兽肉质；寄生蛊死亡／离体即失去代偿 |
| 蜕皮／换甲 | 周期性替换外层 | 换甲期鳞甲防御临时下降，是明确时间窗口 |

> 铁律：妖兽恢复能力属于肉体／生理，**不等于蛊师的治疗蛊**。不得因妖兽「恢复快」就假定它拥有空窍、真元或能催动 C-G-162 人如故一类宙道复原蛊。

### 2.3 特殊抗性（须写明「对什么、通过什么机制、到什么程度」）

| 抗性类型 | 判定口径 |
|---|---|
| 元素抗性 | 对炎／冰／雷／水等：写明是「鳞甲隔热」「体液导电」「毛皮疏水」还是「体质」，并给出可承受上限（无据写未知） |
| 毒抗性 | 写明「解毒腺／血脑屏障／体型稀释／共生蛊分解」；并核对速度——原著明载 C-G-563 蛇毒蛊、鸠毒蛊「对大型猛兽效较慢」、C-G-565 蜂毒蛊「被熊体克制」，这类口径须进入判定 |
| 魂／精神抗性 | 写明「有无魂魄、魂魄强弱、是否无心智」；无魂则魂道攻击无效（结果「无效」），有魂但强则降级 |
| 控制抗性 | 写明对束缚／定身／催眠的抵抗机制（体型、多足、无中枢神经、鳞甲导电免疫等） |
| 空间／封印抗性 | 写明是否受宇道／阵道影响；须核对蛊的前置条件（如定星蛊须先种、洄游蛊须埋标记） |
| 道痕相关 | 妖兽若被设定带道痕，须写明流派、数量、来源；**道痕不是万能能量**，不得据此让妖兽随意催动任意蛊或杀招 |

### 2.4 明确弱点（必须成对出现「弱点部位／触发条件／后果」）

- 每个弱点写明：**部位**（眼、囟门、甲缝、黏膜、特殊器官开口、翼膜）、**触发条件**（何种攻击方式、何种状态、何种时段）、**后果**（轻伤／中伤／重伤／致命／特殊控制／能力被剥夺）。
- 弱点不得只写「腹部较软」；须写「腹部无鳞甲覆盖，穿刺类攻击命中即由『仅表面伤』升为『伤及内脏』」这类机制句。
- 换甲期、蜕皮期、产卵期、进食时、特殊器官外露时，是**时间型弱点**，须标注窗口时长（无据写未知）。

### 2.5 四类破防判据（攻击结果归类）

| 判据 | 定义（机制句） | 典型成因 |
|---|---|---|
| 破甲 | 攻击穿透／破坏鳞甲或硬化外层，但未稳定伤及肌层以下；结果为「轻伤～中伤」 | 穿刺、钻破（C-G-100 水钻蛊）、高动能钝击、沿甲缝切入 |
| 仅表面伤 | 攻击止步于外皮／鳞甲表层，未穿透；结果为「微弱～轻伤」，可累积 | 擦划、被圆球水罩卸力（C-G-059 须圆球状）、被旋转光罩偏折（O-G-010 仅对直线有形攻击） |
| 伤及内脏 | 攻击越过前四层或由开口直达脏器／血脉／中枢；结果为「重伤～致命」 | 穿透后深入、震荡传导、经眼／口／鼻／黏膜入体、破坏特殊器官 |
| 绕过肉体防御 | 攻击不沿上述层级，直接作用于**状态／真元／蛊虫／魂魄／空间／时间**；结果多为「特殊控制」或内脏级后果 | 毒、魂、封印、控制、空间、宙道、运道、奴道 |

### 2.6 非肉体攻击如何绕过普通肉体防御

| 攻击类型 | 绕过机制 | 仍须核对的限制（不因「绕过」就无条件成立） |
|---|---|---|
| 毒道 | 经呼吸道／黏膜／创面／血液进入体内，不与鳞甲比硬度 | 须「进入体内」；受体型（大型效较慢）、解毒蛊（C-G-060 清热蛊、C-G-157 雪洗蛊、C-G-476 濯洗蛊）、体质克制（蜂毒被熊体克制）约束 |
| 魂道 | 直接作用于魂魄／心神，不经皮肉 | 须目标**有魂魄**；C-G-204 须对视、C-G-674 魂牵为牵拽；受壮魂／净魂（C-G-217）／魂道防御克制 |
| 封印 | 作用于「蛊虫／真元／空窍／空间通路」，令其失效或沉眠 | C-G-160 乌七蛊**只封六转以下蛊虫**；C-G-194 符底抽薪蛊抽出并封镇蛊师体内蛊虫；对无蛊妖兽多数不生效 |
| 控制 | 作用于行动／状态／时间，不造成物理穿透 | C-G-240 瞬不转仅六瞬间；C-G-207 铁索束缚「行动」；C-G-305 僵滞蛊须配金针蛊；受体型／结构／抗性约束 |
| 空间 | 改变位置／拉入异空间／隔离，绕过「打不穿」 | C-G-183 斗空蛊把敌我拉入另一空间死战、须分胜负或真元耗尽才出；C-G-228 定仙游须地点印象；O-G-008 洄游蛊须预置标记且两里/三里内 |
| 状态类（点化、睡眠、发情） | 命中即改写状态，不比硬度 | C-G-190 点金蛊须「被射中」；C-G-377 席地草令生物入梦；C-G-327 发情蛊须「吸入光粉」——闭气／无呼吸目标不触发 |

> 关键约束：**绕过肉体防御 ≠ 自动命中、≠ 自动生效**。每条仍要过「发动条件／作用距离／命中方式／目标是否有对应承载（魂魄、呼吸道、蛊、真元）／抗性／克制」六关。

## 三、蛊虫攻击效果矩阵

### 3.1 七级效果定义

| 级别 | 定义（机制句） | 对战斗判定的含义 |
|---|---|---|
| 无效 | 攻击未满足发动条件，或作用机制被目标结构／抗性完全挡回，未产生任何状态改变 | 不扣任何持续资源、不改变战局；须写明「被哪一层、以何机制挡回」 |
| 微弱 | 仅造成外皮级擦划／短暂干扰，不累积为有效伤势 | 单次不计入伤势累积；可附加极短硬直 |
| 轻伤 | 破外皮或浅入肌层，未及骨骼／内脏；可自愈 | 计入伤势累积；轻微影响机动 |
| 中伤 | 深入肌层或破甲后稳定命中，或破骨但未及内脏；影响机能 | 明显削机动／出力；可叠加失血、疼痛 |
| 重伤 | 伤及内脏、中枢、大血脉，或特殊器官被毁、能力被剥夺 | 战力大幅下降；可能失去某类攻击／防御能力 |
| 致命 | 摧毁生命维持机能（心肺／脑／中枢）或触发即死机制 | 判定为击杀前提，但**仍需第七节「能杀≠能安全取蛊」复核** |
| 特殊控制 | 不沿伤害层级，直接施加束缚／定身／催眠／封禁／位移／奴役等状态 | 单列一类；须写控制时长、解除条件、对蛊师催动的打断效果 |

### 3.2 判定流程（顺序不可跳）

1. **核编号**：攻击所用蛊／杀招编号是否在权威文件真实存在；查不到→【未识别野生蛊虫】／【待考证】，不进入判定。
2. **分单蛊／杀招**：是单只蛊虫能力，还是多蛊杀招（C-K／O-K）？杀招须核对组件、同时催动限制、真元压力（见第六节），不得把杀招效果当单蛊用。
3. **核发动条件**：喂养、前置标记、对视、接触、地点印象、供真元、转数匹配（低转催高转须判「孩童挥重锤」）；任一不满足→「无效」或打折。
4. **核消耗**：真元／仙元品质与储量、或魂魄底蕴／心力／寿元／气运／道痕；**不得默认仙道杀招必耗仙元**（鬼官衣不耗仙元、耗魂魄底蕴）。
5. **核作用距离与命中方式**：射程、直线／曲线／自动寻敌、是否须命中开口；脱靶→「无效」。
6. **过部位层级**：外皮→鳞甲→肌肉→骨骼→内脏／头骨／眼／翅肢／特殊器官；逐层给「通过／被阻／被绕」。
7. **过抗性／弱点**：元素、毒、魂、控制、空间；命中明确弱点则升级，命中强抗则降级。
8. **定级**：按 3.1 落到七级之一，并写**机制原因**（哪一层、什么条件、耗了什么、结果是什么）。
9. **复核后续**：是否产生持续伤势、是否破坏防御蛊、是否打断催动；结果若为「致命」，转第七节。

### 3.3 三个完整示范（真实蛊虫 × 假想防御）

> 示范中的「假想防御」为跑团判定用的构造样例【合理推测】，非任何原创妖兽档案正文；真实蛊虫的能力、射程、限制全部照录基准库。

**示范 A：C-G-011 月光蛊（一转·月刃·射程十米）× 假想「叠瓦矿化鳞甲 + 厚肌」中型妖兽**

| 项 | 内容 |
|---|---|
| 发动条件 | 蛊师一转、月光蛊已喂养月兰花瓣（早晚各 2 片）；目标在十米内 |
| 命中方式 | 巴掌大幽蓝月刃，直线 |
| 部位层级 | 月刃为切割型、单体、一转；命中叠瓦矿化鳞甲**被弹开／只在甲面留浅痕**，未穿透鳞甲层，更未达肌肉 |
| 抗性 | 矿化鳞甲对低转动能切割抗性充足 |
| 结果 | **仅表面伤（微弱～轻伤）** |
| 机制原因 | 不是「防御高所以无效」，而是：一转月刃攻击力未最大化（对照 C-G-056 月芒蛊才「最大化增幅」、C-G-055 月痕蛊「攻击力不变」），切割型攻击未沿甲缝切入、未形成钻破或震荡传导，能量在鳞甲表层被分散，故只达表层 |
| 升级条件 | 改沿甲缝／换甲期切入，或改用 C-G-100 水钻蛊（钻破山石钢铁、攻坚）判「破甲」；或经眼／口黏膜入体判「绕过肉体防御」 |

**示范 B：C-G-563 蛇毒蛊、鸠毒蛊（毒道）× 假想「大型、鳞甲致密、有解毒腺」妖兽**

| 项 | 内容 |
|---|---|
| 发动条件 | 毒须进入体内（呼吸道／黏膜／创面）；本蛊「毒道蛊虫，但对大型猛兽效较慢」 |
| 命中方式 | 毒（具体释放方式原著未明确→未知），须先达成「入体」 |
| 部位层级 | 不经外皮／鳞甲硬度比对，属**绕过肉体防御**候选；但须先有入体通道 |
| 抗性 | 大型体型稀释 + 解毒腺；原著明载「对大型猛兽效较慢」 |
| 结果 | **微弱（起效延迟）→ 若解毒成功则「无效」** |
| 机制原因 | 不是「有毒就赢」：毒绕过的是硬度而非「剂量—时间—解毒」三关。大型目标体液稀释使有效浓度上升慢，解毒腺持续分解，故在起效前存在可被 C-G-060 清热蛊／C-G-157 雪洗蛊／C-G-476 濯洗蛊或自身代谢清除的窗口；若毒始终未进入体内（鳞甲无缝、无黏膜接触），则直接「无效」 |
| 升级条件 | 先造成开放伤口（示范 A 的「破甲／伤及内脏」）再施毒，或经眼／口黏膜给药，缩短起效时间 |

**示范 C：C-G-204 金刚怒目蛊（五转·对视攻击心魂）× 假想「无瞬膜、有魂魄、鳞甲极厚」妖兽**

| 项 | 内容 |
|---|---|
| 发动条件 | 催动后**须与目标对视**；目标须有心魂 |
| 命中方式 | 无形目光，一旦对视直接攻击对方心魂 |
| 部位层级 | 不经外皮／鳞甲，属**绕过肉体防御**，直接作用于心魂 |
| 抗性 | 目标有魂魄（故不「无效」）；鳞甲厚度与此攻击无关；未给魂魄强度→「未知」 |
| 结果 | **特殊控制（心魂受击）**，具体级数依魂魄强度（未知）待判；不写「重伤」因为原著未给心魂受击的伤害量 |
| 机制原因 | 不是「防御高所以无效」反过来变成「必中」：鳞甲对心魂攻击不构成屏障，故「绕过肉体防御」成立；但成立的前提是「对视」这一命中条件被满足，且目标有魂魄。若目标闭眼／无眼／无瞬膜遮挡视线/以遮蔽物阻断对视，或目标被设定为无魂魄，则结果为「无效」 |
| 反制 | 阻断对视（C-G-036 隐石蛊隐去身体、烟幕、闭眼）、魂道防御、壮魂类；对视类魂道与「范围攻击／钝击」无关 |

以上三条示范均把结果落到机制、部位、条件、消耗与结果，不以「防御高」作结论。

## 四、妖兽对蛊师攻防矩阵

### 4.1 通用框架与五个分析维度

> 本节方向是「**妖兽攻、蛊师防**」【合理推测：判定层框架】。铁律：**不得为强化妖兽而随意判定蛊师防御失效**。蛊师防御蛊的有效性必须按其原著机制逐条核对，妖兽攻击要成立，须满足「命中方式／部位／条件／消耗」，不能一句「妖兽力大」就击穿。

每次交锋除给「防御结果」外，必须逐一回答以下五问（Yes／No + 机制原因）：

| 维度 | 判定问题 | 常见机制依据 |
|---|---|---|
| ① 能否破坏防御蛊 | 攻击是否作用于**蛊虫本体／真元供给／催动者**，而不只是护罩表面？ | 护罩类（C-G-059 水罩蛊、C-G-133 水幕天华蛊）挡的是「伤害」而非「对蛊本体的封禁」；C-G-160 乌七蛊、C-G-194 符底抽薪蛊才直接作用于蛊 |
| ② 能否击穿身体强化 | 是否越过硬化皮／骨层伤及内脏？ | C-G-018 玉皮蛊、C-G-034 铜皮蛊、C-G-127 古铜皮蛊、C-G-115 钢鬃蛊、C-G-101 玉骨蛊、C-G-145 精铁骨蛊、C-G-618 金钢筋蛊、C-G-619 钢筋蛊、C-G-620 钢衣蛊均为「 hardening 肉体」；震荡／钻刺／毒入体可绕 |
| ③ 能否追上移动蛊 | 妖兽机动是否能抵消位移？ | C-G-447 气遁蛊「单论直线速度天下第一」、C-G-153 金霞蛊、C-G-661 风驰、C-G-131 横冲直撞蛊、O-G-008 洄游蛊（须预置标记）、C-G-228 定仙游（须地点印象） |
| ④ 能否打断催动 | 是否造成硬直／失聪／惑乱／真元断供，使蛊师无法持续供真元？ | 多数防御蛊须「持续供真元」（O-G-010 转灯蛊、O-G-001 回声蛊）；C-G-132 正气蛊使心志不坚者不战自溃、C-G-495 狮吼蛊让敌方蛊师乱阵脚、C-G-169 天地宏音蛊音浪群攻（反向：蛊师压制妖兽） |
| ⑤ 能否造成持续伤势 | 是否留下失血、中毒、感染、骨折、器官损毁等跨回合后果？ | C-G-111 血月蛊「伤口血流不止」；C-G-020 生机叶疗伤后一小时内其他无效；毒须核对解毒蛊 |

### 5.3 八级结果分类

| 级别 | 定义（机制句） |
|---|---|
| 轻松击杀 | 蛊师输出机制对口弱点、能在自身消耗可承受内达成「致命」，且击杀后取蛊／撤离无额外阻碍 |
| 优势明显 | 蛊师多数交锋维度占优，能稳定压制，但仍须付出一定真元／蛊损耗，存在个别未被覆盖的威胁 |
| 较大胜算 | 正面取胜概率高，但依赖关键蛊成功催动或某条前置条件（标记、对视、地点印象）；条件失手则降级 |
| 取决于搭配 | 胜负主要由「蛊组合是否对口 + 情报是否正确」决定，而非境界；换一组蛊结果反转 |
| 势均力敌 | 双方各有可成立的攻防机制，须逐回合按第三／四节矩阵裁定，无一方能稳定压制 |
| 明显劣势 | 蛊师多数防御不对口或真元不足，须靠撤退 / 特殊克制 / 外部条件才不被击溃 |
| 基本无法正面取胜 | 妖兽关键机制（绕过肉体防御、破前置、断真元）稳定成立，蛊师正面配置无解 |
| 主要靠撤退或特殊克制 | 正面不可取，但存在移动蛊撤离（C-G-447 气遁蛊、C-G-228 定仙游、O-G-008 洄游蛊）或某只针对性蛊的窄窗口 |

### 5.4 为何「三转蛊师」不是固定战力 + 判定因子如何进入

**结论**：转数只决定**真元品质与储量上限的档位**，不决定战力。同为三转（白银真元），配置①～⑦、所带蛊、杀招、情报、环境不同，结果可横跨「轻松击杀」到「基本无法正面取胜」八级。合集 7.3「转数不可尽信」、7.1「蛊虫转数宜与蛊师修为匹配」共同支撑。

| 判定因子 | 如何进入判定（机制句） | 依据 |
|---|---|---|
| 修为（转数×初中高巅） | 决定真元品质／储量档位、可稳定催动的蛊转数上限；不直接给胜负 | 合集 7.1 |
| 真元品质与储量 | 决定能否供起「持续供真元」类蛊（O-G-010 转灯蛊、O-G-001 回声蛊）、能否连催多蛊、能否催动杀招 | 7.1 品质表；C-G-164 功倍蛊「转数越高真元消耗越多」 |
| 蛊的组合 | 单蛊能力有限，须按兼容性组织；组合是否对口目标弱点，决定「取决于搭配」级 | 第六节；铁律「蛊虫单独能力与多蛊杀招分开」 |
| 杀招 | 多蛊协同可越过单蛊上限，但须核对组件、同时催动、真元压力、发动条件；不得假定仙道杀招必耗仙元 | 第六节；鬼官衣「不耗仙元、耗魂魄底蕴」 |
| 道痕 | 仅同流派、达相应境界（大宗师用自然道痕、道主超脱仙元）方可用；多流派互斥；「成功道痕一道至多用于六转仙蛊」；**不是万能能量** | 合集第五节三、7.2 境界十阶、C-G-539 纲「让道痕不互斥」、O-G-109 敛痕蛊 |
| 经验 | 决定能否识别弱点、选择对口蛊、判断撤退时机；不写数值，只写「是否触发配置④／⑥」 | 【合理推测】 |
| 情报 | 决定配置④「专门针对」是否成立；情报错→对口蛊选错→防御不对口 | 2.4／4.2；C-G-161 五行熊皮蛊仅对五行 |
| 环境 | 水道／静水／嘈杂／黑暗／空间封闭分别影响对应蛊（C-G-189 激突蛊、O-G-001 回声蛊被静水削弱、C-G-228 定仙游需地点印象、C-G-133 无法移动） | 各蛊「使用限制／弱点」列 |

## 七、八种战斗结果的判定条件

> 铁律：**「能杀≠能安全取蛊」「能败≠能长期驯服」**。八种结果各有独立门槛，不得互相替代；每条都落到机制、条件、消耗、结果。

| 结果 | 判定条件（须全部满足） | 常见误区（明确禁止） |
|---|---|---|
| 击退 | 使目标**脱离交战／退出指定区域**且短期内不回；可由伤害、威慑、位移、地形达成；目标未必负伤 | ≠击败：目标仍具完整战力，只是离开；须核对是否真「不回」（否则只是暂退） |
| 击败 | 目标**丧失继续战斗的能力**（力竭、重伤、被控制、关键器官／能力被剥夺），但生命体征尚存 | ≠击杀；≠活捉（击败后目标可能逃走或反扑）；须写明「因何丧失能力」 |
| 击杀 | 生命维持机能终止（心肺／脑／中枢损毁，或触发即死机制），按第三节「致命」级复核 | ≠「能安全取蛊」；死后蛊的状态另判（见下） |
| 活捉 | 在**存活**状态下被稳定控制且可运输；须同时满足「击败／压制」+「 restraint 手段」+「不使其自毁／逃逸」 | 缺任一即不成立；控制须写时长与解除条件 |
| 驯服 | 长期改变其意志／归顺，须有**持续机制**（喂养、契约、伴生、奴道蛊），并承受断食／反噬／环境后果 | ≠击败；击败只解决「当下不能打」，不解决「日后听命」 |
| 奴役 | 以**奴道／驾驭蛊**建立主从，须核对蛊的适用范围：C-G-170 奴隶蛊「能控制五转蛊师为己所用」、C-G-040 驭犬蛊限犬类、C-G-210 驭狐蛊限狐类、C-G-177 御鹤蛊限鹤类、C-G-665 驯兽师蛊「最克制野兽、最擅长将野兽驯服化为己用」 | 不得用「限犬类」的蛊去奴役非犬类；不得把「吸引／引来」（C-G-380 引狼蛊、C-G-327 发情蛊）当成长期奴役 |
| 捕获野生蛊虫 | 野生蛊**无主**，须专门捕蛊／封印手段：C-G-454 水笼蛊「专门被用来捕捉野生蛊虫，有着奇效」；C-G-526 矩蛊 + C-G-577 规蛊「与规蛊合力能捕获天下所有的蛊，包括九转蛊，使用一次增加一个条件」；C-G-143 皓珠蛊／C-G-683 龟息蛊「封印蛊虫使沉眠易保存」；C-G-168 地藏花王蛊「用于储藏蛊虫」 | ≠击杀宿主后自动获得；野生蛊可能逃逸／反噬；「使用一次增加一个条件」是规／矩蛊的硬代价，须计入 |
| 捕获仙蛊 | 在上一行基础上追加：仙蛊**同名天下唯一、有意志、多需特定食物**（春秋蝉食光阴河水、定仙游食仙元、智慧蛊需寿蛊）；捕获 ≠ 炼化 ≠ 催动；还须核对仙蛊唯一性铁律（「只要此蛊尚存，所有尝试炼制必失败」，仿伪蛊是唯一例外） | ≠把仙蛊当普通战利品；不得假定捕获即可使用；不得绕过「低转催高转蛊如孩童挥重锤」 |

### 7.1 「能杀≠能安全取蛊」

- 击杀只解决「目标不再反抗」，**不解决其身上蛊的状态**。野生蛊／共生蛊／寄生蛊在宿主死亡后可能：逃逸、反噬取蛊者、自毁、或随宿主气息消散（参照 C-G-085 冥路蝶「蛊虫一死，魂香便散」所体现的「蛊—宿主状态绑定」）。
- 安全取蛊须额外满足：①先以 C-G-143 皓珠蛊／C-G-683 龟息蛊封印沉眠，或 C-G-561 蒙尘蛊／C-G-425 暗投蛊减弱其气息；②核对蛊是否有主动攻伐能力（如 C-G-566 蝎针蛊带毒、C-G-235 暗箭仙蛊自动寻敌）；③若是仙蛊，追加第七行「捕获仙蛊」条件。
- 契约中 O-B-008 泥囊螈「携大量被动寄生野生蛊」、O-B-012 阈鹿「携野生仙蛊」即属此类：击杀档案中的妖兽，不等于能安全取得其蛊；具体蛊编号须在《原创妖兽图鉴》对应档案核对，未给编号者写【未识别野生蛊虫】。

### 7.2 「能败≠能长期驯服」

- 击败是**一次性战力清零**，驯服是**跨回合的意志／机制维持**。二者判据不同。
- 长期驯服须持续投入：喂养（原创蛊档案均载「断食后果」，如 O-G-001 回声蛊「回响逐次变闷、蜕壳硬化裂开、蛊亡」）、契约／律道约束、伴生蛊同源炼化（O-K-001 加蛊改良须「与记仇蛊同源炼化」）、以及奴道蛊的适用范围。
- 任何「一次击败即永久听命」的判定都违反本节；须写明维持机制、维持成本、失效条件（断食、被梦道／律道消解、被更高明手段夺控）。
