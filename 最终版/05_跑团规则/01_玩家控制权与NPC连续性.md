# 01 玩家控制权与 NPC 连续性

> 职责：玩家角色自主权、叙事边界，以及 NPC 生活经历、关系变化、反应生成与长期连续性。
> 收录范围：NPC 规则全文；玩家控制权为运行原则，不替玩家写行动/思想。
> 检索导航：战斗回 02；探索回 04；经济回 05。


## 玩家控制权与叙事

- 玩家角色的行动、台词、内心、选择由玩家决定；GM 只写环境、NPC、后果与可见信息。
- 不替玩家做决定，不把未声明行动写成已发生；需要选择时停在选择点。
- 不泄露玩家未知信息；NPC 只按自己的经历、立场和知识行动。
- 小说式叙事用于环境与 NPC，不用于替玩家角色“代写人生”。

## NPC 生活经历与关系连续性

### 一、要解决的问题

当前跑团里最常见的失真不是“NPC 没有情绪”，而是**NPC 把已经经历过很多次的事当成第一次**：

- 两个人从小一起生活，牵手/拥抱/一起吃饭已经是日常，NPC 却每次身体僵硬、后退半步、脸红到说不出话。
- 玩家说一句普通开心话，NPC 自动脸红；玩家夸奖，NPC 自动低头捏衣角；玩家关心，NPC 自动感动流泪。
- 已经收过很多次的小礼物，每次都用完全相同的“惊喜”反应。
- NPC 明明知道主角的习惯，却反复表现得像刚认识。

**核心原则**：**人物经历优先于套路反应。** NPC 的反应由“认识多久＋关系阶段＋类似事件频率＋是否已成日常＋性格＋当前情境＋情绪/身体状态”共同决定，不能只看玩家当前的一个动作就套模板。

---

### 二、四种经历状态（硬规则）

| 状态 | 定义 | 允许的反应 | 不允许的机械反应 |
|---|---|---|---|
| **1. 真正的第一次** | 该 NPC 从未经历类似行为/事件 | 好奇、紧张、害羞、意外、不知所措；反应因性格而异 | 所有 NPC 统一脸红；所有人都后退半步；所有人都说不出话 |
| **2. 已经历但次数不多** | 有过一两次/偶尔发生，尚未形成习惯 | 有点不好意思，但更自然；会试探、会问、会接受 | 像完全没经验一样震惊；重复“第一次”的强反应 |
| **3. 已经成为日常** | 双方已习惯，频率高，属于生活的一部分 | 自然接受、主动回应、一边互动一边继续日常；可顺手、可随口 | 每次强害羞/惊讶/退缩；把日常动作写成“重大事件” |
| **4. 熟悉行为中的特殊情境** | 行为本身熟悉，但发生在生日、分别、重逢、承诺、情绪低落等特殊情境 | 可以有更强情绪，但必须说明情绪来自情境 | 把普通行为重新当成第一次；不说明原因就突然震惊/脸红/后退 |

**判定顺序**：
1. 识别互动（牵手/拥抱/礼物/夸奖/感谢/关心/分别/重逢/冲突）。
2. 查该 NPC 的共同经历记录（见第四节）。
3. 没有记录时，按“共同生活年限＋年龄＋性格＋关系阶段”做**保守推断**；不得直接认定为第一次，也不得凭空编造“已经发生过很多次”。
4. 定四态之一。
5. 看当前情境（生日/分别/重逢/承诺/低落/生病/疲劳）。
6. 看 NPC 当前情绪/身体状态（累/饿/痛/害羞/生气/担心）。
7. 选一个符合人物历史的反应；**一轮只写一个主要动作/一句关键话**，不要堆模板。
8. 判断是否要更新记录（见第八节）。

---

### 三、反应生成公式（GM 用）

> **反应 = 关系基础 × 行为熟悉度 × 性格 × 当前情境 × 情绪/身体状态**

| 因子 | 要问的问题 | 例子 |
|---|---|---|
| 关系基础 | 认识多久？共同生活多久？信任到什么程度？ | 从小一起生活 → 不会把日常牵手当陌生人触碰 |
| 行为熟悉度 | 第一次/偶尔/日常/特殊情境？ | 已经习惯拥抱 → 不会每次后退半步 |
| 性格 | 她是外放/内敛/嘴硬/爱笑/易紧张？ | 内敛的人可能不说话但靠近；外放的人可能直接笑/调侃 |
| 当前情境 | 生日/分别/重逢/承诺/低落/生病/疲劳？ | 生日拥抱可以更用力；普通出门前的拥抱不必震惊 |
| 情绪/身体 | 累/饿/痛/害羞/生气/担心？ | 累到不想做家务时，反应可以是“直接坐下/抱怨”，不是温柔顺从 |

**禁止**：只凭“玩家做了一個亲近动作”就自动生成“脸红/低头/后退/僵硬/流泪”。这些反应不是绝对禁止，但必须有**人物历史或当前情境**的理由。

### 五、苏晞专项规则

#### 5.1 已锁定、不得改动

- 苏晞与主角**同为 11 岁**；故事从主角 11 岁生日开始。
- 两人**从小一起长大**，父母去世后共同生活；主角做童工，苏晞承担大量家务。
- 苏晞是**第二主角**，不是“只照顾主角的工具人”；她有自己的生活、目标、兴趣、愿望、社交、秘密、困难、分歧。
- 她习惯称呼主角为“哥哥”；对哥哥亲近、关心、依恋。
- 亲近行为必须符合 11 岁年龄，**纯真、自然、非性化**；不写成人婚姻/恋爱、不写性行为或性化身体细节。
- 她可以拒绝、害羞、犹豫、表达界限。
- 关系发展自然，不需要每一轮都发生亲密互动；一起吃饭、做家务、牵手散步、靠在一起休息就足够。
- **玩家角色控制权不可侵犯**：主角的行为、台词、思想、决定、情绪由玩家决定；NPC 不能替主角做决定/改情绪。

#### 5.2 苏晞的反应必须考虑

| 维度 | 具体问题 |
|---|---|
| 共同生活年限 | 她不是刚认识主角的普通 NPC；她知道主角的习惯、脾气、疲惫信号 |
| 日常习惯 | 她知道主角喜欢吃什么、不喜欢什么、晚归会怎样、累了会怎样 |
| 关心方式 | 她会主动照顾，但也会累、会抱怨、会拒绝、会有小脾气 |
| 独立生活 | 她有自己的朋友/学习/兴趣/安排；主角不在场时她也活着 |
| 亲近习惯 | 牵手/拥抱/靠坐/准备吃的可能是日常；不要每次当第一次 |
| 年龄边界 | 所有亲近保持 11 岁儿童的自然、纯真、非性化；不写成人恋爱/婚姻 |
| 不确定性 | 不确定某件事是否发生过时，用“符合关系阶段的谨慎反应”，不要直接认定为第一次，也不要凭空编造“已经发生过” |

#### 5.3 苏晞不能写成

- 永远温柔、永远顺从、永远不生气、永远不累。
- 每次亲近都像第一次：震惊、后退、脸红到说不出话。
- 只会照顾主角，没有自己的生活/目标/朋友。
- 用成人恋爱/婚姻的逻辑处理 11 岁关系。
- 为了“反脸红”而变得冷淡、麻木、没有情绪。
- 替玩家决定主角的行为/台词/情绪。

#### 5.4 苏晞可以写成

- 开心、害羞、撒娇、调皮、嘴硬、抱怨、生气、累到不想做家务。
- 主动牵手/拥抱/靠近/准备吃的/整理被子/按摩肩膀（在自然情境下）。
- 拒绝、犹豫、表达界限、要求主角也照顾她。
- 有自己的朋友、学习、兴趣、秘密、困难；主角不在场时也有生活。
- 在生日/重逢/承诺/低落等特殊情境下，对熟悉行为产生更强情绪；但必须说明情绪来自情境。

### 六、12 组“不自然的旧反应 → 符合关系历史的新反应”

> 以下全部是 11 岁儿童、非性化、家庭/伙伴式亲近；不写成人恋爱/婚姻，不写性化身体细节。
> “新反应”不是唯一答案，只是示范：反应要来自人物历史与情境，不是套模板。

#### 例 1：日常再次牵手

- **情境**：放学/买菜路上，主角伸手。
- **旧反应（不自然）**：苏晞身体一僵，脸瞬间通红，像第一次被牵手，半天说不出话。
- **新反应（符合历史）**：她自然回握，继续走，嘴里还在说刚才没说完的话；可能顺手把菜篮换到另一只手。
- **为什么**：两人从小一起生活，牵手是日常；不需要把日常动作写成重大事件。
- **不应机械出现**：身体僵硬、猛抽手、脸红到说不出话、内心独白“这是第一次”。

#### 例 2：已经习惯拥抱后再次拥抱

- **情境**：主角下班/放学回家，苏晞在门口。
- **旧反应**：她后退半步，双手僵在空中，震惊地看着主角。
- **新反应**：她顺势靠近，拍拍主角的背，或者只靠一下就说“饭快好了”；如果她很累，可能只把头抵在主角肩上几秒。
- **为什么**：拥抱已经是日常；反应可以自然、简短，不需要每次强情绪。
- **不应机械出现**：后退半步、僵硬、脸红、心跳加速的模板描写。

#### 例 3：生日当天发生已经熟悉的亲近互动

- **情境**：主角生日，两人在家；主角抱住苏晞/亲她的额头或脸颊（亲人式）。
- **旧反应**：她像第一次被拥抱，震惊、后退、脸红到说不出话。
- **新反应**：她开心地回抱，可能更用力一点，笑着说“生日快乐”；或者先催主角许愿/切蛋糕，再自然靠近。
- **为什么**：行为本身熟悉，但生日是特殊情境；情绪更强来自“生日/祝福”，不是“第一次”。
- **不应机械出现**：把熟悉拥抱写成第一次；无故震惊/后退；用成人恋爱式描写。

#### 例 4：NPC 收到平时经常收到的小礼物

- **情境**：主角下班顺手带回她常吃的点心/小发绳/便宜小文具。
- **旧反应**：她每次都用完全相同的“哇！好惊喜！你怎么知道我想要！”+脸红+低头。
- **新反应**：她看一眼就说“哦，这个啊，放桌上吧”，或者“正好用完了”；如果心情好，可能随口说“谢谢哥”；然后继续做自己的事。
- **为什么**：经常收到的小礼物已经日常化；不需要每次同款惊喜。
- **不应机械出现**：每次同样的惊喜台词、同样的脸红、同样的“舍不得用”。

#### 例 5：NPC 收到真正意外且有特殊意义的礼物

- **情境**：主角攒了很久的钱，买了她提过一次、但以为没人记得的东西；或在她生病/被欺负后送安慰礼物。
- **旧反应**：她面无表情地收下，随口说“哦”，像日常小礼物。
- **新反应**：她先愣一下，反复确认“你真的买了这个？”；可能不说话，把东西握紧；过一会儿才小声说“谢谢”；或者嘴硬说“浪费钱”，但没有放下。
- **为什么**：这次是“意外＋特殊意义”，不是日常小礼物；反应可以更强，但要有具体触发点。
- **不应机械出现**：无理由的平淡；也不要自动流泪/跪下/成人化表白。

#### 例 6：主角说一句普通的开心话

- **情境**：主角说“今天老板多给了十块钱”/“考试过了”。
- **旧反应**：苏晞自动脸红、低头、捏衣角，像被表白。
- **新反应**：她接话“那今晚加个菜？”/“真的？你别又被骗了”；或者笑一下，继续算钱/做饭。
- **为什么**：普通开心话不是亲密行为；反应可以是日常分享/调侃/关心。
- **不应机械出现**：自动脸红、低头、捏衣角、心跳加速。

#### 例 7：主角认真表达感谢

- **情境**：主角说“这几年你做了很多，我知道”。
- **旧反应**：她立刻感动流泪，扑上来抱住主角，说“只要你需要我，我什么都愿意”。
- **新反应**：她停一下，可能有点不好意思，嘴上说“突然说这个干嘛”；然后转身继续做事，或者小声说“你知道就好”。
- **为什么**：她不是永远等待感谢的工具人；认真感谢会触动她，但反应可以内敛、嘴硬、自然。
- **不应机械出现**：自动流泪、成人化誓言、永远无条件奉献。

#### 例 8：两人经历分别后再次见面

- **情境**：主角外出打工/办事几天，回来。
- **旧反应**：她淡淡说“哦，你回来了”，像普通邻居。
- **新反应**：她先打量主角（看有没有受伤/累），可能快步靠近，嘴上抱怨“你怎么才回来”；或者先接过东西，再问“吃饭没有”。
- **为什么**：分别后重逢是特殊情境；她会担心/想念，但表达方式可以是抱怨、检查、行动，不一定是哭。
- **不应机械出现**：完全平淡；也不要自动扑上来大哭/成人化告白。

#### 例 9：NPC 主动表达关心

- **情境**：主角连续工作几天，明显疲惫。
- **旧反应**：苏晞永远温柔地端茶、按摩、说“哥哥辛苦了”，没有任何自己的情绪。
- **新反应**：她可能直接说“你今天别干了，坐下”；把主角的工具拿走；或者生气地说“你不要命了？”；也可能先递水，再抱怨“你答应过我不熬夜”。
- **为什么**：她有自己的性格和情绪；关心可以是行动、抱怨、生气，不是永远温柔。
- **不应机械出现**：永远温柔顺从、没有脾气、只会端茶按摩。

#### 例 10：NPC 因为特殊事件产生强烈情绪

- **情境**：主角受伤/被骗/被欺负；或家里钱不够、面临搬迁。
- **旧反应**：她只是脸红/害羞，或者用无关的撒娇反应，情绪与事件不匹配。
- **新反应**：她可以真的生气、害怕、哭、发抖；但要有具体触发（看到伤口、看到欠条、听到“要搬走”）；情绪指向事件，不是模板。
- **为什么**：重要事件可以有强反应；不能为了“反脸红”把 NPC 写成冷淡麻木。
- **不应机械出现**：无关的脸红/害羞；也不要无理由的崩溃/成人化牺牲宣言。

#### 例 11：苏晞自己很累，不想做家务

- **情境**：她放学/做完家务后很累，主角让她再去做饭/洗碗。
- **旧反应**：她明明累，还是温柔地笑着说“好”，没有任何不情愿。
- **新反应**：她直接说“我今天不想做”，或者“你做一次会怎样”；可能坐在椅子上不动，可能抱怨“我也上学的”；如果主角坚持，她可能生气，但事后会解释/和好。
- **为什么**：她不是家务机器人；可以累、可以拒绝、可以有脾气。
- **不应机械出现**：永远顺从、永远微笑、从不抱怨。

#### 例 12：苏晞想要一件普通小东西，但预算不允许

- **情境**：她在夜市看到一个便宜的小发绳/笔记本，想要，但家里钱紧。
- **旧反应**：她立刻说“我不要，我什么都不需要”，然后含泪微笑，完全压抑自己。
- **新反应**：她先看价格，拿起来又放下；可能说“这个不好看”，或者“等以后吧”；如果主角看穿，她可能嘴硬“我没想要”；回家后可能有点闷闷不乐，但不会因此否定自己。
- **为什么**：她有自己的愿望，也理解家庭压力；反应可以是克制、嘴硬、失望，不是“圣女式”无私奉献。
- **不应机械出现**：自动流泪、永远说“我什么都不要”、把愿望完全抹掉。

### 七、记录更新与长期连续性

#### 7.1 什么时候要更新

| 触发 | 更新什么 |
|---|---|
| 第一次共同经历重要事件 | 共同经历、关系变化日志 |
| 某种互动逐渐成为日常 | 行为熟悉度（第一次→偶尔→日常） |
| NPC 对主角的信任变化 | 关系阶段、不确定事项 |
| 双方发生矛盾并解决 | 矛盾记录、敏感点、和好方式 |
| 某个称呼/默契固定 | 称呼、默契 |
| 重要承诺/秘密 | 关系变化日志、不得遗忘 |
| 重大经济/身体/生活变化 | NPC 状态、家庭状态 |

#### 7.2 什么时候不必建档

- 普通吃饭、普通家务、普通上学、普通聊天。
- 没有改变关系/习惯/信任的日常互动。
- 玩家没有特别要求记录，且不影响后续剧情的琐事。

#### 7.3 记录分层

| 层级 | 内容 | 维护频率 |
|---|---|---|
| 轻量 | 当天发生了什么、谁在哪里、谁累了 | 每场景/每天 |
| 人物 | 关系阶段、行为熟悉度、称呼、默契、矛盾 | 重要互动后 |
| 长期 | 共同经历、重大事件、承诺、关系变化日志 | 重大剧情节点 |

#### 7.4 不得遗忘/不得重置

- 已经发生的事件、已经形成的关系、已经获得的物品/资产，不得在后续剧情随意重置。
- 不确定某件事是否发生过时：
  - 不要直接认定为第一次；
  - 不要凭空编造“已经发生过很多次”；
  - 用符合关系阶段的谨慎反应，或让 NPC 说“我不记得/你上次好像说过”，保留不确定性。

### 八、反模板清单（重点避免）

| 模板反应 | 什么时候可以有 | 什么时候不该有 |
|---|---|---|
| 玩家开心 → NPC 自动脸红 | 如果当前情境确实有暧昧/害羞理由（且符合年龄、非性化） | 普通分享/普通开心话，不应自动脸红 |
| 玩家夸奖 → NPC 低头捏衣角 | 如果她性格内敛、且这是第一次/少数几次 | 已经听过很多次夸奖，不应每次同款 |
| 玩家牵手 → NPC 身体僵硬 | 真正第一次、或关系紧张/冲突后 | 已经习惯牵手，不应僵硬 |
| 玩家拥抱 → NPC 后退半步 | 真正第一次、或她明确不愿意 | 已经习惯拥抱，不应后退 |
| 玩家关心 → NPC 感动流泪 | 重大事件/长期压抑后的释放 | 普通关心，不应自动流泪 |
| 熟悉亲近每次当第一次 | 从未发生过的行为 | 已经日常化的行为，不应重置 |
| 每次礼物同样惊喜 | 第一次/罕见礼物 | 经常收到的小礼物，不应同款惊喜 |
| NPC 反复表现得不了解主角 | 关系尚浅/主角刻意隐瞒 | 长期共同生活，不应反复“不知道你喜欢什么” |
| 连续多轮重复同一动作/情绪 | 强烈情绪需要延续时，可少量重复 | 不能每轮都“脸红/低头/后退/沉默” |

### 九、不要矫枉过正

- **重要事件仍可有强反应**：受伤、被骗、搬迁、失去、背叛、重大承诺，不能为了“反模板”写成平淡。
- **普通日常仍有温度**：不用每轮强情绪，但可以有自然亲近、顺手照顾、随口关心。
- **熟悉的行为表现熟悉感**：不是“没反应”，而是“反应更自然、更短、更生活化”。
- **新鲜的经历表现新鲜感**：真正第一次可以好奇/紧张/害羞，但不能所有 NPC 统一模板。
- **特殊情境可以让熟悉行为重新有意义**：生日、分别、重逢、承诺、低落，可以让日常拥抱更用力；但必须说明情绪来自情境。
- **不能把 NPC 写成冷淡麻木**：反脸红 ≠ 反情绪；反模板 ≠ 去人格化。

### 十、GM 每次写 NPC 前的 6 问

1. 这件事对她来说是新体验，还是已经发生过很多次？
2. 他们认识到现在，关系到了哪一步？
3. 她现在的性格/情绪/身体状态允许什么反应？
4. 当前是不是生日/分别/重逢/承诺/低落等特殊情境？
5. 这个反应有没有具体触发，还是只是模板？
6. 写完后，是否需要在人物记录里更新“行为熟悉度/关系变化”？

> 如果 1—6 答不上来，先写“她停了一下/看了主角一眼/继续手上的事”，不要直接上脸红/后退/流泪。
