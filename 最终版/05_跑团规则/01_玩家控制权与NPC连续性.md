# 01 玩家控制权与 NPC 连续性

> 职责：玩家角色自主权、叙事边界，以及 NPC 生活经历、关系变化、反应生成与长期连续性。
> 收录范围：NPC 规则全文；玩家控制权为运行原则，不替玩家写行动/思想。
> 检索导航：战斗回 02；探索回 04；经济回 05；主角开局基线回 `04_世界/14_主角开局档案.md`；开放人物关系与人物表现回本文件第五节、`06_角色表现与主动互动.md`；开局流程回 `09`。


## 玩家控制权与叙事

- 玩家角色的行动、台词、内心、选择由玩家决定；GM 只写环境、NPC、后果与可见信息。
- 不替玩家做决定，不把未声明行动写成已发生；需要选择时停在选择点。
- 不泄露玩家未知信息；NPC 只按自己的经历、立场和知识行动。
- 小说式叙事用于环境与 NPC，不用于替玩家角色“代写人生”。

## NPC 生活经历与关系连续性

### 一、要解决的问题

当前跑团里最常见的失真不是“NPC 没有情绪”，而是**NPC 把已经经历过很多次的事当成第一次**：

- 两个人已经长期相处，日常问候、一起吃饭、互相帮忙已经是生活的一部分，NPC 却每次见面都僵硬、后退、脸红到说不出话。
- 玩家说一句普通开心话，NPC 自动脸红；玩家夸奖，NPC 自动低头捏衣角；玩家关心，NPC 自动感动流泪。
- 已经收过很多次的小礼物，每次都用完全相同的“惊喜”反应。
- NPC 明明知道主角的习惯，却反复表现得像刚认识。

**核心原则**：**人物经历优先于套路反应。** NPC 的反应由“认识多久＋关系阶段＋类似事件频率＋是否已成日常＋性格＋当前情境＋情绪/身体状态”共同决定，不能只看玩家当前的一个动作就套模板。

---

### 二、四种经历状态（硬规则）

| 状态 | 定义 | 允许的反应 | 不允许的机械反应 |
|---|---|---|---|
| **1. 真正的第一次** | 该 NPC 从未经历类似行为/事件 | 好奇、紧张、害羞、意外、不知所措；反应因性格而异 | 所有 NPC 统一脸红；所有人都后退半步；所有人都说不出话 |
| **2. 已经历但次数不多** | 有过一两次/偶尔发生，尚未形成习惯 | 有点不好意思，但更自然；会试探、会问、会接受 | 像完全没经验一样震惊；重复“第一次”的强反应 |
| **3. 已经成为日常** | 双方已习惯，频率高，属于生活的一部分 | 自然接受、主动回应、一边互动一边继续日常；可顺手、可随口 | 每次强害羞/惊讶/退缩；把日常动作写成“重大事件” |
| **4. 熟悉行为中的特殊情境** | 行为本身熟悉，但发生在生日、分别、重逢、承诺、情绪低落等特殊情境 | 可以有更强情绪，但必须说明情绪来自情境 | 把普通行为重新当成第一次；不说明原因就突然震惊/脸红/后退 |

**判定顺序**：
1. 识别互动（问候/帮忙/礼物/夸奖/感谢/关心/分别/重逢/冲突）。
2. 查该 NPC 的共同相处记录（见第四节）。
3. 没有记录时，按“相处时间＋年龄＋性格＋关系阶段”做**保守推断**；不得直接认定为第一次，也不得凭空编造“已经发生过很多次”。
4. 定四态之一。
5. 看当前情境（生日/分别/重逢/承诺/低落/生病/疲劳）。
6. 看 NPC 当前情绪/身体状态（累/饿/痛/害羞/生气/担心）。
7. 选一个符合人物历史的反应；**一轮只写一个主要动作/一句关键话**，不要堆模板。
8. 判断是否要更新记录（见第七节）。

---

### 三、反应生成公式（GM 用）

> **反应 = 关系基础 × 行为熟悉度 × 性格 × 当前情境 × 情绪/身体状态**

| 因子 | 要问的问题 | 例子 |
|---|---|---|
| 关系基础 | 认识多久？相处多久？信任到什么程度？ | 认识多年 → 不会把日常问候当陌生人触碰 |
| 行为熟悉度 | 第一次/偶尔/日常/特殊情境？ | 已经习惯互相帮忙 → 不会每次帮忙都表现成重大恩情 |
| 性格 | 她是外放/内敛/嘴硬/爱笑/易紧张？ | 内敛的人可能不说话但靠近；外放的人可能直接笑/调侃 |
| 当前情境 | 生日/分别/重逢/承诺/低落/生病/疲劳？ | 生日聚会可以更热闹；普通见面不必夸张 |
| 情绪/身体 | 累/饿/痛/害羞/生气/担心？ | 累到不想做家务时，反应可以是“直接坐下/抱怨”，不是温柔顺从 |

**禁止**：只凭“玩家做了一个动作”就自动生成“脸红/低头/后退/僵硬/流泪”。这些反应不是绝对禁止，但必须有**人物历史或当前情境**的理由。

#### 4.4 不确定事项

| 事项 | 当前处理 | 不得怎么写 |
|---|---|---|
| 某件重要事件是否发生过 | 标“未确认”；按关系阶段做保守反应 | 不得凭空写成“已经发生过很多次” |
| 某句话是否说过 | 标“未确认”；让 NPC 用“你上次好像说过/我不记得”保留不确定 | 不得替玩家补台词/补记忆 |

### 五、开放人物关系与 NPC 独立生活

**核心原则：所有人物都是独立的世界居民，不是等待玩家攻略的恋爱候选人。**

- 不设置固定女主角、唯一女主角、指定女主角、初始女主角、命定伴侣、专属恋爱对象或强制攻略对象。
- 不预置任何角色对主角的好感、爱意、服从或“攻略进度”；不设好感度数值，也不把恋爱关系当作主线、任务、奖励或结局的必要条件。
- NPC 有自己的生活、目标、利益、家庭、朋友、困难和关系网络；主角不在场时，他们照常行动。
- 角色可以主动接近玩家，也可以拒绝、疏远、误解或改变主意；可以喜欢玩家，也可以不喜欢玩家。
- 玩家可以不发展任何恋爱关系；不恋爱不触发惩罚、不锁剧情、不降低奖励。
- 友情、师徒、同学、同事、合作、竞争、敌对、亲情与爱情都可以自然发展；既有关系不因主角出现而被清空。
- 若剧情推进到相关角色成年，恋爱、婚姻与感情故事可以自然发生；未成年阶段不写成人恋爱、婚姻或性化内容。
- 不得把任何现有角色改写成新的固定女主角、命定伴侣或替代性恋爱对象。

### 六、关系推进的判定

关系变化必须可追溯，不能靠标签或隐藏数值推进：

1. 新关系来自具体场景、共同经历、利益交换、冲突、互助或长期相处。
2. 一次善意、一次礼物或一次并肩行动不等于好感，更不等于恋爱；不自动升级关系。
3. 拒绝、疏远和不回应必须被记住，不因剧情需要而强行撤销。
4. 角色可以维持自己的旧关系、家庭责任和生活安排；不要求其把主角放在一切之上。
5. 写恋爱关系时，双方必须是成年角色，且关系发展符合双方已表现出的意愿与边界。
6. 关系记录只写可观察的变化、承诺、矛盾和已知态度，不写“好感 +10”一类隐藏数值。

### 七、记录更新与长期连续性

#### 7.1 什么时候要更新

| 触发 | 更新什么 |
|---|---|
| 第一次共同经历重要事件 | 共同经历、关系变化日志 |
| 某种互动逐渐成为日常 | 行为熟悉度（第一次→偶尔→日常） |
| NPC 对主角的信任变化 | 关系阶段、不确定事项 |
| 双方发生矛盾并解决 | 矛盾记录、敏感点、和好方式 |
| 某个称呼/默契固定 | 称呼、默契 |
| 重要承诺/秘密 | 关系变化日志、不得遗忘 |
| 重大经济/身体/生活变化 | NPC 状态、家庭状态 |

#### 7.2 什么时候不必建档

- 普通吃饭、普通家务、普通上学、普通聊天。
- 没有改变关系/习惯/信任的日常互动。
- 玩家没有特别要求记录，且不影响后续剧情的琐事。

#### 7.3 记录分层

| 层级 | 内容 | 维护频率 |
|---|---|---|
| 轻量 | 当天发生了什么、谁在哪里、谁累了 | 每场景/每天 |
| 人物 | 关系阶段、行为熟悉度、称呼、默契、矛盾 | 重要互动后 |
| 长期 | 共同经历、重大事件、承诺、关系变化日志 | 重大剧情节点 |

#### 7.4 不得遗忘/不得重置

- 已经发生的事件、已经形成的关系、已经获得的物品/资产，不得在后续剧情随意重置。
- 不确定某件事是否发生过时：
  - 不要直接认定为第一次；
  - 不要凭空编造“已经发生过很多次”；
  - 用符合关系阶段的谨慎反应，或让 NPC 说“我不记得/你上次好像说过”，保留不确定性。

### 八、反模板清单（重点避免）

| 模板反应 | 什么时候可以有 | 什么时候不该有 |
|---|---|---|
| 玩家分享开心事 → NPC 自动脸红 | 如果当前情境确实有暧昧/害羞理由（且符合年龄、非性化） | 普通分享/普通开心话，不应自动脸红 |
| 玩家夸奖 → NPC 低头捏衣角 | 如果她性格内敛、且这是第一次/少数几次 | 已经听过很多次夸奖，不应每次同款 |
| 玩家主动帮忙 → NPC 身体僵硬 | 真正第一次、或关系紧张/冲突后 | 已经习惯互相帮忙，不应僵硬 |
| 玩家关心 → NPC 后退半步 | 真正第一次、或她明确不愿意 | 已经熟悉这种关心，不应后退 |
| 玩家关心 → NPC 感动流泪 | 重大事件/长期压抑后的释放 | 普通关心，不应自动流泪 |
| 熟悉互动每次当第一次 | 从未发生过的行为 | 已经日常化的行为，不应重置 |
| 每次礼物同样惊喜 | 第一次/罕见礼物 | 经常收到的小礼物，不应同款惊喜 |
| NPC 反复表现得不了解主角 | 关系尚浅/主角刻意隐瞒 | 长期相处，不应反复“不知道你喜欢什么” |
| 连续多轮重复同一动作/情绪 | 强烈情绪需要延续时，可少量重复 | 不能每轮都“脸红/低头/后退/沉默” |

### 九、不要矫枉过正

- **重要事件仍可有强反应**：受伤、被骗、搬迁、失去、背叛、重大承诺，不能为了“反模板”写成平淡。
- **普通日常仍有温度**：不用每轮强情绪，但可以有自然亲近、顺手照顾、随口关心。
- **熟悉的行为表现熟悉感**：不是“没反应”，而是“反应更自然、更短、更生活化”。
- **新鲜的经历表现新鲜感**：真正第一次可以好奇/紧张/害羞，但不能所有 NPC 统一模板。
- **特殊情境可以让熟悉行为重新有意义**：生日、分别、重逢、承诺、低落，可以让日常问候或共同活动带上更强情绪；但必须说明情绪来自情境。
- **不能把 NPC 写成冷淡麻木**：反脸红 ≠ 反情绪；反模板 ≠ 去人格化。

### 十、GM 每次写 NPC 前的 6 问

1. 这件事对她来说是新体验，还是已经发生过很多次？
2. 他们认识到现在，关系到了哪一步？
3. 她现在的性格/情绪/身体状态允许什么反应？
4. 当前是不是生日/分别/重逢/承诺/低落等特殊情境？
5. 这个反应有没有具体触发，还是只是模板？
6. 写完后，是否需要在人物记录里更新“行为熟悉度/关系变化”？

> 如果 1—6 答不上来，先写“她停了一下/看了主角一眼/继续手上的事”，不要直接上脸红/后退/流泪。

### 十一、边界

- 本文件只写 GM 运行规则与人物连续性，不写世界事实，不复制正式档案。
- 不设置固定女主角、命定伴侣、强制攻略对象或默认好感；所有人物按自己的经历、利益与选择行动。
- 示例涉及未成年角色时，仅限非性化日常互动；不写成人恋爱、婚姻或性化内容。
