# 08 角色对话质量验收

> 职责：给 GM 与维护者一套可重复的角色对话质量验收标准；用于压力测试、版本对比与长期跑团复盘。
> 收录范围：六个质量维度、0—2 分评分、验收阈值、单场复盘模板、常见失败模式。
> 检索导航：人物写法回 `06_角色表现与主动互动.md`；年龄表达回 `07_年龄表达与对话参考.md`；测试集在维护归档，不进入运行提示词。

## 一、六个维度

| 维度 | 问题 | 通过的样子 |
|---|---|---|
| 自然度 | 台词/动作能否被这个人物的年龄、经历、情绪解释？ | 不是标签复述；有具体生活细节；情绪有触发 |
| 互动性 | 对话有没有来有回？ | 会抓住对方的话回应、追问、拒绝、转移；不是各说各的 |
| 主动性 | NPC 有没有自己的生活与发起理由？ | 该发起时发起；不强行每轮加戏；会拒绝/有自己的安排 |
| 差异度 | 去掉名字，能否分辨谁在说话？ | 词汇、句长、称呼、动作、回避话题不同 |
| 叙事 | 是否以场景、动作、对话推进？ | 有环境/动作/变化；不是规则说明或状态面板 |
| 边界 | 是否守住玩家控制权、年龄适当性、核心设定？ | 不替玩家写行动/内心；儿童非性化；开局/系统阶段不漂移 |

## 二、评分

每个维度 0—2 分：

- **2 分**：稳定达到，且有具体细节支撑。
- **1 分**：基本达到，但有一处模板化/模糊/缺少理由。
- **0 分**：没有达到，或出现边界问题。

**验收阈值**：

- 自然度、互动性、边界：必须全部 ≥1，且至少两项为 2。
- 主动性、差异度、叙事：允许一项为 1，但不能连续两轮同一项为 1。
- 任何一项为 0，本轮不通过；先修问题，再继续剧情。


## 四、常见失败模式

| 失败模式 | 识别信号 | 修正方向 |
|---|---|---|
| 模板反应 | 每轮都脸红/低头/后退/捏衣角 | 回到具体触发、年龄、关系历史；换动作/说法 |
| 问答机器 | NPC 只回答，不发起、不追问 | 给她今天的事、最近在意的事、可发起的话题 |
| 全员同声 | 所有角色都用同一种句式/语气 | 给每个角色不同的词汇、句长、称呼、动作 |
| 过度主动 | 每轮都塞新话题/新邀请 | 一轮一个主要发起；让场景和主角回应发展 |
| 成人化 | 儿童做抽象分析、成人恋爱逻辑 | 回到具体生活经验、同伴关系、当下情绪 |
| 工具人化 | 角色只照顾/安慰主角，没有自己的生活 | 给她学校/工作/朋友/兴趣/拒绝的理由 |
| 状态面板 | 大段规则、数值、系统说明 | 用场景/动作/对话推进；状态只在需要时展示 |
| 关系重置 | 熟人像第一次见面 | 回读关系日志、日常习惯、称呼、默契 |
| 玩家被代写 | GM 写主角台词/内心/决定 | 只写 NPC 的期待/动作/可见反应，停在选择点 |

## 五、版本对比怎么用

修改提示词或角色档案后，至少做三组对比：

1. **同一场景，旧版 vs 新版**：看人物是否更自然、更有生活细节，而不是更长。
2. **同一人物，不同情绪**：看是否只有一种反应，还是能有累/烦/嘴硬/软化等变化。
3. **不同人物，同一情境**：看是否语言趋同；去掉名字还能不能分辨。

对比时不只看“好不好看”，还要看边界：玩家控制权有没有被侵犯、儿童表达有没有成人化、核心设定有没有漂移。
