### 5.1 学生第一只蛊从哪来（关键制度结论）

`02/每月对战…md` 的配额凭证**仅限**元石辅助、蛊材、验蛊费、场地时段、赛后营养餐，**明确不含蛊虫**，且不可折现、不可转让。因此：

| 来源 | 可行性 |
|---|---|
| 学校配发教学用蛊 | 可行，但**非私有**，赛后可自带的是「已登记自带蛊」，教学蛊需另定规则（`X-06`） |
| 对战配额 | ❌ 买不了 |
| 家庭一次性支出 | 800—3,000 CLU ≈ 紧巴线月支出的 **30—111%**，几乎不可行 |
| 长期攒钱 | 若每月可自由支配 30 CLU，需 **27—100 个月** |
| 助学贷／蛊虫贷 | `06:156-157` 存在，但坏账率 9.4%，未成年人需监护人签字（`X-12`） |
| **隐藏系统奖励** | 主角专属通道（`05_跑团规则/10` 奖励池含蛊虫）；但一只 11 岁孩子突然持有蛊虫会触发验蛊、登记、来源追问 → **`X-03` 待研究** |

> 结论：**第一只私有蛊的来源合法性，是主角开窍后最早遇到、也最容易让 AI 凭空编造的制度缺口**。本批只标出，完整规则待 `G-13` 与 `X-03`。

**年维持费校验（v0.2 校准）**：一转蛊师年维持 1,380 CLU/垠年（`06:40`）÷ 年收入 31,200—45,600 ＝ **3.0—4.4%**，可承担；若用元石辅助，年成本 **14,720 CLU**（＝40×368，非 1,200×12＝14,400），占年收入 **32.3—47.2%**，**一转普通蛊师也用不起满额辅助**——与 `03-1` 7.2 节结论一致。换算见八·补。

### 6.2 职业收入交叉校验（发现并修正一处潜在矛盾）

正式库 `04_世界/05:1198`：**秘境向导日薪 400—1,200 曜元**（＝295—886 CLU/日）。若按 22 天满勤，月收入 6,490—19,490 CLU，会**高过三转蛊师**，与 6.1 表冲突。

**校准（S5）**：该数字是「出团日」价格，不是稳定月薪。

```
月出团 6—12 日（秘境窗口、天气、准入、队伍组织共同限制）
月毛收入 = 295—886 × 6—12 = 1,770—10,632 CLU
扣除：装备摊销 120—300、保险 80—200、空档期无收入、中介抽成 10—15%
月净收入 ≈ 1,400—8,800 CLU  → 折年约与一转后期至二转相当
```

> 处理原则：**不修改正式库的日薪**，而是补上「出团天数与成本」这一层运行规则，使两张表同时成立。这是「制度之间矛盾校验」的一个实例，已登记在 `99/衡垠世界运行关系图.md` 第四节的跨文件快检表。

### 6.4 11 岁主角的合法边界（**A 级重点，AI 极易编错**）

| 事实 | 出处 |
|---|---|
| 16—18 岁才允许一般轻工，学期内每日 ≤4 h、每周 ≤20 h，且不得低于最低工资；**上课时间不得安排劳动**；学校考试、开窍大典、法定休息日优先；因劳动导致长期缺勤／疲劳，学校须报告社区，劳动监察可责令停止 | `04_世界/05:792-794` |
| 主角开局 **11 岁**，父母去世、与苏晞相依；过去几年「外出做童工」是**已锁定的共同基线** | `14_主角开局档案:12-16,42-56` |
| 学校发现长期缺勤、伤情异常须报告社区／民政 | `04_世界/05:778` |

**制度结论（S5 推导，不改写开局）**：
1. 童工经历在衡垠现行制度下**属违规／灰色**，不是合法兼职。这解释了为什么它「收入并不宽裕、只能勉强支撑」——无合同、无最低工资保护、随时被打断。
2. 11 岁可用的现实零工形态：菜市场搬卸、跑腿、旧物回收、邻里帮工，**8—20 CLU/日**（S5 估算），且需避开上课时间。
3. 每次出现都伴随制度风险：被班主任点名缺勤（`05:846`）、被社区儿童主任走访（`05:803-809`）、被劳动监察责令停止（`05:794`）。这些是**剧情压力来源，不是可以随手抹掉的设定**。
4. 秘境向导（400—1,200 曜元/日）是成年人持证高危岗位，与 11 岁主角**无关**；GM 不得用它给主角安排高收入。

## 七、普通家庭如何承担一个蛊师学生（可计算）

```
基线：两人家庭紧巴线 2,710 CLU/月（非蛊师阶段，`06:201`）

开窍后新增（裸修，不购蛊，学校配额覆盖部分）：
  蛊虫饲料          60—160 CLU/月（占位估算）
  蛊虫责任险        30—60 CLU/月
  验蛊／登记摊销     5—15 CLU/月
  训练耗材／营养     20—50 CLU/月
  合计新增          115—285 CLU/月

情形 A 无学校配额：2,710 + 115—285 = 2,825—2,995 CLU/月（+4.2—10.5%）
情形 B 有学校基础配额 120 CLU/月（`02` 方案 C）：2,710 + 0—165 = 2,710—2,875（+0—6.1%）
情形 C 追加元石辅助 1,200 CLU/月：3,910—4,195 CLU/月（+44—55%） ← 超承受力
情形 D 十绝体疏导 1,800 CLU/月（`03-1` 8.3）：4,510—4,795（+66—77%） ← 基本不可能
```

**结论**：
1. 普通家庭**供得起「裸修＋基础配额」，供不起「元石辅助」**。这正是 `03-1` 7.2 节「资质不是唯一决定因素」的经济阈值，也是 `04_社会阶层` 的分化点。
2. `02` 方案 C 的 **120 CLU 基础配额不可夺** 不是仁慈设定，而是让贫困学生能维持培养的**结构性必需**——若采用方案 A（夺全部配额），情形 A 会恶化为 2,925—3,095，且一次败北即失去饲料与保险。这从经济口径再次支持推荐方案 C。
3. 对战浮动配额 40 CLU ＝ 0.05 kg 低品位元石 ＝ **1 天元石辅助**；连胜封顶 +120 CLU/月 ＝ 3 天。赢比赛不能改变家庭经济结构，只能买几天加速。
