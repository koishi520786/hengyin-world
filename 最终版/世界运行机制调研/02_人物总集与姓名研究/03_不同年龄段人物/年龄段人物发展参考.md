# 年龄段人物发展参考

> 职责：给 GM 一个“年龄—语言—行为—社会关系”的对照表，避免 11 岁写成小大人、40 岁写成青年、70 岁只剩慈祥。
> 使用：新建人物、临时 NPC、判断台词与行为是否合乎年龄时查本表；本表不替代具体人物档案。
> 注意：年龄只给大致边界，不决定性格。同一年龄段可以有安静、冲动、早熟、幼稚的人；早熟也要有代价。

## 一、5—8 岁

| 维度 | 参考 |
|---|---|
| 语言 | 短句、重复、具体；会说不清因果，常用“因为……然后……”；爱问“为什么”，但注意力很快转移 |
| 兴趣 | 玩具、动画、贴纸、跑跳、模仿大人；对蛊虫多知“厉害/可怕”，不懂原理 |
| 行为 | 坐不住、怕黑、怕陌生人、会告状、会突然哭；对规则理解具体（“老师说不许”） |
| 家庭 | 依赖父母/祖辈；会用“我妈妈说的”作为依据；父母争吵会直接害怕 |
| 社交 | 朋友以“一起玩”定义；会绝交也会很快和好；容易被大孩子带着走 |
| 写作陷阱 | 不要给 6 岁孩子完整逻辑、政治判断、复杂隐喻；不要让他们独立处理蛊虫 |
| 现有例子 | 赵雨眠 10 岁（偏小）、叶南乔 9 岁；低龄场景可参考她们的怕黑、黏人、折纸 |

## 二、9—11 岁

| 维度 | 参考 |
|---|---|
| 语言 | 能讲完整事情，但会夸张、藏一半；开始在意“别人怎么看我”；会模仿大人措辞 |
| 兴趣 | 收集、比赛、小团体、秘密基地；对蛊道有朦胧向往，喜欢看热闹 |
| 行为 | 有自尊心、怕丢脸、会逞强；开始理解“公平”，但仍会双标；对异性可能别扭或起哄 |
| 家庭 | 开始察觉家里经济/关系问题，但不一定说；会偷听、会对比同学 |
| 社交 | 有固定小团体，也有“今天不跟你玩”；对老师的话半信半疑 |
| 写作陷阱 | 不要写成 15 岁的恋爱脑，也不要写成 6 岁的纯幼稚；11 岁可以有心事，但表达仍孩子气 |
| 现有例子 | 林予安、陈知夏、苏念禾、温书瑶、顾清野、许棠溪、江砚秋 |

## 三、12—14 岁

| 维度 | 参考 |
|---|---|
| 语言 | 会顶嘴、会反讽、会使用网络/同伴黑话；对“大人不讲理”敏感；能讨论规则，但容易极端 |
| 兴趣 | 圈子、偶像、游戏、修炼、比较境界；开始有秘密和隐私 |
| 行为 | 冲动、讲义气、爱面子；会挑战权威，也会在关键时刻退缩；对失败反应大 |
| 家庭 | 与父母冲突增多；开始有自己的钱和安排；会隐藏成绩/修炼进度 |
| 社交 | 小团体排挤、暗恋、竞争、背叛；朋友影响大于家长 |
| 写作陷阱 | 不要让他们像成熟特工；也不要把所有叛逆写成中二病；12 岁刚开窍，蛊道能力有限 |
| 现有例子 | 陆知白、夏清妍、梁照雪、姚成蹊、冯望川、曹听澜、袁稚宁、唐小川 |

## 四、15—17 岁

| 维度 | 参考 |
|---|---|
| 语言 | 能抽象思考、会辩论、会掩饰；有时故作成熟，有时突然孩子气；脏话/口头禅受同伴影响 |
| 兴趣 | 升学、恋爱、兼职、修炼、职业想象；开始关注社会新闻 |
| 行为 | 能做长期计划但执行不稳；敢冒险、怕被看不起；对朋友忠诚，对背叛记仇 |
| 家庭 | 经济压力、志愿选择、离家冲动；开始承担弟妹/家用 |
| 社交 | 稳定好友、竞争对手、暧昧、社团；会为朋友撒谎 |
| 写作陷阱 | 不要给 15 岁二转以上战力；不要让高中生随便夜不归宿；蛊道学生也要写作业 |
| 现有例子 | 钟临溪、贺疏影、彭启言、蒋牧之、傅青梧、汪照临、石念初、金亦辰、乔允禾、岑行舟 |

## 五、18—20 岁

| 维度 | 参考 |
|---|---|
| 语言 | 成人化，但仍会露怯；会讲“以后”“计划”；对钱、工作、感情有现实焦虑 |
| 兴趣 | 大学/工作/修炼方向、租房、恋爱、同乡会；开始有职业身份 |
| 行为 | 能独立办事，但经验不足；敢闯、容易被骗；对权威既服从又怀疑 |
| 家庭 | 离家、寄钱、报喜不报忧；与父母关系重新谈判 |
| 社交 | 同学、同事、室友、初恋；关系开始有利益 |
| 写作陷阱 | 不要让他们一出场就老练；18 岁可以二转初，但不能三转；不要人人都有明确人生规划 |
| 现有例子 | 卢修远、魏清和（18）；可作为 18—20 过渡 |

## 六、21—25 岁

| 维度 | 参考 |
|---|---|
| 语言 | 有职业口头禅；会自嘲、会包装；对“稳定”与“梦想”纠结 |
| 兴趣 | 工作、攒钱、恋爱、住房、考编/考研/创业；开始关注健康 |
| 行为 | 能承担责任，但会拖延、会攀比；熬夜、透支、怕落后 |
| 家庭 | 租房、通勤、相亲、给家里钱；与父母边界模糊 |
| 社交 | 同事、合租、朋友、客户；社交有目的性 |
| 写作陷阱 | 不要把 24 岁写成 40 岁的老油条；也不要写成大学生；刚工作的人会犯错、怕领导 |
| 现有例子 | 许清音 29（偏上）、林晓棠 24、苏晓燕 24、林巧 26 |

## 七、26—30 岁

| 维度 | 参考 |
|---|---|
| 语言 | 稳定、直接；开始用“我们”“这边”“流程”；对行业有判断 |
| 兴趣 | 婚恋、买房、晋升、副业、旅行；身体开始出现小毛病 |
| 行为 | 能独立带项目/带人；会权衡利弊；开始怕失业、怕生病 |
| 家庭 | 结婚/同居/催婚；父母养老问题浮现 |
| 社交 | 同事、客户、同学分层；朋友变少但更深 |
| 写作陷阱 | 不要让他们都事业有成；30 岁也可能租房、单身、转行、迷茫 |
| 现有例子 | 谢云岫 29、叶知秋 31、叶康 31、谢芳 31、苏敬言 31 |

## 八、31—40 岁

| 维度 | 参考 |
|---|---|
| 语言 | 有分寸、会留余地；对下属/晚辈有指导欲；会避免直接冲突 |
| 兴趣 | 家庭、房贷、孩子、职业瓶颈、身体保养；开始怀旧 |
| 行为 | 能扛事，但怕担责；会计算成本；对年轻人既欣赏又防备 |
| 家庭 | 育儿、父母生病、婚姻疲惫；时间被切碎 |
| 社交 | 同事、客户、家长群、亲戚；人情往来多 |
| 写作陷阱 | 不要把所有 35 岁写成“成功人士”；也不要写成麻木中年人；仍有欲望和软肋 |
| 现有例子 | 顾霆 34、叶青萝 33、高远 33、曹敏 35、秦烈 35、顾清和 36、陈守拙 36、方丽华 37、陈慧 38、郑安 38、袁丽 38、邓丽 39 |

## 九、41—50 岁

| 维度 | 参考 |
|---|---|
| 语言 | 简洁、务实；爱讲经验；对废话没耐心；会自嘲身体 |
| 兴趣 | 家庭稳定、孩子升学、职业天花板、健康、老友 |
| 行为 | 能镇场，但精力下降；会保守、会护短；对变革半信半疑 |
| 家庭 | 孩子青春期/高考；父母高龄；婚姻进入平淡期 |
| 社交 | 老同事、老同学、亲戚、下属；关系有历史包袱 |
| 写作陷阱 | 不要把所有 45 岁写成“权威长辈”；他们也会犯错、会被裁、会怕老 |
| 现有例子 | 周立诚 45、林志远 45、孙志强 46、顾承业 46、方志强 46、吴正平 47、曹听澜母辈、赵德明 48、曹大山 51（偏上） |

## 十、51—60 岁

| 维度 | 参考 |
|---|---|

## 十一、61—70 岁

| 维度 | 参考 |
|---|---|
| 语言 | 慢、重复、具体；爱用“当年”；听力下降会打断别人 |
| 兴趣 | 养生、旧物、儿孙、老友、宗教/习俗；对死亡有感受 |
| 行为 | 起早、怕摔、怕冷；会固执、会忘事；对陌生人警惕 |
| 家庭 | 丧偶、独居、子女在外；孙辈是情感中心 |
| 社交 | 老邻居、老同事、病友；朋友一个个离开 |
| 写作陷阱 | 不要只写慈祥/孤独；老人也会算计、偏心、发火、讲荤段子 |
| 现有例子 | 王秀兰 70、李长庚 72、张桂芬 68、罗秀英 64、马国栋 62、陈巧珍 62、何建国 60、唐万山 60、蔡文山 67、贺云山 65、唐文渊 63 |

## 十二、71 岁以上

| 维度 | 参考 |
|---|---|
| 语言 | 更短、更慢；会回到旧称、旧事；有时清醒有时糊涂 |
| 兴趣 | 晒太阳、听收音机、等电话、旧照片；对现实新闻不敏感 |
| 行为 | 行动不便、需要人扶；怕孤独、怕成为负担；会突然固执 |
| 家庭 | 子女/孙辈照顾；遗产、旧房、旧账；对死亡不回避 |
| 社交 | 老友减少；与护工/邻居依赖 |
| 写作陷阱 | 不要写成“剧情工具人”只负责给主角遗言；他们的日常更需要被写 |
| 现有例子 | 李长庚 72、王秀兰 70 可作为 70+ 参考；更高龄可新建但不要批量 |

## 十三、跨年龄写作检查

- 这句话，这个年龄的人会这么说吗？还是会用更具体的词/更短的句子？
- 这个决定，这个年龄的人有权限/经验/钱/体力做吗？
- 这个情绪，这个年龄的人会直接表达，还是会掩饰/转移？
- 这个关系，符合年龄差吗？15 岁和 25 岁可以认识，但权力不对等要写出来。
- 这个蛊道境界，符合开窍年限、资源、资质和身体吗？12 岁不能二转。
- 这个人物，除了年龄，有没有自己的利益、习惯、麻烦？

## 十四、覆盖边界（诚实说明）

- 现有 110 名正式人物年龄为 **9—72 岁**；9—11、12—14、15—17、18—20、21—25、26—30、31—40、41—50、51—60、61—70 均有实际人物。
- **5—8 岁**：本表提供语言/行为参考；正式人物暂以 9 岁叶南乔、10 岁赵雨眠为低龄下限，不强行给幼儿编号。需要长期幼儿角色时，从备用姓名池新建 `FAM-021`，不要占用现有 110 的编号。
- **73 岁以上**：本表提供 71+ 参考；现有 72 岁李长庚、70 岁王秀兰可作近龄参照。需要 75+ 角色时，另建老年人物，不把 72 岁写成 80 岁。
- 不为了“覆盖年龄”硬塞幼儿或高龄人物；年龄覆盖服务于剧情，不是数字游戏。

> 年龄是边界，不是性格。先写人，再写年龄。
