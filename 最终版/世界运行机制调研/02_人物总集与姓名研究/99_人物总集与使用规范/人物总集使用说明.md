# 人物总集使用说明

> 职责：告诉 GM 在什么场景读哪个文件、怎么取人、怎么新增人物、怎么保持连续性。
> 适用：从开局到长期跑团；不是每轮都读全库，而是按场景按需加载。
> 规模：110 名正式人物 + 130 个姓名（其中 20 个备用）+ 年龄/性格/成长/关系规范。

## 二、按需加载顺序

1. **先场景，后人物**：先判断场景（学校/家庭/商业/蛊师/医疗/官方），只读对应总集。
2. **先现有人物，后新建**：总集里有合适的人就用；没有才从姓名库取备用名。
3. **先规则，后演绎**：涉及开窍/蛊虫/未成年/金钱/制度，先读 `01_蛊虫` 或 `04_世界/05` 正文，不要凭印象。
4. **不要每轮读全库**：日常家庭场景不需要读蛊师成长表；蛊道战斗不需要读商业总集。
5. **读取正文，不只看索引**：索引只给位置；具体蛊虫能力、价格、制度以正文为准。

## 三、取人流程（场景已有需要的人）

```
1. 定场景：学校/家庭/社区/商业/蛊师/医疗/官方/组织
2. 定条件：年龄、性别、职业、性格、蛊师状态、与主角关系
3. 查总集：先看同类别，再看交叉类别
4. 选中 1—3 个候选：不要一次塞太多新人物
5. 核对连续性：上次见过吗？关系是什么？年龄/职务变了吗？
6. 演：用档案里的语言习惯/目标/弱点，不临时改性格
```

## 四、新增人物流程

```
1. 查重：00 总索引 + 11 姓名库 + 04_世界/08 的 PER/HIS
2. 定年龄/出生年代 → 03 年龄段参考
3. 定家庭/地域/职业 → 02 姓名规范
4. 从 11 姓名库取未分配名（优先备用池 NM-111—130）
5. 写最小档案：姓名/性别/生日/身份/家庭/识别特征/性格/语言/爱好/目标/关系/弱点
6. 若是蛊师：补开窍/资质/境界/本命蛊/常用蛊/杀招/资源/限制（回 01 正文核对）
7. 分配人物编号：STU/TCH/FAM/BIZ/GUP/MED/FUT/ORG 等
8. 更新姓名库状态、00 总索引、对应总集
9. 若是重要人物，补成长时间线与关系记录
10. 自检：年龄像吗？名字自然吗？蛊虫合理吗？和现有角色重复吗？
```

## 七、常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 每个新场景都造新人 | 人物爆炸、名字重复 | 先查总集，优先复用 |
| 全班都是帅哥美女/天才 | 失真 | 大多数是普通人；能力有上限 |
| 11 岁说成年人台词 | 年龄崩 | 回 `03` 年龄段参考 |
| 蛊师随手借蛊/越级用蛊 | 规则崩 | 回 `01_蛊虫` 与未成年限制 |
| 生日随机改/年龄不更新 | 连续性崩 | 用 `99` 年龄公式，跨年统一更新 |
| 受伤下一段就好 |  stakes 崩 | 记录伤病、恢复时间、疤/瘸 |
| 所有商人都奸/所有老师都好 | 扁平 | 给利益、偏见、弱点 |
| 角色只围着主角转 | 世界假 | 给每个人物一个与主角无关的目标 |
| 名字生僻/全员古风 | 出戏 | 回 `02` 命名规范与 `11` 姓名库 |

## 八、质量自检（每次新增/使用后）

- 姓名自然、易读、不重名？
- 年龄、生日、年级/职务一致？
- 家庭背景能解释他的行为吗？
- 性格有负面/矛盾吗？
- 说话习惯能区分吗？
- 目标/弱点能推动剧情吗？
- 蛊师境界/蛊虫/杀招符合规则？
- 和现有角色的关系有历史吗？
- 不是只有名字的空壳？
- 主角不在场时，他也有事做吗？

## 九、维护节奏

- 每 10—20 个剧情节点：更新年龄、关系、伤病、债务、职业。
- 每新增 10 个正式人物：复查姓氏/名字集中度、类别覆盖、年龄分布。
- 每完成一个篇章：把重要人物成长线/关系变化写回档案，不要只留在对话里。
- 发现冲突：先改档案，再改索引；不要用“临时设定”覆盖正式设定。

> 人物总集是“可调用的人”，不是“必须出场的人”。用得上就用，用不上就让他们过自己的日子。
