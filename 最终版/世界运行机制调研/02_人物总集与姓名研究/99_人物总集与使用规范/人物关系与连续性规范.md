# 人物关系与连续性规范

> 职责：规定生日、年龄、关系、状态变化与长期连续性，防止“去年 12 岁今年还 12 岁”“老师突然变陌生人”“受伤下一段就好”。
> 适用：全部 STU/TCH/FAM/BIZ/GUP/MED 人物，以及未来新增人物。
> 原则：关系有历史、有距离、有利益；人物有自己的生活，不全部围绕主角。

## 一、生日与年龄规则

### 1.1 历法基准

- 一年 368 日，12 个月；1—8 月各 31 日，9—12 月各 30 日（依据 `04_世界/01_自然环境与历法.md`）。
- 日期格式：`垠历 YYYY.MM.DD`；人物档案可简写 `727.03.12`。
- 年龄按“周岁”计，不按虚岁；出生当天为 0 岁，满生日当天为 1 岁。

### 1.2 年龄计算

```
年龄 = 当前垠历年 - 出生年
若（当前月/日）在（出生月/日）之前，则年龄减 1
若当天正是生日，则年龄已加 1
```

- 例：出生于 727.03.12，当前 738.02.01 → 10 岁；当前 738.03.12 → 11 岁；当前 738.05.01 → 11 岁。
- 例：出生于 727.12.30，当前 738.12.30 → 11 岁；当前 738.12.29 → 10 岁。
- 不要用“看起来像几岁”代替计算；重要人物必须有出生日期。
- 年龄变化不自动改变年级/职务；年级按学年，职务按聘任/退休制度。

### 1.3 生日事件

- 生日是自然事件，不是强制剧情：可以写同学送礼物、家人吃饭、老师随口提一句，也可以完全不写。
- 重要人物生日可做关系节点（朋友/暧昧/家庭矛盾），但不要每个角色生日都安排大事件。
- 生日当天年龄 +1；若剧情跨年，所有人物同步更新，不要只更新主角。
- 生日不允许频繁随机改；如需改，必须在人物档案标注“设定修正”，并说明原因。

### 1.4 年龄差检查

| 关系 | 合理范围 | 注意 |
|---|---|---|
| 同班同学 | 通常 ±1 岁，极少数 ±2 岁（留级/跳级） | 不要全班同一天生日 |
| 同校不同年级 | 按学制差 1—6 岁 | 小学/初中/高中边界要清 |
| 师生 | 至少 10 岁以上；实战教官可 8—15 岁差 | 避免 20 岁老师带 18 岁毕业班 |
| 兄弟姐妹 | 1—15 岁差 | 长兄/长姐要有照顾/压迫感 |
| 父母与子女 | 20—45 岁差 | 高龄父母/年轻父母都可，但要有代价 |
| 祖孙 | 40—70 岁差 | 不要 50 岁当爷爷还像 30 岁 |
| 同事 | 按入职年份，不一定同龄 | 上下级可以有 5—25 岁差 |
| 恋爱/伴侣 | 成年人；年龄差可以有，但权力不对等要写 | 未成年人只写朦胧好感，不写性内容 |

## 二、关系类型与边界

| 关系 | 基础 | 允许的张力 | 禁止/注意 |
|---|---|---|---|
| 同学 | 同班/同校/同路 | 竞争、嫉妒、互助、暗恋、绝交 | 不要全班都成为主角好友 |
| 同桌 | 座位相邻 | 习惯冲突、抄作业、互相掩护 | 座位可调；不是绑定关系 |
| 朋友 | 共同经历/信任 | 借钱、背叛、隐瞒、站队 | 朋友也有自己的生活 |
| 竞争对手 | 成绩/名额/资源 | 互相认可、使绊子、公平竞争 | 不要一律写成反派 |
| 师生 | 教与学 | 偏心、严格、保护、误解 | 权力不对等；不写师生恋（未成年绝对禁止） |
| 同事 | 同单位 | 合作、甩锅、抢功、抱团 | 离职后关系会变 |
| 上下级 | 雇佣/管理 | 压任务、护短、裁员、越级 | 不要下属无条件忠诚 |
| 家庭成员 | 血缘/抚养 | 偏心、养老、遗产、家暴（克制） | 不写美化家暴；不写未成年性内容 |
| 邻居 | 住得近 | 噪音、借东西、八卦、照看孩子 | 距离近不等于亲密 |
| 商业合作 | 合同/利益 | 账期、压价、违约、信任 | 合作会散；不要都讲情义 |
| 竞争组织 | 抢资源/地盘 | 挖人、举报、谈判、火并 | 不要全员恶人；有规则/底线 |
| 医患 | 治疗/付费 | 信任、误诊、医闹、隐私 | 医生不是万能 |
| 官民 | 审批/服务 | 流程、人情、投诉、推诿 | 不要“特事特办”成常态 |
| 蛊师与凡人 | 能力差 | 敬畏、恐惧、利用、歧视 | 蛊师不是贵族；凡人不是炮灰 |

## 四、关系变化与连续性

### 4.1 必须跟踪的状态

| 状态 | 示例 | 后果 |
|---|---|---|
| 住址变化 | 搬家、转学、租房 | 距离/见面频率/学校变化 |
| 伤病 | 旧伤、蛊虫反噬、住院 | 战斗/工作/情绪/钱 |
| 经济 | 欠债、失业、涨租、奖金 | 关系紧张/求助/选择 |
| 学业/职业 | 升学、转正、升职、裁员 | 身份/权力/时间 |
| 关系 | 朋友→对手、师生→同事、邻居→陌路 | 称呼/信任/利益 |
| 承诺 | 借钱、帮忙、保密、介绍工作 | 必须兑现或解释 |
| 谣言 | 校园/社区/单位传言 | 误会/声誉/冲突 |
| 生死 | 退休、重病、死亡 | 不可逆；不要随意复活 |

### 4.2 连续性检查

- 上次见面是哪一天？关系是什么？这次称呼变了吗？
- 上次的伤好了吗？有没有留下疤/瘸/怕冷？
- 上次借的钱/人情还了吗？对方记得吗？
- 上次的承诺兑现了吗？没兑现怎么解释？
- 上次的误会解开了吗？还是绕过去了？
- 这个人物的年龄/年级/职务变了吗？
- 这个人物的目标变了吗？为什么？
- 这个人物对主角的态度，有足够的事件支撑吗？

### 4.3 关系变化记录模板

```
【人物】编号/姓名
【时间】垠历 YYYY.MM.DD
【关系】对主角/对某人：陌生→认识→朋友→信任/疏远/敌对
【触发】什么事件
【当前状态】称呼、距离、欠人情、误会、承诺
【下次可写】可能升级/恶化的钩子
```

## 五、人物不围绕主角转

- 每个重要人物至少有一个**与主角无关的目标**：涨租、升学、还债、养老、升职、找对象、给孩子治病。
- 人物之间可以有**自己的关系**：老师之间的矛盾、商人之间的竞争、家人之间的旧账。
- 主角不在场时，世界仍会变化；GM 可以在主角回归时给出“这段时间发生了什么”。
- 不要让所有人物都刚好有空、刚好帮忙、刚好喜欢主角；帮忙要有时间/代价/人情。
- 不要让所有冲突都因主角而起；有些冲突在主角出现前就存在。

## 六、年龄与未成年人边界

- 12 岁以下：不写恋爱线、不写性内容、不写未成年人承担成人责任；可以写朦胧好感/朋友义气。
- 12—16 岁：可以写暗恋、误会、同伴压力；不写性内容；蛊道受限制级。
- 16—18 岁：可以写恋爱/亲密关系，但必须克制、非露骨；蛊道受监护级。
- 师生、监护、医患等权力不对等关系：不写浪漫化/性化；重点写边界、责任、后果。
- 任何未成年人性化内容绝对禁止；不要用“古代/奇幻/角色扮演”规避。

## 七、长期维护

- 每 10—20 个剧情节点，更新一次人物状态：年龄、住址、职业、关系、伤病、债务。
- 人物死亡/退场要记录；不要让同名/同姓人物顶替。
- 新人物加入前查 `00_人物研究总索引.md` 与姓名库，避免重名/重复人设。
- 重要人物成长线更新到 `13_人物蛊虫与成长档案`；关系变化更新到本文件的关系网。
- 发现年龄/生日/境界矛盾，先改档案，再改剧情；不要用“设定变了”糊弄。

> 关系不是标签，是历史。连续性不是备忘录，是人物为什么变成现在这样。
