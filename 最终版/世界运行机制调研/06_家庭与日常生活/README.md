## 待研究的关键问题（登记，非答案）
1. 11 岁主角与苏晞的**逐日时间表**：起床／早餐／上学／午餐／放学／家务／修炼／作业／睡眠，各占多少分钟？睡眠是否达 9—10 小时？
2. 一顿在家做的饭、食堂餐、面馆外食分别多少钱？与 700—1,050 CLU/月食品区间如何对账？
3. 校服、鞋袜、洗护用品单价与更换周期；换季月支出怎么峰值化？
4. 家务分工：买菜、做饭、洗衣、清洁各需多少时间，谁承担，与「苏晞承担大量家务」如何一致？
5. 周末、节日、闭窍日、开窍节的家庭安排；娱乐（网吧、旧书摊、北苑公园、江堤夜市）费用。
6. 水电燃气 180—320 CLU/月如何在夏冬峰值分配；老房管线损耗的具体表现。
