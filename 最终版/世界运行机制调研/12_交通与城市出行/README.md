## 待研究的关键问题（登记，非答案）
1. 云栖花园 → 第二小学的步行距离与分钟数；雨天、冬天天黑早的替代方案。
2. 开窍后若升入第一中学（含蛊道班，北苑街道）或北城蛊师中学（老站街道），通勤方式与时间如何变化？
3. 学生月票价格与 100—220 CLU/月交通预算如何对账；打车一次 20—40 CLU 在什么情境下才会发生。
4. 自行车／电动车在 11—12 岁年龄段的法规与家校态度。
5. 跨江去中城区（比赛、蛊道医疗中心、蛊坊街）的时间成本与费用，是否构成剧情阻碍。
6. 蛊道交通为何不进入学生日常（成本、执照、禁入核心区）。
