## 待研究的关键问题（登记，非答案）
1. 一名 12 岁学生从开窍到拿到「在册／持证／执业」三层身份，具体经过哪些窗口、多久、需哪些材料？
2. 学校、社区、民政、蛊道管理部门之间谁管什么，出现推诿时剧情如何呈现？
3. 校内对战、蛊虫携带、未成年人持有上限（16—18 岁监护级、D2 上限）由谁审批？
4. 蛊虫责任事故、秘境失联、妖兽进入城区的响应流程与时限。
5. 补助、减免、保险、救助的申请—审核—到账—年审周期与卡点。
6. 高阶蛊师管理的特殊问题：力量与现代法治如何共存，为何不演变成「蛊师治外法权」。
