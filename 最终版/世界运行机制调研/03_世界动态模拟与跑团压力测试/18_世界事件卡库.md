# 18 世界事件卡库（9 类 18 张）

> 职责：给 GM 一组“可随机抽、可按条件触发、可离屏发生”的事件卡。每张有触发、参与人、过程、后果、升级、离屏版。
> 边界：事件卡不是“主角剧情安排表”。事件可以发生在主角周围、主角不在场、或主角只是听说；不强制主角介入。
> 标签：【正式设定】仅用于已锁定背景；事件本身多为【研究建议】/【模拟参数】。

## 使用规则

1. **先抽类别，再抽卡**；不要每天抽“灾害”。
2. **触发条件不满足就不发生**；可以“迟到/ weaker 版”。
3. **后果分三层**：立刻（场景内）、短期（1—7 天）、长期（30 天+）。
4. **离屏版**：主角没去，事件仍发生；通过新闻/邻居/同学/账单听到。
5. **不强迫主角**：主角可以不管、报警、帮忙、围观；不给“必须救”的剧本。
6. **不连续轰炸**：同一类别 7 天内最多 1 次；灾害/重大事件 30 天内最多 1 次（S5）。
7. **事件要留钩子**：票据、伤口、承诺、目击者、未结事项，供 14 回扣。

## 一、普通城市生活

### EV-01 公交/地铁延误

| 字段 | 内容 |
|---|---|
| 触发 | 高峰、暴雨、事故、设备故障；通勤/上学路上 |
| 参与人 | 乘客、司机、站务、学生、上班族 |
| 过程 | 车晚到/临时改线/挤不上；有人抱怨、有人改打车 |
| 后果 | 迟到 10—40 分钟；打车多花 20—60 CLU；学校记迟到 |
| 升级 | 暴雨封路→滞留；有人晕倒→急救 |
| 离屏版 | 新闻/同学说“今天全线堵”；主角改步行 |
| 备注 | 不每次都延误；用时间压力，不用车祸 |

### EV-02 停电/欠费

| 字段 | 内容 |
|---|---|
| 触发 | 线路检修、暴雨、欠费；晚间/做饭时 |
| 参与人 | 家庭、物业刘大勇、电力维修、邻居 |
| 过程 | 灯灭/冰箱停/电梯困人；检查是欠费还是故障 |
| 后果 | 食物变质（20—60 CLU）；手电/蜡烛；作业延误 |
| 升级 | 电梯困人→救援；医疗设备断电→急救 |
| 离屏版 | 整栋楼停；主角回家才发现 |
| 备注 | 不点蜡烛；冰箱少开；欠费可协商 |

## 二、学校日常

### EV-03 随堂测/月考

| 字段 | 内容 |
|---|---|
| 触发 | 教学进度、月末；学生准备不足 |
| 参与人 | 学生、任课教师、班主任、家长 |
| 过程 | 临时测验/排名不公开；有人作弊/焦虑 |
| 后果 | 成绩波动；补课/家长沟通；情绪 |
| 升级 | 作弊→教务；晕倒→校医 |
| 离屏版 | 别的班考了；主角班下周 |
| 备注 | 不把成绩当人格；不公开羞辱 |

### EV-04 同学冲突/轻微欺凌

| 字段 | 内容 |
|---|---|
| 触发 | 座位、绰号、财物、朋友圈；课间/放学 |
| 参与人 | 学生、班主任、校医、家长 |
| 过程 | 争吵/推搡/孤立/藏东西；目击者 |
| 后果 | 情绪、伤痕、家长到校、班级气氛 |
| 升级 | 持续欺凌→教务/报警；打伤→医疗 |
| 离屏版 | 主角听说；加害者被调班 |
| 备注 | 不写“小孩子打闹没事”；不公开隐私 |

## 三、商业活动

### EV-05 菜价/蛊材涨价

| 字段 | 内容 |
|---|---|
| 触发 | 季节、暴雨、供应、节日；菜市场/蛊市 |
| 参与人 | 摊主、家庭、蛊师、餐馆 |
| 过程 | 某类涨 10%—30%；有人囤货/改菜谱 |
| 后果 | 伙食超支 20—80 CLU；蛊材预算紧 |
| 升级 | 囤积/假货→市场管理；冲突→调解 |
| 离屏版 | 主角看价签才发现 |
| 备注 | 不天天涨价；给替代品 |

### EV-06 店铺/摊位纠纷

| 字段 | 内容 |
|---|---|
| 触发 | 短斤少两、假货、退款、占位；市场/商业街 |
| 参与人 | 买家、摊主、市场管理员、调解 |
| 过程 | 争吵、围观看、叫管理员、退钱/换货 |
| 后果 | 损失 10—100 CLU；时间 0.5—2h；关系 |
| 升级 | 动手→报警；涉蛊→GAB |
| 离屏版 | 隔壁摊出事；主角绕开 |
| 备注 | 保留小票；不私了高价值 |

## 四、家庭与社区

### EV-07 邻居噪音/漏水

| 字段 | 内容 |
|---|---|
| 触发 | 装修、深夜电视、管道老化；晚上/周末 |
| 参与人 | 邻居、租户、物业刘大勇、房东马国栋 |
| 过程 | 上门沟通/找物业/吵架；检查源头 |
| 后果 | 睡眠差、维修费 20—100 CLU、关系紧张 |
| 升级 | 冲突→社区调解；漏水泡电器→赔偿 |
| 离屏版 | 主角回家看到门口水渍 |
| 备注 | 不把邻居写成纯恶人；有合理理由 |

### EV-08 老人跌倒/突发不适

| 字段 | 内容 |
|---|---|
| 触发 | 独居老人、地面湿、血压/低血糖；楼道/家中 |
| 参与人 | 王秀兰类老人、邻居、社区高远、急救 |
| 过程 | 听到呼救/敲门无应；判断意识、呼救、不随意搬动 |
| 后果 | 骨折/住院；社区上门；家属联系 |
| 升级 | 昏迷→急救；无人认领→民政 |
| 离屏版 | 主角放学看到救护车 |
| 备注 | 不每次都让主角救；社区也会慢 |

## 事件卡与长期状态

- 每张卡发生后，写 `EVENT`：ID、日期、涉及人、后果、是否解决、回扣条件。
- 未结事件进快照“未结事件”；已结但重要的进“需回扣”。
- 同一事件可在数月后回扣：旧伤、旧债、旧怨、旧承诺、旧票据。
- 不让事件卡变成“主角必须出场”的剧本；主角可以拒绝/错过/事后知道。
