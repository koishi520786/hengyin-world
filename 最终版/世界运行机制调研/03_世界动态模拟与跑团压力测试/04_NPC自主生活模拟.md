# 04 NPC 自主生活模拟

> 职责：建立一套 NPC 不在主角面前时也能继续生活的状态表、更新节奏与事件生成规则；让 NPC 有自己的目标、钱、体力、关系和麻烦。
> 边界：人物身份、生日、家庭、性格取第二专项档案；本文件只补“当前状态”，不改人物设定。

## 一、为什么 NPC 会变成“工具人”

常见退化路径：

1. 主角敲门，NPC 立刻放下手里的事；
2. NPC 永远在家/永远在店/永远有空；
3. NPC 没有钱的压力，也没有自己的计划；
4. NPC 只记得与主角有关的事；
5. 主角不参与，NPC 的生活就暂停。

根因不是“人物写得不够多”，而是**没有记录 NPC 的当前状态**。档案是简历，状态才是生活。

## 二、NPC 状态表（五项核心）

> 每个长期 NPC 一张；临时路人不必建表。

| 字段 | 内容 | 更新频率 |
|---|---|---|
| **① 今天原本要做什么** | 1—3 件事，带时间/地点；不是“日常”两个字 | 每日/每场景 |
| **② 钱** | 现金、月收入、固定支出、欠款/被欠、近期大额 | 每周/发生交易时 |
| **③ 身体与情绪** | 疲劳、伤病、睡眠、当前情绪 | 每日/事件后 |
| **④ 当前目标** | 最在意的一件事＋次要目标；目标可失败/改变 | 每周/月 |
| **⑤ 未结关系** | 欠人情、冲突、承诺、合作、怀疑；谁知道 | 每周/事件后 |

### 2.1 扩展字段（需要时）

| 字段 | 用途 |
|---|---|
| 当前位置 | 主角去找他时，他到底在哪 |
| 已知信息 | 他听说了什么、误信了什么 |
| 下一次计划变化 | 什么条件会让他改计划 |
| 可打断程度 | 现在能不能放下手里的事 |
| 对主角的看法 | 亲近/客气/防备/厌烦，不等于好感度数值 |
| 独立事件日志 | 主角不在场时他做了什么 |

## 四、五名样本 NPC 的基线

> 选择标准：不同年龄、职业、家庭、经济层；且与主角生活圈有自然交集。数值无正式记录处标 S5，不冒充正式收入。

### 4.1 马国栋（FAM-012，62 岁，房东）

| 项 | 基线 |
|---|---|
| 固定 | 云栖花园；两套房出租；妻子管账；儿子做小生意；非蛊师 |
| 今天 | 上午收租/看空置单间；下午下棋；傍晚带看房 |
| 钱 | 租金收入稳定，但有一套单间空置；怕房客拖欠；修东西要花钱 |
| 身体/情绪 | 微胖，腿脚一般；表面稳，心里算得清 |
| 目标 | 主：把空置单间租出去；次：不被欠租 |
| 关系 | 主角家（按时交租）、陈慧（可能晚交）、刘大勇（维修）、高远（租客登记） |
| 可打断 | 下棋时不爱动；带看房时可谈；收租日最敏感 |
| 变化触发 | 空置超过 20 天→降价/找中介；租客欠租→催/换人 |

### 4.2 王秀兰（FAM-001，70 岁，退休社区护士）

| 项 | 基线 |
|---|---|
| 固定 | 3 号楼独居；老伴去世；儿子在外地；非蛊师 |
| 今天 | 早上量血压/买菜；上午串门；下午社区活动；晚上听收音机 |
| 钱 | 退休金覆盖基本生活；药费是固定支出；不宽裕但不欠租 |
| 身体/情绪 | 耳朵背，背略驼；怕给人添麻烦；爱操心 |
| 目标 | 主：把楼道老人血压记全；次：有人说话 |
| 关系 | 罗秀英（邻居）、张桂芬（牌友）、主角家（老邻居）、社区医生 |
| 可打断 | 白天大多可；晚上耳朵更背；看病日不在 |
| 变化触发 | 头晕/血压异常→诊所；罗秀英几天没开门→上门/找社区 |

### 4.3 陈慧（FAM-005，38 岁，超市理货员，单亲母亲）

| 项 | 基线 |
|---|---|
| 固定 | 4 号楼；离婚；女儿赵雨眠 10 岁；父母在外地；非蛊师 |
| 今天 | 早班/晚班轮换；接女儿；做饭；算账 |
| 钱 | 工资紧；房租、女儿兴趣班、药费三头挤；可能晚交租 |
| 身体/情绪 | 瘦，眼下青；坚韧但疲惫；怕被看不起 |
| 目标 | 主：让女儿上兴趣班；次：不被房东赶 |
| 关系 | 马国栋（房租）、赵雨眠（女儿）、学校班主任、邻居 |
| 可打断 | 上班时不能；接孩子时急；发薪日前最焦虑 |
| 变化触发 | 女儿生病/学校收费/加班→晚交租或借钱 |

### 4.4 钟临溪（STU-013，15 岁，北城蛊师中学初三，一转高阶/乙等）

| 项 | 基线 |
|---|---|
| 固定 | 云栖；父亲二转蛊师/炼蛊厂技术员；母亲教师；非主角同校 |
| 今天 | 6:30 起床；7:20 到校；文化课/蛊道课；17:30 训练；21:00 作业 |
| 钱 | 家庭支持修炼；个人零花有限；一双训练鞋穿到旧 |
| 身体/情绪 | 肩宽，手有旧伤；寡言；怕达不到父亲期待 |
| 目标 | 主：毕业前冲二转；次：下月对战不被降组 |
| 关系 | 顾霆（实战老师）、贺疏影（同组竞争）、父亲、队友 |
| 可打断 | 训练/上课不能；钓鱼时能；比赛前紧张 |
| 变化触发 | 受伤/输赛/父亲施压→加练或退缩 |

### 4.5 周明诚（MED-001，43 岁，北城社区医院全科医生）

| 项 | 基线 |
|---|---|
| 固定 | 北城；妻子药房；儿子高中；非蛊师 |
| 今天 | 8:00 门诊；12:00 午休；14:00 门诊；18:00 交班；夜班另排 |
| 钱 | 收入稳定；儿子高中学费/补课是压力；不富但不紧 |
| 身体/情绪 | 戴眼镜；耐心但怕医闹；夜班后脾气差 |
| 目标 | 主：把社区慢病档案做全；次：儿子升学 |
| 关系 | 林巧（护士）、叶青萝（校医/旧同事）、顾清和（蛊道医疗）、患者 |
| 可打断 | 门诊中不能；午休可；夜班后不想说话 |
| 变化触发 | 病人投诉/档案检查/夜班过多→疲惫或争执 |

## 五、NPC 自主生活四项驱动

每个 NPC 的行动，优先由这四项驱动，而不是“主角需要”：

| 驱动 | 表现 | 例子 |
|---|---|---|
| **安全** | 保住房租、工作、健康、孩子 | 陈慧先保女儿看病，再想办法补房租 |
| **义务** | 对家人、工作、承诺的责任 | 周明诚必须完成门诊/交班；王秀兰答应给邻居量血压 |
| **利益** | 钱、机会、地位、资源 | 马国栋想把空房出租；钟临溪想升二转 |
| **关系/情绪** | 亲近、面子、怨气、孤独 | 王秀兰不想麻烦人；陈慧怕被看不起；钟临溪怕父亲失望 |

**冲突优先**：当两个驱动冲突，先满足“安全/义务”，再谈“利益/情绪”。这能让 NPC 的选择稳定，而不是随机。

## 六、NPC 事件生成

### 6.1 四步

```
① 选 NPC：他当前的主目标是什么？
② 加阻碍：钱/时间/身体/制度/关系，哪一项不够？
③ 让他行动：他会先找谁、花多少、瞒什么、放弃什么？
④ 留变化：目标推进/失败/转向；关系变好/变坏；钱变多/变少。
```

### 6.2 频率

- 每个长期 NPC **每周最多 1 个独立事件**；5 个 NPC 一周最多 5 个，不要同时爆炸。
- 事件不必都被主角看见；可先记录，后续通过后果/传闻撞上来。
- 同一 NPC 连续两周同一事件，应升级或转向，不能原地循环。

### 6.3 NPC 不会全知

- 马国栋不知道学校对战规则；
- 钟临溪不知道主角家现金；
- 周明诚不知道蛊虫黑市价格；
- 王秀兰听错是常态，不是恶意。

**NPC 只知道自己的圈子、职业、经历允许他知道的事**；跨圈信息要通过人传、公告、新闻，且可能失真。

## 七、NPC 与主角的互动边界

| 情况 | 正确写法 | 错误写法 |
|---|---|---|
| 主角临时上门 | 先写 NPC 原本在做什么；能否放下 | NPC 永远在家、永远有空 |
| 主角求助 | NPC 有自己的顾虑/成本/能力上限 | 所有邻居都无条件帮忙 |
| 主角不参与 | NPC 按自己的目标继续 | NPC 生活暂停等主角 |
| 主角改变计划 | NPC 可能失望/改约/自己走 | NPC 强行把主角拉回原计划 |
| 主角隐瞒 | NPC 只能根据可见信息判断 | NPC 自动识破或自动相信 |
| NPC 拒绝 | 给出理由/替代方案 | 把拒绝写成“冷漠”标签 |

## 八、30 天状态更新节奏

| 节点 | 更新什么 | 产出 |
|---|---|---|
| 第 1 天 | 建表：今天计划、钱、目标、关系、可打断程度 | 基线 |
| 第 7 天 | 一周变化：钱、疲劳、目标推进、关系 | 周记 |
| 第 14 天 | 月中压力：房租/学费/比赛/门诊 | 事件卡 |
| 第 21 天 | 目标是否转向；是否出现新关系/新麻烦 | 周记 |
| 第 30 天 | 月结：现金、健康、目标、关系、未结事项 | 月快照 |

**月快照必须回答**：这个 NPC 下个月最想做什么？最怕什么？欠谁/谁欠他？主角若不再出现，他会怎样？

## 九、常见失败与修正

| 失败 | 表现 | 修正 |
|---|---|---|
| 工具人化 | NPC 只等主角上门 | 每次登场先写“他原本在做什么” |
| 全员好人 | 所有人都帮主角 | 给出拒绝的理由/成本/能力上限 |
| 经济透明 | NPC 不为钱发愁 | 记现金/欠款/近期大额 |
| 时间透明 | NPC 随时有空 | 记工作/家庭/通勤/休息 |
| 情绪跳跃 | 上次吵架这次亲热 | 记未结关系与事件日志 |
| 全知 | NPC 知道不该知道的事 | 标信息来源与失真 |
| 主角中心 | 所有关系都绕主角 | 建 NPC 之间关系（房东—租客、医生—护士、老师—学生） |

## 十、结论

- NPC 自主生活的核心不是“写更多对白”，而是**五项状态＋每周一事件＋月快照**。
- 五名样本覆盖房东、独居老人、单亲母亲、学生蛊师、社区医生，足以验证不同年龄/职业/经济层。
- 状态表是 GM 工具，不需要玩家看到全部；但 GM 必须知道 NPC 现在在干什么、缺什么、下一步会怎样。
- 测试 E 将用这五人跑 30 天，验证“主角不参与时，生活是否还能成立”。
