# 16 两名 11 岁儿童的日常生活边界

> 职责：给 GM/AI 一份“两名 11 岁儿童同住”的日常运行底线与典型事件，不把他们写成小大人，也不把日常写成处处危险。
> 边界：不扩展成人恋爱/性内容；不新增亲属；不把苏晞写成主角的保姆/监护人；不替玩家决定性格。
> 依据：`04_世界/13_苏晞人物档案.md`；`04_世界/14_主角开局档案.md`；`04_世界/05:840-867`（学校作息）；第三项测试 A/B/E。

## 一、能力基线

| 能力 | 能做 | 不能做/需帮助 |
|---|---|---|
| 做饭 | 煮面、蒸蛋、炒简单菜、用电饭煲/微波炉/电磁炉；看懂火候 | 不独立处理大量热油、不深炸、不徒手端沸锅、不杀鱼/剁骨 |
| 厨房安全 | 关火、盖锅盖灭火、烫伤冲水 | 不独自处理燃气泄漏、不逞强扑油火 |
| 家务 | 扫地、洗衣、晾衣、洗碗、倒垃圾、简单缝补 | 不搬重物、不登高擦窗、不修电器 |
| 购物 | 列清单、比价、看保质期、算找零 | 不大额赊账、不网贷、不买蛊材/烟酒 |
| 独自在家 | 白天短时、锁门、不给陌生人开门 | 夜间长时间独居需社区知会；生病/受伤要联系大人 |
| 出行 | 步行 1—2 km、公交、认路 | 不夜间独自去偏僻地、不搭陌生人车 |
| 照顾彼此 | 量体温、倒水、煮粥、陪去医院 | 不擅自用药、不签手术/同意书、不隐瞒病情 |
| 情绪 | 会害怕、会生气、会逞强、会和好 | 不要求“永远懂事”；不把情绪当剧情工具 |

## 二、一日流程（上学日）

| 时间 | 做什么 | 谁负责 | 安全底线 |
|---|---|---|---|
| 6:30—7:00 | 起床、洗漱、早饭 | 两人分工；苏晞常先起 | 不赖床到 7:20；煤气/电器关好 |
| 7:00—7:30 | 出门、步行/公交 | 两人同行 | 7:50 到校；雨天提前 |
| 7:50—16:30 | 上课；周五 15:40 放学 | 学校 | 请假/晚归要通知 |
| 16:30—17:30 | 课后服务/社团/回家 | 苏晞/主角 | 最晚 18:00；不跟陌生人走 |
| 17:30—19:00 | 做饭、吃饭、洗碗 | 轮换；苏晞主厨时可打下手 | 热油/开水不让孩子单独端 |
| 19:00—20:30 | 作业、复习、家务 | 两人 | 不抄作业；不熬夜到 23:00 |
| 20:30—21:30 | 洗澡、洗衣、收拾 | 两人 | 浴室防滑；热水不烫 |
| 21:30—22:30 | 睡前、检查门窗/电器 | 两人 | 手机/电话可联系大人 |
| 22:30 | 熄灯 | — | 夜间异常先打电话，不自己开门 |

**周五**：15:40 放学，课后服务最晚 18:00；不默认“周五可以玩到很晚”。

## 三、厨房规则

### 3.1 允许

- 用电饭煲、微波炉、电磁炉、热水壶；锅柄朝内；灶台旁不放抹布/纸。
- 煮面、蒸蛋、炒青菜、加热剩饭；油温不用等到冒烟。
- 烫伤立即用凉水冲 10—15 分钟，不涂牙膏/酱油；严重去诊所。
- 切菜用中小刀，手指蜷起；不剁骨、不处理活鱼。

### 3.2 禁止

- 11 岁独自深炸、端整锅热油、掀高压锅。
- 燃气泄漏时开灯/打火；先关阀、开窗、到室外打电话。
- 用湿手插拔电器；一个插座接多个大功率。
- 把蛊材/药品当食材；不认识的野菜/蘑菇不吃。

### 3.3 分工

- 苏晞会做饭，但不是“必须做”；她累了/考试周，主角应接手或简化（面条/蛋炒饭/外带）。
- 一人做饭，另一人洗碗/擦桌；不把厨房全压给苏晞。
- 每周至少 1 天“简单餐/剩菜/外带”，避免“每天三菜一汤”的假日常。

## 四、夜间与独处

| 情形 | 规则 |
|---|---|
| 正常夜间 | 门窗锁好；走廊灯；电话放床边；不随便开门 |
| 一人晚归 | 另一人保持电话畅通；超过 21:00 未归，联系班主任/社区 |
| 两人独处过夜 | 需临时照料人/社区知会；不是“完全没人管” |
| 停电 | 用手电/手机灯；不点蜡烛；冰箱少开；联系社区 |
| 陌生人敲门 | 不开门；说“大人在忙”；记外貌/离开方向；报警/联系门卫 |
| 生病 | 量体温；喝水；联系临时照料人/社区医生；不擅自吃成人药 |
| 受伤 | 先止血/冲水；严重打急救；不隐瞒 |
| 噩梦/害怕 | 可以开灯、互相陪伴；不嘲笑；第二天可告诉老师 |

**不要**：为了剧情让陌生人随便进门、让儿童深夜独自去偏僻地、让两人“什么都不怕”。

## 五、生病照顾

1. **观察**：体温、精神、进食、疼痛、呼吸、皮疹、呕吐/腹泻。
2. **联系**：临时照料人/社区医生/校医；说明症状、持续时间、用药。
3. **用药**：只按说明书/医生；不把成人药减半给儿童；不重复吃退烧药。
4. **隔离**：发烧/呕吐/传染期不去学校；通知班主任；补作业/请假。
5. **陪护**：一人陪、另一人跑腿；不两人都倒下；必要时社区上门。
6. **红线**：高热惊厥、呼吸困难、意识不清、持续呕吐、脱水、剧烈腹痛→急诊。

## 六、学校与出行

- 7:50 到校；16:30 放学；周五 15:40；课后服务最晚 18:00。
- 两人同行优先；分开走要约定到家时间。
- 不跟陌生人走；不坐无牌车；不把家庭地址/钥匙给同学。
- 请假/晚归/活动变更：班主任→临时照料人；不自己编理由。
- 校园欺凌/被勒索：告诉班主任/校医/社区；不私下“摆平”。
- 不带蛊虫/蛊材入校（除非学校课程登记）；不炫耀系统物品。

## 七、家务与采购

| 事务 | 频率 | 分工 | 标准 |
|---|---|---|---|
| 做饭 | 每日 | 轮换/苏晞主厨时主角打下手 | 一荤一素/面/饭；不浪费 |
| 洗碗 | 每日 | 做饭者以外 | 不隔夜 |
| 洗衣 | 每周 2—3 次 | 轮换 | 深浅分开；不堆到没衣服 |
| 扫地/拖地 | 每周 2 次 | 轮换 | 厨房/卫生间重点 |
| 倒垃圾 | 每日/隔日 | 轮换 | 厨余不过夜 |
| 采购 | 每周 1—2 次 | 两人/一人 | 清单、预算、票据 |
| 记账 | 每日/每周 | 一人记、一人核 | 不重复、不漏 |

**采购规则**：先看家里库存；列清单；带固定预算（如 150—250 CLU/次）；不买临期大量；不赊账；保留小票；超支说明。

**求助顺序**：现场危险→先离开/报警；受伤→急救；学校→班主任/校医；家里→临时照料人/社区；被跟踪→进店/保安/人多处→报警。

**不要**：让儿童“自己解决”暴力/侵害/跟踪；不把报警写成添麻烦。

## 九、苏晞的独立面

- 她会做饭、记账、照顾人，但不是“全能姐姐”；她也会累、考砸、和朋友吵架、想被照顾。
- 她有自己的朋友、兴趣（如画画/植物/阅读）、零花钱、秘密；不是主角的附属。
- 她可以拒绝不合理要求（“今天我不想做饭”“你自己洗”）；主角不能把她当保姆。
- 她的情绪有原因：学校压力、朋友疏远、想念父母、对钱焦虑；不要只写“她温柔地笑了”。
- 两人关系是**相依为命的家人/朋友**，不是成人恋爱；不写性暗示、不写求婚/同居浪漫化。

## 十一、AI 执行规则

1. 先问“这个年龄能不能做”，再写“她愿不愿意做”。
2. 不把苏晞写成保姆/监护人/成人恋人；她有拒绝权。
3. 不为了剧情频繁制造危险；日常大多数时候是平淡的。
4. 不把“独立”写成“不需要任何人”；求助是正常能力。
5. 厨房/夜间/生病/陌生人四条线要有底线。
6. 学校时间按 7:50/16:30/周五 15:40/课后 18:00。
7. 钱的事走 12 的账本；不让孩子管大额现金。
8. 情绪要绑定行为与原因；不写“莫名其妙发脾气”。
9. 两人关系可以亲密，但不写成人恋爱/性。
10. 信息不足写“未知”；不替玩家决定主角性格。
