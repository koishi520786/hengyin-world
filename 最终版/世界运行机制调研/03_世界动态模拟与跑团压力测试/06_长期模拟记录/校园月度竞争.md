# 测试 C：校园月度竞争

> 样本：北城蛊师中学初三一个年级，按专项一推荐方案 C（双向押注＋基础保底＋封顶豁免）模拟。
> 时间：垠历 738 年 10 月 1 日—10 月 31 日（测试周历：10.1 周六；最后周六 10.29）。
> 性质：方案 C 仍是 **S5 研究建议、S6 待负责人裁定**，不是正式制度；本测试验证“如果采纳，能不能跑”，不宣布已生效。

## 一、制度参数（来自专项一方案 C）

| 项 | 值 |
|---|---|
| 对象 | 蛊道班在册学生，自愿参加；不强制全体 |
| 资格 | 上月蛊道实践课评前 60%；课评＝理论 40%＋操作 40%＋课堂记录 20%，不含资质数据 |
| 名额 | 每年级 32 人（16 组）；三个年级 48 场/月 |
| 配额 | 基础 120 CLU/月（不可夺）＋浮动 80 CLU/月（最多押 50%＝40） |
| 胜负 | 胜者下月 240；败者下月 160；差距 80 CLU |
| 赛制 | 三局两胜，每局 3 分钟，局间 2 分钟；同组 16 场分两场地 |
| 蛊虫 | 自带已登记一转凡蛊 ≤3 只；赛前 30 分钟验蛊、编号封存；禁辅助蛊/消耗品 |
| 时间 | 最后一周周六 9:00—12:00；避开月考周、开窍节、闭窍日 |
| 伤病 | 五级医疗路径；保险先付；伤者下月自动豁免、配额不减 |
| 账目 | 学校只做账面划转；另出 20 CLU/场胜场补贴；配额凭证当月有效、不可提现/转让 |

## 五、正式对战记录

### 5.1 B 组：贺疏影 2:1 钟临溪

| 局 | 过程 | 结果 | 消耗/后果 |
|---|---|---|---|
| 第 1 局 | 钟用石皮蛊硬抗，近身压迫；贺用月旋蛊拉开距离 | 钟胜 | 钟真元消耗约三成；贺护罩被磨掉 |
| 第 2 局 | 贺改节奏，月痕蛊连续试探；钟急于终结，两次扑空 | 贺胜 | 钟真元见底；右小臂被月痕擦伤 |
| 第 3 局 | 钟想速战，输出下降；裁判在有效命中差拉开后终止 | 贺胜 | 钟小臂流血；校医止血/清创 |

**赛后处置**：
- 校医叶青萝？北城蛊师中学校医未在人物库锁定；使用“校医组”临时。止血、清创、包扎，建议去蛊道医疗中心查是否有蛊毒残留。
- 钟父 12:10 到校，带钟去临江市蛊道医疗中心；初诊 200—600 CLU，实际检查＋药 **280 CLU**（S5 模拟值，落在正式区间内）。
- 按方案 C：保险先付；但正式库没有保险条款/直付流程，测试按“家庭先垫 280，保险后报”记录。**这是缺口，不是已解决。**
- 钟下月自动豁免，配额不减；但“恢复到什么程度能复训”无正式标准，顾霆只能按“伤口结痂、无真元逆行”临时判。

## 十、结论

**方案 C 可跑，但必须补四个接口**：

1. **12—15 岁赛前监护人知情/签字**：正式库只明确 16—18 双签；15 岁限制级不能只靠口头。
2. **保险直付/校方责任**：方案 C 写“保险先付”，正式库无条款；测试只能家庭先垫。
3. **恢复期四联表**：无正式恢复天数，GM 只能临时判“能不能复训”。
4. **验蛊/保管/裁判**：方案 C 有流程，但正式库未采纳；需要校规/教务细则落地。

**制度本身没有造成“永久底层”**：基础 120 保底、押注上限 40、零押注通道、伤病豁免都在起作用。**真正的风险在社交层**：输的人会被同学议论，穷的人会被迫选零押注；这不是配额能解决的，需要班主任/校医/家长共同处理。

**最值得补的正式资料**：校医赛时职责、保险直付、恢复期表、12—15 岁知情书。四项都属于 B 级，不影响开局，但决定校园线能否长期跑。
