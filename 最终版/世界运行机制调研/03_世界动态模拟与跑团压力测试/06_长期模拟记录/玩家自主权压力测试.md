# 测试 H：玩家自主权压力测试

> 目的：验证玩家临时改变计划、拒绝、沉默、绕路、做出 GM 没预想的决定时，GM 是否还能只写环境与 NPC，不替主角思考/行动，不强行拉回预设路线。
> 原则依据：`05/01` 玩家控制权与 NPC 连续性、`05/06` 角色表现与主动互动、`05/11` 叙事与长期连续性、`05/12` 核心锁定。
> 测试方式：每个场景给出“玩家可能的选择”，再给“正确 GM 写法/错误写法/停点”。不是替玩家预设选择，而是测试 GM 的反应边界。

## 一、通用停点模板

当玩家改变计划，GM 按四步：

```
① 先确认当前可观察事实：时间、地点、谁在场、什么被改变。
② 只写环境与 NPC 的反应：NPC 会做什么/说什么/不做什么。
③ 不写主角的想法、情绪结论、内心独白；不替主角补下一步行动。
④ 停在选择点：把可见后果摆出来，问“你要怎么做/去哪里/说什么”。
```

**一句话**：GM 可以切镜头、推进 NPC 行动、写后果；不能替主角决定“他还是去了/他其实想/他最终选择”。

## 二、10 个压力场景

### H-01 上学日，玩家决定不去学校

- **场景**：738.9.14 周三 7:20，主角本该出门去第二小学；玩家说“我不去学校，去云栖河边”。
- **可见事实**：雨刚停，楼道潮湿；苏晞已经背书包；楼下有邻居出门。
- **NPC 反应**：
  - 苏晞会问“你不去吗？”，但她要上学，不会陪主角逃课；她可能替主角跟班主任说“他没来”，也可能不说（由她的性格/关系决定）。
  - 班主任沈静姝 7:55 点名发现缺勤，打第一联系人；无人接，再打第二联系人/社区儿童主任；不会“突然出现在河边”。
  - 门卫韩守义如果看到主角往外走，会问“上课时间，去哪？”；按校规登记，不替主角撒谎。
- **正确写法**：“你走到校门口又拐向河堤。韩守义从门岗探出头：‘上课了，你往哪走？’雨后的河堤没什么人，只有广告牌在滴水。”
- **错误写法**：主角“心里其实很愧疚，最后还是转身回学校”；或老师突然骑车追来把他拉回去。
- **停点**：“你要回学校、继续去河边，还是先躲开门卫？”
- **后续**：缺勤记录、班主任联系监护人、社区关注；逃课后果不会自动消失。

### H-02 放学后，玩家决定去蛊市/黑市

- **场景**：16:30 放学，玩家不回家，想坐公交去南岸蛊虫市场或“听说有黑市”。
- **可见事实**：公交 2 曜元；蛊市 6:00—18:00；到南岸需要换乘/时间；未成年人身份明显。
- **NPC 反应**：
  - 公交司机不会拒载，但会看一眼校服；到站自己下。
  - 蛊市门卫/摊主会问“你一个人？家长呢？”；未开窍、无登记、无钱的未成年人，买不到正规蛊，反而容易被黑市盯上。
  - 苏晞/邻居可能发现他没回家，告诉班主任/社区；不是“没人管”。
- **正确写法**：“你在南岸市场门口下车，门口保安拦了一下：‘小孩，找谁？’里面摊位的灯还亮着，有人看了你一眼，又低头整理盒子。”
- **错误写法**：主角“顺利买到一只蛊”；或 GM 直接说“你不能去”而剥夺选择。
- **停点**：“你要进市场、在门口等，还是回去？”
- **后续**：黑市风险、被盯上、GAB/学校介入；不是“去一次就变强”。

### H-03 班主任让去诊所，玩家拒绝/改去药房

- **场景**：主角在校咳嗽/低烧，沈静姝让他去社区诊所；玩家说“我不去，我去药房买点药”。
- **可见事实**：校医叶青萝建议看医生；药房 8:00—22:00；社区诊所 8:00—20:00。
- **NPC 反应**：
  - 班主任不能绑他去；她可以通知监护人/紧急联系人，记录“建议就医、学生拒绝”。
  - 校医可以给基础处置/建议，但不能替代医生开处方；药房可能不卖某些药给未成年人。
  - 如果症状重，老师会坚持联系家长/社区，不是“随他去”。
- **正确写法**：“叶青萝把体温计收好：‘37.8℃，最好去诊所看一下。’沈静姝拿出手机：‘我联系你家里人，你自己跟他说。’”
- **错误写法**：GM 替主角决定“他还是去了诊所”；或老师强行拖走。
- **停点**：“你要去药房、去诊所，还是先回家？”
- **后续**：病情可能加重；学校记录；监护人/社区介入。

### H-04 同学邀请去公园，玩家选择独自离开

- **场景**：16:30 放学，林予安/陈知夏邀请主角去河滨公园；玩家说“我不去，我想一个人走走”。
- **可见事实**：公园 500 m；天还亮；主角 11 岁，独自行动有安全边界。
- **NPC 反应**：
  - 同学会失望/追问/自己离开；不会强行拉他。
  - 如果主角走向偏僻河堤，门卫/邻居可能提醒；不是“全世界都知道他心情不好”。
- **正确写法**：“陈知夏‘哦’了一声，和林予安往公园走。你拐进小区另一条路，路灯还没亮，楼道里有人在炒菜。”
- **错误写法**：同学“看出他心情不好，陪他走了一路”；或 GM 替主角说“他其实想静静”。
- **停点**：“你往哪走？回家、去河边，还是回学校？”
- **后续**：晚归、家里问、同学关系小变化；没有大剧情也可以。

### H-05 房东催租，玩家选择拖/借钱/卖东西

- **场景**：9.5 晚上，马国栋敲门：“房租今天到期。”玩家说“我没钱，再宽限几天”/“我明天去借”/“我把东西卖了”。
- **可见事实**：合同、收据、上月是否按时；陈慧也欠租；马国栋怕拖欠。
- **NPC 反应**：
  - 马国栋会看主角家的记录；可能同意 3—5 天，也可能要求先付一部分；不会因为“主角可怜”无限宽限。
  - 他不会自动介绍工作/借钱；可以提“你去找社区/学校”。
  - 如果拖太久，他会贴通知/找社区调解/考虑解约；这是他的利益。
- **正确写法**：“马国栋把钥匙串往手心一压：‘上个月是准时，这个月我也有账要付。你最晚什么时候能给我个准话？’”
- **错误写法**：房东“叹了口气说不用给了”；或 GM 替主角决定“他去借钱”。
- **停点**：“你要怎么答复？给日期、先付一部分、还是让他找社区？”
- **后续**：信用/关系/居住稳定；不是一次对话就解决。

### H-06 校园对战报名，玩家选择不报名/零押注/隐藏实力

- **场景**：10.1 公布资格名单，主角在蛊道班；玩家说“我不报名”/“我零押注”/“我故意输”。
- **可见事实**：报名自愿；资格前 60%；零押注通道；故意输违反赛风。
- **NPC 反应**：
  - 教务不会强迫报名；会记录“自愿放弃”。
  - 同学可能觉得他怕/装；教练可能问原因；不会替她填表。
  - 如果故意输/利益交换，裁判/教务按规则查；不是“主角聪明占便宜”。
- **正确写法**：“教务把名单往下翻：‘不报？行，签个自愿放弃。’旁边的同学看了你一眼，没人说话。”
- **错误写法**：老师“苦口婆心劝他一定要参加”，最后他还是报了；或 GM 认定他“其实想报”。
- **停点**：“你签不签？零押注还是完全不参加？”
- **后续**：配额/分组/同学关系变化；不参加也有后果（少一次机会），但不是惩罚。

### H-07 系统任务，玩家拒绝/只完成一半/改做别的事

- **场景**：系统发布“整理书桌/散步 15 分钟”；玩家说“我不做”/“我只做一半”/“我去做别的”。
- **可见事实**：系统只对主角可见；任务不强制；未完成无奖励、不惩罚。
- **NPC 反应**：NPC 看不见系统，不会知道“任务失败”；他们只看到主角在不在整理/散步。
- **正确写法**：“系统界面淡去。桌上还是那几本书，窗外有人在倒垃圾。没有人知道你刚拒绝了什么。”
- **错误写法**：系统“警告/扣除奖励/强制惩罚”；或 GM 替玩家判定“他完成了”。
- **停点**：“你做不做？做到什么程度？”
- **后续**：没有奖励；系统不补发、不叠加；玩家可继续自己的安排。

### H-08 邻居求助，玩家选择不帮/报警/找别人

- **场景**：王秀兰在楼道扶着墙，脸色发白；玩家说“我不帮，我怕”/“我打社区电话”/“我去叫陈慧”。
- **可见事实**：王秀兰 70 岁、独居、耳朵背；社区/诊所电话可见；主角 11 岁。
- **NPC 反应**：
  - 王秀兰可能说“没事，老毛病”，也可能真的需要帮助；她不会自动康复，也不会强求一个 11 岁孩子。
  - 如果主角不帮，她可能自己敲邻居门/坐下缓一缓；后果按时间发展。
  - 如果主角报警/找社区，社区会按流程来；不是“主角一喊，所有人立刻到”。
- **正确写法**：“王秀兰摆摆手：‘没事，歇会儿。’她手还扶着墙，钥匙掉在地上。楼道声控灯灭了又亮。”
- **错误写法**：GM 说“你怎么能见死不救”，逼主角帮忙；或王秀兰“突然好了”。
- **停点**：“你要扶她、去叫人、打社区电话，还是走开？”
- **后续**：王秀兰的健康/对主角的看法/社区记录；不帮不是“道德审判”，但有后果。

### H-09 危险区域，玩家决定进入/带朋友进入

- **场景**：听说云栖河水眼/废弃地下层有“好东西”，玩家说“我进去看看”/“我带林予安一起”。
- **可见事实**：REALM-064 云栖河水眼 S0/D1/R1，已登记无开发；未成年禁 D2 以上；无监护/无登记不能进。
- **NPC 反应**：
  - 门卫/居民/同学会警告；不会替主角开路。
  - 如果带朋友，朋友可能拒绝/害怕/告诉家长；不是“全员冒险”。
  - 真出事，救援/医疗/GAB 按规则来，不是系统保命。
- **正确写法**：“水眼入口的铁栅栏上了新锁，旁边贴着‘未开放，禁止入内’。林予安拉了拉书包带：‘真要进去？’”
- **错误写法**：GM 直接“你们顺利进入并找到宝物”；或强行“你不能去”而不给选择。
- **停点**：“你撬锁、绕路、还是回去？”
- **后续**：违规/受伤/被查/朋友关系；系统不能兜底。

### H-10 玩家改变长期目标（不考蛊师中学/退学/打工）

- **场景**：主角说“我不想考蛊师中学了，我要去打工/退学”。
- **可见事实**：11 岁未满 12，原则上不得正式雇佣；义务教育；监护/社区/学校会介入；蛊师中学是分轨选项，不是唯一路。
- **NPC 反应**：
  - 班主任会问原因、联系监护人/社区；不会替主角改志愿。
  - 雇主可能拒绝 11 岁童工；正规店不敢用；黑工有风险。
  - 社区/民政会评估监护/辍学风险；不是“主角一句话就退学”。
- **正确写法**：“沈静姝把笔放下：‘退学不是你说一句就行，我要联系你家里人和社区。你先告诉我，为什么？’”
- **错误写法**：GM 说“你成功退学，开始打工”；或老师“你必须考蛊师中学”，强行拉回原路线。
- **停点**：“你要怎么回答？坚持、改口、还是去找社区？”
- **后续**：学校/社区/监护程序；不是立刻成功/失败。

## 三、测试结果

| 场景 | 能否只写环境/NPC | 是否容易滑回预设 | 判定 |
|---|---|---|---|
| H-01 逃课 | 能 | 中：容易让老师“恰好出现” | 条件通过，需停点 |
| H-02 去蛊市/黑市 | 能 | 高：容易“顺利买到/直接禁止” | 条件通过，需信息边界 |
| H-03 拒绝就医 | 能 | 中：容易替主角决定“还是去了” | 通过 |
| H-04 独自离开 | 能 | 低 | 通过 |
| H-05 欠租 | 能 | 中：容易让房东“心软免租” | 通过 |
| H-06 不报名/零押注 | 能 | 中：容易老师劝回 | 通过 |
| H-07 拒绝系统任务 | 能 | 低 | 通过 |
| H-08 不帮邻居 | 能 | 高：容易道德绑架 | 条件通过，需克制 |
| H-09 进危险区 | 能 | 高：容易“系统保命/直接禁止” | 条件通过，需规则前置 |
| H-10 退学/打工 | 能 | 高：容易一句话成功/强行拉回 | 条件通过，需程序 |

**总计**：10 个场景都能按原则处理；其中 5 个（H-01/02/08/09/10）容易滑回预设或替玩家决定，需要停点模板与规则前置。

## 四、GM 高频错误

| 错误 | 表现 | 修正 |
|---|---|---|
| 替主角思考 | “你觉得害怕/你其实想……” | 只写可见：手抖、后退、沉默 |
| 替主角行动 | “你最终还是去了学校” | 停在选择点，问玩家 |
| 强行回主线 | 老师/NPC 恰好出现拉回 | 让主线事件继续，主角缺席也有后果 |
| NPC 全配合 | 所有人都帮/都原谅 | 按 NPC 利益/性格拒绝/犹豫/收费 |
| 道德绑架 | “你不帮就是冷血” | 写后果，不写审判 |
| 系统兜底 | 危险时系统救/奖励 | 系统不能绕过世界规则 |
| 信息全知 | NPC 知道主角秘密 | 按可见/听说/被告知分级 |
| 场景瞬移 | 上一句在家，下一句到蛊市 | 写路上时间/车费/门卫 |

## 五、结论

**玩家自主权原则可执行，但需要“停点”而不是“少写”。**

- GM 可以切镜头、推进 NPC、写后果；不能替主角决定想法/行动。
- 玩家改变计划时，世界要继续：老师会联系、房东会催、同学会走、社区会记录；不是“主角不在，世界暂停”。
- 最容易出错的是“好心强行拉回”：老师恰好出现、房东免租、邻居自动获救、系统兜底。这些都要避免。
- 最值得补：一张“停点卡”（可见事实→NPC 反应→选择点→后果），贴在 GM 手边；不需要新增规则。
