# 测试 G：隐藏系统与世界规则交互

> 目的：模拟主角开窍前获得系统奖励、在系统空间存放蛊虫、开窍后处理奖励，检查系统是否会被误写成“绕过世界规则的外挂”。
> 规则依据：`05/10` 隐藏系统、`05/09` 开局、`04/01` 第九节、`04/05` 7.1、`01_蛊虫/10` 与一转蛊虫档案。
> 说明：D0＝玩家确认的 11 岁生日；本测试取 738.9.1 作模拟起点，**不代表正式锁定开局日期**。开窍按 12 岁、739 年 3 月第 2 周（测试周历 3.8—3.14）。

## 一、系统硬边界

| 系统能做 | 系统不能做 |
|---|---|
| 给主角发布每日两个低难度任务 | 替主角完成现实任务；GM 不得擅自判定完成 |
| 给物品/资源奖励（蛊虫、材料、元石、仙材） | 直接给境界、战斗胜利、关系好感、剧情豁免 |
| 存放奖励在系统空间；主角主动取出才进现实 | 自动把奖励变成已炼化、已登记、可催动的蛊虫 |
| 只对主角可见 | 被 NPC 看见/探测/复制/交易；NPC 不会突然猜出 |
| 按奖励池随机发放 | 按主角当前最需要定制；连续给高转/仙材 |
| 提示任务/奖励 | 替主角分析局势、提示未发现的危险、当全知旁白 |

## 二、模拟时间线

| 节点 | 事件 | 系统侧 | 现实侧 |
|---|---|---|---|
| D0（738.9.1） | 11 岁生日，系统激活 | 发布两个任务：整理书桌、散步 15 分钟 | 主角刚开学；住在云栖花园；未开窍 |
| D+1—D+6 | 每日任务 | 学习/生活类 OOC 任务；玩家可拒绝 | 上课、作业、家务；没有“系统面板”被同学看见 |
| D+7 | 首次奖励 | 常见档：**C-G-022 石皮蛊（一转）**，存入系统空间 | 主角看不到实物，只在系统中看到记录 |
| D+30 | 第二次奖励 | **低品位元石 0.05 kg**，存入系统空间 | 现实没有多出元石；家庭账不变 |
| D+40 | 主角主动取出石皮蛊 | 系统记录“已取出”；空间减少 1 | 现实中出现一只活蛊；需要容器/喂养；不能催动 |
| D+60 | 第三次奖励 | **C-G-037 青丝蛊（一转）**，存入系统空间 | 仍未炼化；主角开始想“开窍后能不能用” |
| D+188（739.3.8—3.14） | 开窍大典 | 系统不替开窍；不保成功 | 62% 成功/38% 失败（全球口径）；主角结果待判定 |
| 开窍后 D+189 | 处理奖励 | 系统不自动炼化 | 若成功：可按规则尝试炼化石皮蛊/青丝蛊；若失败：仍不能催动 |

## 三、开窍前：奖励只是“存放物”

### 3.1 D+7 首次奖励

系统记录：

```
日期：738.9.8
任务：整理书桌 / 散步 15 分钟
奖励：C-G-022 石皮蛊（一转凡蛊）×1
存放：系统空间
是否取出：否
备注：正式档案 C-G-022；未炼化、未登记、未认主
```

现实：
- 主角没有空窍/真元，不能炼化、认主、催动；石皮蛊在系统空间里，NPC 看不到。
- 家庭现金不变；没有“系统送钱”。
- 主角可以查看系统记录，但不能把“系统里的蛊”当成 already owned/已炼化。

### 3.2 D+40 主动取出

| 问题 | 结果 |
|---|---|
| 取出后在哪 | 主角手里/盒子里；需要透气、避光、防止逃脱（S5；正式库未写具体饲养容器） |
| 是否能催动 | 不能；未开窍、无真元；强行催动按未成年违规用蛊处理 |
| 是否已登记 | 没有；系统奖励不带登记号/来源证明 |
| NPC 是否看见 | 看见“一只蛊虫”，但看不见系统；会问“哪来的” |
| 是否可以卖 | 未登记/来源不明，正规市场不能正常交易；黑市有风险 |
| 是否要喂 | 活蛊需要喂养/温湿度；系统空间存放期间是否暂停代谢，**正式库未明确** |

**关键**：取出不等于拥有，拥有不等于炼化，炼化不等于能催动。四层不能混。

### 3.3 NPC 认知测试

| NPC | 看到什么 | 可能反应 | 不会发生 |
|---|---|---|---|
| 林予安（同学） | 主角盒子里有只黑色小虫 | “你哪来的？你会养蛊？” | 不会看穿系统 |
| 沈静姝（班主任） | 学生带未登记蛊虫到校 | 按校规暂扣/通知监护人/GAB | 不会相信“系统送的” |
| 马国栋（房东） | 可能听说“主角有蛊” | 好奇/担心/压价 | 不会知道系统 |
| 孙敬（GAB） | 未登记蛊虫 | 要求来源说明/登记/隔离观察 | 不会因为“系统”免登记 |
| 王秀兰（邻居） | 可能听错/传闲话 | “那孩子哪来的蛊？” | 不会自动帮忙隐瞒 |

**写法**：NPC 只能看见“蛊虫/盒子/主角的紧张”，不能看见“系统面板/奖励弹窗”。

## 四、开窍后：系统不自动炼化

### 4.1 分支 A：开窍成功

| 步骤 | 内容 | 规则 |
|---|---|---|
| 1 | 开窍成功，形成空窍；进入蛊师学籍 | `04/01` 第九节 |
| 2 | 尝试炼化石皮蛊 | 需蛊虫规则、空窍条件、真元、炼化条件；不是“点一下成功” |
| 3 | 是否本命蛊 | 由蛊虫规则与开窍情况判断；不是所有系统奖励都能当本命 |
| 4 | 登记 | 炼化/持有后按 GAB 登记；系统来源要说明；未登记不能正常交易 |
| 5 | 催动 | 一转蛊需真元；未成年 12—16 岁只能用一转蛊、禁 D2 以上、禁夜间单独用蛊 |
| 6 | 系统空间剩余 | 青丝蛊/元石仍在；取出/使用另记 |

**不能写**：开窍当天自动炼化两只蛊、直接战力飙升、系统帮他把蛊喂好。

### 4.2 分支 B：开窍失败

| 步骤 | 内容 | 规则 |
|---|---|---|
| 1 | 开窍失败（38% 口径） | 仍可从事蛊道非修炼职业；不是“废人” |
| 2 | 系统奖励仍在 | 石皮蛊/青丝蛊可存/取出，但不能催动 |
| 3 | 是否能卖 | 未登记/来源不明，正规市场难；黑市风险 |
| 4 | 心理/社会 | 同学/家庭目光；学校分流；系统不能安慰/替决定 |
| 5 | 未来 | 可走蛊材加工、饲养、秘境后勤、蛊具制造等；不是死路 |

**不能写**：开窍失败后系统立刻给“第二空窍/补开窍”奖励；系统不能绕过开窍规则。

## 五、经济影响

| 奖励 | 名义价值 | 能否直接改善家庭 | 风险/成本 |
|---|---:|---|---|
| 石皮蛊（一转） | 800—3,000 CLU | 不能；未登记/未炼化不能正常卖 | 喂养/容器/登记/来源说明 |
| 青丝蛊（一转） | 800—3,000 CLU | 同上 | 同上 |
| 低品位元石 0.05 kg | 40 CLU（800 CLU/kg） | 可忽略；只够 1 天辅助 | 不能当货币；使用需蛊师 |
| 三转蛊（少见） | 1.8—6 万 CLU | 账面大，但一转空窍不能炼化/催动 | 保管/登记/被盯上 |
| 仙材（稀有） | 高价值 | 不能当现金；来源难说明 | 黑市/监管/危险 |

**结论**：系统奖励可以制造“账面财富”，但不能直接变成家庭现金流；要卖、要登记、要说明来源，都是世界规则。**系统不是脱贫按钮。**

## 六、系统任务与现实的边界

| 任务 | 系统写法 | 现实写法 | 不能写 |
|---|---|---|---|
| 数学错题 | “分析一道错题，写出错因” | 主角在书桌前做小学错题 | 高等数学成为小学课程 |
| 散步 | “散步 15 分钟” | 主角在小区/河滨公园走 | 系统替主角走 |
| 整理书桌 | “把书桌整理干净” | 主角自己收拾 | NPC 看见系统面板 |
| 早睡 | “23:00 前睡” | 主角实际睡/没睡 | 系统强制关机 |

**OOC 口径**：系统任务是玩家现实学习/生活任务，不是垠历 738 年小学课程；叙事中不解释成世界内教育制度。

## 七、边界压力测试

| 场景 | 错误写法 | 正确写法 |
|---|---|---|
| 主角开窍前想催动石皮蛊 | 系统给临时真元 | 不能催动；强行按违规用蛊/受伤处理 |
| 主角把蛊卖给蛊市 | 直接换 2,000 CLU | 未登记/来源不明→不能正常交易；需登记/验蛊/来源说明 |
| 主角带蛊到学校 | 同学羡慕、老师不管 | 校规暂扣/通知监护人/GAB；未成年持有边界 |
| 主角向 NPC 说“系统送的” | NPC 相信/帮忙保密 | NPC 不信/追问/可能报告；系统不可见 |
| 系统给三转蛊 | 主角立刻战力飙升 | 存着/不能炼化/不能催动；来源与保管风险 |
| 开窍失败 | 系统补开窍 | 不能；走非修炼职业/分流 |
| 系统空间存放活蛊 | 永不饥饿/无限容量 | 正式库未明确；需标“待确认”，不能当免费仓库 |
| 系统奖励元石 | 直接当钱花 | 元石不能当货币；只能蛊道用途/黑市风险 |

## 八、暴露的缺口

| 缺口 | 表现 | 级别 |
|---|---|---|
| 系统空间是否保鲜/喂食/容量 | 活蛊长期存放是否死亡/饥饿，正式库未明确 | **A/B** |
| 系统奖励来源证明 | 取出后如何向 GAB/市场说明来源 | **A** |
| 未登记蛊虫的未成年持有 | 12 岁以下不能炼化/催动，但“持有”边界与学校保管 | A/B |
| 系统奖励与家庭经济 | 卖蛊/元石是否影响补助资格/家庭账 | B |
| NPC 认知分级 | 看见蛊/听见传闻/被主角告知，三种信息不同 | B |
| 系统任务 OOC 与现实叙事 | 容易把高数/模电写成小学课程 | B |
| 开窍后炼化成功率 | 系统奖励蛊虫的炼化条件未逐只核对 | A/B |

## 九、结论

**系统规则边界清楚，现实接口不清。**

- 开窍前：奖励只能存/取，不能炼化/催动；NPC 看不见系统；家庭现金不变。
- 开窍后：系统不自动炼化；是否本命、能否催动，按蛊虫规则与空窍条件。
- 经济：奖励是物品，不是现金；要变现必须走登记/验蛊/来源说明/市场，系统不能绕过。
- 最大风险：**系统空间被写成免费、无限、保鲜的仓库**，以及**系统奖励被写成“来源不明也能正常使用/交易”**。
- 最值得补：系统空间存放规则（喂养/容量/时间）、奖励来源证明、未登记蛊虫的学校/GAB 保管流程、NPC 认知分级。四项都是 A/B 级，决定系统线是否会被读成“外挂”。
