# 07 问题与缺口清单

> 来源：`01` 能力审查＋`06` 八项测试。每条问题都标：测试来源、已有内容、为什么不够、缺什么类型、实际后果、建议、与其他专项关系、级别、解决方式。

## 三、A 级问题详述（开局/当前生活直接相关）

### A-01 监护与签字权

- **现状**：`04/05` 7.1 明确“制度上有监护顺位、临时监护、补助，但不自动出现照顾者”；7.1.5 给了“名义监护人/临时照料人、租赁持有人、学校紧急联系人、医疗同意人”字段。
- **缺**：开局卡没有填具体人；学校/医院/房东不知道找谁。
- **后果**：测试 B 中两名 11 岁儿童独立居家；一旦生病/受伤，学校只能找“第一联系人”，医院无人签手术；房东不敢续租。
- **建议**：开局卡加四栏；允许“社区儿童主任为临时联系人”但不等于收养；玩家可拒绝/更换，GM 不替选。
- **冲突**：不违反“不替主角安排亲戚”；只是把已有字段填上。

### A-02 补助金额/到账

- **现状**：有“按月补助、可叠加/择一、要年审”；无金额、无到账日。
- **后果**：测试 B 不能算“申请后下月够不够”；只能写“等审批”。
- **建议**：先给区间/测算表，不写死具体金额；负责人定“临江标准”。
- **冲突**：与专项一经济/民政可能重复；建议由专项一出标准，本专项只做家庭账接口。

### A-03/A-04/A-05/A-06 校园医疗四件套

- 事故报告、保险直付、未成年签字、恢复期表，是测试 D 的四个断点。
- **建议**：合成一张“校园伤病处理单”，不要拆成四套制度；学校/医院/保险各一栏。
- **冲突**：专项一医疗可能已有恢复研究；本专项只提“学校接口”，不重写医疗。

### A-07 家庭现金流

- **现状**：月支出有，日账无。
- **建议**：用 `05` 默认日（5/10/20/月末），每月一页；不新增物价。
- **冲突**：专项一经济已有价格体系；本专项只做“日期映射”。

### A-08 长期记忆

- **现状**：`05/11` 有原则；无快照/日志。
- **建议**：90/180/365 天三张快照；事件日志只记“谁/何时/欠什么/谁知道”；旧事回扣至少 3/5/8 条。
- **冲突**：专项一时间/连续性可能有类似；建议合并为一张表。

### A-09 系统接口

- **现状**：系统空间/奖励记录有；活蛊存放/来源证明无。
- **建议**：补“存放—取出—登记—来源说明”四步；容量/喂养标 S6，不擅自写“永不饥饿”。
- **冲突**：与 `01_蛊虫` 的养蛊规则可能冲突；必须先核对，不能另造。

### A-10 儿童独立居家

- **现状**：有劳动/监护字段；无“11 岁能不能独自做饭/过夜/谁知晓”。
- **建议**：三张清单：可做（简单早饭/洗衣/扫地）、不可做（明火/刀具/蛊材/夜间独行）、必须有人知晓（生病/晚归/陌生人）。
- **冲突**：不替玩家安排监护人；只写安全边界。

## 五、B/C 级处理顺序

1. **先做 R/I**：流程卡、索引、状态表——不改正式库，先让 GM 能跑。
2. **再做 N**：家庭现金流、恢复期、路线、价格指数——需要数值，但可由研究库先给区间。
3. **再做 S**：校园对战、事故报告、保险、系统接口——涉及正式制度，需负责人审核。
4. **最后做 D**：补助标准、方案 C 是否采纳、系统空间容量、高阶流动——留给负责人选择。

## 六、不建议做的事

- 不要为每个问题新增一套机构/货币/境界。
- 不要把“测试用 S5 默认值”直接写成正式法律。
- 不要把所有 NPC 都补成完整档案；先给高频 10 人建状态表。
- 不要用“系统”解释所有缺口；系统不能替代学校/医院/市场/监护。
- 不要把“玩家自主权”理解成“GM 什么都不写”；GM 要写环境、NPC、后果，只是不替主角决定。

## 七、结论

- 首轮共识别 **23 项问题**：A 级 10、B 级 10、C 级 3。
- 第二轮：A-01/A-03/A-05/A-06/A-07/A-08/A-10 已转为规则/工具；A-02/A-04/A-09 仍部分；B-01/B-05 已部分工具化；B-03 仍待确认。
- **A-03—A-06** 已合并到 `13` 的“校园伤病处理单”，不再拆四套制度。
- 剩余最硬的是 **补助、保险、系统活蛊/来源、负现金、368 边界**；这些不是再写一份流程卡能解决的，需要负责人/正式库。
