# 15 系统空间规则草案与来源衔接

> 职责：给隐藏系统的“奖励存储空间”划出可执行边界，并说明它和现实社会（登记、交易、税务、GAB、保险）如何衔接。
> 边界：正式库只锁定“可存奖励、取出记录时间/地点/见证者/现实存放位置、开窍前只能存/取”等少数规则；容量、活物、活蛊、喂养、时间影响、来源证明均【未知】。本文提出候选，不擅自定案。
> 依据：`05_跑团规则/10_隐藏系统.md`；`05_跑团规则/05_经济物品与资源.md`；`04_世界/05`（GAB/蛊师登记）；第三项测试 G。

## 一、正式已锁定

| 项 | 正式规则 | 含义 |
|---|---|---|
| 可见性 | 系统只对主角可见；NPC 不能感知/猜出 | NPC 不能“看穿”系统 |
| 存放 | 奖励可存入系统空间 | 不是主角随身背包的无限版 |
| 取出 | 记录时间、地点、见证者、现实存放位置 | 取出是可追溯事件 |
| 开窍前 | 只能存/取，不能炼化/催动 | 11 岁未开窍，不能靠系统用蛊 |
| 取出≠炼化 | 取出只是到现实，不等于认主/能催动 | 仍需炼化、登记、喂养 |
| 奖励≠现金 | 系统奖励不是 CLU | 不能直接当钱花 |

## 二、六个必须分开的东西

| 层 | 谁能知道 | 例子 |
|---|---|---|
| 系统内部 | 只有主角 | 空间里有几只蛊、容量多少 |
| 主角行为 | 主角自己/见证者 | 主角从空房间取出一个盒子 |
| 现实结果 | 周围人可观察 | 主角突然有了一只蛊/一块元石 |
| NPC 推测 | NPC 可怀疑/调查 | “来源不明”“可能走私”“家里留下的” |
| 社会记录 | 登记/票据/交易记录 | GAB 登记、蛊市收据、税单 |
| 世界规则 | 正式设定 | 蛊师登记、未成年交易限制 |

> 关键：**NPC 看到的是“现实结果”，不是“系统”。** 他们可以怀疑、追问、举报，但不能直接知道系统存在。

## 三、候选运行剖面

> 以下是候选，不是正式设定。测试默认用 **剖面 A（保守）**；只有项目主人确认后才可升级。

### 剖面 A：惰性储物格（推荐测试默认）

| 项 | 规则 | 级别 |
|---|---|---|
| 容量 | 12 个“条目位”；同种小物可叠 1 格（最多 99 件）；大件/高价值蛊 1 件 1 格 | 【模拟参数】 |
| 重量 | 合计不超过 100 kg；超过需分包/拒绝 | 【模拟参数】 |
| 活物 | 不能存；活蛊也不能存 | 【待主人确认】 |
| 活蛊 | 不允许；必须现实饲养 | 【待主人确认】 |
| 时间 | 外界时间正常流逝；食物会坏、药会过期、纸会黄 | 【待主人确认】 |
| 取出 | 主角清醒、非战斗、同场景；1 个动作；可被看见 | 【研究建议】 |
| 存入 | 同上；不能存他人活体/绑定物 | 【研究建议】 |
| 战斗 | 不能战斗中开空间/取物 | 【研究建议】 |
| 容量扩展 | 不做；没有“升级扩容”正式依据 | 【未知】 |
| 来源证明 | 系统不给现实票据；需主角自行解释/登记 | 【研究建议】 |

**优点**：不把系统写成万能仓库；活蛊/保鲜/容量问题被明确挡住；测试可重复。
**缺点**：奖励多了放不下；活蛊奖励无法长期保存；需要主角尽快处理。

### 剖面 B：低温保鲜柜

- 可存食物/药/标本；时间流速慢（例如 1/10）；活物仍不能存；活蛊需休眠舱（未定）。
- 风险：一旦“保鲜”成立，食物/药品经济会被改写；需要主人确认。
- 用途：只作为候选，不默认。

### 剖面 C：活蛊寄存（高风险）

- 可存活蛊；每 24h 消耗 1 份饲料/CLU；不喂→虚弱→死亡/逃逸；空间内不能炼化。
- 风险：等于给主角一个“随身蛊巢”，会绕开现实喂养、登记、监管；必须主人确认。
- 若启用，至少要有：饲料成本、存活上限、取出冷却、疾病/逃逸、GAB 登记。

> **默认 A**。B/C 只在主人明确选择时启用；不得在叙事中悄悄升级。

## 四、存取流程卡

### 4.1 存入

```text
[存入]
时间/地点：____
物品：____（名称/数量/状态）
来源：____（奖励/购买/拾获/他人）
是否活物/活蛊：是/否
是否绑定/他人所有：是/否
系统记录：S-____
见证者：____（无人/主角一人/他人）
现实残留：____（包装/票据/痕迹）
```

### 4.2 取出

```text
[取出]
时间/地点：____
物品：____
取出目的：____
见证者：____（无人/苏晞/同学/商家/监控）
现实存放位置：____（家中/随身/银行/蛊市/他人）
是否立即使用：是/否
是否登记：是/否（GAB/蛊市/学校）
异常：____（被人看见/物品损坏/活蛊苏醒）
```

**规则**：
- 取出必须写“现实存放位置”；不能“取出来又凭空消失”。
- 有见证者时，见证者只知道“东西出现”，不知道系统；可怀疑、可追问。
- 监控/摄像头只能拍到结果，不能拍到系统。
- 取出后物品仍受现实规则：蛊要喂养、元石可被抢、药会过期。

## 六、来源、登记与交易

### 6.1 来源证明链

| 来源 | 系统记录 | 现实证据 | 可交易性 |
|---|---|---|---|
| 系统奖励 | 有（内部） | 无票据 | 低：需解释来源 |
| 家族遗留 | 可能有 | 遗嘱/旧照片/长辈证言 | 中：需登记 |
| 购买 | 有 | 收据/蛊市登记 | 高：按市场规则 |
| 拾获 | 有 | 拾获记录/见证 | 低：可能涉侵占 |
| 他人赠与 | 有 | 赠与记录/见证 | 中：需登记 |
| 走私/黑市 | 无/假 | 无 | 违法；GAB 可查 |

### 6.2 登记与交易流程

1. **先判断物品类别**：普通物/元石/蛊虫/蛊材/高价值。
2. **蛊虫/蛊材**：GAB 登记；未成年人需监护人/临时照料人同意；来源说明；健康检查。
3. **元石**：按重量/成色；大额交易需身份/来源；不要默认“系统元石=干净”。
4. **蛊市**：摊位/拍卖/寄售；收据；税/手续费；高价值可能触发审查。
5. **保险/抵押**：需要权属证明；系统奖励无票据，保险公司可拒保。
6. **NPC 反应**：好奇→追问→怀疑→举报/压价/偷窃/勒索；按人物性格，不是统一“惊讶”。

### 6.3 高价值物品的社会影响

- 一只高转蛊/大量元石突然出现，会引来：GAB 问询、蛊市压价、同行觊觎、房东/邻居窥探、学校/社区关注。
- 不能“卖了就完事”；要记买家、价格、税、登记、后续追踪。
- 高价值物品可能改变家庭现金流，但不自动解决监护/补助/身份问题。

## 七、NPC 推测表

| NPC 看到 | 合理解释（NPC 不一定信） | 可能行动 |
|---|---|---|
| 主角突然有蛊 | 家里留下的/亲戚给的/捡的/买的/偷的 | 问、查、压价、举报 |
| 主角拿出元石 | 遗产/打工/赌/走私 | 收购、试探、报告 GAB |
| 主角拒绝说明 | 心虚/被人叮嘱/害怕 | 怀疑加深 |
| 主角频繁存取 | 有秘密/有仓库/被人控制 | 跟踪、偷窥、勒索 |
| 主角卖出高价物 | 发财/替人销赃 | 税/登记/黑市线 |

**禁止**：NPC 说“你有系统”“我看到空间”“我知道你凭空取物”。他们只能描述观察与推测。

## 八、与现有世界制度的衔接

| 制度 | 衔接 | 未定 |
|---|---|---|
| GAB 蛊师登记 | 蛊虫来源/种类/转数登记；未成年需同意 | 系统奖励是否可登记、是否罚 |
| 蛊市 | 交易收据、摊位费、税 | 无票据物品能否寄售 |
| 学校 | 学生带蛊/蛊材入校需登记；校园安全 | 系统取出后带入学校 |
| 医疗 | 蛊伤/真元伤需说明接触史 | 系统蛊是否算“接触” |
| 民政/补助 | 高价值资产可能影响补助资格 | 系统物品是否申报 |
| 保险 | 权属/来源证明 | 系统奖励能否投保 |
| 税务 | 高价值交易申报 | 系统奖励是否应税 |

## 九、AI 执行规则

1. 未确认前，默认剖面 A：不能存活物/活蛊，时间正常，12 格/100kg（S5）。
2. 系统只对主角可见；NPC 只能看到结果。
3. 取出必记时间/地点/见证者/现实存放位置。
4. 取出≠炼化；开窍前不能催动。
5. 奖励≠现金；不能直接付房租/医药费。
6. 活蛊默认不能存；若剧情必须，标【待主人确认】并走剖面 C 风险。
7. 不默认无限容量/无限保鲜/无限养蛊。
8. 来源不明物品交易前先登记/问询；NPC 可怀疑，不可全知。
9. 高价值物品要有后续追踪，不“卖完就消失”。
10. 信息缺失写“未知”，不补系统设定。

## 十、待确认

- 容量、重量、格数、是否可扩展。
- 能否存活物/活蛊；活蛊喂养/死亡/变异。
- 时间是否冻结/减缓；食物/药品/蛊材保质。
- 取出冷却、战斗限制、见证者规则。
- 系统奖励的来源证明、登记、税务、保险。
- 高价值物品对补助资格的影响。
- 系统是否会给“说明书/任务/惩罚”，还是纯仓库。
