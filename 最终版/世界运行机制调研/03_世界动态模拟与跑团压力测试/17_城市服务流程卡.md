# 17 城市服务流程卡（8 大类）

> 职责：把“有机构”变成“能办事”。每张卡按 9 个字段写：适用场景／参与人物／触发条件／具体流程／分支／费用与时间／材料或资格／常见异常／备注。
> 边界：正式库只锁定机构职责、价格区间、学校作息、GAB 存在；窗口时间、排队时长、表格名称、保险条款多为【研究建议】/【模拟参数】，不冒充正式。
> 用法：GM 先选卡，再按“触发→流程→分支→费用/材料→异常”走；不要只说“去办一下”。

## 1. 医疗

| 字段 | 内容 |
|---|---|
| 适用场景 | 门诊、急诊、复诊、转诊、蛊伤、真元/空窍伤、疫苗、体检 |
| 参与人物 | 学生/居民、校医、社区医生、医院分诊/专科、临时照料人、GAB（涉蛊） |
| 触发条件 | 发热/疼痛/外伤/昏迷/蛊伤/真元逆行/学校事故 |
| 具体流程 | ①判断轻重→②校医/社区初诊→③分诊→④挂号/建档→⑤医生问诊/检查→⑥缴费/医保→⑦取药/治疗→⑧复诊/转诊 |
| 分支 | 轻→诊所；重→急诊；骨折→影像/复位；蛊伤→蛊伤科；真元→专科；传染病→隔离/报疾控；无钱→救助/挂账 |
| 费用与时间 | 诊所 30—80＋药 20—60；急诊 80—200；蛊伤 200—600；真元/空窍 300—800；妖兽咬伤 100—300＋疫苗；候诊 0.5—3h（S5） |
| 材料/资格 | 学生证/身份证/医保卡/救助证明；未成年需临时照料人；蛊伤需接触史/登记 |
| 常见异常 | 排队久、医生夜班疲劳、押金不够、保险不报、转诊重复检查、家属联系不上 |
| 备注 | 急诊先治后付；不让儿童独自就医；涉蛊同步 GAB；票据全留 |

| 参与人物 | 学生、班主任、教务、校长、临时照料人、教育局/GAB |
| 触发条件 | 开学、转学、长期缺课、事故、升学、开窍 |
| 具体流程 | ①咨询/领表→②交材料→③学籍审核→④缴费/减免→⑤编班→⑥入学/复课→⑦记录归档 |
| 分支 | 正常入学；转学；借读；困难减免；休学；复课；开窍年级分流；校园事故调查 |
| 费用与时间 | 学费/餐费/课后服务【未知/因校而异】；办理 1—5 个工作日（S5）；开学高峰更慢 |
| 材料/资格 | 户口/身份、监护/临时照料证明、住址、原校学籍、疫苗/体检（按校） |

| 分支 | 堵车；末班已过；交通事故；暴雨/台风；儿童独自乘车；逃票/纠纷 |
| 费用与时间 | 公交/地铁单程【未知，按城市】；打车按里程/时段；夜 2 路 21:00—23:30；高峰 18 km/h |

## 4. 住房

| 参与人物 | 租户、房东马国栋、物业刘大勇、社区、民政 |
| 触发条件 | 合同到期、漏水/跳闸、欠租、噪音、陌生人、搬家 |
| 具体流程 | ①看房/合同→②押金/登记→③入住验收→④报修→⑤缴费→⑥续租/退租→⑦结算 |
| 分支 | 维修（房东/物业）；欠租（催告/分期/调解）；退租（押金/损坏）；转租（禁止/需同意）；驱赶未成年人（民政介入） |
| 费用与时间 | 房租 1,366 CLU/月（1,850 曜元）；物业 60.2；维修按工料；押金【未知】；报修 1—3 天（S5） |
| 材料/资格 | 身份证/租约/押金收据；未成年人不能独立签约；临时照料人/成年签约人 |

## 通用办事原则

1. **先问“哪张卡”**，再问“谁有资格”，最后问“钱/时间/材料”。
2. 每张卡至少给一个**分支**，不要直线通关。
3. 办事失败不是“剧情惩罚”，而是信息/材料/权限/时间问题；给下一步。
4. 窗口/医院/学校都有排队与下班；不要让所有人随叫随到。
5. 儿童办事需成人；成人帮忙要标权限。
6. 费用按正式区间；没有正式价的写【未知】，不编。
7. 票据/记录/见证人是后续回扣的钩子。
8. 涉蛊/涉暴/涉未成年优先保护，不公开隐私。
