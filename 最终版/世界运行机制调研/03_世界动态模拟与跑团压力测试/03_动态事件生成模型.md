# 03 动态事件生成模型

> 职责：让事件从世界自身的条件、人物目标、制度安排和资源变化中产生，而不是 GM 每轮临时想一个。
> 边界：本文件是事件生成工具，不新增世界事实；事件里涉及的蛊虫、价格、机构，必须回正式库核对。

## 一、事件不是“剧情点子”，是“状态变化”

一个事件至少改变以下一项：

- 时间安排（谁迟到/谁不能来/什么被推迟）；
- 资源（钱、食物、蛊材、元石、床位、名额）；
- 身体（伤、病、疲劳、恢复）；
- 关系（信任、欠情、冲突、合作）；
- 信息（谁知道什么、谁被骗、谁隐瞒）；
- 计划（目标改变、路线改变、交易取消）；
- 世界状态（机构关闭、价格波动、警戒升级）。

**没有状态变化的事件，不写。** “今天学校正常上课，主角正常回家”不是事件，只是背景。

## 二、事件卡八字段

> 任何需要持续推进的事件，先填八字段；只出现一次的路人小事，可只填前四项。

| 字段 | 要写什么 | 例子 |
|---|---|---|
| ① 条件 | 为什么现在发生；触发条件是否已满足 | 连续降雨 3 天＋老楼排水管堵塞 |
| ② 参与人 | 直接当事人、经办人、旁观者、受影响者 | 3 号楼 602 主角家、楼下 502 王秀兰、物业刘大勇 |
| ③ 地点 | LOC 编号/距离/开放时间 | 云栖花园 3 号楼楼道；物业房 200 m |
| ④ 持续 | 几分钟/几小时/几天/几周；何时升级/结束 | 停水 4 小时；维修预约排到次日 |
| ⑤ 资源 | 钱、物资、床位、名额、时间、人情 | 换管 60 CLU；请假半天；欠刘大勇一个人情 |
| ⑥ 后果 | 直接结果＋二次后果 | 地板浸水→书本受损→苏晞作业重写 |
| ⑦ 谁知道 | 主角是否知情；谁知道多少；谁在传 | 王秀兰听见水声；房东知道但未到场 |
| ⑧ 不参与是否继续 | 主角不出面时，事件如何发展/自然结束 | 物业先关总阀；房东次日才决定修 |

## 三、五层事件

| 层级 | 范围 | 例子 | 对主角的典型影响 | 谁在推动 |
|---|---|---|---|---|
| **微观** | 个人/家庭/一个班 | 感冒、作业没写、同学矛盾、家里盐没了 | 当天/当周的钱、时间、情绪 | 个人目标、身体、家庭账本 |
| **局部** | 学校/小区/一条街 | 月考、家长会、停水、菜价涨、邻里纠纷 | 一周/一月安排 | 学校、物业、社区、商户 |
| **城市** | 临江市级 | 公交调整、秘境溢流警报、医院满床、蛊市休市 | 出行、工作、上学、医疗 | 市级机构、市场、天气 |
| **区域** | 澜东州/曜川 | 元石配额、产业裁员、州际交通管制 | 家庭收入、物价、迁移 | 州/联邦政策、企业 |
| **全球** | 国际 | 元石价格波动、贸易冲突、秘境争端 | 长期物价、职业机会、舆论 | 国际组织、大国、市场 |

**层级不是“越大越重要”**：一个楼道停水对主角的影响，可能大于国际元石谈判。事件的重要性由**与当前人物目标的距离**决定，不由地图范围决定。

## 四、事件从哪里来

### 4.1 六类触发源

| 触发源 | 事件怎么产生 | 例子 |
|---|---|---|
| **人物目标** | 某人想要什么，遇到什么阻碍 | 马国栋想把空置单间租出去→带看房→租客压价→空置期延长 |
| **制度安排** | 日历/规定到了，必须做什么 | 3 月第 2 周开窍大典→学校准备→家长请假→交通拥堵 |
| **资源变化** | 钱、货、床位、名额变了 | 菜市场因暴雨缺菜→价格上涨→家庭改菜单 |
| **身体/情绪** | 疲劳、生病、伤势、冲突 | 苏晞连续做家务＋考试→疲劳→作业出错→被老师点名 |
| **关系变化** | 信任、欠情、竞争、误会 | 陈慧晚交租→马国栋催→社区介入→关系紧张 |
| **外部冲击** | 天气、事故、政策、市场 | 秘境溢流橙色警报→学校停课→家长接孩子 |

### 4.2 事件合法性自检

写一个事件前，问五句：

1. 谁因此得到什么/失去什么？
2. 如果主角不在场，这件事还会发生吗？
3. 触发条件在现有资料里有依据吗？
4. 参与人的年龄、职业、能力允许他这样做吗？
5. 后果会不会在下一场景自动消失？

五句里有一句答不上，就先不写“大事件”，写成背景变化或推迟。

## 五、事件生命周期

```
潜伏（条件积累）
  → 触发（一个可见动作/通知/事故）
  → 应对（当事人/机构行动）
  → 升级或收敛（资源够不够/有人介入/天气变化）
  → 结束（解决/失败/转介/放弃）
  → 余波（钱、伤、关系、记录、旧事）
```

**四种结束方式**：

| 结束 | 例子 | 必须记录 |
|---|---|---|
| 解决 | 水管修好、病看好、纠纷调解 | 花了多少、谁欠谁人情 |
| 失败 | 补助被退回、比赛输了、交易取消 | 为什么失败、下次何时 |
| 转介 | 诊所转社区医院、学校转社区 | 转到哪、谁接手、等待时间 |
| 放弃 | 家庭决定不修/不买/不申请 | 放弃的代价与后续影响 |

**没有“自然遗忘”**：事件结束后至少留一个记录：钱变了、伤没好、关系变了、计划改了、有人记得。

## 六、主角是否知情

| 知情级别 | 表现 | GM 写法 |
|---|---|---|
| 亲历 | 主角在场，看见/听见/被涉及 | 只写可观察信息，不写主角内心 |
| 转告 | NPC 告诉主角，可能不完整/有偏差 | NPC 的说法带立场；不自动等于事实 |
| 传闻 | 邻居/同学/市场在传，真假混杂 | 标明“听说”；可能夸大/漏细节 |
| 公开 | 通知/警报/新闻 | 信息广，但不等于主角理解 |
| 不知 | 主角不在场/没人告诉他 | 事件照常发展；后续可通过后果撞上来 |

**重要原则**：主角不知道的事件，不等于没发生。NPC 会继续做，后果会在以后出现。

## 八、两条因果链示例

### 8.1 暴雨→菜价→家庭账→学校

```
连续降雨（天气）
→ 云栖菜市场进货少、叶菜烂根（D-01）
→ 孙志强把青菜从 3 CLU/斤提到 4.5 CLU/斤
→ 主角家一周食品支出 +15 CLU；苏晞改做土豆/豆腐
→ 学校食堂成本上升，午餐份量略减（S-01 背景）
→ 学生抱怨、家长群议论；班主任在班会上说“最近菜贵，别浪费”
→ 两周后天气转好，价格回落，但家庭已经多花了 30 CLU
```

**关键**：不是“暴雨制造戏剧”，而是暴雨通过价格、菜单、食堂、抱怨，改变了几十个日常决定。

### 8.2 校园对战→伤病→家庭账→下月资格

```
10 月月末对战（S-10）
→ 钟临溪在第三局被对手蛊虫擦伤小臂（G-04）
→ 校医止血/清创；建议去蛊道医疗中心（200—600 CLU）
→ 父亲请假带他去；检查＋药 280 CLU
→ 家庭当月多支出 280 CLU；钟临溪停训 3 天
→ 学校按伤病豁免下月配额不减（方案 C 5.7）
→ 但“能否参加下月对战”没有正式复诊标准，GM 只能临时判
→ 若判太早，伤口反复；判太晚，学生失去一次机会
```

**关键**：制度能处理“钱”和“配额”，不能处理“恢复到什么程度算好”——这是测试 D 的核心缺口。

## 九、事件生成六步

1. **看当前状态**：日期、地点、在场人、钱、体力、关系、未结事项。
2. **选一个触发源**：人物目标/制度/资源/身体/关系/外部冲击；不要“随机”。
3. **填八字段**：条件、参与人、地点、持续、资源、后果、知情、是否继续。
4. **判断层级**：微观/局部/城市/区域/全球；只写与当前人物目标有关的那层。
5. **决定主角位置**：亲历/转告/传闻/不知；不知就写“事件继续”。
6. **留余波**：至少一个记录（钱、伤、关系、计划、信息）。

## 十、频率与节制

| 频率 | 用法 | 注意 |
|---|---|---|
| 每场景一个小变化 | 天气、排队、缺货、同学一句话 | 不改变大结构 |
| 每周一个局部事件 | 班级活动、邻里小事、价格波动 | 让日常有变化 |
| 每月一个制度事件 | 月考、对战、房租、发薪 | 与日历绑定 |
| 每季一个较大事件 | 学期结束、开窍大典、秘境波动 | 有前兆、有后果 |
| 每年少数大事件 | 政策、产业、城市事故 | 不年年都“全城危机” |

**不要把所有事件都写成主角必须解决**。大多数事件只需要主角知道、受影响、做一个小选择，甚至不参与也会结束。

## 十一、结论

- 事件生成的核心不是“随机表”，而是**状态→触发→行动→后果→余波**的因果链。
- 八字段事件卡可以直接贴在 GM 备忘里；不需要每件事都写长篇。
- 主角不知情的事件必须继续；这是世界“自主性”的最低证明。
- 事件频率要节制；日常变化比大危机更能支撑长期跑团。
- 本文件的事件表是工具，不是正式剧情；具体人物、价格、机构仍回正式库与第二专项人物库。
