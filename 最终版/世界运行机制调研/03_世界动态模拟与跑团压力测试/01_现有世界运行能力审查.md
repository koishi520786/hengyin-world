# 01 现有世界运行能力审查

> 职责：判断现有正式资料已经能支撑哪些场景、哪些只能提供概念、哪些缺乏实际执行条件；为后续流程、事件、模拟与补充建议定缺口。
> 方法：先读正式正文，再用八项压力测试反向验证；不以索引摘要代替正文，不把“有机构名”当成“能办事”。

## 一、审查结论

现有资料的能力分布不是“均匀缺”，而是三层：

| 层级 | 状态 | 表现 |
|---|---|---|
| **硬锚层** | 足够支撑具体场景 | 城市空间、云栖生活圈、学校作息、医疗五级路径、家庭账本、蛊师人口与制度、未成年边界、秘境与应急框架 |
| **概念层** | 知道“有这么回事”，但不能直接跑 | 城市机构流程、学校开窍后体系、蛊道市场交易、NPC 自主生活、长期事件因果、系统与现实的接口 |
| **空白层** | 没有可执行规则 | 发薪日、学期精确日历、考试周、家访/请假、校园赛事伤病豁免、医疗恢复期、NPC 经济账、旧事回扣机制 |

**一句话**：可以写一个“可信的今天”，还不能只靠资料写一个“不编造的这一年”。

## 三、五个结构性问题

### 3.1 “点状细节”多于“连续流程”

现有资料最擅长写“一个场景”：菜市场早上、学校一天、医院挂号、公交挤。它不擅长回答“这件事从触发到结束经过了哪些窗口、哪些人、哪些失败分支”。这不是资料少，而是**没有把点连成线**。

典型表现：
- 知道社区诊所在哪、几点开、多少钱；不知道没带医保卡/监护人不在/需要转诊时怎么办。
- 知道学校 16:30 放学；不知道家长临时不能接、孩子被留校、课后服务怎么报名。
- 知道蛊虫市场 6:00—18:00；不知道验蛊、议价、纠纷、登记、离场各自在哪一步。

### 3.2 学校是“最完整的系统”，但只完整到小学

小学一天、开窍大典、五级看病、未成年劳动/监护都有正文；但“开窍之后”只有学制、分轨原则和两所中学地点。蛊道班的课表、考试、排名、社团、赛事、宿舍/食堂、师生关系，均无执行层。

这不是本专项能单独补完的：专项一已把 `G-06/G-07/G-08/G-09` 列为缺口，本专项只测试“现有骨架能不能支撑校园月度竞争”，并把需要的接口写进 `08_正式资料补充建议.md`。

### 3.3 经济有“月账”，没有“日账”

家庭月支出区间、房租、物价、工资中位都可查；但：
- 没有发薪日、房租到期日、补助到账日；
- 没有“这个月第几天交校服费/餐费/物业费”的现金流；
- 没有收入中断、延迟发薪、临时医疗支出的处理顺序。

测试 B 只能用“按月结算”的近似；一旦剧情问“今天家里还剩多少钱”，GM 仍要现算。建议补“月初/月中/月末三段式现金流表”，不必新增物价。

### 3.4 NPC 有“档案”，没有“当前状态”

第二专项的 110 人档案足以让 NPC 有性格、家庭、目标、弱点；但档案是“静态简历”，不是“今天在干什么”。NPC 自主生活的关键字段是：
- 今天原本要做什么；
- 身上有多少现金/欠款；
- 体力/情绪/伤病；
- 当前最在意的一件事；
- 下一次计划变化可能由什么触发；
- 与哪些人有未结事项。

不记这五项，NPC 就会变成“主角一敲门就放下一切”的功能人。

### 3.5 长期连续性有“原则”，没有“检索点”

`05/11` 明确“不得重置”，但没给“多久检查一次、查哪些字段、旧事如何回扣”的方法。测试 F 显示：
- 90 天能记住学期、生日、房租；
- 180 天开始忘“上次比赛谁赢、谁受伤、谁欠谁钱”；
- 365 天如果没有事件日志，会把旧矛盾写成新矛盾、把旧伤写成已痊愈。

## 六、审查方法上的自我限制

1. **只读了部分正文**：本审查以 `04/01、04、05、06、07、11、13、14` 与 `05/00、01、04、05、06、07、09、10、11、12` 为主；`04/02、03、08、09、10、12` 与 `01_蛊虫` 具体档案未逐页通读。涉及蛊虫/杀招/秘境细节时，本专项只标“需回正文”，不代替核对。
2. **没有把索引当事实**：所有关键数值都回到正文；无法回到正文的，标“未明确”。
3. **没有用现实制度直接套**：现实只提供“流程结构”参照（如挂号—接诊—检查—缴费—取药），具体费用、时限、签字权仍以衡垠资料为准；没有依据的，标 S5/S6。
4. **没有替其他专项做结论**：学校分轨、职业体系、医疗恢复、城市设施等已有专门研究目录；本专项只记录“测试中卡住”，把深入方案留给对应专项。

## 七、结论

- **能支撑**：云栖生活圈内的日常、家庭账本、小学日常、五级医疗路径、蛊师制度常识、城市交通与应急框架、系统与玩家控制原则。
- **不能直接支撑**：开窍后校园、城市办事全流程、蛊道交易全流程、NPC 自主生活、长期世界状态、系统奖励现实化。
- **最优先补的不是“更多设定”，而是四张可执行表**：① 机构办事流程卡；② 时间/周期事件表；③ NPC 30 天状态表；④ 90/180/365 天世界快照。
- 这四张表不需要改正式世界观；先作为研究工具使用，验证后再决定哪些回灌正式库。
