# 02 日常生活与城市服务流程

> 职责：把“日常”和“办事”从概念变成 GM 可直接调用的时段表、流程卡与失败分支。
> 原则：先写人怎么活，再写机构怎么转；能用现有时间、地点、价格解决的，不另造设定。标 **S5** 的是本专项推导的执行流程，不是正式制度；标 **待确认** 的是正式库没有、需要负责人决定的内容。

## 一、四类居民的 24 小时

### 1.1 11 岁小学生（第二小学，云栖花园出发）

| 时间 | 动作 | 地点/耗时 | 备注 |
|---|---|---|---|
| 6:40—6:55 | 起床、洗漱、换校服 | 家 | 冬季可延后 10 分钟，但 7:20 前必须出门 |
| 6:55—7:15 | 早饭 | 家 | 在家吃约 1.2—2.0 CLU/人；苏晞常做粥/面 |
| 7:15—7:20 | 装书包、带伞/水、出门 | 家 | 雨天多 3—5 分钟找伞/穿雨衣 |
| 7:20—7:33 | 步行到校 | 1.0 km，13 分钟 | 走育才路；过人行桥/路口等 1—2 分钟 |
| 7:33—7:50 | 进校、到班、交作业 | 校门/教室 | 7:50 前到班；门卫不搜书包、不查蛊师证 |
| 7:50—8:00 | 早读、点名 | 教室 | 缺勤当天联系监护人/紧急联系人 |
| 8:00—11:40 | 上午 4 节 | 教室/操场 | 10:00 大课间；开窍预备课每周 1 节 |
| 11:40—13:10 | 午餐、午休 | 食堂/教室 | 食堂按年级错峰；困难生减免不公开 |
| 13:10—16:30 | 下午 2—3 节 | 教室/功能室 | 体育、美术、劳动照常；16:30 放学 |
| 16:30—16:50 | 放学、值日/等同学 | 校门/教室 | 周五 15:40 放学；课后服务最晚 18:00 |
| 16:50—17:10 | 步行回家 | 1.0 km，13—20 分钟 | 顺路买盐/取快递会多 10—15 分钟 |
| 17:10—18:00 | 作业/家务/休息 | 家 | 11 岁儿童家务宜 30—45 分钟，不做重体力 |
| 18:00—19:00 | 晚饭 | 家 | 家庭食品盘已含，不再另记 |
| 19:00—20:30 | 作业、阅读、和同学/苏晞相处 | 家/社区 | 作业量按年级；不应每天写到 22:00 |
| 20:30—21:30 | 洗漱、收拾书包、准备明天 | 家 | 系统任务可安排“整理书桌/早睡” |
| 21:30—6:40 | 睡眠 | 家 | 9—9.5 小时；低于 8 小时按疲劳处理 |

**关键校验**：7:20 出门、13 分钟到校，与 `04/05` 7:50 到校、`04/04` 1.0 km 生活圈一致；16:30 放学后到 21:30 只有 5 小时，扣掉通勤、晚饭、家务，作业与自由时间约 2.5—3 小时——**任何“每天修炼 2 小时＋家务 1 小时＋作业 2 小时”的写法都会挤掉睡眠**。

### 1.4 夜班者（护士/保安/便利店/物流）

| 时间 | 动作 | 备注 |
|---|---|---|
| 14:00—15:00 | 起床、早饭 | 不是“睡到中午”的懒，是夜班作息 |
| 15:00—17:00 | 处理家务/办事/接孩子 | 银行、街道办只在工作日白天开，夜班者办事成本高 |
| 17:00—18:00 | 晚饭 | 离家前吃 |
| 18:00—21:00 | 通勤/准备上班 | 夜 2 路 21:00—23:30 有车 |
| 21:00—6:00 | 值班/工作 | 医院、保安、便利店、物流分拣 |
| 6:00—7:00 | 交班、回家 | 早高峰反向通勤 |
| 7:00—14:00 | 睡眠 | 白天噪音、光照影响恢复；长期夜班需记疲劳 |

**写法提醒**：不要把夜班者写成“白天随时有空”；他们办事、看病、接孩子都比日班者难，这是真实生活压力。

## 二、不同收入家庭的日常差异

| 维度 | 紧巴线（约 2,710 CLU/月） | 普通线（3,200—3,600） | 宽松线（3,900＋） |
|---|---|---|---|
| 早餐 | 在家粥/面/馒头，1.2—2.0 CLU/人 | 在家为主，偶尔外食 | 外食/便利店/早点铺常见 |
| 午餐 | 自带饭或食堂基础餐 | 食堂/快餐 | 食堂加菜/外卖 |
| 晚餐 | 菜市场收摊前买便宜菜，一荤一素 | 正常买菜，偶尔买水果 | 超市/外卖/下馆子 |
| 交通 | 步行/公交，非必要不打车 | 公交为主，急事打车 | 打车/私家车/地铁月票 |
| 衣物 | 校服为主，旧衣改穿，换季买一件 | 换季添置，不追品牌 | 品牌/商场/网购 |
| 医疗 | 能拖就拖，先问药房/邻居 | 及时看社区诊所 | 直接医院/私立/专家号 |
| 娱乐 | 公园、免费活动、电视/手机 | 偶尔电影/夜市/兴趣班 | 付费活动/短途游 |
| 居住 | 老六层整租/合租，房租占收入 40%＋ | 老小区/次新合租 | 电梯房/新区/买房 |

**不要写成“穷人有穷开心、富人没烦恼”**：紧巴线的压力是具体的（房租、药费、校服费）；宽松线也有自己的问题（时间、攀比、保险、投资）。

## 三、办一件事的通用流程

任何机构服务，GM 按九步走；缺一步就会变成“NPC 一句话搞定”。

```
① 触发：为什么现在办（到期/生病/通知/纠纷/机会）
② 准备：谁去、带什么、钱够不够、时间窗口
③ 出发：距离、交通、排队、天气
④ 受理：窗口/前台/班主任/医生，先看什么材料
⑤ 核验：身份/关系/保险/学籍/登记/监护
⑥ 费用：谁付、能否报销/减免/欠款
⑦ 办理：检查/填表/面谈/实验/交易
⑧ 结果：当场/隔日/数周；凭证/回执/记录
⑨ 失败与后续：缺材料/不合格/排队过号/费用不足/转介/投诉
```

**四类常见失败**：

| 失败 | 典型场景 | GM 应写 |
|---|---|---|
| 材料不全 | 补助、转学、登记 | 白跑一趟，清单补开，下一次窗口/请假成本 |
| 资格不符 | 未成年用蛊、保险、减免 | 不是“通融”，而是明确拒绝+替代路径 |
| 资源不足 | 医院满床、学校名额满、市场缺货 | 排队/转院/改日/涨价/买替代品 |
| 人不在/时间错 | 街道办下班、医生休诊、房东不接电话 | 改天再来，影响工作/上课/房租 |

## 四、机构流程卡

> 以下“材料/时限/费用”未在正式库写明的，均为 **S5 可执行建议**；需要成为正式制度时，走 `08_正式资料补充建议.md`。

### 4.1 第二小学：请假/缺勤/晚接

| 项 | 内容 |
|---|---|
| 服务对象 | 在校学生、监护人/紧急联系人 |
| 时间 | 上学日 7:20—16:30；课后服务至 18:00 |
| 触发 | 生病、家里有事、迟到、不能按时接 |
| 材料 | 家长电话/书面说明；病假 3 天以上带诊所/医院证明（S5）；事假提前说 |
| 流程 | 家长 7:50 前打班主任电话/发消息 → 班主任记缺勤 → 当天联系紧急联系人 → 返校补交说明 → 3 天以上报教务（S5） |
| 费用 | 无 |
| 经办 | 班主任（TCH-001 沈静姝）、教务（TCH-008 罗文静）、门卫（TCH-015 韩守义） |
| 失败 | 电话打不通→联系第二联系人/社区；长期缺勤→学校须报告社区/民政（`04/05` 7.1） |
| 联动 | 课后服务、校医、社区儿童主任、劳动监察（若因打工缺勤） |

### 4.2 第二小学：转学/升学/开窍登记咨询

| 项 | 内容 |
|---|---|
| 服务对象 | 学生、监护人 |
| 时间 | 工作日，教务在岗 |
| 材料 | 学籍号、户口/居住证明、监护人身份、原校转学证明、开窍结果（若已开窍） |
| 流程 | 教务领表 → 原校盖章 → 新校/教育局核学籍 → 开窍结果进全国蛊道登记系统（与身份证、医保、学籍绑定） |
| 费用 | 义务教育免学费；校服/教辅另计 |
| 经办 | 教务主任、班主任、区教育局 |
| 失败 | 材料缺、学位满、跨区转接慢；不能因欠费拒收（`04/05` 7.2） |
| 联动 | 民政补助、社区台账、医保 |

### 4.3 云栖社区诊所：普通门诊

| 项 | 内容 |
|---|---|
| 服务对象 | 居民（普通门诊不查蛊师证） |
| 时间 | 8:00—20:00；夜间转北城社区医院 |
| 材料 | 医保卡/身份证（建议带）、既往病历/药盒；儿童带监护人 |
| 流程 | 挂号（30—80 CLU）→ 候诊 → 问诊/测体温/基础化验 → 开药/处置 → 缴费（药 20—60 CLU）→ 取药/复诊 |
| 费用 | 门诊 30—80 CLU；药 20—60 CLU；医保可刷（`04/05` 7.3） |
| 经办 | 全科医生 MED-001 周明诚、护士 MED-002 林巧 |
| 失败 | 排队过号、药缺货、需要转诊、下班/午休；夜间只能去社区医院 |
| 联动 | 学校请假、家庭账本、药房、社区医院 |

### 4.4 北城社区医院/市属医院：急诊

| 项 | 内容 |
|---|---|
| 服务对象 | 骨折、缝针、腹痛、高烧、普通外伤 |
| 时间 | 社区医院 8:00—20:00；中心医院全天急诊 |
| 材料 | 身份证/医保卡、监护人（未成年人）、事故说明（学校/单位） |
| 流程 | 分诊 → 挂号（80—200 CLU）→ 医生查体 → 拍片/化验/清创/固定（处置另计）→ 缴费 → 取药/留观/转院 |
| 费用 | 急诊 80—200 CLU＋处置；住院另计；报销比例未明确 |
| 经办 | 急诊医生/护士；未成年人签字权待确认 |
| 失败 | 满床/设备故障/需转中心医院/家属未到；急诊先救治后补签（`04/05` 7.1） |
| 联动 | 学校校医、保险、交警（交通事故）、GAB（蛊伤） |

### 4.5 临江市蛊道医疗中心：蛊伤/真元损伤

| 项 | 内容 |
|---|---|
| 服务对象 | 蛊虫造成的伤口、蛊毒、真元逆行、空窍受损 |
| 时间 | 按医院急诊/专科；蛊伤科与普通急诊分开 |
| 材料 | 身份证/医保、蛊师登记信息（若已开窍）、用过的蛊虫/蛊材信息、监护人（未成年） |
| 流程 | 挂号（初诊 200—600 CLU）→ 蛊伤科问诊（是否开窍、用什么蛊，用于用药安全）→ 清创/解毒/血清/稳定空窍 → 检查（300—800 CLU）→ 治疗/住院/复诊 |
| 费用 | 初诊 200—600；检查 300—800＋疗程；住院另计；不是所有空窍损伤都能完全恢复 |
| 经办 | 医疗蛊师 MED-003 顾清和、药剂师 MED-004 陈药生 |
| 失败 | 血清缺货、专家号满、需转院、费用不足；不能写成“一只治疗蛊立刻长好” |
| 联动 | 学校、GAB 登记、保险、家庭账本、后续复诊 |

### 4.6 云栖街道办事处/社区：补助、监护、租赁咨询

| 项 | 内容 |
|---|---|
| 服务对象 | 困难家庭、孤儿/事实无人抚养儿童、独居老人、租户 |
| 时间 | 工作日；社区网格员常在片区跑 |
| 材料 | 身份证/户口、死亡/失踪证明（若适用）、监护顺位材料、收入/困难证明、租房合同、学校证明、银行卡 |
| 流程 | 社区受理 → 网格员入户/学校核实 → 街道/民政审核 → 公示/审批 → 按月发放 → 年审 |
| 费用 | 无申请费；材料复印/交通成本 |
| 经办 | 居委会主任谢芳、网格员高远、民政/儿童主任 |
| 失败 | 材料缺、亲属不配合、监护顺位争议、跨区转接慢；补助不是自动到账 |
| 联动 | 学校减免、医保、房东、法院（监护权） |

### 4.7 云栖物业/维修：水管、楼道灯、门锁

| 项 | 内容 |
|---|---|
| 服务对象 | 业主/租户 |
| 时间 | 物业工作日；急修可电话 |

### 4.9 银行自助/柜台：存取、缴费

| 项 | 内容 |
|---|---|
| 服务对象 | 有账户居民；未成年人开户/大额业务需监护人 |
| 时间 | 自助 24h；柜台工作日 9:00—17:00 |
| 材料 | 银行卡/身份证；未成年人带监护人+户口本 |
| 流程 | 取号 → 填单/自助操作 → 核验 → 办理 → 回执 |

## 五、资源不足时的降级规则

| 资源 | 不足表现 | 降级顺序 |
|---|---|---|
| 医院床位/医生 | 满床、排队、专家号满 | 社区医院留观→转市属医院→择期→居家观察（仅轻症） |
| 学校学位/课后服务 | 名额满、老师不足 | 排队/就近分流/家长接回/社区托管咨询 |
| 蛊虫/蛊材 | 缺货、涨价、来源不明 | 等下一批/买替代品/租借（需登记）/不用 |
| 现金 | 不够付挂号/房租/校服 | 减免申请/分期/向亲友借/拖欠（有后果） |
| 时间 | 家长上班、不能接孩子 | 第二联系人/邻居/课后服务/社区儿童主任 |
| 交通 | 暴雨、桥堵、末班车过 | 改公交/打车/留宿/推迟办事 |

**降级不是“问题消失”**：每次降级都要写谁等了、谁多花了钱、谁欠了人情、哪件事被推迟。

## 七、结论

- 云栖生活圈足以支撑“吃、买、看病、上学、坐车、寄快递、取钱、修鞋”的日常闭环；真正需要补的是**材料、窗口、时限、失败处理**。
- 学校、诊所、社区、物业是最高频四个机构；先把这四张流程卡用熟，再扩展 GAB、蛊市、秘境。
- 所有流程卡都必须保留“失败分支”；没有失败，世界就会变成“主角一到就办成”的假运行。
- 本文件不新增收费/时限为正式事实；标 S5 的内容先作为 GM 工具，验证后再决定是否入正式库。
