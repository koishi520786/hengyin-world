## 待研究的关键问题（登记，非答案）
1. 家传／工业／职业三型在临江分别对应哪些组织与人群？
2. 一个一转持证蛊师的家庭，与无窍家庭，在住房、教育、医疗上的可量化差距是多少？
3. 阶层跃迁的实际通道有几条（学历、证书、赛事、企业雇佣、秘境收益），各需多少年与多少钱？
4. 开窍失败者（曜川每年约 10.4 万）的补助、就业与污名如何运行？
5. 家族／企业资源如何合法传递给未成年人，与「学校不掌握空窍品质」如何共存？
6. 社会评价（「会开窍的普通人」）如何体现在对话与 NPC 态度上？
