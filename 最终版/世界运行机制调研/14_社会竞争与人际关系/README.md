## 待研究的关键问题（登记，非答案）
1. 在「资质不公开」的前提下，学生之间实际靠什么形成层级（战绩、消费、家庭、证书、蛊虫品相）？
2. 学生间资源交易（蛊虫、蛊材、代练、作业）哪些合规、哪些会触发校规。
3. 11—12 岁冲突的典型形态与升级／和解路径，成人介入的触发条件。
4. 家庭背景差异如何被孩子感知与表达，而不写成标签化霸凌。
5. 师生关系边界：老师能知道什么、不能知道什么、什么情况必须上报。
6. 合作与小团体的形成条件，与「每月对战」制度如何互相影响。
