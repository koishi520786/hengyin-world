# 一、维兰（CITY-002）

## 基本资料

| 项目 | 内容 |
|---|---|
| 城市编号 | CITY-002 |
| 所属 | 赫兰联邦·维兰州（ADM-002-01） |
| 坐标 | 76.0°W 40.0°N（G11-N14） |
| 面积 | 6,180 km²（都会区 11,400 km²） |
| 人口 | 2,240 万（都会区 3,120 万） |
| 城市等级 | MET-1 |
| 经济定位 | 全球金融与炼蛊工业中心 |
| 主要产业 | 金融、炼蛊装备、军工、蛊道科研、专业服务 |
| 交通 | 两座国际机场、四条高铁干线、地铁 14 条、内河港 |
| 蛊师人口 | 56 万（2.5%） |
| 秘境 | 辖区 6 处（全部 D0—D1，训练与科研型） |

## 一、概况

垠历 512 年由内海贸易站发展为联邦首都，现为全球第一大城市。城市性格：精确、昂贵、效率至上。全球 71% 的蛊虫检定证书在此签发。

## 二、地理

东岸平原与德拉贡河三角洲交汇，海拔 4~28 m；温带湿润气候，冬季 0 ℃左右，夏季 24 ℃。河流穿城 42 km。

## 三、行政区划

| 编号 | 城区 | 功能 |
|---|---|---|
| DIST-002-01 | 中环区 | 联邦政府、央行、CLU 清算中心 |
| DIST-002-02 | 铁桥区 | 炼蛊装备工业带 |
| DIST-002-03 | 学园区 | 联邦蛊道研究院、三所大学 |
| DIST-002-04 | 港北区 | 内河港、物流 |
| DIST-002-05 | 南苑区 | 高密度住宅、移民社区 |
| 其余 3 区 | — | 军工、旧城、绿带 |

## 四、经济

金融占全市 GDP 38%；炼蛊装备 24%；军工 14%。维兰交易所是全球蛊道企业上市首选地，市值 21 万亿 CLU。

## 五、居民生活

房租中位数 2,800 CLU/月（全国均值 1,400）；通勤平均 52 分钟；公共教育强，但学区房溢价 3.2 倍。

## 六、蛊师社会

联邦蛊道厅总部、仙蛊持证委员会、GCO 秘书处均在此。六转以上蛊师 410 人居住，形成"高阶蛊师社区"（受监管的聚居区）。

## 七、交通

地铁 14 条、市郊铁路 6 条；维兰港年吞吐 4,100 万吨；机场年客流 1.1 亿。

## 八、治安

联邦警 4.2 万、州警 2.8 万；蛊虫危险品稽查队总部；反蛊师犯罪特勤组 600 人。

## 九、秘境与特殊地点

6 处训练型秘境，全部对持证蛊师开放；"零号检定场"是 global 蛊虫标准测定地。

## 十、势力

联邦政府、CLU 清算联盟、赫兰炼蛊工业协会、三大军工集团、两家跨国蛊材贸易商。

## 十一、特色

**"证书之城"**：在维兰，一张检定证书比一只蛊虫更值钱。城市的权力来自"谁有资格定义合格"。

## 基本资料

| 项目 | 内容 |
|---|---|

| 所属 | 苍垠共和邦联·晏邦（ADM-001-01） |
| 坐标 | 12.6°E 45.8°N（G20-N14） |
| 面积 | 9,240 km² |
| 人口 | 1,860 万 |
| 城市等级 | MET-1 |
| 经济定位 | 政治首都、元石定价中心、重工 |
| 主要产业 | 元石贸易、矿山机械、金融、粮食加工 |
| 交通 | 国际机场 1、高铁 3 线、地铁 9 条、岐水支流港 |
| 蛊师人口 | 31 万（1.7%） |
| 秘境 | 辖区 4 处（D1—D2） |

## 一、概况

垠历 214 年《晏京盟约》签订地，邦联首都。城市气质是"议会气"：谈判、配额、听证会构成日常。

## 二、地理

天枢山脉东麓冲积扇，海拔 120~340 m；温带半湿润，冬季 −6 ℃；岐水支流穿城。

## 三、行政区划

| 编号 | 城区 | 功能 |
|---|---|---|
| DIST-001-01 | 盟约区 | 联邦议会、邦权院、元石配额会议 |
| DIST-001-02 | 枢西区 | 元石交易市场、检验所 |
| DIST-001-03 | 重工区 | 矿山机械、铁路装备 |
| DIST-001-04 | 大学区 | 联邦蛊道协调署、三所大学 |
| 其余 3 区 | — | 住宅、旧城、仓储 |

## 四、经济

元石贸易与金融占 41%；重工 26%；农业加工 12%。枢港离岸价每天 10:00 发布，全球 68% 的元石长协挂钩。

## 五、居民生活

生活成本低于维兰（房租中位 1,600 CLU）；邦际移民多，社区按来源邦聚集。

## 六、蛊师社会

联邦蛊道协调署（BCA）驻地；11 个邦协会在此设联络处；邦际蛊师流动协议签约地。

## 七、交通

高铁至枢港 2h20、至岐水口 3h40；机场年客流 6,800 万。

## 八、治安

联邦警 2.4 万＋邦警 3.6 万；元石押运由联邦武装警察负责。

## 九、秘境与特殊地点

4 处低危秘境，其中"盟约厅地下档案库"为登记型秘境（S0），存放历代元石合同原件。

## 十、势力

联邦政府、11 邦驻京办、元石出口商协会、两大矿业集团。

## 十一、特色

**"配额之城"**：晏京的政治就是分蛋糕的技术。每年 4 月的配额会议决定全球元石价格的基准情绪。

# 三、环港（CITY-003）

## 基本资料

| 项目 | 内容 |
|---|---|

| 坐标 | 160.0°E 2.0°N（G35-N10） |

| 人口 | 980 万 |

| 经济定位 | 全球航运保险与商事仲裁中心 |
| 主要产业 | 保险、再保险、海事仲裁、蛊材转口 |
| 交通 | 国际机场、邮轮港、环岛铁路 |
| 蛊师人口 | 14 万（1.4%） |
| 秘境 | 辖区 3 处（海洋型 D2—D3） |

## 一、概况

14 城邦的轮值首府，每 2 年轮换一次。城市以"环礁港"得名：港口围绕珊瑚环礁建成，潮差 4~6 m。

## 二、地理

热带海洋性气候，年均 27 ℃；双月大潮时部分码头停装 2 日。

## 三、行政区划

| 编号 | 城区 | 功能 |
|---|---|---|
| DIST-003-01 | 环礁区 | 联合议事会、商事法院 |
| DIST-003-02 | 保险区 | 全球 34% 航运保险承保中心 |
| DIST-003-03 | 转口区 | 蛊材保税仓、冷链 |
| DIST-003-04 | 珊瑚区 | 旅游、海洋研究 |
| 其余 2 区 | — | 住宅、军港（护航队） |

## 四、经济

保险与再保险占 44%；仲裁与法律服务 18%；转口 21%。

## 五、居民生活

高收入、高物价；外籍专业人士占 28%；住房以高层与水上社区为主。

## 六、蛊师社会

各城邦公会联合办事处；"海洋蛊虫执照"考试在此举行；海生蛊虫研究站 2 处。

## 七、交通

环岛铁路 68 km；至长环港航班 2h50；邮轮年停靠 4,200 艘次。

## 八、治安

联合海关 1.2 万；城邦警 1.8 万；护航队基地。

## 九、秘境与特殊地点

3 处海洋秘境，其中"环礁外沿"为 S2/D3，年产珊瑚蛊材 1,200 吨。

## 十、势力

联合秘书处、澜屿保险公会、两大再保险集团、海事仲裁院。

## 十一、特色

**"用合同代替军舰"**：环港的安全由保单与仲裁条款构成，任何攻击它的行为都会触发全球保险条款的连锁反应。

## 基本资料

| 项目 | 内容 |
|---|---|

| 交通 | 国际机场、沙漠铁路、驼队商道 |
| 蛊师人口 | 9.6 万（1.3%） |
| 秘境 | 辖区 8 处（遗迹型为主） |

## 一、概况

九王议事会所在地，建在乌祖河支流的九条泉眼上。城市形状如九瓣花，每瓣一个王庭使馆。

## 二、地理

热带沙漠气候，年降水 84 mm；依靠地下水与引渠；昼夜温差 22 ℃。

## 三、行政区划

| 编号 | 城区 | 功能 |
|---|---|---|
| DIST-004-01 | 九庭区 | 议事会、九王使馆 |
| DIST-004-02 | 拍卖区 | 仙材拍卖院、鉴定所 |
| DIST-004-03 | 绿洲区 | 农业、水市 |
| DIST-004-04 | 遗迹区 | 探符交易所、文物修复 |
| DIST-004-05 | 外城区 | 商队驿站、劳工社区 |

## 四、经济

仙材贸易占 46%；遗迹衍生 17%；绿洲农业 14%。

## 五、居民生活

王室与平民差距极大；外城自来水每天限供 6 小时；富人区有私人水井。

## 六、蛊师社会

王庭蛊师院；九王私兵蛊师队驻地；"探符"发放与转让在此登记。

## 七、交通

沙漠铁路至乌祖港 9h；机场至环港 12h40。

## 八、治安

王庭禁军 2.4 万；九王私兵在城外各有营地（敏感）。

## 九、秘境与特殊地点

8 处遗迹型秘境，REALM-003 九城沉眠的入口管理局设于此。

## 十、势力

九王、仙材拍卖院、三大遗迹开发公司、澜屿资本的代理行。

## 十一、特色

**"一座城，九个主人"**：九庭城没有市长，只有轮值首席王。任何一条街道的归属都可能引发九王之间的照会。

# 五、东陵（CITY-016）

## 基本资料

| 项目 | 内容 |
|---|---|
| 城市编号 | CITY-016 |
| 所属 | 东陵自由市（NAT-017，城市即国家） |
| 坐标 | 68.5°E 36.8°N（G25-N13） |
| 面积 | 4.6 万 km²（含飞地） |
| 人口 | 1,120 万 |
| 城市等级 | MET-1 |
| 经济定位 | 全球蛊道专利与秘境许可交易中心 |
| 主要产业 | 金融、专利、许可交易、研发 |
| 交通 | 国际机场、高铁、内河港 |
| 蛊师人口 | 148 万（13.2%，全球最高） |
| 秘境 | 14 处（全部高度开发） |

## 一、概况

由三个河谷镇合并而成的城市国家。全球 28% 的有效蛊道专利在此注册；LRE（秘境许可交易所）把进入权做成了标准化合约。

## 二、地理

东陵山脉西麓丘陵，海拔 180~620 m；曜澜江北岸；亚热带湿润。

## 三、行政区划

| 编号 | 城区 | 功能 |
|---|---|---|
| DIST-016-01 | 中陵区 | 市议会、金融监管 |
| DIST-016-02 | 专利区 | 专利局、律所、研究园 |
| DIST-016-03 | 港区 | 内河港、物流 |
| DIST-016-04 | 北苑区 | 大学、住宅 |
| DIST-016-05 | 许可区 | LRE 交易所、保险 |
| DIST-016-06 | 飞地一 | 专利审查分局 |
| DIST-016-07 | 飞地二 | 蛊材检测中心 |
| DIST-016-08 | 南丘区 | 高端住宅、私立学校 |

## 四、经济

金融与许可 34%；专业服务 22%；研发 18%。

## 五、居民生活

全球最高收入城市之一；房租中位 3,600 CLU；年轻蛊师外流是主要社会问题。

## 六、蛊师社会

13.2% 的蛊师密度意味着"蛊师是普通职业"；市蛊道局与专利局合署；六转以上 86 人。

## 七、交通

高铁至朔京 1h50；机场年客流 4,200 万；与曜川有防卫协定。

## 八、治安

市警 2.4 万；金融犯罪调查局 1,200；卫队 8,000。

## 九、秘境与特殊地点

14 处秘境全部纳入 LRE；"零号许可场"是训练型 S1/D1，按小时出租。

## 十、势力

市政府、专利局、LRE、东陵蛊道理工学院、六家跨国专利代理行。

## 十一、特色

**"许可即领土"**：东陵的边界只有 4.6 万 km²，但它的合约效力覆盖全球 71 个秘境。

## 七、交通

高铁至临江 5h10、至澜州 3h20、至东陵 1h50；地铁 11 条；机场年客流 8,600 万。

## 八、治安

联邦警 3.2 万；州警 2.6 万；GAB 稽查总队总部。

## 九、秘境与特殊地点

6 处，其中"旧渠"为 S1/D2 城市秘境，已被改造成蛊师实训场（需预约）。

## 十、势力

联邦政府、GAB、FRA、曜川联邦银行、三大炼蛊集团总部。

## 十一、特色

**"制度之城"**：朔京不生产蛊虫，它生产"资格"。全国每一张开窍证书都从这里发出编号。

| DIST-005-03 | 育种区 | 耐寒蛊虫繁育基地 |
| DIST-005-04 | 居住区 | 封闭式社区 |

## 四、经济

科研与服务 31%；耐寒蛊虫 28%；矿产加工 22%。

## 五、居民生活

高福利、高税收；人口稀少，服务业营业时间短；外来科研人员占 18%。

## 六、蛊师社会

国家研究院主导；六转以上 24 人；"公共服务配额"制度要求高阶蛊师每年服务 30 日。

## 七、交通

至霜港铁路 3h；至白栎城 6h；机场季节性加班。

## 八、治安

国家警 6,000；冰原救援队 400。

## 九、秘境与特殊地点

5 处冰下秘境，REALM-006 霜盖冰窟由"冰下秘境共管委员会"管理。

## 十、势力

国家研究院、冰下共管委员会、两家矿业公司、外国科研站 6 处。

## 十一、特色

**"把寒冷变成专利"**：霜栎城研究的是"如何在 −40 ℃ 里让蛊虫活着"，这项能力全球只此一家。

## 基本资料

|---|---|

## 一、概况

长环群岛主岛南端的自由港，关税为零、船籍登记宽松，全球 18% 的商船挂其船旗。

## 二、地理

热带海洋性，年均 26 ℃；台风季 7—10 月；港口水深 18 m。

## 三、行政区划

| DIST-034-05 | 居住区 | 高密度住宅、外劳社区 |
| DIST-034-06 | 离岛区 | 锚地、修船 |

## 四、经济

转口与仓储 38%；船舶注册与服务 24%；金融 19%。

## 五、居民生活

物价低、工资低；外籍劳工占 34%；公共服务弱于周边城邦。

## 六、蛊师社会

蛊师公会薄弱；蛊材转口需"过境许可"，监管宽松是其主要竞争力也是主要批评点。

## 七、交通

至环港航班 2h50；至澜京 4h；跨海大桥连接南港。

## 八、治安

港警 1.6 万；海关稽查 4,000（以"申报"为主）。

## 九、秘境与特殊地点

4 处海洋秘境，其中 REALM-009 长环外礁已开发为潜水与蛊材采集区。

## 十、势力

港务局、船东协会、三家转口贸易集团、两家"船籍代理"公司（争议）。

## 十一、特色

**"世界的中转站"**：长环港不生产任何东西，它只让货物换个身份继续走。
