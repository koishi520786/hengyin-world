## 二、城市概况与历史

### 2.1 定位

临江是"产业城市"，不是政治城市。它的名气来自三件事：凡蛊量产（全球第 11）、秘境服务（全国第 1）、澜东州第二大港。它没有首都的仪式感，也没有东陵的金融光环，城市气质是"上班、交货、赶船期"。

### 2.2 历史分期

| 时期 | 年份 | 事件 |
|---|---|---|
| 渔村期 | 垠历 460—560 | 曜澜江口右岸渔村，以盐、鱼、芦苇为生 |
| 建镇期 | 560—601 | 因澜海航道与江口转运兴起，设镇 |
| 设市期 | 601—660 | 曜川联邦成立后设市；修建江堤与第一代码头 |
| 工业期 | 660—700 | 炼蛊作坊聚集，形成"北城蛊坊街"；人口破百万 |
| 扩张期 | 700—730 | 江东工业区、临港保税区建成；地铁开工 |
| 服务期 | 730—738 | 秘境服务产业化；临江成为全国最大秘境服务基地 |

### 2.3 城市性格（写作用得上的五条）

1. **务实**：市民谈论最多的是船期、订单、学费，不是政治。
2. **分层明显**：江东新区与北城老区的生活质量差距肉眼可见。
3. **蛊师密度高但不精英化**：2.4% 的密度意味着"每条街都有蛊师"，蛊师是邻居、同事、修车铺老板。
4. **对秘境又依赖又警惕**：秘境服务养活 18% 的就业，但溢流事故每年上新闻。
5. **老小区多**：2000 年代建的六层砖混住宅占存量 34%，云栖花园是典型。

## 三、城市地理

| 项目 | 内容 |
|---|---|
| 地形 | 曜澜江下游冲积平原，海拔 8~46 m；北部为低丘（屏岭余脉，最高 186 m） |
| 河流 | 曜澜江自西北向东南穿城，江面宽 480~1,200 m；支流"云栖河"（宽 18 m）自北向南汇入 |
| 气候 | 亚热带湿润；年均 18.6 ℃；7 月均温 29.2 ℃，1 月均温 8.4 ℃；年降水 1,260 mm；梅雨 6 月中—7 月中 |
| 海岸 | 澜海西岸，海岸线 41 km；潮差 3.2~4.6 m（合潮年 +35%） |
| 自然灾害 | 夏季台风外围暴雨、江汛（6—8 月）、合潮年海水倒灌 |
| 城市形态 | 沿江带状＋多中心；江北老城、江东新区、江南主城、滨海新城四片 |

**江与城的关系（重要）**：城市主城在曜澜江**东南岸**（左岸），北城区在**西北岸**（右岸），两片由三座桥连接：云栖大桥（北城—中城）、北城大桥（北城—西陵）、临江大桥（下游，连临港）。北城区到市中心直线 9.6 km，跨江通勤 35~55 分钟。

## 十二、城市特色

**"三层城市"**：

1. **上层（江东与澜湾）**：新区、写字楼、海景房、会展中心——临江的"面子"。
2. **中层（中城与南岸）**：CBD、老商业、市政府——临江的"账本"。
3. **下层（北城与临港旧区）**：六层住宅、蛊坊街、旧码头、地下管网——临江的"里子"，也是故事最常发生的地方。

三层之间不是简单的贫富，而是**时间差**：上层是 2015 年后的临江，中层是 1990 年代的临江，下层是 1980 年代的临江。主角住在下层，抬头能看见上层的光，低头能踩到 1980 年代的排水管——而那条排水管，通着一个登记在册的秘境。
