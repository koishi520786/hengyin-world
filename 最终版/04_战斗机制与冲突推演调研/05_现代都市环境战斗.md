# 05 现代都市环境战斗

> 前提：临江市是公开的现代都市蛊师社会，蛊师、蛊虫、秘境不是秘密；监控、报警、保险、GAB、学校、医院都知道。城市战斗不是“荒野换皮”，第一分钟就受建筑、人群、交通、法规影响。

## 一、城市战斗的五个总原则

1. **空间破碎**：城市不是一张开阔地图，是墙、门、窗、车、电梯、管道、人群组成的“碎片地形”。
2. **旁观者即变量**：路人、学生、病人、乘客会恐慌、拍摄、报警、挡路、被误伤；不是背景板。
3. **基础设施双向**：监控帮追凶也暴露自己；地铁/公交帮逃跑也困住自己；水电燃气帮控场也反噬。
4. **执法会到场**：市警 2.8 万、北城分局 4,200、GAB 稽查中队 400；不是“打完就走”。
5. **后果可计算**：赔偿、保险、学校处分、GAB 记录、封禁、通缉、舆论；比伤势更长久。

## 二、十类环境表

| 环境 | 结构/人流 | 对战斗的影响 | 对蛊虫的限制 | 典型后果 |
|---|---|---|---|---|
| 普通居民住宅 | 68 m²两室一厅、六层顶楼、楼道声控灯、铁门生锈 | 门窄、墙薄、家具多；声音/烟雾惊邻；逃生靠楼梯 | 大范围/毒/火/音浪易误伤；水幕自困；隐身怕监控/邻居 | 邻居报警、房东追责、赔偿、学校/家长介入 |

| 高层建筑 | 电梯、楼梯、玻璃、风、管道 | 垂直战场；电梯困人；楼梯窄；高空坠落 | 飞行蛊受风/室内限制；水幕/烟囱效应 | 坠楼、玻璃雨、电梯事故、消防 |
| 地铁/公共交通 | 封闭车厢、金属、人群、急停 | 无处可躲；急停/开门决定撤退；金属导电 | 毒/火/音浪/电几乎不可用；隐身无用 | 乘客伤亡、全线停运、公共安全事件 |
| 荒野/城市边缘 | 开阔/林地/水边、无监控 | 远程/追逐/伏击强；天气/地形主导 | 蛊虫效果完整；但补给/救援远 | 失踪、妖兽、秘境溢流、无目击 |
| 秘境入口/内部 | 登记/守卫/限流；内部规则不同 | 入口是瓶颈；内部可能禁蛊/压制/道痕环境 | 需许可/登记；S/D/R 等级限制 | 秘境事故、封禁、救援、保险拒赔 |
| 组织/公司/家族场所 | 门禁、保安、监控、私兵、密室 | 主场优势；有增援/撤退通道；有非战斗人员 | 私兵/家蛊/阵盘；但受组织授权/法规 | 组织内斗、开除、报复、GAB 调查 |

| 设施 | 可被利用 | 风险 |

| 墙/楼板 | 破墙、穿墙、躲藏 | 承重破坏、塌方、邻居 |
| 楼梯/电梯 | 垂直追击、伏击、困人 | 电梯停运、烟囱效应、踩踏 |
| 水管/消防 | 水罩/水钻/电流传导、灭火 | 漏水、触电、淹水、短路 |
| 燃气/电力 | 火/爆/断电、制造混乱 | 爆炸、全楼停电、自己被困 |
| 监控/门禁 | 追踪、封锁、识别 | 暴露自己、被反追踪、记录成证据 |
| 通讯 | 呼叫援兵、引爆/干扰 | 信号屏蔽、误报、定位 |
| 车辆 | 冲撞、阻挡、逃跑 | 碰撞、起火、堵路 |

## 四、现代监控与反监控

| 手段 | 能力 | 限制 | 反制 |
|---|---|---|---|
| 城市监控 | 脸部/车牌/轨迹 | 有盲区、存储期、需权限 | 口罩/换装/走盲区/破坏（违法） |
| C-G-422 星辉假眼 | 方圆五里观察，可长期联系 | 不能侦破隐形；耗真元+疲累魂魄 | 隐身、遮断、假目标 |
| C-G-200 蛛丝马迹 | 五百里标记蛊动用即红光；藏空窍缩至千步 | 需预标记；只对“标记过的蛊” | 不带动蛊/换蛊/反标记 |
| C-G-069 蛇信 | 热感 | 范围小、易干扰、不能测冷血 | 冷血/隔热/干扰 |
| C-G-103 电眼 / C-G-525 真视 | 窥隐破形/勘破隐形 | 需真元/距离/视线 | 不隐身、遮眼、远程 |
| 通讯 | 手机/纸鹤/电文 | 可被屏蔽/截获/定位 | 静默、暗语、分段 |

**判定**：监控不是“全知”。先问：谁在看、看什么、存多久、谁能调、是否被遮挡。不能因为“城市有监控”就判隐身无效。

## 五、现代交通与追击

| 方式 | 速度/时间 | 战斗影响 | 限制 |
|---|---|---|---|
| 步行 | 1 km/13 分钟（云栖→二小） | 短距最灵活；可穿楼道/人群 | 体力、伤、雨 |
| 公交 | 2 曜元；北城→临江北站 35 分钟 | 便宜、可混入人群 | 线路/末班 23:30；车厢封闭 |
| 地铁 | 3 线 68 站；北城→中城 40 分钟含步行 | 快速转移；封闭车厢 | 安检、停运、急停 |
| 出租车 | 起步 8 曜元；北城→中城 35 分钟非高峰 | 灵活、可载伤员 | 塞车、登记、司机报警 |
| 自驾 | 桥 7:30—9:00 均速 18 km/h | 追击/冲撞/堵路 | 车祸、牌照、查车 |
| 飞行蛊 | 视蛊档案 | 越障、直线 | 风、禁飞、暴露、真元 |
| 定仙游 | 三息到“有具体印象”的地点 | 战略脱离/斩首 | 六转仙蛊；地点巨变会失败；食物仙元 |
| 气遁 | 直线速度极快 | 追/逃 | 直线、真元、被预判 |

**城市追击三问**：①有没有路线？②有没有交通工具/飞行？③前方有没有封锁/人群/红灯？三问缺一，不能“追到就杀”。

## 六、城市战斗的合法性与后果

| 行为 | 可能后果 |
|---|---|
| 公共场所催动攻击蛊 | 治安/公共安全调查；赔偿；GAB 记录 |
| 校园内用蛊 | 校规处分；家长/教育部门；保险；刑事（若伤人） |
| 住宅内用蛊 | 房东/邻居/物业索赔；消防；强制搬离 |
| 地铁/公交内用蛊 | 全线停运；公共安全；重罚；舆论 |
| 无证/未登记蛊 | 没收/封禁/罚款；GAB 重点 |
| 未成年人用蛊 | 监护/学校/儿童保护介入；更严 |
| 秘境入口冲突 | 取消许可/封禁/救援费用；组织拉黑 |
| 致伤/致死 | 刑事/民事；组织切割；仇怨；长期追索 |

> 城市战斗不是“打完就结束”；战斗结束后的 1—30 天，赔偿/调查/处分/舆论可能继续。

## 七、三类典型城市战场

### 7.1 云栖花园住宅（主角家）

- 68 m²、两室一厅、六层顶楼、楼道窄、声控灯、铁门生锈、邻居近。
- **适合**：谈判、威慑、抓捕、短距防御（T-03/T-05/T-07）。
- **不适合**：毒气、火、音浪、大范围、飞行、水幕自困（把全家困住）。
- **特殊**：苏晞/主角是未成年人；任何战斗都触发监护/学校/邻居/房东后果。

### 7.2 第二小学/校园

- 42 班/1,980 学生、7:20—16:30、楼道/操场/食堂/门房；12—16 岁限制级。
- **适合**：非致命切磋、控制、护人、疏散；校园对战需方案 C/校规。
- **不适合**：毒、火、音浪、电网、致命蛊；任何误伤都会升级为公共事件。
- **特殊**：老师/校医/保安/监控；学生不能用“社会蛊师”规则。

### 7.3 地铁/公交车厢

- 封闭、金属、人群、急停、开门受限。
- **适合**：贴身控制、威慑、短距防御；T-05/T-03。
- **不适合**：毒/火/音浪/电/大范围；隐身也难躲。
- **特殊**：急停/开门是唯一撤退窗口；乘客恐慌可能造成踩踏，比战斗本身更致命。

## 八、城市环境修正表（AI 直接用）

| 条件 | 修正 | 写法 |
|---|---|---|
| 狭窄（楼道/车厢/电梯） | 限制大范围/闪避/群战；近战/控制+；远程− | “狭窄：T-01 月刃可发，但闪避空间不足；T-09 音浪反射误伤” |
| 开阔（操场/广场/河岸） | 远程/追击+；遮蔽− | “开阔：T-01/T-08 可用；但无遮蔽，容易被远程锁定” |
| 人群 | 误伤/恐慌/挡路；隐身+（混入） | “人群：T-14 可混入；T-02 毒/ T-09 音浪高风险” |
| 低光/烟雾 | 视觉−；热感/听觉+ | “低光：蛇信+；星辉假眼−；隐身+但易撞人” |
| 水/雨 | 水行/电+；火/毒− | “雨：T-10 电风险+；T-02 毒被稀释；T-03 青丝防水+” |
| 金属/车辆 | 电/磁/冲撞+ | “停车场：T-10 电网+；T-08 横冲+；但车辆起火” |
| 高层/风 | 飞行−；坠落风险 | “高层：飞行蛊受风；水幕/烟囱效应；坠楼致命” |
| 秘境道痕 | 可能强化/压制特定流派 | “按秘境档案；无档案不补” |

## 九、结论

- 城市战斗的胜负，往往在“谁先控制空间/人群/信息/执法”而不是“谁转数高”。
- AI 必须先写环境三件事：**空间、旁观者、逃生路线**；再写蛊虫。
- 不把城市当荒野；不把监控当全知；不把警力当不会到；不把误伤当无后果。
