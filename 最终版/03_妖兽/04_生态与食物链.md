### 7.2 六个生态区域食物链示意

> 读法：`A → B` 表示「A 被 B 取食／能量由 A 流向 B」；`〔非 O-B〕` 为环境／资源项，不立编号。每行另注该区的关键限制条件。蛊群在该区的位置见 `05_妖兽战力与蛊道兼容.md`「蛊群资源表」，**蛊不进入食物链箭头**（蛊是独立资源，不是营养级）。

#### 区域一：城市边缘

```
〔非 O-B〕城市飞虫 → O-B-001 檐鸮 → O-B-003 层藓兽（幼体猎物，R-01）
〔非 O-B〕高空气流微粒 → O-B-010 悬丝鹞
O-B-001 ⇄ O-B-010（城市上空竞争，R-10，非取食）
```
**限制条件**：檐鸮／悬丝鹞依赖檐下结构／上升气流；建成区核心缺少檐下与飞虫密度，故两者止于「城市边缘」；层藓兽仅在森林—城市边缘交界带接触幼体，不进入建成区（档案明载 O-B-003 栖地为森林）。

#### 区域二：地下管廊

```
〔非 O-B〕腐屑／矿锈 → O-B-002 隧锈鼠 → O-B-003 层藓兽（R-02）
                                     → O-B-008 泥囊螈（R-04）
                                     → O-B-006 沉沙螯（R-08，荒漠边缘矿道）
〔非 O-B〕结晶渗出的能量凝结体 → O-B-011 晶隙蛰（R-35）
O-B-002 ⇄ O-B-011（共存矿道 R-15，非取食）
O-B-004 砾背驮兽 ⇄ O-B-011（甲缝清理共生 R-13）
```

**限制条件**：管廊／地铁／矿道为封闭无光环境；O-B-011 必需能量凝结体，只出现在「洞窟／特殊能量环境」，与 O-B-002 的矿锈资源位不同，故判「共存」而非竞争同一食物。

#### 区域三：森林

```
〔非 O-B〕草／林下植被 → O-B-005 草潮羚（草原侧，森林边缘取食）→ O-B-003 层藓兽（R-03）
O-B-001 檐鸮（幼体）→ O-B-003 层藓兽（R-01）
O-B-002 隧锈鼠 → O-B-003 层藓兽（R-02）
O-B-011 晶隙蛰 → O-B-003 层藓兽（偶食 R-09）
O-B-003 ⇄ O-B-012 阈鹿（秘境林缘竞争 R-11，非取食）
```
**限制条件**：层藓兽为「森林顶级伏击捕食者」，依赖林冠／藓层遮蔽；离开森林遮蔽后伏击机制不成立，故不跨区追猎至城市或荒漠腹地。

#### 区域四：草原与荒漠

```
〔非 O-B〕草场 → O-B-005 草潮羚（群 200～2000）→ O-B-003 层藓兽（R-03）
                                            → O-B-006 沉沙螯（落单个体，R-07）
O-B-002 隧锈鼠 → O-B-006 沉沙螯（R-08）
O-B-005 踩踏／粪肥 →〔非 O-B〕草原（生态调节 R-24，非取食）
O-B-006 流沙伏击 →〔非 O-B〕荒漠微地形（R-30）
```
**限制条件**：沉沙螯仅取「落单 O-B-005」与进入流沙带的 O-B-002，群体正面对峙不触发伏击；草潮羚迁徙（R-25）决定草原侧捕食压力的季节性。

#### 区域五：河湖与沼泽及近海

```
〔非 O-B〕元气絮与藻 → O-B-007 洄鳞鲮 → O-B-008 泥囊螈（R-05）
                                    → O-B-009 潮脊鲸（洄游群 R-06）
O-B-002 隧锈鼠 → O-B-008 泥囊螈（R-04）
O-B-007 洄游 ⇢ 河湖 ↔ 近海（迁徙连接 R-25）
O-B-009 跨近海迁徙 ⇢ 近海 ↔ 深海（R-25）
O-B-008 ⇄ O-B-009（河口个体竞争 R-12，非取食）
```
**限制条件**：洄鳞鲮是「水质指示」种（R-26），其种群状态可作该区观测指标；泥囊螈与潮脊鲸的竞争仅限**河口个体**（R-12），不扩为全种群竞争；潮脊鲸主体在海洋／深海。

#### 区域六：高空与洞窟及秘境

```
〔非 O-B〕高空气流微粒 → O-B-010 悬丝鹞（R-33）
〔非 O-B〕结晶渗出的能量凝结体 → O-B-011 晶隙蛰（R-35）
O-B-011 → O-B-003 层藓兽（偶食 R-09）
〔非 O-B〕秘境边界裂隙 ⇄ O-B-012 阈鹿（感知并短暂稳定 R-23，非取食）
O-B-003 ⇄ O-B-012（秘境林缘竞争 R-11）
O-B-010 ⇄ O-B-001（城市上空竞争 R-10）
```
**限制条件**：O-B-011 的「道痕逸散」仅【合理推测】，不进食物链、不作能量转换；O-B-012 与边界裂隙的关系是**本体天赋调节**，不是捕食也不是蛊效；秘境／小世界蛊群单列于 `05_妖兽战力与蛊道兼容.md`「蛊群资源表」的秘境特有蛊群。

#### 7.3.2 妖兽为何不随意出现在市中心（机制判定，非「设定如此」）

| # | 机制 | 可判定句 | 档案依据 |
|---|---|---|---|
| 1 | 必需资源缺席 | 市中心建成区不提供檐下飞虫密度（O-B-001）、矿锈与腐屑（O-B-002）、岩菌矿液（O-B-004）、草场（O-B-005）、流沙（O-B-006）、元气絮与藻（O-B-007）、沼泽腐质（O-B-008）、深水（O-B-009）、上升气流微粒（O-B-010）、能量凝结体（O-B-011）、边界裂隙（O-B-012） | 各条「环境」列 |
| 2 | 特殊能量／场域缺席 | O-B-011 必需结晶渗出能量、O-B-012 必需边界裂隙，二者在建成区常态不存在；「道痕逸散」仅【合理推测】，不作为「城市里也有」的依据 | O-B-011／012 档案设定 |
| 3 | 体型与暴露成本 | O-B-009 巨兽需深水浮力与大面积滤食场，O-B-005 群 200～2000 需连片草场，二者无法在建成区隐蔽或维持种群 | O-B-009／005 档案设定 |
| 4 | 生态位边界 | O-B-003 伏击依赖森林林冠／藓层遮蔽、O-B-006 依赖流沙地形，离开主场即核心机制不成立（主场优势记在环境、不计入本体战力） | `03_妖兽/05_妖兽战力与蛊道兼容.md`1.2 第 11 类 |
| 5 | 人为管控 | 官方封控、协会登记、秘境公司界隙封锁、企业作业区圈定，把异常个体限制在边缘／管廊／近海／秘境 | 7.3.1 |
| 6 | 触发条件化 | 市中心出现只能作为**异常事件**判定：①界隙外溢（O-B-012 窗口失效）、②人为运输逃逸（O-B-004 驯养个体）、③迁徙偏航（O-B-007／009）、④地下管廊连通意外（O-B-002）。须逐条核触发原因并记录，**不是常态** | 【合理推测】＋档案设定 |

> **判定结论**：常态下 12 种原创妖兽物种均不出现在市中心；凡市中心目击，先按上表 6 条核触发条件，再调`05_跑团规则/02_战斗与能力判定.md`第 9.8 节「突袭／主场优势」场景，不得直接以「妖兽入侵城市」作无机制判定。

## 蛊虫群与资源系统

> **总纲**：蛊是**独立个体**（`03_妖兽/05_妖兽战力与蛊道兼容.md`〇·1、第二节六类关系），不是妖兽器官、不是妖兽本体战力。凡引用蛊虫编号，必须以权威档案为据；查不到写【未识别野生蛊虫】／【待考证】，禁止编造编号、禁止改原著能力。**携带蛊虫 ≠ 可控 ≠ 可催动 ≠ 能组杀招**（同档案案例 F 星魔蝠 C-B-018「缺乏智慧，不能使用杀招」【原著明确】）。

### 当前生态深化（檐鸮、沉沙螯、阈鹿）

> 本卷只深化 **O-B-001 檐鸮、O-B-006 沉沙螯、O-B-012 阈鹿** 三种，不新增 O-B 编号，不改既有二十节档案的既有数值。分布用 NAT-001—120 编号锚定；某国出现该物种，不等于全国都有，只表示该国至少有一个登记栖息带。

### 七、普通城镇的批量登记规则

**范围**：全球 59 座核心城市见 `04_世界/04_城市与行政区.md`；其余约 1,400 座城镇按普通城镇规则登记，不逐条建详档。

**规则**：
- 编号段：`CITY-1XX-9YY`（9 开头为"普通城镇"），XX 为国家段。
- 每座只登记 6 字段：编号、名称、所属行政区、人口、功能（1 词）、最近秘境距离。
- **不建详档**，需要时按统一口径“12 问”临时扩写。
- 已登记示例（曜川）：`CITY-101-901 青溪（澜东州，4.2 万，农业）`、`CITY-101-902 石坳（北岭州，1.8 万，矿业）`。

**40 座重点城市**（每国 1—2 座）另见 `04_世界/04_城市与行政区.md` 城市索引；本卷不逐一列名其余城市。
