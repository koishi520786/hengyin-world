## 四、可信度标记（全文统一）

| 标记 | 含义 |
|---|---|
| 【原著明确】 | 有原著章节或正文逐字表述可印证 |
| 【可靠资料佐证】 | 百科词条／有声书转写／社区考据多源互证，未取到正文逐字 |
| 【原著未明确】 | 原著确实没写该字段，**留空不推测** |
| 【存在争议】 | 两种以上互斥说法，**并列保留、不调和** |
| 【合理推测】 | 本资料库的推断，显式标注，不冒充事实 |
| 【待考证】 | 线索不足，待后续补证 |
| 【原创设定】 | 仅出现在两部原创图鉴，**不进原著区** |

**六条不可破的纪律**：
1. 原始文件不覆盖、不删除；旧版可回溯。
2. 原著蛊虫名称／能力／品阶不擅自修改；已有杀招设定不改写。
3. 冲突记录并列保留，不自行发明「上一回／另一次」替用户调和设定。
4. 原著与原创严格分离，原创全标【原创设定】。
5. 信息不足只标【原著未明确】／【待考证】，**绝不编造组件、章节号与消耗**。
6. 组成蛊虫流派 ≠ 杀招流派；杀招按主要运行机制或原著明确归属分类。
