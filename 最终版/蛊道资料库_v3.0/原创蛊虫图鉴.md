# 【原创设定】回声蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-001 |
| 名称 | 回声蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 音道 |
| 核心用途 | 侦查（回声标记与追踪） |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：形如一只干瘪的空蝉蜕，半透明，腹内无实。
- 大小：拇指盖大小。
- 颜色：通体灰白，边缘泛一层极淡的蓝。
- 形态特征：背上有三道环纹，环纹随最近一次「回响」的强弱或深或浅。
- 特殊视觉效果：催动时，空蝉蜕会轻轻震颤，发出人耳几乎听不见的嗡鸣；嗡鸣撞上障碍后会折返，在蛊师心窍中形成「第二重声响」。

### 二、核心能力

- 基础能力：向四周发出一次不可闻的低频回响，声波遇到障碍折返，蛊师据此在脑海中描出周围环境的粗糙轮廓。
- 作用机制：低频声穿透力强、衰减快，只适合近距；声波并非「看见」，而是「听见形状」，故无法分辨颜色、文字，只能勾勒凹凸、疏密与远近。
- 作用对象：半径约十五步内的实体障碍。
- 能力范围：十五步，越远越模糊。
- 效果强度：能辨明通路、门窗、沟壑与静止的大物；对贴地匍匐、柔软吸音之物几乎无效。
- 使用限制：每次催动需持续供真元；环境中噪声越大、杂响越多，轮廓越乱；对有音道修为者，这回响本身可被其察觉。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，音道或兼修音道者炼化更易 |
| 炼化难度 | 低；回声蛊意志微弱 |
| 特殊要求 | 无 |
| 炼化风险 | 几乎无 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 静水；每三日一碗 |
| 辅助食物 | 铜铃的锈屑（可让下次回响更清） |
| 频率 | 每三日一次 |
| 成本 | 低 |
| 特殊环境 | 若在「无声之室」（四面皆吸音软泥）中喂养一次，效果维持更久 |
| 断食后果 | 回响逐次变闷，最终无法勾勒轮廓，蜕壳硬化裂开、蛊亡 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 需持续供真元；环境偏静方可用 |
| 消耗 | 二转赤铁真元，低耗、可连发 |
| 范围 | 十五步内，越远越模糊 |
| 持续 | 单次回响一瞬，可连续催动 |
| 缺陷 | 无攻击力；无法辨字辨色；易受噪声干扰；对吸音软物、匍匐贴地之物近乎失明 |
| 克制 | 克制以视觉扰乱／迷幻为主的隐匿（因它不靠眼睛）；被音道反制（察觉并扰乱回响）、被水道「静水」环境削弱 |
| 优势 | 消耗低、可连发、不依赖光线，黑暗中亦可用；能识破视觉遮蔽但非实体隐藏 |
| 适用场景 | 洞穴、密道、浓雾、黑夜、废墟等目不能视之地 |
| 不适用场景 | 市集、战场、风口等嘈杂处；面对专精音道的对手 |

# 【原创设定】余烬蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-002 |
| 名称 | 余烬蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 炎道 |
| 核心用途 | 资源（余火回收炼成可复用火种） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一撮永不熄灭的暗红灰烬，无固定形状，被微弱的火星托起悬浮。
- 大小：约一握之灰。
- 颜色：暗红为主，偶见金点闪灭。
- 形态特征：靠近尚有余温之物时，会自行聚拢成一小团火茧。
- 特殊视觉效果：吞食余火时，灰烬表面浮起细密火星，如星子自下而上攀爬。

### 二、核心能力

- 基础能力：吸收环境中的「余火」「余温」——篝火残烬、灶膛余炭、被炎道攻击灼烧后残留的余焰——将其凝练为可存蓄的「火种」。
- 作用机制：余烬蛊只回收「将熄未熄」的火，不主动引火；它把散逸的热力压成一点火种，封存在自身灰烬中，蛊师需要时再引燃。
- 作用对象：一切余温未散的炭、灰、残焰。
- 能力范围：贴身，约数尺。
- 效果强度：积满一握灰，可存约可维持一夜营火之热；火种可反复引燃、多次取用，但每取一次总量减。
- 使用限制：不能凭空生火，必须有「余温来源」；封存的火种会缓慢流失，最长存续七日；遇水即大损。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，炎道或兼修炎道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 需亲手以真元护住一次「自然熄灭的火」至最后一星 |
| 炼化风险 | 低；但若炼化失败，火星反扑可灼伤蛊师心窍 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 余温炭灰（以将熄的炭火喂食） |
| 辅助食物 | 无 |
| 频率 | 视取用情况；不取用时每七日喂一次即可 |
| 成本 | 低 |
| 特殊环境 | 最好喂「自己参与熄灭的火」，火种更纯 |
| 断食后果 | 火种彻底冷透，蛊成死灰，无法再醒 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 必须有「余温来源」，不能凭空生火 |
| 消耗 | 二转赤铁真元（回收时低耗），火种本身为存蓄资源 |
| 范围 | 贴身数尺 |

### 一、外观

- 外观：一枚折成雁形的竹简薄片，翅上有一道未干的墨线。
- 大小：两指长。
- 颜色：竹黄，墨线乌亮。
- 形态特征：封入口信后，雁翅会轻轻一合；送达被读，墨线自断。

### 二、核心能力

- 基础能力：把蛊师亲口说的一句「口信」封进竹膜，循预先留在收信人身上的「标记」飞递到其手中；送达被读，翅上墨线自断，示「已阅」。

- 作用对象：一句口信（原声），收信人为预置标记者。
- 能力范围：两标记点之间，约数十里。
- 效果强度：口信原声不失真、不可中途改写、不可复听第二遍（墨线断即散）；一次只寄一句。
- 使用限制：须事先在收信人身上或居处留标；一次一句、须蛊师亲口；途中被截则竹简碎、口信随散；不辨收信人死活，标在人亡亦照投。

### 一、外观

- 外观：一根微缩的扁担，两头各坠一枚小石砣，担身有一道磨得发亮的肩痕。
- 大小：一拃长。
- 颜色：竹黄泛褐，石砣青灰。

- 基础能力：把蛊师所负之物的「重」分一部分到担形虚影上，令长途负重省力、步履稳当。

- 能力范围：本人肩挑 / 背负之物。
- 效果强度：可长途承重而气力不坠、少耗真元于「撑住」；但不增速、不增力、举不起原本举不动之物。
- 使用限制：须「肩挑/背负、缓行」之姿；一旦放下货物、改作奔袭或腾挪，分重即散；陡坡、湿滑处担影易歪，分重失衡。

# 【原创设定】谷雨蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-015 |
| 名称 | 谷雨蛊 |
| 品阶 | 三转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 木道 |
| 核心用途 | 种植：催种子抽芽、匀苗 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一粒饱胀将裂的谷种，壳上凝着一层细密水珠。
- 大小：指甲盖大。
- 颜色：谷黄泛青，水珠澄亮。
- 形态特征：近了湿土，谷壳会微微一鼓，像要裂开。
- 特殊视觉效果：催动时，谷种周围浮起一层极淡的雨气，落地无声，却见土面针尖似的冒出嫩芽。

### 二、核心能力

- 基础能力：催动一方已播之田，令种子齐整抽芽、并按疏密匀苗，使一季出苗不稀不挤。
- 作用机制：木道「催生」——它不凭空造种、不替代水肥，只把「本就要发」的芽催得齐、催得匀；土、水、种三者缺一，它催不动。
- 作用对象：一方已播种、且有水有肥的田畦。
- 能力范围：约一畦（数丈见方）。
- 效果强度：出苗齐整、疏密合度；但不增产、不改良种、不催「已死之种」、不代替后续生长。
- 使用限制：须应时令（谷雨前后最验，违时则芽弱）；须田已播种、水肥已备；一季对同一畦只验一次，重催反致苗挤根弱。

### 三、炼化条件

| 项目 | 内容 |

### 一、外观

- 外观：一小把象牙色的细算筹，捆在一根旧绳里，筹头磨得发亮。
- 大小：一握。
- 颜色：牙白，绳褐。
- 形态特征：清点之物一多，算筹会自行在绳间挪位，筹头朝外者即「已点」。
- 特殊视觉效果：核账时，算筹会轻轻磕碰出细响；数目对得上，响止于一声；数目有缺，便多出一声空磕。

### 二、核心能力

- 基础能力：对一批货物 / 元石 / 账目做清点、核数、按既定单价核价，并把结果记成一份不易漏的「筹账」，可防缺漏、防调包导致的数目不对。

- 作用对象：一批可数、且已有定价的货 / 钱 / 账。
- 能力范围：一批，数越大越耗心力。
- 效果强度：点数准、核价准、缺一件即「空磕」示警；但只核「数与价」，不核「质与真伪」。
- 使用限制：须「物已定价、且可逐件点数」；散装难计、活物乱窜、价目未定者核不了；一次只理一批，混批则乱；市集嘈杂、清点被打断则须从头再点。

# 【原创设定】结绳蛊

**基本资料**

|---|---|

| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一段旧麻绳，绳上打着疏密不一的结，结尾垂着一缕散穗。
- 大小：一尺长，可绕腕。
- 颜色：麻褐，结处磨得发白。
- 形态特征：记一件事，绳上便多一个结；结越大，所记越要紧。
- 特殊视觉效果：回放时，蛊师指尖捏住某结一捻，那段见闻便「按当时次序」在心头过一遍，不添不漏。

### 二、核心能力

- 基础能力：把一段亲眼所见 / 亲耳所闻的见闻、口供、契约条款「结」成绳结，日后按结回放，次序与细节不失真，可作记忆存档与推演底本。
- 作用机制：智道「结以存真」——只「录」不「解」：它保证「记下的不歪」，但不替蛊师推断、不补忘掉的部分、不辨所记真伪。原著书虫【原著蛊虫】是「喂什么记什么、永记不失」，本蛊与之同类而更重「次序」，二者可并用不悖。
- 作用对象：一段亲身经历 / 见闻 / 契约条款。
- 能力范围：绳长有限，结数有限（约十数结，结大者占得多）。
- 效果强度：回放次序、细节不失真；但不能推演未来、不能辨伪、不能记自己没留意到的细节。
- 使用限制：只记「亲身经见」；道听途说、事后脑补者结不牢；结满须「解结」（抹去旧记）方能再结；绳断则所记尽失。

# 【原创设定】存息蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-107 |
| 名称 | 存息蛊 |
| 品阶 | 六转 |

| 所属流派 | 魂道 |
| 核心用途 | 生命与魂魄：温养将散残息、延缓消散 |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一缕将断未断的游丝，尽头悬着一点比米粒还小的温光，光不亮却不肯灭。
- 大小：游丝寸许，光点如尘。
- 颜色：丝灰白，光暖黄。
- 形态特征：所托之息越弱，丝越细、光越垂；息一散，丝立断。
- 特殊视觉效果：托住一线残息时，光点会极缓地一涨一落，像替它接着最后一口气。

### 二、核心能力

- 基础能力：温养一缕「将散未散」的残息 / 残魂，延缓其消散，为招魂、辨认、超度留一段窗口。
- 作用机制：魂道「留息」——不造魂、不补魂、不复活、不延寿，只把「本就还在、正要散」的那一线托住，慢一点散。
- 作用对象：单缕尚存一线的残息 / 残魂，或壶天熟地中「将枯未枯」的一线微弱生机。
- 能力范围：单缕。
- 效果强度：可把「数息即散」延缓到「数日」，供从容辨认 / 超度；一旦散尽不可追，离体越久越难托。
- 使用限制：只托「尚存一线」者；散尽者无效；不能令其恢复神智、不能还魂附体、不能增寿；托养期间持续耗魂魄底蕴 / 心力。

### 五、能力限制

- 效果强度：可让「熟地成型那一刻」「将枯之苗」「将凝之材」暂时定住以避外扰；但封存期间该物不可用、不可被催动、不可取出干预，解封后一切照旧继续。

## 五、第二阶段深化新增：黑暗机制蛊虫（2026-11-13）

> **本节性质**：全部为【原创设定】，状态 **proposed（拟定，未经长期跑团检验）**。
> **设计目标**：补足本图鉴此前「32 只全为良性／实用向」的机制缺口——以人体材料、血亲条件、魂魄、寿元、生命力、炼尸、多人炼制、极端代价为核心机制的蛊虫，每只都有用途、有代价、有限制、有现代社会监管接口（详见《现代蛊道世界_v1.0/17_蛊师社会与制度.md》第十一节）。

- 效果强度：三档判定准确；**验不出更细的辈分**（叔侄与同祖兄弟同档），验不出死血。

### 一、外观

- 外观：一只灰白色小蠹虫，形如书蠹，头前有两根细如发丝的探须。
- 大小：半寸。
- 颜色：骨白，节间有淡金纹。
- 形态特征：静时蜷成环，探须收拢如问号。
- 特殊视觉效果：催动时探须探入骨缝，虫身透出极淡的青芒，似骨内余光。

### 二、核心能力

- 基础能力：栖于合法批号遗骨之上，读出死者临终前最后三日的残息记忆——所见、所闻、临终执念，以碎影方式呈现于蛊师识海。
- 作用机制：魂道「问骨」——人死后魂魄消散，但重度情绪与执念会在最亲近的骨骼（多为颅骨、胸骨）中留下残息印记；问骨蛊只读取印记，不招魂、不通灵。
- 作用对象：死亡不超过三年、保存完好的人类遗骨。
- 能力范围：单具遗骨，读取一次。
- 效果强度：碎片式影像，无声音、无完整叙事；情绪浓烈的死前一刻最清晰。
- 使用限制：**只认合法批号遗骨**——蛊在炼制时烙入了批号感应，无批号的骨骼蛊直接休眠；每具遗骨只能被读取一次，读后残息即散、骨色转灰。

| 项目 | 内容 |
|---|---|
| 炼化条件 | 四转蛊师，魂道或兼修魂道者 |
| 炼化难度 | 中高 |
| 特殊要求 | 炼制须在官方遗骨批号数据库登记的场所内进行，蛊成即烙印批号感应——**这道行政烙印不可去除**，是本蛊的存在前提 |
| 炼化风险 | 中；炼制失败则探须反噬蛊师识海，致一日目盲 |

| 成本 | 低 |
| 特殊环境 | 须避强光与喧哗 |
| 断食后果 | 探须失灵，读取影像越读越碎，直至全不可读 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 合法批号遗骨＋持有调查许可（执法、公证、直系亲属申请） |

- 能力范围：一对一，公证大厅内完成。
- 效果强度：整十年，不可拆零；受渡者须为「五年内将死」的诊断者，转给健康人无效（寿元不叠加，只补不足）。
- 使用限制：**每对血亲一生只能让渡一次**；须双方在公证蛊师见证下自愿，双向真元烙印落锁。

# 【原创设定】燃薪蛊

| 品阶 | 三转 |

| 所属流派 | 血道 |

| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】｜状态：proposed |

### 一、外观

- 外观：一节焦黑的小竹薪，内有暗红炭心。
- 大小：指节长。
- 颜色：外焦黑，内暗红。
- 形态特征：炭心如呼吸般明灭。
- 特殊视觉效果：催动时竹薪燃起无烟的红焰，焰色由红转白，蛊师气血亦随之一暗。

### 二、核心能力

- 基础能力：十息之内，燃烧蛊师自身生命力，使真元输出临时暴增约五成。
- 作用机制：血道「燃薪」——生命力是薪，真元是火；十息燃尽一截薪，火便猛十息。**燃掉的生命力不复还**。
- 作用对象：蛊师自身。

# 【原创设定】悯生蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-032 |
| 名称 | 悯生蛊 |
| 品阶 | 四转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 木道 |
| 核心用途 | 医疗：以濒死者自愿献出的一缕生机为引，吊住其伤势七日，为救治争时间 |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】｜状态：proposed |

### 一、外观

- 外观：一株掌心高的白芷状小草，叶脉透明。
- 大小：掌心高。
- 颜色：白绿，叶缘泛一线银。
- 形态特征：草叶间常凝一滴不落的露珠。
- 特殊视觉效果：催动时露珠顺叶脉流入伤者眉心，伤者面色由灰白转微青，如枯木逢春。

### 二、核心能力

- 基础能力：濒死者自愿以一缕生机为引，悯生蛊吊住其性命七日——七日内伤势不恶化、气血不散，等得到救治则活，等不到则蛊与生机同灭。
- 作用机制：木道「系生」——以伤者自己的生机为绳，把命拴在七日的窗口上；**蛊不生造生机、不治愈、只延缓**。
- 作用对象：重伤濒死、五日内将亡者的自愿者。
- 能力范围：接触式（露珠入眉心），此后蛊与伤者相系，不离一里。
- 效果强度：七日窗口；窗口期内治得了的伤才治得了，治不了的（如高位截瘫）依然治不了——**吊命不是续命**。
- 使用限制：须伤者自愿（昏迷者以贴身至亲按其生前意愿代诺，代诺须公证）；每只悯生蛊一生吊三人。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 四转蛊师，木道或兼修木道者；医疗蛊师执照优先 |
| 炼化难度 | 中 |
| 特殊要求 | 须在曾救活过人的药圃炼制（「活气」之地） |
| 炼化风险 | 低 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 药圃晨露 |
| 辅助食物 | 每月一撮伤者康复后赠的谢糖（习俗，非机制必需，但喂过的草吊命更稳——心理机制存疑，实录之） |
| 频率 | 每日晨露 |
| 成本 | 低 |
| 特殊环境 | 须避死气重的场所（停尸房旁养不活） |
| 断食后果 | 露珠干涸，吊命窗口逐日缩短 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 濒死者自愿（昏迷则公证代诺） |
| 消耗 | 四转黄金真元中耗；**吊命失败的第四例起，蛊师自身折寿一年/例**（前三例蛊担，之后人担——逼蛊师量力而行） |

| 持续 | 七日/人 |
| 缺陷 | 等不到救治则**蛊与伤者生机同灭**（伤者死、蛊枯、蛊师折寿——三方皆输）；吊命者七日无意识如深眠，醒后对窗口期全无记忆 |
| 克制 | 「催命」类毒蛊可强行截断窗口（毒杀吊命者是谋杀加重情节）；「涤生」类邪术同 |

| 适用场景 | 战伤、事故、秘境重伤转运 |

| 监管接口 | 代诺程序与「急救优先级」制度见世界观 17 号第十一节；**「强取生机」（不经自愿）不在此蛊——那是邪术「抽生」的罪名，与本蛊无关但常被污名混同，须澄清** |

# 【原创设定】化胎蛊

**基本资料**

|---|---|

| 所属流派 | 炼道 |
| 核心用途 | 医疗：以法定批号的胎产医疗组织（胎盘、合法妊娠终止组织）为基，炼制「再生肉芽」，治疗大面积毁容与断肢 |
| 稀有程度 | 稀有（材料管制所限） |

### 一、外观

- 外观：一团温润的粉玉色胚状蛊，表面如婴儿肌肤。
- 大小：核桃大。
- 颜色：粉玉色，微透。
- 形态特征：静时蜷如胎儿，触之温热。
- 特殊视觉效果：催动时胚体化开为细密肉芽，覆上创面，与宿主肤色渐渐相融。

### 二、核心能力

- 基础能力：治疗大面积毁容、深度烧伤、断肢（腕、踝以下）——肉芽按宿主肌理重新铺生，三月成肤，半年成肢。
- 作用机制：炼道「化生」——胎产组织天然携带「尚未定型」的生长之性，炼制后只认「重塑」一事；**只补缺失，不改原貌**。
- 作用对象：人体创面。
- 能力范围：单处创面；断肢限于腕踝以下（再向上，肉芽无力回天）。
- 效果强度：成肤与原生肌肤九成相似（细微差异：新肤无汗毛、畏晒）；成肢恢复八成功能。
- 使用限制：一人一生限用两次（肉芽有「认主」上限，第三次全身排异）；**材料批号与创面病历须两证齐全方可催动**。
