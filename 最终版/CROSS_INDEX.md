### 一、关联纪律

| 规则 | 说明 |
|---|---|
| 不凭提及建链 | 同一段文字出现两个名字，不等于二者有制度、生态、师承或产业关系 |
| 关系要写方向 | 国家→人物、秘境→国家、妖兽→蛊虫、杀招→蛊虫，方向不同不可互换 |
| 不重复计数 | POL 的人口/面积归母国；妖兽携带蛊虫不等于妖兽拥有/控制/炼化蛊虫 |
| 不补未知 | 原著未载的数值、章节、成功率一律不补；只写“已登记的关联” |
| 争议并列 | 同一实体两种说法并存时，链上标【争议】，不强行合并 |
