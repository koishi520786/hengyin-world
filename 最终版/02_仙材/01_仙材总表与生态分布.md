## 二、按生态关系类型分

| 类型 | 条目 | 说明 |
|---|---|---|
| 仙材—妖兽有 C 级关联 | SM-001、SM-006、SM-007、SM-008、SM-010 | 全部是“可能同域/间接”，没有一条是“守护兽”或“共生” |
| 仙材—环境有 C 级关联 | SM-002、SM-003、SM-004、SM-005、SM-009 | 依赖特殊地貌/气候/水文，但无确认妖兽 |
| 原著 A 级生态 | 无 | 原著只给名称/用途，没有生态记载 |
| 正式 B 级生态 | 无 | 正式设定只给价格、用途、产业，没有把具体妖兽与仙材绑定 |
| D 级/无直接关系 | SM-011、SM-012、SM-013 | 没有足够证据安排妖兽；保留为空 |

> **统计口径**：SM-001、006、007、008、010 共 5 条有 C 级妖兽关联；SM-002、003、004、005、009、011、012、013 共 8 条无确认妖兽（其中 SM-002/003/004/005/009 仅环境 C，SM-011/012/013 为 D）。因此“有 C 级妖兽关联 5；仅环境/无直接关系 8”。这比“13 种都配守护兽”更符合现有证据。
