## 五、NPC 连续性规则的主要变化

| 变化 | 内容 |
|---|---|
| 四态硬规则 | 真正第一次 / 已经历但次数不多 / 已经成为日常 / 熟悉行为中的特殊情境 |
| 行为熟悉度字段 | 牵手、拥抱、脸颊/额头亲吻、一起吃饭、靠坐、小礼物、被夸奖、被感谢、被关心、分别/重逢、吵架/和好 |
| 反模板清单 | 玩家开心→自动脸红；夸奖→低头捏衣角；牵手→身体僵硬；拥抱→后退半步；关心→感动流泪；熟悉亲近每次当第一次；每次礼物同样惊喜；NPC 反复不了主角；连续多轮重复同一动作/情绪 |
| 不确定性规则 | 未记录的重要事件标“未确认”；不直接认定第一次，也不凭空编造已经发生 |
| 特殊情境规则 | 生日/分别/重逢/承诺/低落可以让熟悉行为产生新意义；情绪必须来自情境，不是重新当第一次 |
| 记录分层 | 普通日常不必每次建档；重要互动/新习惯/信任变化/矛盾解决要更新 |
| 苏晞专项 | 11 岁、共同生活、称呼“哥哥”、第二主角、独立生活、可拒绝/累/生气/嘴硬；所有亲近纯真、非性化；不写成人恋爱/婚姻 |
| 玩家控制权 | 主角行为/台词/思想/决定/情绪由玩家决定；NPC 不得替主角做决定/改情绪 |

**与 `ll.txt` 的关系**：第六章核心已经足够强，本轮不重写；只建议在 6.6 与 16.3 增加“四态/行为熟悉度/反模板/不确定性/记录分层”的引用。`ll.txt` **未修改**。
