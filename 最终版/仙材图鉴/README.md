## 一、这个图鉴负责什么

| 负责 | 不负责 |
|---|---|
| 已登记仙材的名称、别名、来源、形态、形成环境、生态关联、采集与用途 | 不重写原著蛊虫、杀招、妖兽的既有能力 |
| 把仙材挂到已有妖兽、秘境、地形、气候与产业上 | 不为每种仙材强行安排守护妖兽 |
| 标明原著事实、衡垠正式设定、合理推演、设计提案 | 不把 C/D 级推演写成原著或已生效设定 |
| 给 GM 提供可观察迹象、采集困难、生态变化 | 不替代 `跑团提示词/ll.txt` 的运行规则 |

**边界**：`SM-` 是仙材图鉴内部编号，不占用 `NAT/CITY/REALM/PER/HIS/C-G/O-G/C-B/O-B` 任何既有编号段；新增仙材一律顺延，不插号、不改号。`跑团提示词/` 未读取正文用于本轮生态设计，未修改。

## 二、权威层级与证据等级

| 等级 | 含义 | 本图鉴用法 |
|---|---|---|
| **A 原著明确** | 《蛊真人》原文直接出现名称、用途或条件 | 只照录原文能确认的部分；原文没写的生态、形态、产地一律不补 |
| **B 衡垠正式设定** | 本项目正式档案已写明的名称、价格、分布、产业或用途 | 可作世界事实引用；仍要回原文件核对 |
| **C 合理推演** | 依据已有地形、妖兽习性、产业逻辑提出的生态方案 | 必须标 `C`；GM 可用，但不得说成原著事实 |
| **D 设计提案** | 尚无足够资料、仅备选的方案 | 只作讨论，不进入默认世界事实 |

**硬规则**：
1. 同一行里既有 A 又有 C 时，分开写，不能把 C 混进 A 的句子里。
2. 原著只给名字、不给生态的，生态栏写“未知”，再另起“合理推演（C）”。
3. 妖兽只引用 `O-B/C-B` 已存在物种；不新增妖兽、不给妖兽补蛊、不把“携带”写成“拥有/可控/炼化”。
4. 仙材是材料，不是仙蛊；`归墟水` 不等于 `归墟蛊`，`洞天土` 不等于 `洞天蛊`，`安魂露` 不等于 `安魂蛊`，`尘眼` 不等于 `微尘蛊`，`余音` 不等于 `回响蛊`。
5. 采集数量、成功率、价格没有正式出处的，写“未知”或“待考证”，不编数值。

## 三、分类规则（工作分类，C 级）

> 原著没有“仙材分类学”。以下分类是本图鉴为检索方便设的**工作分类**，不是原著分类，也不是世界公认分类。

| 工作分类 | 判据 | 本图鉴条目 |

| 天象凝材 | 名称/用途指向天象、时间、潮汐、光候 | SM-002 漩涡晨曦 |
| 水液凝材 | 以水、露、泉、海液为载体 | SM-003 七宝水、SM-006 归墟水、SM-009 安魂露、SM-013 停水 |

**分类可信度**：以上归类的依据是名称与已有用途，标 `C`；若后续原文或正式设定给出新分类，以新证据覆盖本表，并保留旧归类为历史。

## 五、单种档案怎么读

每份档案按同一顺序：
1. **基本信息**：编号、名称、别名、分类、品阶/层次、资料来源、原著/原创/待考证。
2. **外观与特征**：只写有出处或明确标 C 的形态；没有就写未知。
3. **生长与形成环境**：B 级分布与 C 级候选环境分开。
4. **生态关联**：相关妖兽、植物/资源、共生/捕食/竞争/寄生、相关环境；每条带 A/B/C/D。
5. **采集与获取**：条件、难度、风险、工具、是否破坏环境、保存、人工培育。
6. **用途与价值**：炼蛊用途、其他用途、稀有度、经济价值、替代材料。
7. **世界观补充**：分布、已知产地、相关秘境、组织/产业、确定性、待核实问题。

**没有证据的字段不删，写“未知/未确认/待考证”**；删掉字段会让 GM 误以为“没有这项”。

## 六、生态组合怎么用

组合档案回答六个问题：
1. 仙材为什么出现在这里？
2. 妖兽为什么生活在这里？
3. 两者是什么关系（守护/食用/传播/寄生/竞争/无直接关系）？
4. 环境如何影响两者？
5. 玩家到这里能看到什么迹象？
6. 采集时遇到什么实际困难；妖兽离开或环境变化后生态怎么变？

**组合不是“守护兽配置表”**。没有证据时，明确写“无直接关系”或“未确认”，不要为了戏剧性硬塞一只妖兽。

## 七、质量门槛

- 与 `蛊道资料库_v3.0` 的仙材/蛊虫/杀招不重复、不混淆。
- 同名异物、异名同物必须在 `待考证与待补充.md` 列出。
- 原著仙材不改名、不改性质、不改用途。
- 普通材料不误列：`元石`、`蛊材`、`晶砂`（O-B-011 资源）不等同于本图鉴仙材。
- 每条生态关联有 A/B/C/D；没有证据不写“守护”。
- 采集难度与稀有度匹配；没有数值就写未知。
- GM 能据此写出“观察—接近—采集—失手—交易”的场景，而不是只回答百科。

## 八、当前统计（详见总索引）

- 已登记名称：**13**。
- 来源性质：A 原著 **3**（漩涡晨曦、七宝水、八部玉）；B 衡垠正式 **10**；C/D 作为“来源性质”暂 **0**。
- 生态关联：A 级 **0**（原著没有生态记载）；B 级 **0**（正式设定没有把具体妖兽与这些仙材绑定）；C 级 **10**（其中与妖兽 C 5、仅环境 C 5）；D 级/无直接关系 **3**。
- 完整档案 **10**；仅一行记录、暂作简档 **3**（尘眼、余音、停水）。
- 生态组合 **4**。

> 这些数字是“当前已登记”，不是“世界上只有 13 种仙材”。赤砂一地就占全球已确认仙材种类的 44%，具体名录未公开；本图鉴只收有名字、有出处、可追溯的条目。
