## 原著蛊虫（C-G）

### C-G-046 九叶生机草
- 草类蛊虫，具备治疗作用。它的每一片叶子，若撕下来，就是一棵生机叶。生机叶也是草蛊的一种，一转级数，属于消耗型，用一次就消失，它还有一个缺陷，那就是使用了一片生机叶疗伤之后，一个小时之内，其他的生机叶将没有治疗
- 草类蛊虫，具备治疗作用。它的每一片叶子，若撕下来，就是一棵生机叶。生机叶也是草蛊的一种，一转级数，属于消耗型，用一次就消失，它还有一个缺陷，那就是使用了一片生机叶疗伤之后，一个小时之内，其他的生机叶将没有治疗的效果。【方源】

### C-G-047 十年寿蛊
- 消耗类蛊虫，用了可增加十年到九十年寿命。

### C-G-048 四味酒虫
- 由两只酒虫加酸甜苦辣四种美酒合练而成，能够凝练提纯真元使之提高半阶，只对二转蛊师有效。【方源】

### C-G-049 地听肉耳草
- 在侦察的距离上简直可以媲美许多三转蛊虫。要使用地听肉耳草，并非炼化了就行，还需要切掉一只耳朵，将肉耳草和伤口黏合起来，成了新的耳朵。食物为参须。【方源】

### C-G-050 大肚蛙
- 后勤类蛊虫，肚子里另有宽敞空间，具有存储的功用，但每次吐出事物，都要叫一声，不能存储蛊虫，不免疫毒素。【古月空井】

### C-G-051 幽影随行蛊
- 让身体化为一团浓郁的黑暗。【王大】
- 既有原文只写“身体化为一团浓郁的黑暗”；未载隐身、免伤、移动或持续时间，不补这些效果。

### C-G-052 强取蛊
- 消耗类蛊虫，每次催动，都要消耗不少的真元。针对的蛊虫目标越强大。过程就越艰难，真元的消耗就越多。如果强取失败，蛊师就会遭到力量反噬。【方源】

### C-G-053 影殇蛊
- 持蛊者受多少的伤，攻击者也要承受其中的十分之一。【熊姜】

### C-G-054 月旋蛊
- 攻击类蛊虫，不同于寻常月刃直线的攻击，使用出来月刃由蓝变绿，同时攻击方式由直线变化为曲线。

### C-G-055 月痕蛊
- 二转凡蛊
- 攻击类蛊虫，由月光蛊和痕石蛊合炼而成，攻击力不变，但是攻击范围却能增长一倍，达到二十米远。

### C-G-056 月芒蛊
- 二转凡蛊
- 攻击类蛊虫，由月光蛊和两只小光蛊合炼成，最大化增幅月刃的攻击力，月刃的攻击范围仍旧是十米远。【方源】

### C-G-057 月霓裳
- 二转凡蛊
- 防御类蛊虫，由玉皮蛊和月光蛊合练而成。虽然在防御上，月霓裳比白玉蛊要差上一筹，但是它却有能帮助其他人防御的能力【方正】

### C-G-058 棕熊本力蛊
- 消耗类蛊虫，能赋予蛊师临时性的巨大力量，号称“一熊之力”。【方源】

### C-G-059 水罩蛊
- 防御类蛊虫，水罩的防御能力，甚至比白玉蛊还要优秀一些。但它也有个很大的缺陷，那就是必须形成圆球状，依靠水罩上流动的水流不断卸力、分散伤害，才能充分发挥出最大的防御能力。【方源】

### C-G-060 清热蛊
- 治疗类蛊虫，可去毒。【方源】

### C-G-061 游僵蛊
- 僵尸类蛊虫，最经典的一系列蛊虫之一。令蛊师彻底化身僵尸，只要定时吸血，就能活动自由，苟且长存。

### C-G-062 照影蛊
- 二转凡蛊

### C-G-063 爱生离
- 毒类蛊虫，号称二转蛊虫第一毒，要炼成，须得需要一转生息草、寡妇蛛、红针蝎及一颗爱人之心。【王大】
- 黑暗炼蛊·**人体脏器材料类**（须「一颗爱人之心」）：关键材料非寻常蛊材，而是一种特定的情感关系器官，材料来源本身即构成道德与法律问题（现代社会定性见 `04_世界/05_政治组织与社会制度.md`）。配方主线蛊为生息草、寡妇蛛、红针蝎。【原著明确｜条目原文】
- “二转蛊虫第一毒”是称号，不是绝对毒性排名；配方须生息草、寡妇蛛、红针蝎与一颗爱人之心，原著未载毒性数值、发作时间与成功率，不补。人体材料伦理边界见 `04_世界/05_政治组织与社会制度.md` 第十一节。

### C-G-064 癞土蛤蟆
- 二转蟾蛊
- 每顿食用一斤黄泥，黄泥越肥沃越佳。它数量稀少，是炼成宝气黄铜蟾的必须主蛊。市价500块元石。【贾家商队-赌石坊】

### C-G-065 白玉蛊
- 二转凡蛊
- 防御类蛊虫，由白豕蛊和玉皮蛊加野猪牙合练成，用于防御。【方源】

### C-G-066 白虫茧
- 毫无能力。

### C-G-067 石窍蛊
- 消耗类蛊虫，用一次就消失，作用是将蛊师的窍壁转变成坚硬的石壁。此举是将空窍的底蕴和潜力完全榨干，令蛊师能在瞬间达到巅峰修为。【方源、白凝冰】

### C-G-068 纸鹤蛊
- 后勤类蛊虫，专门用来传信，同时也是进入三王传承中，信王传承的钥匙。【方源】

### C-G-069 蛇信蛊
- 能够感应热量。不过有三个明显的缺陷，一是感知范围小，二是容易受到干扰，三是不能检测冷血生物。【古月赤舌】

### C-G-070 蜥屋蛊
- 防御类蛊虫，屋蛊的一种。

### C-G-071 螺旋骨枪蛊
- 攻击类蛊虫，骨枪蛊的进阶蛊。【方源】

### C-G-072 血气蛊
- 二转凡蛊

### C-G-073 赤铁舍利蛊
- 消耗类蛊虫，瞬间提升一个小境界，只对二转蛊师有效。【白凝冰、方源】

### C-G-074 隐鳞蛊
- 由隐石蛊与鱼鳞蛊合练成，能力是隐身，可以连通身上的衣服一起隐身。【方源】

### C-G-075 鬼火蛊
- 寄托在蛊师舌底，催动后可化为蓝色的火焰团，和一转的骨竹蛊搭配可修复战骨车轮，在商队购买获得。【方源】

### C-G-076 魂球蛊
- 可以和丹火蛊合炼为二转鬼火蛊。

### C-G-077 黑鬃蛊
- 二转凡蛊
- 防御类蛊虫，由青丝蛊和黑豖蛊合练而成，催动起来，全身的汗毛都能变得又黑又粗，在几个呼吸之内，在蛊师的身上生长成一片黑鬃护甲。黑鬃蛊 = 青丝蛊 + 黑豕蛊【贾家商队】

## 原创蛊虫（O-G）

### 流派：信道

#### 【原创设定】雁书蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-012 |
| 名称 | 雁书蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 信道 |
| 核心用途 | 通讯：承载一句口信，循预置标记飞递收信人 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一枚折成雁形的竹简薄片，翅上有一道未干的墨线。
- 大小：两指长。
- 颜色：竹黄，墨线乌亮。
- 形态特征：封入口信后，雁翅会轻轻一合；送达被读，墨线自断。
- 特殊视觉效果：放飞时竹雁不振翅、只顺着风贴地滑走，像一片被风推着的叶。

##### 二、核心能力

- 基础能力：把蛊师亲口说的一句「口信」封进竹膜，循预先留在收信人身上的「标记」飞递到其手中；送达被读，翅上墨线自断，示「已阅」。
- 作用机制：信道「寄语循标」——不传物、不传画面，只传一句「原声」。它靠标记认人，不靠记路，故不问山川，只认那道标。
- 作用对象：一句口信（原声），收信人为预置标记者。
- 能力范围：两标记点之间，约数十里。
- 效果强度：口信原声不失真、不可中途改写、不可复听第二遍（墨线断即散）；一次只寄一句。
- 使用限制：须事先在收信人身上或居处留标；一次一句、须蛊师亲口；途中被截则竹简碎、口信随散；不辨收信人死活，标在人亡亦照投。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，信道或兼修信道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 须亲口对竹简说一句「不假手他人」的真话作炼化之引 |
| 炼化风险 | 低；若以伪言作引，竹简自裂、不成蛊 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 竹膜 / 竹叶一片 |
| 辅助食物 | 松烟墨一蹭（养墨线） |
| 频率 | 每递一次喂一次；久不递则每半月一片竹叶 |
| 成本 | 低 |
| 特殊环境 | 须在「有风而不烈」处放飞；无风不飞、狂风折翼 |
| 断食后果 | 竹简脆化，飞递中途易折、口信半途散失 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 须预置标记、一次一句、须亲口、须有微风 |
| 消耗 | 二转赤铁真元，单程一递 |
| 范围 | 数十里内、两标记点之间 |
| 持续 | 单程一递，读毕即散 |
| 缺陷 | 只传一句、依赖预标记、口信不可改、被截即毁、不辨收信人生死、不传实物与文书 |
| 克制 | 被信道封锁、宇道截路、音道「抹声」、暗道「截标」克制；冥路蝶【原著蛊虫】魂香可作「拆封即散」的封缄补强 |
| 优势 | 比亲自跑腿快、原声保真、无需见面、不留纸迹，适合密令 |
| 适用场景 | 商队联络、据点传令、报信、约期 |
| 不适用场景 | 长篇文书（宜书虫 / O-G-021 结绳蛊）、无预置标记的突发联络、需回执核验的正式契约 |

### 流派：力道

#### 【原创设定】扁担蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-014 |
| 名称 | 扁担蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 力道 |
| 核心用途 | 运输：分担负重之「重」，令长途负重省力 |
| 稀有程度 | 常见 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一根微缩的扁担，两头各坠一枚小石砣，担身有一道磨得发亮的肩痕。
- 大小：一拃长。
- 颜色：竹黄泛褐，石砣青灰。
- 形态特征：蛊师负物越稳，担影越平；步子一乱，两头石砣便一高一低。
- 特殊视觉效果：催动时担身浮出一道淡影，虚虚搭在蛊师肩上，随人走而不落地。

##### 二、核心能力

- 基础能力：把蛊师所负之物的「重」分一部分到担形虚影上，令长途负重省力、步履稳当。
- 作用机制：力道「分重」——不消物之重、不增蛊师之力，只把「压在人身上的那一份」匀到担影上；担影随人缓行，人停则影散。与原著「蛮力天牛蛊」一类「临时增力」是两回事，本蛊绝不越界增力。
- 作用对象：本人所负之重。
- 能力范围：本人肩挑 / 背负之物。
- 效果强度：可长途承重而气力不坠、少耗真元于「撑住」；但不增速、不增力、举不起原本举不动之物。
- 使用限制：须「肩挑/背负、缓行」之姿；一旦放下货物、改作奔袭或腾挪，分重即散；陡坡、湿滑处担影易歪，分重失衡。

| 炼化风险 | 低 |

| 成本 | 极低 |
| 特殊环境 | 无 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 肩挑 / 背负、缓行；不可奔袭 |
| 消耗 | 二转赤铁真元，低耗 |
| 范围 | 本人所负 |
| 持续 | 一趟路程 |
| 缺陷 | 不增速、不增力、只缓行有效、担影怕陡坡湿滑、放下货即散 |

| 优势 | 让低阶蛊师也能长途运货，省真元、省气力、步履稳 |

##### 一、外观

- 外观：一颗圆润的鹅卵石，石上生着细如发丝的纹路。
- 大小：鸽卵大小。
- 颜色：青灰，纹路银白。
- 形态特征：走过之处，石纹会自行「长」出一条新的细线，对应走过的路。

- 效果强度：能精确回溯走过的路径；但只记录经过，不记录沿途变化后的现状。
- 使用限制：必须本人亲自走过；被外力抹去足迹（如水冲、翻土）不会影响石纹，但若蛊师刻意「忘路」，石纹也会淡去。

### 流派：智道

#### 【原创设定】结绳蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-021 |
| 名称 | 结绳蛊 |
| 品阶 | 二转 |

| 所属流派 | 智道 |
| 核心用途 | 资质 / 记忆 / 推演：把见闻结成绳结，回放不失真 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一段旧麻绳，绳上打着疏密不一的结，结尾垂着一缕散穗。
- 大小：一尺长，可绕腕。
- 颜色：麻褐，结处磨得发白。
- 形态特征：记一件事，绳上便多一个结；结越大，所记越要紧。
- 特殊视觉效果：回放时，蛊师指尖捏住某结一捻，那段见闻便「按当时次序」在心头过一遍，不添不漏。

##### 二、核心能力

- 基础能力：把一段亲眼所见 / 亲耳所闻的见闻、口供、契约条款「结」成绳结，日后按结回放，次序与细节不失真，可作记忆存档与推演底本。
- 作用机制：智道「结以存真」——只「录」不「解」：它保证「记下的不歪」，但不替蛊师推断、不补忘掉的部分、不辨所记真伪。原著书虫【原著蛊虫】是「喂什么记什么、永记不失」，本蛊与之同类而更重「次序」，二者可并用不悖。
- 作用对象：一段亲身经历 / 见闻 / 契约条款。
- 能力范围：绳长有限，结数有限（约十数结，结大者占得多）。
- 效果强度：回放次序、细节不失真；但不能推演未来、不能辨伪、不能记自己没留意到的细节。
- 使用限制：只记「亲身经见」；道听途说、事后脑补者结不牢；结满须「解结」（抹去旧记）方能再结；绳断则所记尽失。

##### 三、炼化条件

|---|---|
| 炼化条件 | 二转蛊师，智道或兼修智道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 须亲手按「事之先后」打过一串不错序的结作引 |
| 炼化风险 | 低；结序打乱则成品回放错序 |

| 成本 | 低 |
| 特殊环境 | 须避潮避虫，麻绳受潮霉、被虫蛀则结散 |

##### 五、能力限制

| 项目 | 内容 |

| 消耗 | 二转赤铁真元 + 心力（结越密、回放越耗神） |

| 持续 | 长期存记，绳断即失 |

| 消耗 | 二转赤铁真元，低耗 |
| 范围 | 单件，手持可及 |
| 持续 | 一次一磨 |
| 缺陷 | 不增材、不改形、不赋道痕、不补裂；过软过脆及仙材磨不得；过磨损器；验材只辨纯杂、不辨具体为何物 |
| 克制 | 被炎道（退火）、水道（锈涩）、变化道「改形」类手段克制；与 O-G-020 牙筹蛊（核数不核质）互补 |
| 优势 | 一件蛊兼「加工」与「粗验」，是商队验货、匠作整坯的常备 |
| 适用场景 | 整坯去刺、磨刃合面、验料纯杂、交易前磨样 |
| 不适用场景 | 补裂、赋道痕、仙材加工、需精辨成分（宜竹君子 / 书虫一类） |

##### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一块磨过千件器、凹弧始终不偏的老青磨石 |
| 辅助材料 | 一撮陈年磨粉、一滴无风之水 |
| 过程 | 以真元把「顺形去余」之意炼入石面凹弧 |
| 难度 | 低 |
| 成功率或风险 | 低；失败仅石面开裂，可再寻石 |
| 替代材料 | 可用细砂岩替代，但落粉更粗、验材更不准 |

##### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | O-G-020 牙筹蛊（验质 + 核数）、O-G-013 束囊蛊（存样）、O-G-017 拾穗蛊（收磨粉）、书虫·竹君子【原著蛊虫】 |
| 可参与杀招 | O-K-012「牙筹清账」（辅助：磨样验货，辨材质真伪，补牙筹蛊「只核数不核质」之短） |
| 蛊虫组合 | 与牙筹蛊、结绳蛊、书虫、竹君子、元老蛊构成「录约—测谎—验货—核价—收付」的交易链，砥砺蛊专司「验质」一环（见 O-K-012） |

| 其他关联资料 | 见`01_蛊虫/12_原创杀招.md`O-K-012 |

### 流派：音道

#### 【原创设定】回声蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-001 |
| 名称 | 回声蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 音道 |
| 核心用途 | 侦查（回声标记与追踪） |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：形如一只干瘪的空蝉蜕，半透明，腹内无实。
- 大小：拇指盖大小。
- 颜色：通体灰白，边缘泛一层极淡的蓝。
- 形态特征：背上有三道环纹，环纹随最近一次「回响」的强弱或深或浅。
- 特殊视觉效果：催动时，空蝉蜕会轻轻震颤，发出人耳几乎听不见的嗡鸣；嗡鸣撞上障碍后会折返，在蛊师心窍中形成「第二重声响」。

##### 二、核心能力

- 基础能力：向四周发出一次不可闻的低频回响，声波遇到障碍折返，蛊师据此在脑海中描出周围环境的粗糙轮廓。
- 作用机制：低频声穿透力强、衰减快，只适合近距；声波并非「看见」，而是「听见形状」，故无法分辨颜色、文字，只能勾勒凹凸、疏密与远近。
- 作用对象：半径约十五步内的实体障碍。
- 能力范围：十五步，越远越模糊。
- 效果强度：能辨明通路、门窗、沟壑与静止的大物；对贴地匍匐、柔软吸音之物几乎无效。
- 使用限制：每次催动需持续供真元；环境中噪声越大、杂响越多，轮廓越乱；对有音道修为者，这回响本身可被其察觉。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，音道或兼修音道者炼化更易 |
| 炼化难度 | 低；回声蛊意志微弱 |
| 特殊要求 | 无 |
| 炼化风险 | 几乎无 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 静水；每三日一碗 |
| 辅助食物 | 铜铃的锈屑（可让下次回响更清） |
| 频率 | 每三日一次 |
| 成本 | 低 |
| 特殊环境 | 若在「无声之室」（四面皆吸音软泥）中喂养一次，效果维持更久 |
| 断食后果 | 回响逐次变闷，最终无法勾勒轮廓，蜕壳硬化裂开、蛊亡 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 需持续供真元；环境偏静方可用 |
| 消耗 | 二转赤铁真元，低耗、可连发 |
| 范围 | 十五步内，越远越模糊 |
| 持续 | 单次回响一瞬，可连续催动 |
| 缺陷 | 无攻击力；无法辨字辨色；易受噪声干扰；对吸音软物、匍匐贴地之物近乎失明 |
| 克制 | 克制以视觉扰乱／迷幻为主的隐匿（因它不靠眼睛）；被音道反制（察觉并扰乱回响）、被水道「静水」环境削弱 |
| 优势 | 消耗低、可连发、不依赖光线，黑暗中亦可用；能识破视觉遮蔽但非实体隐藏 |
| 适用场景 | 洞穴、密道、浓雾、黑夜、废墟等目不能视之地 |
| 不适用场景 | 市集、战场、风口等嘈杂处；面对专精音道的对手 |

##### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一只自然老死的夏蝉蜕壳 |
| 辅助材料 | 三滴春雨后积于凹石的静水、一枚被敲响过九九八十一次的老铜铃碎屑 |
| 过程 | 在完全无声的静室内，以真元浸润蝉蜕三日，令空壳记住「折返之声」 |
| 难度 | 低 |
| 成功率或风险 | 成功率较高；失败则蝉蜕碎裂，损失材料 |
| 替代材料 | 可用秋蝉蜕替代，但成品回响偏短 |

##### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | O-G-003 倒影蛊（声像互补）、O-G-004 守更蛊（守夜警戒）、O-G-104 回响蛊（凡蛊与仙蛊同源） |
| 可参与杀招 | O-K-003「静夜图」（核心：声之警戒）、O-K-007「空谷回音」（辅助：以低频回响锁定来音方位） |
| 蛊虫组合 | 与倒影蛊、守更蛊、问路石蛊（O-G-006）共织「声、影、时、地」四维警戒网（见 O-K-003） |
| 进阶方向 | 可升炼为四转「广域回声蛊」：以回声蛊为主蛊，合炼一只抗噪类气道凡蛊，保留「声之轮廓」单一能力并强化范围与抗噪，代价是真元消耗与体积显著上升、辨形精度不再随距离提升（合炼只保留主蛊能力，符合原著升炼规律） |
| 其他关联资料 | 见`01_蛊虫/12_原创杀招.md`O-K-003、O-K-007；原著蛊道体系分析报告第 6 节「信息不对称」 |

### 流派：食道

#### 【原创设定】沤料蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-016 |
| 名称 | 沤料蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 食道 |
| 核心用途 | 炼材生产：把废料沤渍发酵成可用炼材 / 肥 |
| 稀有程度 | 常见 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一只小口陶瓮，瓮沿总挂着一圈细密水沫，瓮身温热。
- 大小：拳头大。
- 颜色：陶褐，沫白。
- 形态特征：投料入瓮，瓮沿水沫便由白转微黄，示「沤到了火候」。
- 特殊视觉效果：开瓮时先冒一缕酸暖之气，瓮底废料已化成一团匀净的膏 / 肥，不见原样。

##### 二、核心能力

- 基础能力：把秸秆、落叶、残渣、废料等「无用之物」投入瓮中，沤渍发酵，化成可入田的肥或可作低阶炼蛊辅材的「熟料」。
- 作用机制：食道「化废为用」——对应原著「食道＝回收与清算」的既有逻辑；它只「转化」已有之物，不凭空生材、不提质为仙材。
- 作用对象：一批可腐熟的有机废料。
- 能力范围：一瓮，约数升。
- 效果强度：数日成一瓮熟料，品质低、只作肥与低阶辅材；不能把凡材炼成仙材、不能去毒、不能化「不可腐」之物（金石、活蛊）。
- 使用限制：须「投得进瓮、且可腐」；须静置、避暴晒暴雨；一瓮沤成前不可开盖，开早则半熟、前功弃；遇剧毒废料则整瓮废。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，食道或兼修食道者更易 |
| 炼化难度 | 低 |
| 特殊要求 | 须亲手沤成过一瓮「不臭反香」的熟料作引 |
| 炼化风险 | 低 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 即其所沤之废料（自给） |
| 辅助食物 | 一撮旧曲 / 酒糟（起酵） |
| 频率 | 每沤一瓮投一次料；闲时无须另喂 |
| 成本 | 极低 |
| 特殊环境 | 须阴凉静置、不可暴晒暴雨、不可频开瓮 |
| 断食后果 | 瓮沿水沫干、瓮身转冷，再投料久不化 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 投可腐废料、静置数日不启盖 |
| 消耗 | 二转赤铁真元，低耗 |
| 范围 | 一瓮数升 |
| 持续 | 数日一瓮 |
| 缺陷 | 只出低阶肥 / 辅材、不能提质为仙材、不能去毒、不能化金石活蛊；开早则废、遇剧毒整瓮废 |
| 克制 | 被炎道（焦瓮）、冰雪道（冻瓮）、毒道（败料）克制；与天真蘑菇【原著蛊虫】（净化沤场浊气）互补 |
| 优势 | 把「必然丢弃的废料」稳定转成可用资源，是种植/炼材链的供给端 |
| 适用场景 | 田庄堆肥、炼蛊辅材备料、据点垃圾清算 |
| 不适用场景 | 需仙材、需去毒、需即时出料、金石类废料 |

##### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一只沤过十年酱、从未生过坏瓮的老陶瓮 |
| 辅助材料 | 一撮陈曲、一把沤透的旧料底 |
| 过程 | 以真元把「化废」之意炼入瓮壁，令瓮沿水沫能报火候 |
| 难度 | 低 |
| 成功率或风险 | 低；失败仅瓮裂，废料可再沤 |
| 替代材料 | 可用木桶替代，但保温差、沤期更长 |

##### 七、搭配关系
