- 经由血脉关系人的血洗练，可提升蛊师资质。【方源、古月一代、血海老祖】
- 四转血道蛊虫，血海老祖所创、血道真传之一，后被方源升炼至六转。机制：尽取血脉关系亲人之血，凝练成**精华血泉**反复浇灌蛊师，增长空窍潜力、拔升资质；**血亲数量越多、质量越高，提升越大，且效果递减**（先一成一成增，后几分几分涨）。代价：须屠戮血亲，修为越高所需血亲规模越大（方源为冲击更高转数需屠戮灵智高的血亲乃至蛊仙血亲）。方源案例（第一卷第 197—198 节）：屠戮古月族人两三个时辰，资质自丙等四成四暴涨至甲等九成；同时因血颅蛊与其早先用过的石窍蛊（三转，榨空窍潜力换修为）相冲突，空窍由石窍回转光膜，修为自三转巅峰落至一转初阶——**此修为倒退是与石窍蛊冲突的个例，不是血颅蛊本身的普遍代价**，古月一代用之资质增而修为不减。古月一代守候血脉数百年即图屠戮亲族提升自身资质。后方源更设想「海量屠杀＋人海复活」反复刷甲等资质的循环方案。【原著明确｜第一卷第197—198节、第三百二十九节】

## 原创蛊虫（O-G）

### 流派：变化道

#### 【原创设定】断尾蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-005 |
| 名称 | 断尾蛊 |
| 品阶 | 四转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 变化道 |
| 核心用途 | 保命（舍弃肢体分身，代偿一次致命伤） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一截蜷曲的蜥尾，断口处永远滴着不肯干涸的一滴血。
- 大小：小指长。
- 颜色：灰绿，断口猩红。
- 形态特征：遇危时会骤然绷直、微微跳动，似要自行断离。
- 特殊视觉效果：催动时，断口那滴血会化开，在蛊师身外映出一个「将要舍弃」的虚影。

##### 二、核心能力

- 基础能力：在致命一击及身的瞬间，将「这一击」连同被击中的一部分身躯，一起割舍到断尾蛊化出的替身上，本体以残躯脱身。
- 作用机制：变化道「弃形求生」——断尾蛊吃的是「舍弃」本身。它在蛊师体内种下一道「可弃」的标记，命中时把伤害与道痕一起引向被舍弃的部分。
- 作用对象：本人（一次性替死）。
- 能力范围：本人。
- 效果强度：可代偿一次「足以致死的直接打击」，本体存活，但被舍弃的部分永久失去（含其上道痕）。
- 使用限制：每只断尾蛊只能用一次；只对「有形的、可落到肉身上的直接伤害」有效，对魂魄、诅咒、灾劫、梦道侵蚀等无形伤害无效；舍弃的部分不可复原。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 四转蛊师，变化道或兼修变化道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 需蛊师自愿「让出」身上一块肉作种蛊之引，此块肉日后即是最先被舍弃的部分 |
| 炼化风险 | 高；炼化失败会永久损失那块引肉及其道痕 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 蛊师自身的一滴血（低频） |
| 辅助食物 | 其他生灵「断尾求生」后新生的嫩尾 |
| 频率 | 每半月一次 |
| 成本 | 中（损耗自身气血，虽可回补） |
| 特殊环境 | 无 |
| 断食后果 | 断尾蛊与蛊师血肉联结渐松，替死时将「多舍」一截本不该舍的部分 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 致命一击及身的瞬间；每只仅一次 |
| 消耗 | 四转黄金真元；代价是永久丧失一部分肉身与其上道痕 |
| 范围 | 本人 |
| 持续 | 一瞬（一次性） |
| 缺陷 | 代价是永久丧失一部分肉身与道痕；只挡有形直接伤害；一次性、不可叠加多次替死；舍弃后的残躯需长时间休养 |
| 克制 | 克制单体强攻型的「一击必杀」；被魂道、诅咒、梦道、律道（限死）等无形手段克制，被「范围持续伤害」克制（仍只舍一次） |
| 优势 | 保命上限极高，能挡下必死之击，是稀缺的「多一条命」手段；只需一只、不占多个空窍位 |
| 适用场景 | 强敌单挑、被偷袭、突围保命 |
| 不适用场景 | 面对魂道/梦道/灾劫/群体围杀 |

##### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一尾真正断尾求生、且最终重生的石龙子（蜥蜴）的旧尾 |
| 辅助材料 | 蛊师自身一块自愿让出的血肉 |
| 过程 | 在蛊师命悬一线（重伤濒死）之时方成——炼成即种下 |
| 难度 | 高 |
| 成功率或风险 | 高；失败则引肉与材料皆损 |
| 替代材料 | 可用壁虎尾替代，但替死效果打折，会「多舍」更多本体 |

##### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | 任何蛊皆可搭配；尤其配合 O-G-005 之后仍能行动的移动蛊（如 O-G-008 洄游蛊）更佳；O-G-009 记仇蛊（设伏→复仇→保命链末端） |
| 可参与杀招 | **不参与任何 O-K 编号杀招**（纯保命蛊，不与杀招同时催动，避免「杀招崩解时替死标记误触发」） |
| 蛊虫组合 | 与洄游蛊、记仇蛊构成「设伏→复仇→保命」的战术链，但断尾蛊本身只作兜底，不入杀招组成表 |
| 进阶方向 | 可升炼为六转仙蛊「壁虎尾」：保留「弃形替死」单一能力并强化为可多次替死，但每一次仍须逐次舍弃一部分本体（含其上道痕），且因仙蛊唯一，天下仅此一只；多次替死的代价是道痕层层剥落、修为随之缓降，绝不设计为无条件复活 |
| 其他关联资料 | 原著变化道「弃形求生」思路；检查表第 10 条禁「无条件复活／无限重生」 |

### 流派：宇道

#### 【原创设定】洄游蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-008 |
| 名称 | 洄游蛊 |
| 品阶 | 四转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 宇道 |
| 核心用途 | 移动（标记两点，成对往返通路） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一对并生的鱼形石坠，一大一小，鱼首互衔，可拆作两半。
- 大小：拇指长。
- 颜色：青黑，衔口泛银。
- 形态特征：拆开后，两半会各自朝对方「游」去的方向微微倾斜。
- 特殊视觉效果：催动时，两半之间的虚空会荡起一圈极淡的涟漪。

##### 二、核心能力

- 基础能力：拆作「母、子」两半，分别置于两地，可在二者之间架设一条仅蛊师可用的短距宇道往返通路。
- 作用机制：宇道「成对通路」——比原著洞地蛊弱化：只容本人或极小物件往返，且距离受限。
- 作用对象：本人及随身小物。
- 能力范围：两标记点相距约三里之内。
- 效果强度：可短时间内往返数次；距离越远、单次耗时越长、真元耗越多。
- 使用限制：两点须先由蛊师亲自到达并埋下；超过三里则失效；通路每次使用都会损耗两半的「游力」，需时间恢复。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 四转蛊师，宇道或兼修宇道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 无 |
| 炼化风险 | 中；失败则两半皆裂 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|

| 不适用场景 | 自然寿尽的老死（生机已尽，无生可系）；自愿放弃者的安宁疗护（见渡魂蛊） |
| 监管接口 | 代诺程序与「急救优先级」制度见 `04_世界/05_政治组织与社会制度.md`第十一节；**「强取生机」（不经自愿）不在此蛊——那是邪术「抽生」的罪名，与本蛊无关但常被污名混同，须澄清** |

##### 六、炼制路线

| 过程 | 温养四十九日，露珠凝而不落则成 |

##### 七、搭配关系

|---|---|

### 流派：魂道

#### 【原创设定】问骨蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-024 |
| 名称 | 问骨蛊 |
| 品阶 | 四转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 魂道 |
| 核心用途 | 调查：读取合法遗骨中死者临终前三日的残息记忆 |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】｜状态：proposed |

##### 一、外观

- 外观：一只灰白色小蠹虫，形如书蠹，头前有两根细如发丝的探须。
- 大小：半寸。
- 颜色：骨白，节间有淡金纹。
- 形态特征：静时蜷成环，探须收拢如问号。
- 特殊视觉效果：催动时探须探入骨缝，虫身透出极淡的青芒，似骨内余光。

##### 二、核心能力

- 基础能力：栖于合法批号遗骨之上，读出死者临终前最后三日的残息记忆——所见、所闻、临终执念，以碎影方式呈现于蛊师识海。
- 作用机制：魂道「问骨」——人死后魂魄消散，但重度情绪与执念会在最亲近的骨骼（多为颅骨、胸骨）中留下残息印记；问骨蛊只读取印记，不招魂、不通灵。
- 作用对象：死亡不超过三年、保存完好的人类遗骨。
- 能力范围：单具遗骨，读取一次。
- 效果强度：碎片式影像，无声音、无完整叙事；情绪浓烈的死前一刻最清晰。
- 使用限制：**只认合法批号遗骨**——蛊在炼制时烙入了批号感应，无批号的骨骼蛊直接休眠；每具遗骨只能被读取一次，读后残息即散、骨色转灰。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 四转蛊师，魂道或兼修魂道者 |
| 炼化难度 | 中高 |
| 特殊要求 | 炼制须在官方遗骨批号数据库登记的场所内进行，蛊成即烙印批号感应——**这道行政烙印不可去除**，是本蛊的存在前提 |
| 炼化风险 | 中；炼制失败则探须反噬蛊师识海，致一日目盲 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 无事时以檀香灰养于木匣 |
| 辅助食物 | 每次读取任务后须休眠七日、喂食一次晨露 |
| 频率 | 七日一次 |
| 成本 | 低 |
| 特殊环境 | 须避强光与喧哗 |
| 断食后果 | 探须失灵，读取影像越读越碎，直至全不可读 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 合法批号遗骨＋持有调查许可（执法、公证、直系亲属申请） |
| 消耗 | 四转黄金真元，中耗；读取全程蛊师入定、毫无防备 |
| 范围 | 单具遗骨 |
| 持续 | 一次读取约半个时辰；每具遗骨一生只可读一次 |
| 缺陷 | 读不出无声死者的凶手姓名这类「超出残息范围」的信息——残息只是临终碎片，不是全知档案；**蛊不能凭空补全记忆** |
| 克制 | 被「涤骨」类手段销毁残息（凶手常用的灭迹手法）；火化彻底的遗骨无残息 |
| 优势 | 命案侦查的正当利器；为无法开口的死者留下最后证词 |
| 适用场景 | 他杀命案、临终遗嘱争议、工伤事故还原 |
| 不适用场景 | 无批号遗骨（蛊休眠）；三年以上旧骨 |
| 监管接口 | 与遗骨批号制度（`04_世界/05_政治组织与社会制度.md` 第十一节）绑定：批号既是反盗掘的锁，也是问骨蛊工作的门；「涤骨灭迹」被列为独立罪名 |

##### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 以栖过腐骨的蠹虫为种蛊、官库领用的教学遗骨一段 |
| 辅助材料 | 檀香灰、晨露、一枚公证处发行的批号感应玉牌 |
| 过程 | 种蛊于教学遗骨上驯食残息，四十九日成蛊，玉牌烙印随之入体 |
| 难度 | 中高 |
| 成功率或风险 | 失败则识海反噬；**无法绕过批号烙印**——想炼「什么都读」的问骨蛊会当场虫死 |
| 替代材料 | 无（玉牌必须官方发行，防私炼滥用） |

##### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | O-G-031 偿愿蛊（同为读取亡者信息的魂道蛊，一读骨、一读执念）；原著寄魂蚤【原著蛊虫 C-G-360】司存放魂魄，本蛊只读残息不存魂，边界明确 |
| 可参与杀招 | O-K-015「殓行」（辅助蛊，见该档案） |
| 蛊虫组合 | 与守宫蛊（O-G-025）构成「遗骨产业链」的两端：问骨读证、守宫用体，皆须批号 |
| 进阶方向 | 可升炼五转「勘骨蛊」：读取窗口自三日延至七日；代价为蛊师读取后须沉睡一日，且残息中的痛感会部分传导给蛊师，效果提升必伴代价 |
| 其他关联资料 | 原著魂道材料类参照 C-G-313 凌迟蛊（炼魂）、C-G-147 葬魂蟾（储魂） |
