## 原著蛊虫（C-G）

### C-G-249 人气蛊
- 成仙三气，天地人，人气为蛊师自身的积累总和，人气蛊的作用，就是吸纳旁人的人气，转化纯净，并在升仙的时刻，加持到自己的身上，从而大大地提升成为蛊仙的可能，以及加深蛊仙的根基和潜能。

### C-G-250 偃月仙蛊
- 可配合另外两只六转仙蛊，形成仙道杀招--无双偃月斩，形成一轮青色弯月，看似人畜无害，实则悄无声息，威力惊人，为天妒楼的招牌杀招之一。

### C-G-251 因祸得福
- 运道仙蛊，此蛊威能玄妙，乃是针对仙窍灾劫，蛊仙渡劫之后，身上的道痕都会增添许多，修为更加精进，只要用了它。蛊仙成功渡劫后，身上的道痕会在原来的基础上，再增加一倍有余。

### C-G-252 天机蛊
- 七转智道蛊仙砚石老人的本命蛊，不用任何线索证据，也能将直指真相。但不是每次催动天机蛊都能获得成功，十次催动八次失败，一旦失败，就会受到反噬，失去十年到七十年寿命。【砚石老人】

### C-G-253 妇人心
- 毒道仙蛊，是一次性消耗蛊，和寻常仙蛊不同，它养炼合一，毒性极其猛烈，要喂养它，就得需要妇人的心脏。喂养的过程，就是一次次不断微炼提升的过程。喂养给它的心脏越多，那么它的毒性就越强
- 【2026-11-13 深化补注】黑暗炼蛊·**脏器供养类**：本蛊「养炼合一」——喂养即炼制，以妇人心脏为唯一饲料，喂养次数与毒性强度正相关。这建立了「持续供养型人体材料蛊」的机制原型：材料需求不是一次性的，而是**长期、稳定、成规模的供应**（对现代社会意味着持续性的犯罪产业，见世界观 17 号文件）。已见于杀招 C-K-053 毒气吐纳。【原著明确｜条目原文】

### C-G-254 小
- 律道仙蛊，可施展仙道杀招"大而化小"可将任何靠近的东西威力减弱，缩小。【小人蛊仙】

### C-G-255 招灾蛊
- 运道仙蛊，此蛊能够替蛊仙招灾引难，将地灾天劫脱离原来的目标，勾连到自己的身上。

### C-G-256 排难蛊
- 运道仙蛊，此蛊能够将王庭福地中的天劫地灾，都排遣到外界去。

### C-G-257 死期将至
- 律道蛊虫，能限定他人死期，死期一到，哪怕是蛊仙也会迎来死亡。

### C-G-258 水乳交融
- 水道蛊虫，近水楼台的核心仙蛊，能令蛊师与水液彻底融合隐藏，水不灭则身不死。

### C-G-259 逢凶化吉
- 运道仙蛊，此蛊顾名思义，能令人的厄运坏运，转化为好运吉运。

## 原创蛊虫（O-G）

### 流派：土道

#### 【原创设定】息壤蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-106 |
| 名称 | 息壤蛊 |
| 品阶 | 七转 |
| 凡蛊或仙蛊 | 仙蛊（同名天下唯一） |
| 所属流派 | 土道 |
| 核心用途 | 环境改造：把贫瘠之地缓养成宜耕熟地 |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一撮会自己缓缓「长」的湿土，捏之成团、置之自平，土面时有极细的孔。
- 大小：一捧。
- 颜色：深褐泛润，孔中似有微光。
- 形态特征：靠近贫地，土会自行贴伏过去、一点点往板结处渗。
- 特殊视觉效果：养地时，土面细孔会随四季微微开合，像地在缓缓透气。

##### 二、核心能力

- 基础能力：把一片贫瘠 / 板结之地缓慢养成宜耕熟地——松其土、匀其肥、活其孔，令草木可生。
- 作用机制：土道「自长之土」——不凭空造土、不瞬改地形，只把「本就有的地力」一点点唤醒、理顺；极慢，以年计。
- 作用对象：一片「原地有土、有水脉」的地。
- 能力范围：数亩一方。
- 效果强度：数年后薄地成中田、中田成稳产；但不能把荒漠变沃野、不能改气候、不能造水、不能对抗灾劫级地变。
- 使用限制：须「原地有土、有水脉」；极慢（年计）；一次只养一方，养期间不可翻动重植；外力大改地形则前功尽弃。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 七转蛊仙，土道或兼修土道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 须守护一片地「一整季不翻」作炼化之引 |
| 炼化风险 | 中；守土期间地被翻动则认界不成 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 仙元（低频，养地期间按月供） |
| 辅助食物 | 一撮本地旧土、腐熟之肥 |
| 频率 | 养地期间每月一次；空置则每季一次 |
| 成本 | 中 |
| 特殊环境 | 须与地脉相连，不可装囊移走 |
| 断食后果 | 土渐板结，已养之地力回退（对应原著「升炼可逆、状态会衰减」之既有设定） |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 原地有土有水脉、须长期不动、须连着地脉 |
| 消耗 | 七转红枣仙元（维持型，以年计） |
| 范围 | 数亩一方 |
| 持续 | 以年计 |
| 缺陷 | 极慢、只养一方、不造水不改气候、被大改地形打断即废、状态会回退、无战斗力 |
| 克制 | 被炎道焦土、冰雪道冻土、力道震地、灾劫级地变克制 |
| 优势 | 唯一能把「薄地」稳步养成「熟地」的经营型仙蛊，是福地 / 门派百年根基 |
| 适用场景 | 福地垦田、药圃养土、废园复耕、壶天造田之核心改土 |
| 不适用场景 | 实战、荒漠、需立竿见影、无地脉之地 |

##### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一撮自古「取之不尽、愈用愈肥」的息壤遗土 |
| 辅助材料 | 仙材「地脉脂」一滴、老田黑土一捧 |
| 过程 | 以仙元把「自长」之意炼入土中，令其认一方地脉为界 |
| 难度 | 高 |
| 成功率或风险 | 中；认界失败则土四散不聚 |
| 替代材料 | 无 |

##### 七、搭配关系

|---|---|

| 可参与杀招 | O-K-013「壶天造田」（核心之一：把壶内贫土缓养成宜耕熟地） |
| 蛊虫组合 | 在壶天小空间内，由洞地蛊运入外材、地力蛊辅肥、存息蛊温养生机、凝漏蛊封住成型临界、敛痕蛊收逸散痕、寸光阴加速酝酿；息壤蛊专司「改土」这一主环（见 O-K-013） |

##### 一、外观

- 外观：一枚深不见底的漆黑螺壳，入口极小。
- 大小：拳大。
- 颜色：漆黑，壳缘泛一丝海蓝。
- 形态特征：螺壳内壁似有星点，望之如望深渊。
- 特殊视觉效果：吞入仙材时，螺口会缓缓旋开，如深渊张口。

##### 二、核心能力

- 基础能力：把一件受损、道痕残缺的仙材收纳其中，以宇道「归」之力，缓慢温养，使其道痕缓慢复原（极慢，以年计）。

- 作用对象：一件仙材（道痕未彻底消散者）。
- 能力范围：单件，且限于道痕「尚存一线」者。
- 效果强度：极慢复原；道痕散尽者不可复原。
- 使用限制：一次只纳一件；复原期间螺壳不可再纳他物；道痕彻底消散即无法可救。

### 流派：宙道

#### 【原创设定】凝漏蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-108 |
| 名称 | 凝漏蛊 |
| 品阶 | 七转 |
| 凡蛊或仙蛊 | 仙蛊（同名天下唯一） |
| 所属流派 | 宙道 |
| 核心用途 | 时间相关：把小物「此刻状态」封存片刻 |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一枚凝住的漏刻，壶中水线停在半滴将落未落之处，箭尺不升不降。
- 大小：掌高。
- 颜色：铜青，水线澄白。
- 形态特征：只要「凝」着，浮尘落到刻面也会停在半空不动。
- 特殊视觉效果：解封那一瞬，半滴水才「补落」下去，箭尺轻轻一跳，像时间接着走。

##### 二、核心能力

- 基础能力：把一件小物「此刻的状态」连同其极短一段时间冻结封存片刻——封存期间该物不受外界影响、也不自行变化（不腐、不枯、不继续发酵、不被催动）。
- 作用机制：宙道「凝刻」——不逆流、不回溯、不加速他人、不延寿，只把「这一刻」按住一小段。原著寸光阴【原著蛊虫】是「加速酝酿」，本蛊反其道「停住」，二者分用不相混。
- 作用对象：单件小物 / 一小片将成未成之状态。
- 能力范围：单件小物，数息至一刻。
- 效果强度：可让「熟地成型那一刻」「将枯之苗」「将凝之材」暂时定住以避外扰；但封存期间该物不可用、不可被催动、不可取出干预，解封后一切照旧继续。
- 使用限制：只封「小物」，不封活人、不封含活跃道痕之仙材（道痕会挣破凝刻）；封存期间物「不可用」；一次只凝一刻，解封后须隔一段时间方能再凝。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 七转蛊仙，宙道或兼修宙道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 须在「漏刻将滴未滴」之一瞬完成炼化 |
| 炼化风险 | 中；错过那一瞬则刻不停、不成蛊 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 仙元（低频） |
| 辅助食物 | 一滴漏壶停水、一撮更香灰 |
| 频率 | 每凝一次补；空置则每月一次 |
| 成本 | 中 |
| 特殊环境 | 须避强宙道 / 宇道震荡，震荡会「化开」凝刻 |
| 断食后果 | 水线复流、凝刻渐松，封不住「这一刻」 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 只封小物、不封人 / 活跃道痕仙材、封存期间物不可用 |
| 消耗 | 七转红枣仙元 + 心力（对应原著「时间类杀招常催动久」之约束，本蛊只停片刻、不涉天意） |
| 范围 | 单件小物 |
| 持续 | 数息至一刻 |
| 缺陷 | 只停不放、封存期间物不可用、不封人、一次一刻、解封有冷却、被宙道震荡化开、无直接攻防 |
| 克制 | 被宙道「流转变」、宇道破界、更强时间类手段克制 |
| 优势 | 为「怕被打断的临界状态」争一个安稳窗口，是经营 / 炼制 / 养材的时间护栏 |
| 适用场景 | 炼蛊临界保温、熟地成型避扰、将枯之物待救、配合应候蛊择时 |
| 不适用场景 | 战斗、封人、长期冷藏、加速（加速属寸光阴） |

##### 六、炼制路线

| 项目 | 内容 |
|---|---|

### 流派：音道

#### 【原创设定】回响蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-104 |
| 名称 | 回响蛊 |
| 品阶 | 七转 |
| 凡蛊或仙蛊 | 仙蛊（同名天下唯一） |
| 所属流派 | 音道 |
| 核心用途 | 攻伐/辅助（把一次攻击的「余音」延迟返还） |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一只通体透明、形如大钟的蛊，钟壁薄如蝉翼。
- 大小：可缩可放，常态拳大。
- 颜色：透明，透光微蓝。
- 形态特征：钟壁上一道裂纹也无，却会随环境声波轻轻共鸣。
- 特殊视觉效果：催动时，钟内会「记住」一次攻击的余音，并在数息后原样「还」出。

##### 二、核心能力

- 基础能力：接下一次「有声之击」的余音，将其存于钟内，数息后朝来路方向原样返还一次「音之反击」。
- 作用机制：音道「以彼之余还彼之身」——不制造新的音，只延迟、定向返还既有之音。
- 作用对象：一次带声的直线攻击（音杀、含鸣啸的击打等）。
- 能力范围：数步内接音，返还方向为来路。
- 效果强度：返还之音威能与余音相当，不能放大，只能「迟还」。
- 使用限制：只能返还「有声」攻击；纯静默的攻击（暗器无声、魂道）无效；每存一音，钟内只能存一道，须先放空再存下一道。

| 成本 | 中 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 只接「有声」的直线攻击；钟内一音存满须先放空 |
| 消耗 | 七转红枣仙元，每用必补 |
| 范围 | 数步内接音，朝来路返还 |
| 持续 | 存音数息后一击返还 |
| 缺陷 | 只能延迟不能放大；只对有声音攻击有效；存音槽单一、易被预判；延迟期间自身仍暴露于来音之下 |
| 克制 | 克制音道直线攻击；被无声音、魂道、梦道克制 |
| 优势 | 以彼之道还施彼身，出其不意；可反制音杀、可打乱对手节奏 |
| 适用场景 | 反制音杀、音道对轰 |
| 不适用场景 | 静默战斗 |
