## 原著蛊虫（C-G）

### C-G-001 一气金光虫
- 一转凡蛊
- 全身闪着如金豆般的光，以此圆心，撑起一个庞大的淡金色气罩，可以完全遮盖一头肥甲虫，为其防雨。【贾家商队】
- 【第五轮复核｜边界说明】气罩的既有描述只到“遮盖一头肥甲虫、防雨”；不据此推定可挡攻击、可覆盖多人或可长期维持。

### C-G-002 书虫
- 将要记的东西喂给书虫吃，从此以后只要书虫不失，蛊师就能永远清晰地记得。

### C-G-003 兽皮蛊
- 一转凡蛊
- 和铜皮蛊等，属于一个系列。但是价值却有很大分别，兽皮蛊最为普通，市价比石皮蛊还有低一些，但是晋升的路线很多，可以和很多其他蛊虫合炼。
- 【第五轮复核｜边界说明】既有原文只写“最普通、市价低于石皮、晋升路线多”；不据此推定防御力等同石皮或铜皮，也不补具体折损率。

### C-G-004 净水蛊
- 能洗练蛊师的窍壁，将空窍元海中的异种气息都化去。

### C-G-005 地藏花蛊
- 一转花蛊
- 把其他蛊虫包养在花心当中，浸泡在黄金色的花液里。这种黄金花液能在一定程度上，模拟封印状态，让浸泡在其中的蛊虫陷入沉眠。
- 【第五轮复核｜边界说明】黄金花液是“模拟封印状态、让蛊虫沉眠”，不等于真正封印或永久压制；外力取蛊、解封条件原著未明确，不补成功率。

### C-G-006 天真蘑菇
- 一转草蛊
- 具有吸收粉尘浊气，净化空气的作用，是草蛊的一种。
- 大如桌面，小如矮凳，坐上去如同沙发，具有吸收粉尘浊气，净化空气的作用，是草蛊的一种。【贾家商队酒铺】

### C-G-007 寡妇蛛
- 炼成号称二转蛊虫第一毒的爱生离的所需蛊虫。

### C-G-008 小光蛊
- 一转凡蛊
- 辅助类蛊虫，辅助提高月光蛊的攻击力。【古月一族】

### C-G-009 希望蛊
- 一转凡蛊
- 在《人祖传》中有载，可以脱离困境。没人知道它具体的等级，可以帮助蛊师开窍，是爱情蛊和爱意蛊的食物。【人祖】
- 太古时代就存在的蛊，但没人知道它具体的等级，能让人开窍，具体资料不明。【人祖】
- 【第五轮复核｜边界说明】既有原文只写可助开窍、为爱情蛊/爱意蛊食物，且“没人知道具体等级”；不据此推定可批量开窍、稳定可控或可替代开窍蛊。

### C-G-010 幡然蛊
- 可逆炼蛊虫，如可以将四味酒虫炼成一只一转酒虫。

### C-G-011 月光蛊
- 一转凡蛊
- 攻击类蛊虫，古月一族镇族蛊虫，具有远程攻击性。由秘法配置，晶莹剔透，像一块蓝水晶，重量只有一张薄纸左右，能在空中凝成一个巴掌大幽蓝色月刃，攻击范围十米，以月兰花瓣为生，早晚一顿，每顿2片。【古月一族】
- 【第五轮复核｜边界说明】既有原文只载十米月刃、以月兰花瓣为食、早晚各 2 片；原著未载连发间隔、穿甲能力与最大数量，不补数值。

### C-G-012 水晶瓢虫
- 一转凡蛊
- 肚内中空，常常被蛊师用来装载珍贵液水。
- 肚内中空，常常被蛊师用来装载珍贵液水。【贾家商队酒铺】

### C-G-013 水蛛蛊
- 一转凡蛊
- 在蛊师的身上覆盖一层薄薄的淡蓝色水衣。
- 在蛊师的身上覆盖一层薄薄的淡蓝色水衣，淋雨时，水衣会越变越厚，需要排出多余水分。【贾家商队】
- 【第五轮复核｜边界说明】水衣淋雨会增厚、需排多余水分；不据此推定可无限增厚、免疫水行攻击或防止溺水，也不补厚度上限。

### C-G-014 浪子蛊
- 可逆炼蛊虫，如可以将四味酒虫炼成两只一转酒虫。

### C-G-015 温丝蛛
- 后勤类蛊虫。

### C-G-016 溪流蛊
- 溪流蛊是白家的标志蛊虫，就像古月一族的月光蛊，熊家的熊力蛊。
- 一转凡蛊
- 【第五轮复核｜边界说明】“白家标志蛊”只说明家族标志与常见配备，不等于白家全员必备、外人绝不可得，也不证明其为唯一血脉蛊。

### C-G-017 熊力蛊
- 熊力蛊是熊家的标志蛊虫，就像古月一族的月光蛊，白家的溪流蛊。食物是蜂蜜。
- 一转凡蛊

### C-G-018 玉皮蛊
- 一转凡蛊
- 防御类蛊虫，比铜皮蛊优秀，不仅消耗的真元少，而且防御力也比铜皮蛊更强一些。【古月方正（得自族长古月博）、古月方源（得自花酒传承）】

### C-G-019 生息草
- 治疗类蛊虫，炼成号称二转蛊虫第一毒的爱生离的所需蛊虫。

### C-G-020 生机叶
- 消耗类蛊虫，用一次就消逝并且运用了一片生机叶疗伤之后，一个小时之内，其他的生机叶将没有治疗的效果。

### C-G-021 白豕蛊
- 一转凡蛊
- 消耗类蛊虫，增加给蛊师的力量。【古月一族、古月方源（得自花酒传承）】

### C-G-022 石皮蛊
- 一转凡蛊
- 让皮肤顷刻间由自然的黄色皮肤转变成了灰白色。同时像充了气的气球一样膨胀起来，裹上一层十分厚实的石皮。

### C-G-023 粉豕蛊
- 一转凡蛊
- 用于增肥。

### C-G-024 红针蝎
- 炼成号称二转蛊虫第一毒的爱生离的所需蛊虫。

### C-G-025 肥甲虫蛊
- 用于驮运商队货物。【贾家商队】

### C-G-026 臭屁肥虫
- 一转凡蛊

### C-G-027 花豕蛊
- 一转凡蛊
- 消耗类蛊虫，能赋予蛊师临时性的巨大力量，号称“一猪之力”。其消耗的真元量和蛮力天牛蛊一样多，但是它能维持十个呼吸。

### C-G-028 草人蛊
- 本身拥有草木系的轻微自愈能力。【古月一族】

### C-G-029 蛮力天牛蛊
- ：一转凡蛊
- 消耗类蛊虫，能赋予蛊师临时性的巨大力量，号称“一牛之力”，维持五个呼吸的功夫。

### C-G-030 酒囊花蛊
- 一转花蛊
- 草类天然蛊虫，只有灌注真元，就能生长。长成之后，花心中会分泌出花蜜酒。【花酒行者】

### C-G-031 酒虫
- 一转凡蛊

### C-G-032 金钟蛊

### C-G-034 铜皮蛊

### C-G-037 青丝蛊
- 防御类蛊虫，常被蛊师用来防御打击。它使用起来，一次性消耗三成的青铜真元，不需要持续的真元输出，可以将蛊师的身躯和坐骑都包裹住。形成一件临时的密不透水的黑发蓑衣。【贾家商队】
- 一转凡蛊

### C-G-038 青铜舍利蛊

### C-G-039 饭袋草蛊
- 一转草蛊
- 草类天然蛊虫，只有灌注真元，就能生长。长成之后，草袋中会生长出香喷喷的米饭。【花酒行者、陈翠花】

### C-G-040 驭犬蛊

- 【第五轮复核｜边界说明】驭使对象明写“犬类野兽”；不扩为所有犬科妖兽、更不扩为所有妖兽；“犬王传承钥匙”不等于战斗能力。

### C-G-041 骨枪蛊

### C-G-042 骨竹蛊

### C-G-043 黄骆天牛蛊

## 原创蛊虫（O-G）

### 流派：土道

#### 【原创设定】拾穗蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-017 |
| 名称 | 拾穗蛊 |
| 品阶 | 一转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 土道 |
| 核心用途 | 资源采集：拾拢散落细碎之物归堆 |
| 稀有程度 | 常见 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一只极小的竹簸箕，簸沿磨得圆润，箕底编着细密篾纹。
- 大小：掌心大。
- 颜色：竹黄，篾纹深褐。
- 形态特征：近了散落之物，簸箕会自行微微一倾，像等人往里扫。
- 特殊视觉效果：催动时，地面上针尖大的碎屑会「顺篾纹」轻轻滑拢，归成一小堆，不扬灰。

##### 二、核心能力

- 基础能力：把一片地面上散落、细碎、无主的「小物」拾拢归堆——落穗、碎料、散元石屑、药籽皆可，便于收取。
- 作用机制：土道「归堆」——只拢「已落地、无主、细碎」之物，靠篾纹顺其势轻扫，不掘地、不夺人手中物、不取已归属之物。
- 作用对象：地面散落细碎无主之物。
- 能力范围：数步内一片地面。
- 效果强度：归堆整齐、不扬灰、不混类（同类自成一堆）；但不辨贵贱、不识毒、不会替蛊师挑拣「值不值得捡」。
- 使用限制：只拾「落地无主」者；正在被催动的蛊、他人持握之物、嵌入物表的浊气一概不动；湿黏、生根之物拾不起。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 一转蛊师即可 |
| 炼化难度 | 极低 |
| 特殊要求 | 无 |
| 炼化风险 | 无 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 即其所拾的一撮碎屑（自给） |
| 辅助食物 | 无 |
| 频率 | 无需专门喂养 |
| 成本 | 无 |
| 特殊环境 | 须地面干燥平整，泥泞与草丛中篾纹易塞 |
| 断食后果 | 无（靠环境碎屑为生；地面绝对洁净则无物可拾，但不死） |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 落地、无主、细碎、干燥之物 |
| 消耗 | 一转青铜真元，几乎不耗 |
| 范围 | 数步内一片地面 |
| 持续 | 一次一扫 |
| 缺陷 | 不掘地、不夺持握物、不辨贵贱、不识毒、湿黏生根之物无效；无战斗能力 |
| 克制 | 无直接克制；被「无尘净地」「泥泞草丛」废掉效力 |
| 优势 | 零成本、不扬灰、自动归类，是采收与清场的省力底子 |
| 适用场景 | 收割后拾穗、炼材场收碎料、矿场收屑、废墟清场归堆 |
| 不适用场景 | 战斗；需鉴别 / 挑拣 / 去毒（宜配 O-G-019 砥砺蛊、O-G-020 牙筹蛊） |

##### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一只用了整季秋收、从未散篾的旧竹簸箕 |
| 辅助材料 | 一撮落穗、一根旧篾条 |
| 过程 | 以真元把「顺纹归拢」之意炼入篾纹 |
| 难度 | 极低 |
| 成功率或风险 | 极低 |
| 替代材料 | 可用柳条簸箕替代，但遇湿更易变形 |

##### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | O-G-015 谷雨蛊（采收环节）、O-G-013 束囊蛊（归堆即入囊）、O-G-014 扁担蛊（装载）、O-G-020 牙筹蛊（清点） |
| 可参与杀招 | O-K-011「春耕图」（辅助：采收归拢，把成熟作物与落穗拾拢成堆） |

### 流派：气道

#### 【原创设定】聚尘蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-007 |
| 名称 | 聚尘蛊 |
| 品阶 | 一转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 气道 |
| 核心用途 | 资源/生产（聚拢粉尘浊气炼成气晶） |
| 稀有程度 | 常见 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一团米粒大的淡灰气旋，常悬浮在半空微微打转。
- 大小：米粒大。
- 颜色：淡灰，中心微亮。
- 形态特征：周围空气中的浮尘会不自觉地朝它缓缓聚拢。
- 特殊视觉效果：聚满时，中心会凝出一颗极小的、半透明的「气晶」。

##### 二、核心能力

- 基础能力：缓慢吸附周遭的粉尘、浊气与杂质，凝练成可存贮、可贩卖的「气晶」——一种低阶气道资源，可作炼蛊辅材或换取元石。
- 作用机制：气道「聚气成晶」，把散逸的无主之气归拢提纯。
- 作用对象：空气中的浮尘浊气。
- 能力范围：数尺内。
- 效果强度：日夜不停，约七日凝成一颗小气晶。
- 使用限制：空气越污浊效率越高，反之越慢；产出的气晶品质低，只作辅材；不能净化已黏附在物表、人体上的浊气。

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 需空气中有浮尘浊气 |
| 消耗 | 一转青铜真元，几乎为零（自给自足） |
| 范围 | 数尺内 |
| 持续 | 日夜不停，约七日凝成一晶 |
| 缺陷 | 无任何战斗、侦查能力；产率低、品质低；会被「无尘净室」环境废掉产出 |
| 克制 | 无 |
| 优势 | 零成本、可长期稳定产出气道辅材；是低阶蛊师「躺着攒资源」的入门之选 |
| 适用场景 | 城市、矿场、废墟、战场遗址等浊气重之地长期经营 |
| 不适用场景 | 战斗；洁净环境 |
