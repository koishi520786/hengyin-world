### C-G-080 人兽葬生蛊
- 消耗类蛊虫，用于强行突破三转。【方源】
- 黑暗炼蛊·**人兽合炼类**：方源十七岁狼潮时以族人药乐与熊炼成此蛊，用后强行突破三转。「葬生」即以生灵（人＋兽）为代价。更细的炼制条件（性别、资质、驭兽环节等）原著未逐条展开，【原著未明确】不推测。【可靠资料佐证｜方源生平多源记载】

### C-G-081 人药蛊
- 用人类孩童当做炼蛊的主要材料，历时数年，慢慢炼成，一旦炼成，只能用一次，延长寿命，后遗症很大。
- 黑暗炼蛊·**活人长期炼制类＋寿元类**：以人类孩童为主材、历经数年慢炼——材料在炼制全程保持「活着的意义载体」，这是「慢性献祭」而非一次性杀戮；成品只能用一次、延寿、后遗症大，收益与代价极不对称。使用者见【墨大夫】（多源词条佐证）。【原著明确｜条目原文；使用者标注【可靠资料佐证】】

## 原创蛊虫（O-G）

### 流派：土道

#### 【原创设定】弥缝蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-018 |
| 名称 | 弥缝蛊 |
| 品阶 | 三转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 土道 |
| 核心用途 | 建筑修复：弥合墙垣、田垄、器皿裂缝 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一把微缩的抹子，刃上总沾着一点半干的灰泥，泥色温润。
- 大小：三指长。
- 颜色：木柄褐，泥灰白。
- 形态特征：近了裂缝，刃上灰泥会自行微微鼓起，像要往缝里填。
- 特殊视觉效果：抹过时，裂缝像被「抚平」般收拢，不留新痕，只余一道比周围略深的浅线。

##### 二、核心能力

- 基础能力：把墙垣、田垄、沟渠、陶石器皿上的「裂 / 缺 / 缝」用灰泥弥合，恢复其「不漏、不塌、不断」的原状。
- 作用机制：土道「补形」——只补「本是一体、后来裂开」之处，把散开的土 / 石 / 陶重新拢回原形；不新建、不加固、不改形，补出的强度不超过原物完好时。
- 作用对象：一处既有之物的裂缝 / 缺损。
- 能力范围：单处，约一臂所见之缝。
- 效果强度：弥合后不漏不塌、外观只留浅线；但不加固、不新建、不补「整块已粉碎」者、不补含活跃道痕的仙材裂痕。
- 使用限制：须「原物尚在、只是裂了」；粉碎、朽透、被连根毁去者无效；须以同质灰泥 / 土作料；一处只补一次，反复抹反致凸疤。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 三转蛊师，土道或兼修土道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 须亲手抹平过一道「雨后不渗」的墙缝作引 |
| 炼化风险 | 低 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 一小撮同质灰泥 / 田土 |
| 辅助食物 | 无 |
| 频率 | 每补一处喂一次；闲时每半月一撮土 |
| 成本 | 低 |
| 特殊环境 | 须阴干、不可在暴雨 / 暴晒中补，否则泥未合先裂 |
| 断食后果 | 刃上灰泥干硬，补出的缝虚合，一遇水即再裂 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 原物尚在、只是裂缺；须同质灰泥；须阴干 |
| 消耗 | 三转白银真元，中耗（单处） |
| 范围 | 单处，约一臂所见 |
| 持续 | 补合后长期，留浅线 |
| 缺陷 | 不加固、不新建、不补粉碎朽透者、不补仙材道痕裂、一处一次、暴雨暴晒难成 |
| 克制 | 被炎道（烤裂）、冰雪道（冻胀）、力道「震裂」克制；与 O-G-102 归墟蛊（仙材道痕复原）分属凡 / 仙两层，互不替代 |
| 优势 | 低耗地把「坏了一道缝」就地修回，是田庄、据点、器物的常备维护蛊 |
| 适用场景 | 修田垄沟渠、补墙垣仓壁、合陶石器皿、震后小修 |
| 不适用场景 | 整屋重建、加固、仙材裂痕（宜归墟蛊）、粉碎之物 |

### 流派：律道

#### 【原创设定】守更蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-004 |
| 名称 | 守更蛊 |
| 品阶 | 三转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 律道 |
| 核心用途 | 辅助（固定节律内强化「守约」状态） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一枚古朴的更鼓，仅指尖大，鼓面紧绷。
- 大小：指尖大小。
- 颜色：木色鼓身，鼓面灰白。
- 形态特征：鼓身刻着均匀的刻线，恰如一夜的更次。
- 特殊视觉效果：每过一刻，鼓面会自行轻颤一下，发出几乎只有蛊师能听见的「笃」。

##### 二、核心能力

- 基础能力：设定一个「更次节律」（如守一夜、候三更），在节律存续期间，使蛊师的「守约/戒备」状态获得律道加持——精神更清明、不易被催眠或惑乱，对违反既定节律的异动更敏锐。
- 作用机制：守更蛊把「时间」划成固定的更次，蛊师与其「定约」后，节律成为一道微弱的律道道痕，约束心神不散、不惰。
- 作用对象：蛊师自身（守约者）。
- 能力范围：本人。
- 效果强度：能抵御轻微的精神惑乱与困意；对「掐准更次发动」的异动有提前警觉。
- 使用限制：一次只能定一个节律；节律一破（如失约、睡着、被打断）加持即散，且当夜不可再定；只护「守约」不护「肉身」。

| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一尾极扁的银鱼，游于水面时几乎与光融为一体。
- 大小：两指长。
- 颜色：银白，腹下泛青。
- 形态特征：静止时扁如刀片，可贴伏水面；游动时尾鳍搅起一圈不易察觉的细纹。
- 特殊视觉效果：潜入水中后，会「记住」最近一次映在水面的画面，并把它短暂地留在水面。

##### 二、核心能力

- 基础能力：把一片水面当作「镜」，摄下此刻映于水面的影像，并将其凝固在水面数息，供蛊师读取；也可用其倒影覆盖真实水面，制造「假倒影」。
- 作用机制：倒影蛊吃的是「光的反射」，它在水面存下一层极薄的水膜，把已摄下的画面固定在水膜上；旁人看去，水面倒影与真实无异，却已是数息前的旧景。
- 作用对象：一片静水面（约一丈见方）。
- 能力范围：需目视水面；摄取与显影都限于同一片水。
- 效果强度：能清晰摄下并回放数息前的倒影；能造「假倒影」误导观察者，但假倒影是静态的，一经细看会露破绽。
- 使用限制：必须静水，流水、波涛皆不可；光照不足时影像极淡；只能作用于水面，不能凭空成像。

| 炼化条件 | 三转蛊师，水道或兼修水道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 无 |
| 炼化风险 | 低 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 月华照射过的静水 |
| 辅助食物 | 银屑 |
| 频率 | 每五日一次 |
| 成本 | 低 |
| 特殊环境 | 满月之夜喂一次，可增强下次显影的清晰度 |
| 断食后果 | 水膜渐干，蛊僵死 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 必须静水、需目视水面、需一定光照 |
| 消耗 | 三转白银真元，低耗 |
| 范围 | 一丈见方的同一片静水面 |
| 持续 | 显影凝固数息 |
| 缺陷 | 无攻击力；极度依赖静水环境；假倒影静态、细节经不起推敲；被光道「强光」直接废掉水膜 |

| 所属流派 | 魂道 |
| 核心用途 | 临终关怀：承接将散之魂息三日，供遗言交代、身后事安排 |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】｜状态：proposed |

##### 一、外观

- 外观：一只巴掌大的灰蝶，翅如旧纸。
- 大小：巴掌大。
- 颜色：灰白，翅缘一线银。
- 形态特征：静伏时翅合如信封。
- 特殊视觉效果：承接魂息后，翅上浮出一行行细小墨字般的纹，随魂息渐淡而褪。

##### 二、核心能力

- 基础能力：濒死者临终前，渡魂蛊可承接其将散之魂息，为死者多留三日——魂息不散于风，可低语交代遗言、确认遗嘱、指认凶手。
- 作用机制：魂道「承息」——蛊为魂息暂栖之壳；**不复活、不治愈、不延长生命**，只是让最后的话说完。
- 作用对象：七日内将死的自愿者。
- 能力范围：须在濒死者身侧一臂之内承接；之后蝶与死者魂息相系，不离十里。
- 效果强度：死者可低语、可睁眼，神志清明如常人约三个时辰／日，其余时间沉眠。
- 使用限制：**须濒死者生前明确自愿**——魂息不认强迫，强承则魂与蛊俱散；一名蛊师连渡三人后，蛊必受魂息滞留反噬，第四人必失败。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 三转蛊师，魂道或兼修魂道者；医疗与临终关怀机构任职者优先获执照 |
| 炼化难度 | 中 |
| 特殊要求 | 炼制须在「无横死之气的安寝之地」（安宁病房、祖屋正寝） |
| 炼化风险 | 中；炼制失败则蛊师染「滞息」，夜夜闻陌生低语，须月余方消 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 舒缓的临终气息（非强制——蝶自会寻将逝之息，蛊师只须携蛊守于安宁之所） |
| 辅助食物 | 檀香 |
| 频率 | 蝶自取食；蛊师每旬以真元理翅一次 |
| 成本 | 低 |
| 特殊环境 | 安静、避横死者怨气 |
| 断食后果 | 翅纹褪尽、承息之力衰减，须重新随侍安宁之所一月 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 濒死者自愿；一蛊一生只渡三人（每渡一次翅淡一分） |
| 消耗 | 三转白银真元，中耗 |
| 范围 | 承接一臂内，之后十里 |
| 持续 | 三日 |
| 缺陷 | **不复活不治愈**——三日之后魂息仍散，去向不归本蛊所知；连渡三人后第四人必失败、蛊报废 |
| 克制 | 「驱魂」类手段可提前截散魂息；医疗蛊师以强力续命蛊吊住性命时，魂息不上不下、蛊无法承接 |
| 优势 | 让临终者把话说完；家属告别、遗产确证、命案指认的唯一正当窗口 |
| 适用场景 | 安宁病房、死刑见证前的遗言（极重程序）、临终刑事指认 |
| 不适用场景 | 已死者（魂散不可招）；昏迷而未濒死者 |
| 监管接口 | 刑事指认须经执法与公证双在场；「强承未自愿魂息」按蓄意伤害论处（见 `04_世界/05_政治组织与社会制度.md`第十一节） |

#### 【原创设定】偿愿蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-031 |
| 名称 | 偿愿蛊 |
| 品阶 | 三转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 魂道 |
| 核心用途 | 遗产/情感：唯遗孤可炼，感应并收集亡故至亲残存人间的执念碎片，拼合为一段遗言或一门粗浅传承 |
| 稀有程度 | 极稀有（炼化资格本身稀有） |
| 原创标识 | 【原创设定】｜状态：proposed |

##### 一、外观

- 外观：一枚素色纸鹤，翼上有两道泪痕状水渍。
- 大小：掌心大。
- 颜色：素白，边角微黄如旧信。
- 形态特征：形似未折完的纸鹤，尾部留一截没折进去的纸角。
- 特殊视觉效果：催动时纸鹤绕蛊师头前三匝，每拾到一枚执念碎片，泪痕便深一分。

##### 二、核心能力

- 基础能力：收集亡故至亲（父母）残存人间的执念碎片——亡者生前最放不下的一念，散落在其常去之处、遗物之上——拼合后可还原为一段简短遗言，或一门粗浅技艺传承（一个农时口诀、一门腌菜手艺、半招拳脚），一年内碎片不齐则自动失效。
- 作用机制：魂道「拾愿」——执念是魂魄消散时溅落人间的余烬；偿愿蛊只拾不招，拼的是余烬不是魂魄。
- 作用对象：**炼蛊者本人亡故的父母**（遗孤专属，认的是「孤儿之憾」，他人父母无效）。
- 能力范围：执念碎片散布半径百里内。
- 效果强度：遗言至多百字；传承至多「一门谋生手艺」的深度，**不可能是功法神通**——残愿里没有那些东西。
- 使用限制：唯「双亲皆亡的遗孤」可炼化；碎片百枚为期一年，逾期不齐则纸鹤散作白灰。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 三转蛊师，**且须为双亲皆亡之遗孤**——蛊认憾而生，非遗孤者纸鹤不落掌 |
| 炼化难度 | 低（资格难、炼制易） |
| 特殊要求 | 炼化须以父母遗物为引（一件即可） |
| 炼化风险 | 低 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 蛊师对亡亲的追忆（每月静坐回忆一炷香，以心念喂之） |
| 辅助食物 | 无 |
| 频率 | 每月一次 |
| 成本 | 无形（须「真心」，敷衍的回忆蛊不认） |
| 特殊环境 | 遗物须随身 |
| 断食后果 | 纸鹤泛黄发脆，拼合精度下降 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 遗孤身份（炼化时已定，终生不变） |
| 消耗 | 三转白银真元低耗＋夜夜梦见父母临终场景（收集期一年内的神志代价） |
| 范围 | 百里 |
| 持续 | 拼合期一年，成愿即终 |
| 缺陷 | 神志消耗大——夜夜梦见临终，白日恍惚、战力下降一档；**传承上限是「谋生手艺」，不存在捡到神功的侥幸**；碎片被他人先毁（如遗物焚毁）则永远残缺 |
| 克制 | 「涤愿」类手段可抹碎片（罕见邪术）；大量饮酒可短暂不梦——但会令拼合失效，酗酒的偿愿蛊师十有八九拼不成 |
| 优势 | 世上唯一能替死者「把没说完的话说完」的蛊（渡魂蛊给的是临终三日，偿愿蛊给的是身后一年） |
| 适用场景 | 遗孤寻憾、家传手艺抢救、遗言补录 |
| 不适用场景 | 非遗孤（无资格）；想借此求功法神通者（上限锁死） |
| 监管接口 | 传承若涉及「家传秘方」归属，公证处承认偿愿蛊拼合记录为旁证之一（不作为唯一证据） |
