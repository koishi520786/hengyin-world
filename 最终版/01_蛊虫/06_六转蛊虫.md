## 原创蛊虫（O-G）

### 流派：宇道

#### 【原创设定】壶天蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-105 |
| 名称 | 壶天蛊 |
| 品阶 | 六转 |
| 凡蛊或仙蛊 | 仙蛊（同名天下唯一） |
| 所属流派 | 宇道 |
| 核心用途 | 特殊空间：开一方壶中小空间 |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一枚扁圆小葫芦，葫芦口极细，内壁望之似有一线天光。
- 大小：拳头大，可系于腰。
- 颜色：葫芦皮赭黄，口沿泛一线幽蓝。
- 形态特征：壶口开时，细口里会浮出一圈极淡的涟漪，如门将启。
- 特殊视觉效果：纳物时物件不「缩」，而是被壶口那圈涟漪「让」进去，壶身不鼓不胀。

##### 二、核心能力

- 基础能力：以仙元在葫芦腹内撑开一方「壶中小空间」，可纳死物、干材，亦可短时容一件「已封印沉眠」的活物；空间与外隔绝，内物不腐不潮、不与外物互扰。
- 作用机制：宇道「壶里乾坤」——只「容」，不生、不造、不加速、不产道痕；空间大小固定，撑开须持续供仙元维持壶口那道界门。
- 作用对象：一方静物 / 一件已沉眠封印之活物。
- 能力范围：数丈见方的一小方空间。
- 效果强度：可纳一方死物、隔绝外扰；但不能扩界、不能产资源、不能让内物「变好」。
- 使用限制：空间固定不可扩（扩须升炼）；须持续供仙元维持界门；含活跃道痕且未封印之物入内即与空间相冲；壶口一闭不可从内开；一次只开一口。

##### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 六转蛊仙，宇道或兼修宇道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 须亲见「壶口开合一次」并记住那道界门之界 |
| 炼化风险 | 中；记界不清则成品界门不稳、易漏 |

##### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 仙元（低频，维持界门按月供） |
| 辅助食物 | 两地各一撮土（养界） |
| 频率 | 纳物期间每月一次；空置则每季一次 |
| 成本 | 中 |
| 特殊环境 | 壶口须避剧烈宇道震荡，震荡会晃散界门 |
| 断食后果 | 壶口合拢、内空间坍缩，所纳之物尽散 |

##### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 须持续供仙元、只开一口、只纳静物或已沉眠活物 |
| 消耗 | 六转青提仙元（维持型，持续耗）；纳物越多耗越甚 |
| 范围 | 数丈见方 |
| 持续 | 随仙元维持 |
| 缺陷 | 空间固定、须持续供仙元、不纳活跃道痕物、壶口一闭内不可开、壶体被夺则内物易失、无任何战斗力 |
| 克制 | 被宇道「破界」、阵道封印、更强空间类仙蛊克制 |
| 优势 | 唯一「可随身携带一方隔绝小天地」的经营底盘，不与外界互扰 |
| 适用场景 | 福地仓储、长途运仙材、隔离养材、为改土 / 封痕提供封闭场 |
| 不适用场景 | 实战、扩容、容纳活跃仙蛊、无仙元续供时 |

##### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一枚生于绝壁、腹内自成一洞、从未积过外物的老葫芦 |

### 流派：炼道

#### 【原创设定】微尘蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-103 |
| 名称 | 微尘蛊 |
| 品阶 | 六转 |
| 凡蛊或仙蛊 | 仙蛊（同名天下唯一） |
| 所属流派 | 炼道 |
| 核心用途 | 炼制/侦查（以尘眼观入炼蛊过程的微小变化） |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

##### 一、外观

- 外观：一粒几不可见的微尘，寄于蛊仙指尖。
- 大小：微尘。
- 颜色：无色。
- 形态特征：附着于炼蛊炉鼎之上，几乎与器物融为一体。
- 特殊视觉效果：催动时，微尘「张开」成一只极小的眼，洞察入微。

##### 二、核心能力

- 基础能力：以「尘眼」观测一次炼蛊过程中材料、道痕、温度的细微变化，把肉眼不可见的波动转译为蛊仙可读的征兆，辅助判断成败节点。
- 作用机制：炼道「观微」——道痕的变化会在极微处先现端倪，微尘蛊专察此端倪。
- 作用对象：一次炼蛊过程的器物内部。
- 能力范围：贴身观测。
- 效果强度：能提前片刻察觉「即将失败/即将成型的临界」，但只能观测、不能改变。
- 使用限制：只作观测，不能干涉炼蛊；对超出炼道理解的异变无能为力。

| 成本 | 中 |

##### 一、外观

- 外观：一枚极薄的空蚌壳，壳内不积物，只浮着一层会自己聚拢的细砂。
- 大小：两指长。
- 颜色：壳白泛青，砂灰。
- 形态特征：近了「有痕将散」之处，细砂会顺壳纹缓缓聚成一小撮。
- 特殊视觉效果：收痕时，壳内细砂会按流派泛出极淡的不同色泽，随即褪成一律的灰。

##### 二、核心能力

- 基础能力：收拢「自然逸散的游离道痕」——杀招余波、炼蛊废渣、器物崩解时散出、道痕将散未散者——凝成一撮可辨、可封存的「痕砂」，供辨识佐证或作低阶炼材引子。
- 作用机制：炼道「敛屑」——只收「已散、无主、游离」之痕，不夺他人 / 他物身上「尚在生效」的道痕；不凭空生痕、不把痕炼成修为、不补全仙蛊道痕。
- 作用对象：一小片「痕场」内游离将散之痕。
- 能力范围：身边一小片痕场。
- 效果强度：痕砂可看出「属何流派、约何时散」，仅此；不能转化为蛊仙修为、不能反推完整杀招、不能当仙材使。
- 使用限制：只收游离将散之痕；活跃 / 有主道痕收不得（强收反被痕伤）；产出极淡、只堪佐证；一处痕场收一次即尽。

| 稀有程度 | 唯一（仙蛊） |

##### 一、外观

- 外观：一缕将断未断的游丝，尽头悬着一点比米粒还小的温光，光不亮却不肯灭。
- 大小：游丝寸许，光点如尘。
- 颜色：丝灰白，光暖黄。
- 形态特征：所托之息越弱，丝越细、光越垂；息一散，丝立断。
- 特殊视觉效果：托住一线残息时，光点会极缓地一涨一落，像替它接着最后一口气。

##### 二、核心能力

- 基础能力：温养一缕「将散未散」的残息 / 残魂，延缓其消散，为招魂、辨认、超度留一段窗口。

- 作用对象：单缕尚存一线的残息 / 残魂，或壶天熟地中「将枯未枯」的一线微弱生机。
- 能力范围：单缕。
- 效果强度：可把「数息即散」延缓到「数日」，供从容辨认 / 超度；一旦散尽不可追，离体越久越难托。
- 使用限制：只托「尚存一线」者；散尽者无效；不能令其恢复神智、不能还魂附体、不能增寿；托养期间持续耗魂魄底蕴 / 心力。
