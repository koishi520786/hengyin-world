# 14 主角开局档案

> 职责：玩家控制的主角的公开开局基线：年龄、家庭、劳动经历、经济状况、身体条件与初始状态。
> 收录范围：只记录已锁定的共同基线；姓名、性别、外貌、性格、喜好、未来目标与未确认经历由玩家决定。
> 检索导航：开局流程回 `05_跑团规则/09_开局流程与初始状态.md`；家庭支出回 `04_世界/06_经济科技与交通.md`；学校、开窍大典与资质分布回 `04_世界/05_政治组织与社会制度.md`「蛊师社会与制度」2.3—2.4；人物关系回 `05_跑团规则/01_玩家控制权与NPC连续性.md`、`05_跑团规则/06_角色表现与主动互动.md`。

## 一、基本信息

| 项目 | 内容 |
|---|---|
| 称呼 | 叙事中默认称“主角”；姓名由玩家决定 |
| 年龄 | 故事开始时 12 岁 |
| 开局日期 | 垠历 738 年 3 月第 2 周，十二岁开窍大典当天；开局时尚未验窍 |
| 居住 | 临江市北城区云栖街道云栖花园，保留原住房独自居住 |
| 学校 | 临江市北城区第二小学六年级下学期；具体班级、同学关系以玩家开局卡或剧情为准 |
| 身份 | 未成年人；父母去世；独自生活；社区与学校按未成年人重点台账定期走访；开窍大典当天由学校统一组织参加验窍 |
| 控制权 | 主角由玩家完全控制；GM 不替主角决定行动、台词、内心、情绪和人生目标 |

## 二、玩家决定的部分

以下内容由玩家自行决定，GM 不得擅自补写：

- 姓名、性别、外貌细节。
- 性格倾向、说话习惯、喜好与厌恶。
- 人生理想、长期目标、对蛊道的态度。
- 已经确认的过去工作、工作地点、收入与具体经历。
- 对学校、朋友、社区走访人员、金钱和未来的具体看法。
- 对任何 NPC 的态度、好感、信任与关系选择，包括成年后是否愿意发展恋爱关系。
- 开局时的具体现金、随身物品与已确认的家庭安排；未确认的部分按公开基线保守处理。

玩家没有确认的内容，可以随着剧情逐渐补充，但不得一次性编造大量过去，也不得把推测写成已经发生的事实。

## 三、家庭与监护

主角的父母已经去世。父母去世后，主角保留原住房独自生活。

主角没有能够长期承担监护责任的亲属，也没有突然出现的好心成年人主动接管其生活。不要擅自安排富有亲属、神秘遗产、慈善机构或好心人解决所有生活问题。

制度上可能存在未成年人台账、监护顺位核查、临时监护评估、生活补助、学费减免与社区走访；这些程序可以发生，也可能因为材料、亲属、社区判断而卡住。它们带来行政压力、时间成本和社会目光，不是自动送来的养父母，也不保证获批。当前没有成年人与主角同住。

如果社会制度确实存在相关救助、监护或补助机制，可以在剧情中自然出现，但不能直接假设主角一定会获得帮助。具体情况必须符合 `04_世界/05_政治组织与社会制度.md` 的制度与当前人物处境。

## 四、过去几年的生活

父母去世后，为了维持自己的生活，主角在过去几年里一直想办法赚钱。主角曾经做过零工或熟人介绍的补贴性劳动；这些收入并不宽裕，只能勉强支撑日常开销。涉及未成年劳动时，必须同时呈现其灰色/违规风险、时间限制、受伤自付、被学校或监察发现后的后果，不得写成合法稳定全职工作。

这段经历造成长期影响：

- 比同龄孩子更早接触社会和工作环境。
- 对金钱、食物、生活开销有更现实的认识。
- 在长期劳动中锻炼了意志力、耐力和适应能力。
- 体力和抗压能力相较普通同龄孩子可能有所提升。
- 但主角仍然只有 12 岁，身体发育尚未完成，不能拥有成年人一样的体能。

必须区分“经过锻炼”和“身体已经成熟”。主角可能因为长期劳动而比同龄人更能吃苦，但仍然会疲劳、受伤、生病、睡眠不足，甚至因过度劳累而晕倒。

有时主角会不想继续工作，会懒惰、厌烦、想休息。现实的经济压力让主角不得不考虑继续赚钱。不要把这段经历简单写成“获得强大体质的奖励”；它既带来成长，也留下疲惫和身体负担。

## 五、家庭经济与居住基线

主角独自居住在云栖花园一套两室一厅、约 68 m² 的老六层住宅。公开基线如下：

| 项目 | 基线 |
|---|---|
| 月租 | 1,850 曜元（约 1,366 CLU），云栖花园老六层中位水平 |
| 物业/公摊 | 约 75—122 曜元/月 |
| 食品 | 一人在家做饭、学校午餐为主，约 480—720 曜元/月 |
| 水电燃气 | 约 150—280 曜元/月，夏冬取上限 |
| 医疗/常用药 | 约 80—250 曜元/月，不含住院与大病 |
| 学习用品/校服摊销 | 约 60—180 曜元/月 |
| 交通 | 约 90—200 曜元/月 |
| 衣物/鞋袜 | 约 60—180 曜元/月 |
| 通信/宽带 | 约 30—80 曜元/月 |
| 日常维修/替换 | 约 30—100 曜元/月 |
| 合计 | 紧巴线约 2,900 曜元/月；普通线约 3,300—3,960 曜元/月 |

家中钱财有限，按紧巴线理解只够维持一个人约一年的基本生活；不生病、不补课、不换大件、不外食。一旦出现住院、修房、跨城交通或意外赔偿，见底会加快。不要让补助、亲戚借款或临时工作把日子写成宽裕；它们只能改变现金流，不改变生活成本。

主角的经济状况应通过具体资产表现：当前现金、家中剩余食物、已确定的收入、即将到期的支出、已经购买的物品。不要只用一个抽象的“总资产”数字代替生活细节。

## 六、身体与心理边界

- 12 岁，身体发育未完成；耐力可以高于普通同龄人，但力量、恢复速度和抗病能力仍按儿童处理。
- 长期劳动可能带来茧、旧伤、姿势习惯、对某些工作环境的熟悉，也可能带来疲劳积累和睡眠不足。
- 可以比同龄人更会看人脸色、更早理解工资和欠款，但不等于拥有成年人的社会经验、法律知识或情绪控制。
- 可以坚强，也可以害怕、委屈、想逃避、想被照顾；不要写成没有脆弱面的“小大人”。
- 任何“咬牙坚持”之后都要写代价：低血糖、脱水、发烧、疼痛、注意力下降或恢复变慢。

## 七、开局蛊道状态

### 7.1 验窍之前

开局时，主角还没有完成验窍：

- 没有空窍记录、没有资质记录、没有元海成数。
- 没有真元、没有入转、没有本命蛊。
- 没有蛊师学籍或蛊道班录取结果。
- 隐藏系统尚未出现。
- 结果只会在验窍当场告知本人并登记；在此之前，GM 不得提前公布或暗示。

### 7.2 验窍之后（本局锁定）

主角开窍成功，**丙等资质，元海四成六**。这是本局固定结果，只在正式验窍完成时揭晓。

- 空窍已经形成，元海占空窍四成六；具体记录以验窍结果与全国蛊道登记为准。
- 真元尚未经过修炼积累；不预设真元储量、转数或青铜／赤铁等档位。
- 境界未入转；不是一转蛊师，更不是一转以上蛊师。
- 尚无已炼化的本命蛊；第一只蛊的购买、炼化、登记、喂养与使用仍受经济、监护、学校／协会审批与未成年用蛊限制。
- 隐藏系统在验窍确认有窍之后出现。

### 7.3 资质的使用边界

- 丙等不是“废柴”或命运判决：四至五成的元海足以正常修行，常见上限为二转，少数可到三转初阶；成长来自学习、选择、资源积累与经历。
- 不得给主角添加特殊血脉、隐藏体质、天生仙窍、前世记忆或额外天赋。
- 不得把丙等写成“注定低人一等”，也不得用“突然觉醒”抹平资质限制。
- 资质只影响空窍容量、真元上限与恢复效率，不决定悟性、胆量、战术与人品。

验窍之后的资质、空窍、真元、修行进度、购蛊、炼化与登记，按 `01_蛊虫/10_蛊道核心机制.md`、`05_跑团规则/03_修炼与成长判定.md`、`04_世界/05_政治组织与社会制度.md`「蛊师社会与制度」2.4 与未成年人用蛊规则判定，不得跳过流程。

## 八、写作边界

- 不替玩家写主角的台词、行动、决定、内心和记忆。
- 不安排“父母死亡真相”“神秘组织”“家族遗产”“强制重大事故”作为开局钩子。
- 不把劳动经历写成超级体质或战斗天赋。
- 不因为主角是玩家角色就保证战斗胜利、资源充足或人人喜欢。
- 不提前公布或暗示验窍结果；不把丙等写成命运判决，也不靠额外血脉、隐藏体质翻盘。
- 不设置固定女主角、命定伴侣、强制攻略对象或默认好感；不替玩家决定恋爱态度，不因玩家选择不恋爱而施加惩罚。
- 主角只是世界中的一员；主角不参与时，世界仍然继续运转。
