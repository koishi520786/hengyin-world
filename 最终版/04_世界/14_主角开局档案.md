# 14 主角开局档案

> 职责：玩家控制的主角的公开开局基线：年龄、家庭、童工经历、经济状况、身体条件与初始状态。
> 收录范围：只记录已锁定的共同基线；姓名、性别、外貌、性格、喜好、未来目标与未确认经历由玩家决定。
> 检索导航：开局流程回 `05_跑团规则/09_开局流程与初始状态.md`；苏晞回 `04_世界/13_苏晞人物档案.md`；家庭支出回 `04_世界/06_经济科技与交通.md`；学校与未成年人制度回 `04_世界/05_政治组织与社会制度.md`。

## 二、玩家决定的部分

以下内容由玩家自行决定，GM 不得擅自补写：

- 姓名、性别、外貌细节。
- 性格倾向、说话习惯、喜好与厌恶。
- 人生理想、长期目标、对蛊道的态度。
- 已经确认的过去工作、工作地点、收入与具体经历。
- 对苏晞、学校、朋友、金钱和未来的具体看法。
- 开局时的具体现金、随身物品与已确认的家庭安排；未确认的部分按公开基线保守处理。

玩家没有确认的内容，可以随着剧情逐渐补充，但不得一次性编造大量过去，也不得把推测写成已经发生的事实。

## 三、家庭与监护

主角的父母已经去世。父母去世后，主角与从小一起生活的苏晞相依为伴。

两人没有能够长期承担监护责任的亲属，也没有突然出现的好心成年人主动接管他们的生活。不要擅自安排富有亲属、神秘遗产、慈善机构或好心人解决所有生活问题。

制度上可能存在未成年人台账、监护顺位核查、临时监护评估、生活补助、学费减免与社区走访；这些程序可以发生，也可能因为材料、亲属、社区判断而卡住。它们带来行政压力、时间成本和社会目光，不是自动送来的养父母，也不保证获批。

如果社会制度确实存在相关救助、监护或补助机制，可以在剧情中自然出现，但不能直接假设主角一定会获得帮助。具体情况必须符合 `04_世界/05_政治组织与社会制度.md` 的制度与当前人物处境。

## 四、过去几年的生活

父母去世后，为了让两个人能够继续生活，主角在过去几年里一直想办法赚钱。主角曾经外出做童工，以自己的劳动换取收入；这些收入并不宽裕，只能勉强支撑两个人的日常生活。

这段经历造成长期影响：

- 比同龄孩子更早接触社会和工作环境。
- 对金钱、食物、生活开销有更现实的认识。
- 在长期劳动中锻炼了意志力、耐力和身体素质。
- 体力和适应能力相较普通同龄孩子有所提升。
- 但主角仍然只有 11 岁，身体发育尚未完成，不能拥有成年人一样的体能。

必须区分“经过锻炼”和“身体已经成熟”。主角可能因为长期劳动而比同龄人更能吃苦，但仍然会疲劳、受伤、生病、睡眠不足，甚至因过度劳累而晕倒。

有时主角会不想继续工作，会懒惰、厌烦、想休息。现实的经济压力让主角不得不考虑继续赚钱。不要把这段经历简单写成“获得强大体质的奖励”；它既带来成长，也留下疲惫和身体负担。

## 五、家庭经济与居住基线

主角与苏晞居住在云栖花园一套两室一厅、约 68 m² 的老六层住宅。公开基线如下：

| 项目 | 基线 |
|---|---|
| 月租 | 1,850 曜元（约 1,366 CLU），云栖花园老六层中位水平 |
| 物业/公摊 | 约 75—122 曜元/月 |
| 食品 | 两人在家做饭为主，约 950—1,420 曜元/月 |
| 水电燃气 | 约 245—435 曜元/月，夏冬取上限 |
| 医疗/常用药 | 约 110—340 曜元/月，不含住院与大病 |
| 学习用品/校服摊销 | 约 80—245 曜元/月 |
| 交通 | 约 135—300 曜元/月 |
| 衣物/鞋袜 | 约 110—270 曜元/月 |
| 通信/宽带 | 约 80—165 曜元/月 |
| 日常维修/替换 | 约 40—135 曜元/月 |
| 合计 | 紧巴线约 3,670 曜元/月；普通线约 4,300—4,900 曜元/月 |

家中钱财有限，按紧巴线理解只够维持两个人约一年的基本生活；不生病、不补课、不换大件、不外食。一旦出现住院、修房、跨城交通或意外赔偿，见底会加快。不要让补助、亲戚借款或临时工作把日子写成宽裕；它们只能改变现金流，不改变生活成本。

主角的经济状况应通过具体资产表现：当前现金、家中剩余食物、已确定的收入、即将到期的支出、已经购买的物品。不要只用一个抽象的“总资产”数字代替生活细节。

## 六、身体与心理边界

- 11 岁，身体发育未完成；耐力可以高于普通同龄人，但力量、恢复速度和抗病能力仍按儿童处理。
- 长期劳动可能带来茧、旧伤、姿势习惯、对某些工作环境的熟悉，也可能带来疲劳积累和睡眠不足。
- 可以比同龄人更会看人脸色、更早理解工资和欠款，但不等于拥有成年人的社会经验、法律知识或情绪控制。
- 可以坚强，也可以害怕、委屈、想逃避、想被照顾；不要写成没有脆弱面的“小大人”。
- 任何“咬牙坚持”之后都要写代价：低血糖、脱水、发烧、疼痛、注意力下降或恢复变慢。

## 七、开局前状态

开局前，主角：

- 尚未正式开窍。
- 没有空窍。
- 没有真元。
- 不是蛊师。
- 不能正常使用需要真元的蛊虫。
- 隐藏系统尚未激活。

不得提前展示系统界面、任务、奖励或任何明确的系统提示。开窍之后的资质、空窍、真元与修行进度，按 `01_蛊虫/10_蛊道核心机制.md` 与 `05_跑团规则/03_修炼与成长判定.md` 判定，不得跳过流程。

## 八、写作边界

- 不替玩家写主角的台词、行动、决定、内心和记忆。
- 不安排“父母死亡真相”“神秘组织”“家族遗产”“强制重大事故”作为开局钩子。
- 不把童工经历写成超级体质或战斗天赋。
- 不因为主角是玩家角色就保证战斗胜利、资源充足或人人喜欢。
- 主角只是世界中的一员；主角不参与时，世界仍然继续运转。
