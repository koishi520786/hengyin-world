## 秘境分级与评估体系

### 一、秘境的定义

**秘境**：本世界对"具有异常空间、异常生态、异常资源或异常规则，且入口与主世界相连的地理单元"的统一称呼。它是一个**管理术语**，不是力量等级，也不是道德标签。

#### 1.1 十类秘境

| 代号 | 类型 | 说明 | 例子 |
|---|---|---|---|
| T1 | 普通特殊区域 | 无独立空间，但生态/资源异常 | 潮间带蛊材区、地热硫磺谷 |
| T2 | 自然特殊空间 | 有空间异常但不独立，边界不稳定 | 山谷迷雾区、地下溶洞群 |
| T3 | 封闭空间 | 入口有限、内部自洽 | 地下城、冰下湖 |
| T4 | 远古遗迹 | 人造结构，功能不明 | 九城遗址、旧城地下管网 |
| T5 | 古战场 | 大规模死亡残留，真元污染 | 赤焰高原战场带 |
| T6 | 特殊资源区 | 单一资源高度富集 | 元石露头区、仙材矿脉 |
| T7 | 地下空间 | 地下洞窟、管网、矿道 | 裂谷深层、临江地下层 |
| T8 | 失落文明遗址 | 有文字/器物/规则残留 | 石轮、沉城 |
| T9 | 独立小世界 | 独立生态与空间结构，入口稳定 | 北溟深渊门 |
| T10 | 空间异常 | 时间/空间规则异常，不可预测 | 岱泽水眼、时间流速区 |

#### 1.2 术语纪律（硬规定）

| 术语 | 用法 |
|---|---|
| 秘境 | 通用称呼，可用于以上十类 |
| **福地** | **仅**用于符合原著定义的"可种植、可养殖、有独立生态循环、能自给自足的空间"；不是所有秘境都能叫福地 |
| **洞天** | **仅**用于符合原著定义的"依附于福地或独立存在的高阶空间"；本世界已确认洞天数量极少（登记 3 处，见 10） |
| 小世界 | 用于 T9，强调"独立生态"；不用于 T7 地下空间 |
| 遗迹 | 用于 T4/T8；不用于有活生态的空间 |

> **禁止**：把地下洞窟叫"洞天"，把资源区叫"福地"，把所有秘境统称"副本"。原著概念需核对定义后再用，拿不准就写"秘境"。

---

### 二、规模等级（S0—S5）

规模只描述空间大小，**不代表危险或价值**。

| 等级 | 名称 | 参考范围 | 典型 |
|---|---|---|---|
| S0 | 特殊地点 | <1,000 m²，单一房间/节点 | 一间密室、一口井、一段闸门 |
| S1 | 小型区域 | 1,000 m²—10 km² | 建筑群、洞窟、局部地形 |
| S2 | 区域型 | 10—500 km² | 山谷、森林、湖泊、大型地下空间 |
| S3 | 大型区域 | 500—20,000 km² | 多种地形组成的完整区域 |
| S4 | 独立小世界 | 2 万—50 万 km² | 有独立生态与内部结构 |
| S5 | 大型独立空间 | >50 万 km² | 极少数，需国家级勘探 |

**判定规则**：以"已知可进入区域"计算，不以传闻面积计算；未知区域单列"未勘探面积"。

---

### 三、危险等级（D0—D9）

危险等级是**综合评估**，不是蛊师转数换算。

| 等级 | 名称 | 判定 | 建议进入 |
|---|---|---|---|
| D0 | 基本无危险 | 无攻击性生物、无空间异常、可步行 | 普通人，备案即可 |
| D1 | 普通探索风险 | 有迷路、跌落、轻微毒素风险 | 普通人＋向导 |
| D2 | 低度危险 | 有低阶妖兽或野生蛊虫，需基础防护 | 一转以上蛊师，2 人以上 |
| D3 | 明确危险 | 有稳定威胁，需专业装备 | 二转以上，4 人小队 |
| D4 | 危险较高 | 有中阶妖兽/蛊虫群，环境恶劣 | 三转以上，6—8 人，完整补给 |
| D5 | 严重危险 | 有高阶妖兽或空间异常 | 四转以上，10 人，专业队伍 |
| D6 | 极高危险 | 普通队伍可能全灭 | 五转以上，15 人，多重预案 |
| D7 | 重大灾害级 | 溢流可毁城镇 | 六转以上或军队，国家批准 |
| D8 | 战略级 | 可影响区域安全 | 国家力量，军事管制 |
| D9 | 全球灾害级 | 极端未知，几乎不可探索 | 国际共管，原则上禁止进入 |

#### 3.1 危险度评分（六项，各 0—2 分，合计 0—12 → 映射 D 级）

| 因素 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 生物威胁 | 无 | 低阶、可避 | 中高阶、主动攻击 |
| 野生蛊虫 | 无 | 少量、低转 | 成群/高转 |
| 空间异常 | 无 | 轻微、可测 | 强、不可预测 |
| 环境 | 温和 | 恶劣但可适应 | 极端（高温/深水/无氧） |
| 资源短缺 | 水粮充足 | 需自带 | 完全无补给 |
| 特殊规则 | 无 | 有但可遵守 | 违反即死/不可知 |

映射：0—2→D1；3—4→D2；5—6→D3；7—8→D4；9→D5；10→D6；11→D7；12→D8。D0 与 D9 由管理机构特别认定（D0 为无威胁、D9 为全球级）。

> **禁止**：用"三转蛊师能打几只"倒推 D 级。D 级评估的是"队伍能否活着回来"，不是"单挑胜负"。

### 四、资源等级（R0—R9）

资源等级独立于危险等级。低危高值、高危低值都常见。

| 等级 | 名称 | 内容 | 市场含义 |
|---|---|---|---|
| R0 | 无资源价值 | 无可采集物 | 仅科研/训练 |
| R1 | 普通资源 | 常见蛊材、水、木材 | 本地市场 |
| R2 | 常见修炼资源 | 低转蛊材、普通元石碎料 | 区域市场 |
| R3 | 有一定经济价值 | 中阶蛊材、成规模元石 | 全国市场 |
| R4 | 稀有蛊材与高值材料 | 高转蛊材、稀有金属 | 国际市场 |
| R5 | 珍贵资源与特殊蛊虫 | 独特蛊种、仙材原料 | 战略采购 |
| R6 | 极稀有仙材/高阶资源 | 仙蛊炼材、洞天级材料 | 国家级储备 |
| R7 | 战略资源 | 可影响一国产业 | 出口管制 |
| R8 | 国家级/全球级稀有 | 唯一性资源、仙蛊 | 国际争夺 |
| R9 | 极特殊 | 影响规则本身的材料 | 国际共管/禁止交易 |

#### 4.1 资源评级必须写清四件事

1. **稀有程度**：全球已知产地数量。
2. **储量**：已知可采量（吨/枚/株）。
3. **采集条件**：是否需要特定蛊虫、许可、季节、队伍。
4. **市场需求**：谁买、买多少、价格区间（与 18 经济挂钩）。

#### 6.1 权利链（必须分开记录）

| 权利 | 含义 | 常见错配 |
|---|---|---|
| 发现权 | 谁先记录 | 发现者常被误认为所有者 |
| 登记权 | 谁在官方名录登记 | 登记国≠控制国 |
| 所有权 | 法律主张 | 争议区常见多方主张 |
| 控制权 | 实际能封锁/管理 | 强国控制他国领土内秘境 |
| 开发权 | 谁可商业开发 | 常被租赁/特许 |
| 收益权 | 谁分成 | 与开发权分离 |

> **铁律**：发现秘境不等于拥有；拥有不等于能控制；能控制不等于能开发；能开发不等于能独占收益。四句话是本世界经济与政治的常见冲突源。

### 十、事故—关闭—重启—责任分配

> 这一节只给“出了事之后怎么收尾”的统一口径，不替代 `04_世界/09_秘境与特殊空间.md` 各秘境的既有事故记录，也不把每次小事故都升级成全国审批。

#### 10.1 四级事故

| 级别 | 触发（满足一项即可） | 谁先动 | 关闭权限 | 重启门槛 |
|---|---|---|---|---|
| **事件** | 轻伤、局部溢流、单只低阶妖兽逃出、设备故障无死亡 | 运营方现场处置；报本地秘境管理站备案 | 运营方 24 小时内可临时关闭 | 运营方自检＋管理站抽查 |
| **事故** | 重伤、3 人以上受困、低阶妖兽群逃出、资源区塌方 | 本地管理站＋运营方；2 小时内到场 | 本地管理站可封 72 小时 | 结构复检＋逃逸生物清点＋路线重勘 |
| **灾难** | 死亡、S3 以上核心区失稳、高阶妖兽或危险蛊材外泄、城市接口受影响 | 国家秘境管理机构（如 FRA）接管；RMC 知会 | 国家机构可无限期关闭 | 国家验收＋公开调查报告＋保险复核 |
| **封门** | 秘境规则突变、空间通道不稳定、无法排除的未知风险 | 国家机构＋国际共管方（跨境时） | 长期封存，设警戒线 | 重新评级为 S/D/R 后方可申请 |

> 普通“事件”不需要国家级审批；只有死亡、外泄、跨境、核心区失稳才升级。不要把游客崴脚写成封城。

#### 10.2 处置顺序

1. **先救人**：撤离、止血、清点失联；不以“先查责任”耽误救援。
2. **再封口**：按上表权限关闭入口，设警戒线与误导防护；不得用普通路障冒充蛊道封印。
3. **后取证**：记录时间、SITE、触发点、逃逸生物、伤亡、设备状态、天气/潮汐、队伍资质；证据链不完整不得写“原因已查明”。
4. **再定责**：运营方、带队蛊师、队员、设备供应商、监管方分别列；没有证据不把责任推给“临时工”或“妖兽异常”。
5. **最后谈重启**：重启不是“开门”，是重新评级、重新投保、重新排路线。

#### 10.3 责任分配的五条

- **运营方**：设施、预警、救援、日常巡检的第一责任；不能把许可卖出去就免责。
- **带队蛊师**：路线、队员状态、情报核对的直接责任；隐瞒队员伤病或超范围带队，责任加重。
- **队员**：违反明示警戒、擅自离队、隐瞒身体状况，承担相应责任；不因“活着出来”就免责。
- **监管方**：评级、许可、抽查、事故公开；长期不抽查、压事故报告，承担监管责任。
- **跨境/共管**：按 601《垠格公约》与 RMC 规则分责；没有共管协议时，不默认“谁发现谁全责”。

#### 10.4 重启检查清单

- 结构：入口、通道、核心区是否稳定；是否有新的塌方/溢流。
- 生物：逃逸数量、巢位、食物链是否变化；是否出现不该出现的物种。
- 路线：旧路线是否还在；备用撤离线是否可用。
- 人：带队蛊师是否重新认证；运营方是否补足救援队。
- 钱：保险是否恢复；赔偿是否结清；是否因事故被银行抽贷。
- 信息：事故报告是否公开到“可查询”的程度；谣言是否已有正式说法。

#### 10.5 写作用法

- 小事故写“停业、赔偿、谣言、重新开业”，不要每次升级成国家阴谋。
- 大事故写“调查、责任切割、保险拒赔、地方财政、行业规则变化”，不要只写“死了几个人”。
- 728 年临江中学生误入地下层可作为“事故”级样本：学校、管理站、运营方、家长各有一份责任，不能只怪学生。
- 事故后不自动恢复：伤势、真元、蛊虫、设备、信任、牌照都要逐项处理；这是 `04_世界/09_秘境与特殊空间.md` 与跑团战斗通则的共同底线。

### REALM-012 临江地下层

| 项目 | 内容 |
|---|---|
| 编号/名称 | REALM-012 临江地下层 |
| 类型 | T7 地下空间 |
| 所在 | 苍垠大陆·曜川联邦·临江市·中城区 |
| 坐标 | 62.5°E 24.7°N（G25-N12） |
| 入口 | 中城区江堤路 9 号"旧渠闸"（LOC-101-0012）；入口 1 处（市政管控） |
| 规模/危险/资源 | S1／D3／R4 |
| 稳定/状态 | ST-1 永久稳定／DS-07 部分开放（市政管控） |
| 管理者 | 临江市政府＋FRA 临江分局；GAB 临江办事处监督 |
| 已知/未探 | 已知 1.2 km²／未探 0.8 km² |
| 资料可信度 | 【已登记】＋【部分勘探】 |

**一、概况**：1987 年城市排水改造时，工人从旧渠闸进入一段"比图纸长得多"的砖砌管网；后经 FRA 勘探，确认存在局部空间折叠。它不是"宝藏秘境"，而是**城市基础设施风险点**：管网与折叠区相连，溢流或塌陷会直接影响中城区。

**二、外部地理**：临江市中城区江堤路，地面高程 12 m；地下 18—42 m；管网年代 1890—1930 年代。

**三、入口**：旧渠闸（唯一已知入口），铁门＋值守室；进入需市政、FRA、GAB 三方会签；民间无通道。

**四、空间结构**：砖砌排水管网（约 640 m）→ 折叠区（同一段管道重复出现，路径长度约为实际 3.2 倍）→ "干室"（无水空腔，约 1,200 m²）→ 未探段。

**五、内部地图**：A 区旧渠闸、B 区折叠管网、C 区干室、D 区未探段。详见 14。

**六、生态**：鼠、蟑、湿生蛊虫；折叠区有"回声蛊"（低转，无害）；无大型生物。

**七、蛊虫与资源**：低转野生蛊虫、旧城器物（清末民初）、砖石蛊材；R4 主要来自"折叠区砖材"（含微量真元残留）；仙蛊无。

**八、危险**：塌陷、积水、缺氧、折叠区迷路（重复路径导致方向感丧失）、溢流时水位骤升。

**九、资源价值**：R4；因市政管控，商业价值低；黑市把"干室"传成"旧城宝库"，实际考古价值高于经济价值。

**十、开发历史**：1987 发现→1990 首次勘探→1994 封闭→2008 改造为"市政风险监测点"→2019 起允许科研进入→735 年起允许特许探索（每季 6 队）。

**十一、政治商业**：市政府（安全责任）、FRA（监测）、GAB（蛊虫登记）三方共管；地产商曾试图以"秘境景观"抬高周边房价，被叫停；黑市"旧城宝库"传闻屡禁不止。

**十二、进入条件**：二转以上、4 人、市政＋FRA＋GAB 三方许可、保险；D3；禁止携带开采设备；限时 6 小时。

**十三、地图完整度**：已知 60%（折叠区 40%、干室 80%、未探段 0%）。

**十四、特殊事件**：
- 1994 年"七·九溢流"：暴雨导致折叠区水位 3 小时涨 4.2 m，2 名工人被困，救出。
- 2011 年"回声蛊"被发现，确认为低毒 harmless，登记为本地特有种。
- 728 年两名中学生从排水口误入折叠区，36 小时后在干室被找到，引发全市对"地下层"的关注与谣言。
- 738 年市政在旧渠闸加装双层铁门与水位警报。

> **叙事注意**：REALM-012 的存在不是"主角专属副本"。它是城市基础设施的一部分，有值守、有许可、有事故记录、有房地产投机、有中学生误入的新闻。主角若进入，必须面对这些既有条件，而不是发现一个无人知晓的宝库。

### 十四、探索路线设计原则（写新秘境时套用）

1. **入口必须有约束**：许可、潮位、月相、季节、军方，至少一项。
2. **必须有撤退点**：每 2—4 h 路程设一个可撤回的安全点。
3. **资源点不在入口**：至少 1.5 km 深，且需要特定通行方式。
4. **危险与资源不成正比**：R 高的地方 D 不必高（如 003 蛊纹砖在 D4 区），D 高的地方 R 可以低（如 007 深处）。
5. **空间异常必须可被"正确操作"破解**：标记、反向、潮汐表、月相表——不是靠"看一眼就懂"。
6. **每次探索必须有后续成本**：运输、登记、税、被盯上、受伤恢复。
