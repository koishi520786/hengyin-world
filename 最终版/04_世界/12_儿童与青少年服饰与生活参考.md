# 12 儿童与青少年服饰与生活参考

> 职责：专门给儿童/青少年角色的服饰、校园生活、家庭生活、娱乐与社交提供写作参考；重点是 11 岁苏晞与同龄人。
> 收录范围：6—9、10—12、13—15、16—18 岁的穿搭与生活差异；服装品类；家庭经济/气候/活动场景；校园生活；常见偏差。
> 检索导航：全球服饰回 `10_全球服饰文化.md`；日常生活回 `11_全球日常生活文化.md`；年龄表达回 `05_跑团规则/07_年龄表达与对话参考.md`。
> 边界：所有儿童/青少年描写必须适龄、非性化；重点写活动、舒适、家庭、校园与成长，不写成人化身体凝视。

## 一、总原则

1. **先场景，后衣服。** 今天要上学、做家务、下雨、运动、过节，衣服由此决定。
2. **先活动，后好看。** 儿童衣服要方便跑跳、坐地、写字、干活；好看是次要。
3. **先家庭，后时尚。** 衣服会旧、会短、会补、会接；买新衣是事件，不是默认。
4. **先年龄，后风格。** 11 岁不是小大人；不要用成人剪裁、性化描述、夸张配饰。
5. **先地区，后通用。** 热带/寒带/高原/海岛/地下城的衣服不同；不要把所有孩子写成同一种校服。

## 二、年龄分段

### 2.1 6—9 岁

- **穿搭**：T恤/衬衫、针织开衫、背带裤、短裤/长裤、连衣裙、运动鞋/凉鞋；容易弄脏，家长常备换洗衣。
- **校园**：幼儿园/小学低年级；手工、涂鸦、户外活动；书包/水壶/外套。
- **生活**：作业少，玩得多；对钱的概念弱；会直接要东西；朋友关系直接。
- **写作注意**：不要写长段抽象对话；不要让孩子承担成人家庭责任。

### 2.2 10—12 岁（重点 11 岁）

- **穿搭**：校服/运动服、衬衫、针织衫、开衫、卫衣、百褶裙/长裤/短裤、背带裤、帆布鞋/运动鞋/雨靴；按季节加外套/帽子/围巾。
- **校园**：高年级小学/初中预备；课业变多、值日、班会、运动会、合唱/社团；朋友关系开始有小团体。
- **生活**：能做家务、能自己上学/回家（按地区）、有零花钱/预算意识；开始在意形象与同伴看法。
- **写作注意**：可以有自己的主见、计划、拒绝；但表达仍具体、当下、带情绪；不要写成成人或幼儿。

### 2.3 13—15 岁

- **穿搭**：校服/运动服、卫衣、牛仔、针织、短裙/长裤、外套、帆布鞋/板鞋；开始有自己的风格偏好。
- **校园**：初中/高中初期；考试、社团、同伴压力、隐私需求；可能疏远家人。
- **生活**：零花钱/兼职（按法律与文化）、朋友影响力上升、开始有自己的秘密。
- **写作注意**：独立感增强，但不是成人化；不要写成人恋爱/性化内容；距离感不等于背叛。

### 2.4 16—18 岁

- **穿搭**：接近成人，校服/便服/工作服/运动服；开始为面试/毕业/未来准备正式服装。
- **校园**：高中后期/大学预备；考试、毕业、打工、实习；未来规划压力。
- **生活**：更独立，但仍可能冲动/理想主义/受同伴影响。
- **写作注意**：不是所有 16—18 岁都成熟；写“正在成为成人”，不是“已经是成人”。

## 三、服装品类与写作细节

### 3.1 上装

- T恤、衬衫、针织衫、开衫、卫衣、毛衣、校服外套、防晒衣、雨衣、厚外套/羽绒服。
- 细节：领口松了、袖口磨边、扣子换过、下摆短了、颜色洗淡了、口袋里有东西。

### 3.2 下装

- 短裤、长裤、牛仔裤、工装裤、百褶裙、及膝裙、背带裤、运动裤。
- 细节：膝盖磨白、裤脚卷起、裙腰改过、口袋装不下书、雨天裤脚沾泥。

### 3.3 鞋袜

- 运动鞋、帆布鞋、凉鞋、雨靴、雪地靴、室内鞋、拖鞋。
- 细节：鞋底磨平、鞋头踢花、袜子滑下去、鞋带系不好、雨天鞋里进水。

### 3.4 配饰

- 书包、水壶、帽子、围巾、手套、发绳、发夹、手表、小挂件。
- 细节：书包带子太长、水壶掉漆、发绳断过、挂件是同学送的。
- **边界**：不要写成成人首饰/化妆/身材展示；儿童配饰以实用、纪念、兴趣为主。

### 3.5 校服

- 不同学校可有不同颜色/款式：白衬衫+深色裤/裙、运动服、西装式、水手式（按地区参考）。
- 校服状态：太大/太小、改过、洗得发白、周一必须穿、体育课换运动服。
- 不要每场都换新校服；也不要所有学校都穿同一种“动漫制服”。

### 3.6 家居服/睡衣

- 旧T恤、短裤、棉质睡衣、拖鞋、毯子；冬天加厚袜子/毛衣。
- 细节：睡衣图案是动画角色、裤脚短了、袖子太长、 borrowed from sibling/parent。
- **边界**：不要性化描写；重点舒适、家庭感。

## 四、家庭经济与衣服

| 家庭情况 | 衣服可能的样子 | 写作注意 |
|---|---|---|
| 宽裕 | 合身、款式多、换季添新；也可能不追求名牌 | 不要写成炫耀；衣服仍服务于场景 |
| 普通 | 校服+几件日常换洗；买新衣看季节/长个子 | 会有旧衣、改衣、等打折 |
| 紧张 | 接哥哥/姐姐的旧衣、补过、改过、短一截；买新衣是事件 | 不要写成“可怜”；写她的在意、嘴硬、珍惜 |
| 突然变故 | 衣服不合身/来不及换/旧衣；可能接受亲友帮助 | 不要用衣服羞辱人物；写实际困难与尊严 |

**示例**：苏晞的袖子短了一截，她把它往下拉；哥哥说要买新的，她先说“还能穿”，过了两天才承认“手腕冷”。这比直接写“家里很穷”有效。

## 五、气候与场景

| 场景 | 衣服要点 | 细节 |
|---|---|---|
| 热带/雨季 | 轻薄、透气、防晒、防雨；凉鞋/雨靴 | 衣服干得慢、霉味、备换洗衣 |
| 寒带/雪天 | 分层、厚外套、帽子/手套/围巾、防滑靴 | 室内外温差、进门脱外套、雪水弄湿裤脚 |
| 高原/山地 | 防风、防晒、保暖；登山鞋/外套 | 紫外线、风大、早晚冷 |
| 海岛/船家 | 防水、防晒、防滑；凉鞋/胶靴 | 盐渍、潮气、船上来回 |
| 地下/矿区 | 耐磨、反光、防尘；工装/安全帽 | 灯带、通风、灰尘、洗不干净 |
| 校园 | 校服/运动服/室内鞋；书包/水壶 | 值日、体育课、下雨、校服洗没干 |
| 节庆 | 传统/亮色/配饰；只在节庆穿 | 不合身、借来的、怕弄脏 |
| 正式场合 | 衬衫/连衣裙/小西装；干净、合身 | 不习惯、拘谨、鞋子磨脚 |

## 六、校园生活写作参考

### 6.1 一天的基本节奏

- 起床、早饭、上学、早读/班会、上午课、午饭/午休、下午课、值日/社团、放学、作业、家务、晚饭、睡前。
- 不同地区/学校有差异：有的半天课，有的寄宿，有的校车，有的步行；不要所有学校都一样。

### 6.2 可写的小事

- 今天谁值日、谁忘带作业、谁被老师表扬/批评。
- 运动会/合唱/手工课/实验课/春游/家长会。
- 同桌借橡皮、朋友闹别扭、转学生、班级流行的小东西。
- 校服洗没干、鞋带断了、书包带子坏了、午饭不好吃。

### 6.3 家庭与学校冲突

- 家长会/加班/接晚了/作业没签字/校服没洗。
- 学校要买材料/活动费，家里预算紧张。
- 孩子想参加活动，但要做家务/照顾家人。
- 这些冲突比“校园恋爱”更适合 11 岁。

## 七、家庭生活写作参考

- **家务**：洗碗、做饭、晾衣、扫地、倒垃圾、照顾弟妹/老人；按年龄和能力分配，不是所有孩子都做同样的事。
- **零花钱**：少量、按任务/节日；孩子会记账、会攒、会买小东西；不要写成无限资源。
- **家庭空间**：公寓/自建房/船屋/地下城；孩子的房间/桌子/储物角；隐私有限。
- **家人关系**：父母/监护人/亲戚/邻居；谁工作、谁生病、谁不在；孩子对家庭变化的反应。
- **边界**：不写儿童承担成人性/暴力/恋爱内容；家庭困难可以写，但不把儿童当作成人替代品。

## 八、娱乐与社交

- **常见**：动画/漫画/游戏、贴纸/卡片、手工、看书、听广播/音乐、和朋友在小区/公园/市场/河边玩。
- **花钱的**：零食、贴纸、小玩具、电影、集市、游泳/滑冰/球场；要受家庭预算限制。
- **不花钱的**：跳皮筋/捉迷藏/散步/看蚂蚁/做手工/交换贴纸/在图书馆看书。
- **社交**：同学、邻居孩子、亲戚；有小团体、秘密、闹别扭、和好；不是成人社交。
- **写作注意**：娱乐要具体到“玩什么/和谁/在哪里/花不花钱”，不要只写“她开心地玩”。

## 九、常见偏差

| 偏差 | 表现 | 修正 |
|---|---|---|
| 性化 | 描写儿童身体曲线、成人剪裁、恋爱暗示 | 回到活动、舒适、家庭、校园；非性化 |
| 成人化 | 儿童穿成人时装、化成人妆、谈成人关系 | 按年龄/场景；用家庭经济与活动限制 |
| 幼儿化 | 大量蕾丝/蝴蝶结/叠词/装嫩 | 保留年龄感，但给主见、计划、拒绝 |
| 模板化 | 所有女孩都百褶裙+过膝袜+脸红 | 按地区/学校/家庭/性格设计；裤装/运动服也常见 |
| 时装秀 | 每场换新衣、无磨损、无价格 | 衣服会旧/短/补；买新衣是事件 |
| 贫穷奇观 | 用破旧衣服博同情/羞辱人物 | 写具体困难与尊严，不猎奇 |
| 无场景 | 只写“她穿着漂亮的裙子” | 写为什么穿、要去哪、方便吗、谁买的 |

## 十、写作自检

1. 这身衣服，符合今天的天气/场景/活动吗？
2. 这身衣服，符合家庭经济和衣服的状态吗？
3. 这身衣服，符合她的年龄，而不是成人/幼儿吗？
4. 有没有一个具体细节（旧、短、补、借、脏、不合身）？
5. 这段描写，是在写人物生活，还是在做时装展示？
6. 有没有任何性化/成人化的目光？如果有，删掉重写。
7. 这个孩子，除了衣服，有没有自己的朋友/兴趣/烦恼/任务？
8. 如果把衣服换掉，人物还成立吗？如果不成立，说明人物只剩衣服。
