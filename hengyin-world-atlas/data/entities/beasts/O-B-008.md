# O-B-008 泥囊螈

> 来源：《原创妖兽图鉴》v1.1 ｜ 状态：proposed（原创设定）｜ 分区：O-B

## 基本资料

- **编号**：O-B-008
- **名称**：泥囊螈
- **别名**：腐囊螈、沼皮囊、湿坟虫（沼泽周边俗称）【原创设定】
- **生物类别**：妖兽·两栖型（无尾目巨型化，非蛊师改造）【原创设定】
- **起源类型**：天地异变＋诅咒或死亡转化（【合理推测】：腐化沼泽场能长期浸染两栖种群，非人工炼制、非单一诅咒事件可证）
- **威胁等级**：中（契约固定；机制推导见第六、十九节）
- **体型**：体长 2.4 m／体重约 260 kg；独居，偶见 2～3 头共食一具腐体【原创设定】
- **栖息环境**：低洼腐殖沼泽、静水回湾、河岸淤泥带、河口泥滩【原创设定】
- **分布区域**：城郊湿地—旧河道—河口泥滩；不入硬化排水渠与干燥城区（见第十七节）
- **智慧程度**：普通动物：趋腐、趋湿、避光避燥，仅具摄食与扑压反射；无个体识别、无学习、无指挥行为【原创设定】
- **群居方式**：独居／临时共食，无等级、无首领、无协同【原创设定】
- **主要食物**：腐肉、腐殖质、淤积有机碎屑；机会捕食小型活体【原创设定】
- **生态定位**：腐食者／机会捕食者／被动寄生野生蛊的「移动培养基」【原创设定】
- **资源价值**：中（湿皮胶质、黏液囊分泌物、体内野生蛊样本；取蛊成本高于肉材）【原创设定】
- **资料状态**：本物种为【原创设定】；所引 C-G／O-G／C-K／O-K 编号均回 v3.0 权威文件逐条核对；**未识别者一律写【未识别野生蛊虫】**，不指定已知蛊名
