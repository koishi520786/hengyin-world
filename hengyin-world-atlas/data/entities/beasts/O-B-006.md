# O-B-006 沉沙螯

> 来源：《原创妖兽图鉴》v1.1 ｜ 状态：proposed（原创设定）｜ 分区：O-B

## 基本资料

- **编号**：O-B-006
- **名称**：沉沙螯
- **别名**：流沙剪、沙底伏螯【原创设定】
- **生物类别**：妖兽·甲壳型
- **起源类型**：环境异化（流沙）
- **威胁等级**：中高（契约锚定，不得改写）
- **体型**：甲宽约 1.2～1.6m、体重约 40～70kg【原创设定】；具体部位分级【待考证】
- **栖息环境**：荒漠；必需流沙伏击地形
- **分布区域**：荒漠流沙带、戈壁管道出口、沙丘背风塌陷区
- **智慧程度**：普通动物偏高（无语言、无指挥蛊群能力）
- **群居方式**：独居，各守一段流沙陷阱微地形
- **主要食物**：落单猎物（含 O-B-002 隧锈鼠、落单 O-B-005 草潮羚）
- **生态定位**：荒漠伏击捕食者
- **资源价值**：甲壳／螯／毒相关材料【待考证】；伴生毒道低转蛊群另计
- **资料状态**：【原创设定】完整；蛊／杀招编号【原著明确】／【原创设定】／【待考证】
