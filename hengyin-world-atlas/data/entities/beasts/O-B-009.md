# O-B-009 潮脊鲸

> 来源：《原创妖兽图鉴》v1.1 ｜ 状态：proposed（原创设定）｜ 分区：O-B

## 基本资料

- **编号**：O-B-009
- **名称**：潮脊鲸
- **别名**：脊帆鲸、深潮滤脊、界海长鸣（近海观测站俗称）【原创设定】
- **生物类别**：巨兽（鲸型海生巨兽，远古遗种孑遗）【原创设定】
- **起源类型**：远古遗种：地质期元气海槽孑遗种群，非天地异变新产物、非人工炼制【原创设定】
- **威胁等级**：高（契约固定；机制推导见第六、十九节）
- **体型**：体长 28 m／体重约 90 t；独游或 2～4 头松散小群【原创设定】
- **栖息环境**：大陆架外缘—深海海槽，滤食期上浮至近海；洄游跨近海【原创设定】
- **分布区域**：外海深水—近海洄游廊道；不入内河、港湾浅水与市中心水域（见第十七节）
- **智慧程度**：**接近人类（无文明）**：有个体识别、迁徙路线记忆、规避声呐与船只的判断，但无语言、无工具、无组织、无文明；**不具空窍／真元／炼化能力**【原创设定】
- **群居方式**：独游为主，偶 2～4 头松散同行；无等级、无协同围猎、无指挥行为【原创设定】
- **主要食物**：滤食：元气絮团、磷虾群、浮游藻华；偶捕食大型（含 O-B-007 洄游群）【原创设定】
- **生态定位**：顶级滤食者／跨近海物质与元气转运者／稀有研究物种【原创设定】
- **资源价值**：**观测与科研价值极高、材料价值极低**：活体声学、抗压结构、伴生蛊群研究；禁止商业取料【原创设定】
- **资料状态**：本物种为【原创设定】；所引 C-G／O-G／C-K／O-K 编号均回 v3.0 权威文件逐条核对；未识别者一律【未识别野生蛊虫】
