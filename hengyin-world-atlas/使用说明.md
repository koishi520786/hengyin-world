# 衡垠世界图集 · 简单使用教程

> 版本 2.0.0 ｜ 2026-11-13 ｜ 全程零费用、无需账号、无需联网、无需购买服务器或 API

---

## 一、最快用法（推荐，什么都不用装）

**直接双击 `衡垠世界图集.html`。**

网站的所有资料都已经内嵌在网页里，用 `file://` 打开也能：

- 浏览首页、世界、临江市、北城区、云栖街道、云栖花园、蛊道、生灵、秘境、建设状态
- 用顶部搜索框查名称或编号（例如 `CITY-101`、`O-B-012`、`蛊坊街`）
- 打开生活圈地图、点 POI
- 浏览「档案」里的 1,483 条实体总索引和每一条的实体档案
- 在「导出」页一键下载 AI 资料包 ZIP
- 在实体档案页导出单条实体资料（Markdown / JSON）

> 不需要启动服务、不需要 Python、不需要联网。唯一可能用到的外部字体是可选的，缺失时自动回退到系统中文字体，不影响功能。

## 二、第二种用法：启动本地网站服务（可选）

双击 **`启动网站.bat`**。

它会：

1. 自动检测电脑上的 Python（免费软件）；
2. 只在本机 `127.0.0.1` 开一个小型静态服务；
3. 自动打开浏览器，窗口里显示网址（一般是 `http://127.0.0.1:8765/`）。

启动服务之后，额外可以在浏览器里直接打开这些地址看原始资料：

| 内容 | 地址（端口以窗口显示为准） |
|---|---|
| 网站首页 | `http://127.0.0.1:8765/` |
| 实体总索引 | `http://127.0.0.1:8765/data/world-index.json` |
| 关联关系 | `http://127.0.0.1:8765/data/relationships.json` |
| AI 阅读入口 | `http://127.0.0.1:8765/data/AI_START_HERE.md` |
| 建设/冲突报告 | `http://127.0.0.1:8765/data/reports/` |

**关闭窗口或按 `Ctrl+C` 即停止服务。**

如果电脑没有装 Python，脚本会提示你并**自动退回直接打开 HTML**——网站功能一个不少，只是不能通过网址直接翻 `data/` 里的文件。

> 备用启动方式（懂命令行的用户）：在本目录执行 `python tools/serve.py`，或 `python -m http.server 8765`。两者都只监听本机，不对外公开。

## 三、把资料交给 AI（本阶段最重要的新功能）

### 第 1 步：导出资料包

- 打开网站 → 顶部导航「导出」→ 点击蓝色大按钮 **「一键导出 AI 资料包（ZIP）」**。
- 浏览器会下载一个 `衡垠AI资料包_日期.zip`。
- 项目目录里也有一份现成的 **`衡垠AI资料包.zip`**，内容和按钮导出的一致，可以直接拿去用。

### 第 2 步：上传给 AI

把 **整个 ZIP** 上传给支持文件读取的 AI（或解压后把文件夹一起上传）。

### 第 3 步：告诉 AI 先读哪一份

可以直接复制下面这句话发给 AI：

> 请先完整阅读 `AI_START_HERE.md`，再按 `world-index.json` 查实体编号、按 `relationships.json` 查关联。`status=proposed` 不是既定事实，`coverage=index` 不是完整档案；R-B 不是本世界物种；资料冲突请并列说明，不要自行调和或编造。

### 第 4 步：更新资料后

改过 `data/` 里的资料后，双击 **`重新生成资料.bat`**，会重新生成索引、报告、ZIP，并同步网页数据岛。然后重新导出或直接使用新的 ZIP。

## 四、三种能力不是同一件事（请务必分清）

| 能力 | 现在能不能用 | 说明 |
|---|---|---|
| ① 本地网站浏览 | ✅ 可以 | 人用浏览器打开本项目，双击 HTML 或运行 `启动网站.bat` |
| ② 导出资料包给 AI 读取 | ✅ 可以 | 你手动下载 ZIP、手动上传给 AI |
| ③ 云端 AI 自动实时查询本地网站 | ❌ **不可以** | 未实现。未来接口设计见 `data/AI_INTEGRATION_GUIDE.md` |

**ChatGPT、DeepSeek、Claude 等云端 AI 无法自动访问你电脑上的本地网站或 `localhost`。** 只有上传资料包，AI 才读得到。本项目也没有配置任何 API、数据库或付费服务。

## 六、资料放在哪、能不能改

```
hengyin-world-atlas/

├─ index.html                入口跳转页
├─ 启动网站.bat              双击开本地服务
├─ 重新生成资料.bat          双击重建资料包
├─ 衡垠AI资料包.zip          给 AI 的完整资料包
├─ 使用说明.md               本文件
├─ 本次修改记录.md           本次改了什么
├─ AI_START_HERE.md          给 AI 的第一份文件（data/ 正式文件的镜像）
├─ AI_INTEGRATION_GUIDE.md   未来接口指南（镜像）
├─ DATA_SCHEMA.md            字段说明（镜像；详细版在 data/DATA_SCHEMA.md）
├─ 数据结构说明.md           字段速查指针
├─ data/                     ★ 唯一正式数据源
│  ├─ world-index.json       实体总索引
│  ├─ relationships.json     关联关系
│  ├─ manifest.json          版本、统计、校验
│  ├─ entities/              按类型保存的实体记录（改资料改这里）
│  ├─ gazetteers/            地方志正文
│  ├─ rules/                 世界与蛊道规则
│  ├─ sources/               来源、版本、统计口径
│  ├─ reports/               冲突、缺失、待确认、路由报告
│  ├─ AI_START_HERE.md       ★ 给 AI 的第一份文件
│  ├─ AI_INTEGRATION_GUIDE.md
│  └─ DATA_SCHEMA.md
└─ tools/                    构建与本地服务脚本
   ├─ build_kb.py            统一数据层构建器
   ├─ serve.py               本地 HTTP 服务
   └─ patch_site.py          第一版结构补丁（已执行过，不用再运行）
```

**要改实体资料**：编辑 `data/entities/*.json`，然后双击 `重新生成资料.bat`。网页和 ZIP 会一起更新，不会出现两份对不上的数据。

**不要**直接改 HTML 里 `<script id="kb-data">` 这类数据岛，也不要改根目录的 `AI_START_HERE.md` 等三份镜像——它们都是自动生成的，下次重建会被覆盖；正式文件在 `data/`。

## 七、常见问题

**Q：双击 HTML 打开后搜索／导出能用吗？**
能。数据已内嵌，`file://` 下不需要读取外部 JSON。

**Q：导出按钮没反应？**
用较新的 Chrome / Edge / Firefox；某些浏览器会拦截自动下载，留意地址栏右侧的下载提示。也可以直接拿项目目录里的 `衡垠AI资料包.zip`。

**Q：没有 Python 会不会不能用？**
不会。`启动网站.bat` 检测到没有 Python 会自动退回直接打开 HTML。Python 只在「重新生成资料」时需要，且是免费软件。

**Q：AI 说它能直接访问我的本地网站？**
不能。请按第三节手动上传 ZIP。

**Q：为什么有些条目写着「仅索引」？**
因为原始资料只给了编号和名称。本站没有替它编造档案。哪些已导入、哪些还缺，见「导出」页的《资料缺失与完整度报告》或 `data/reports/资料缺失与完整度报告.md`。

**Q：编号冲突怎么办？**
本站没有擅自改原档，只做了并列登记。见 `data/reports/编号冲突检查报告.md`（C-01—C-08）和 `data/reports/待确认清单.md`，需要你裁定后再改 `data/`。
