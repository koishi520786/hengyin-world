# 【原创设定】回声蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-001 |
| 名称 | 回声蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 音道 |
| 核心用途 | 侦查（回声标记与追踪） |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：形如一只干瘪的空蝉蜕，半透明，腹内无实。
- 大小：拇指盖大小。
- 颜色：通体灰白，边缘泛一层极淡的蓝。
- 形态特征：背上有三道环纹，环纹随最近一次「回响」的强弱或深或浅。
- 特殊视觉效果：催动时，空蝉蜕会轻轻震颤，发出人耳几乎听不见的嗡鸣；嗡鸣撞上障碍后会折返，在蛊师心窍中形成「第二重声响」。

### 二、核心能力

- 基础能力：向四周发出一次不可闻的低频回响，声波遇到障碍折返，蛊师据此在脑海中描出周围环境的粗糙轮廓。
- 作用机制：低频声穿透力强、衰减快，只适合近距；声波并非「看见」，而是「听见形状」，故无法分辨颜色、文字，只能勾勒凹凸、疏密与远近。
- 作用对象：半径约十五步内的实体障碍。
- 能力范围：十五步，越远越模糊。
- 效果强度：能辨明通路、门窗、沟壑与静止的大物；对贴地匍匐、柔软吸音之物几乎无效。
- 使用限制：每次催动需持续供真元；环境中噪声越大、杂响越多，轮廓越乱；对有音道修为者，这回响本身可被其察觉。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，音道或兼修音道者炼化更易 |
| 炼化难度 | 低；回声蛊意志微弱 |
| 特殊要求 | 无 |
| 炼化风险 | 几乎无 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 静水；每三日一碗 |
| 辅助食物 | 铜铃的锈屑（可让下次回响更清） |
| 频率 | 每三日一次 |
| 成本 | 低 |
| 特殊环境 | 若在「无声之室」（四面皆吸音软泥）中喂养一次，效果维持更久 |
| 断食后果 | 回响逐次变闷，最终无法勾勒轮廓，蜕壳硬化裂开、蛊亡 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 需持续供真元；环境偏静方可用 |
| 消耗 | 二转赤铁真元，低耗、可连发 |
| 范围 | 十五步内，越远越模糊 |
| 持续 | 单次回响一瞬，可连续催动 |
| 缺陷 | 无攻击力；无法辨字辨色；易受噪声干扰；对吸音软物、匍匐贴地之物近乎失明 |
| 克制 | 克制以视觉扰乱／迷幻为主的隐匿（因它不靠眼睛）；被音道反制（察觉并扰乱回响）、被水道「静水」环境削弱 |
| 优势 | 消耗低、可连发、不依赖光线，黑暗中亦可用；能识破视觉遮蔽但非实体隐藏 |
| 适用场景 | 洞穴、密道、浓雾、黑夜、废墟等目不能视之地 |
| 不适用场景 | 市集、战场、风口等嘈杂处；面对专精音道的对手 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|

| 过程 | 在完全无声的静室内，以真元浸润蝉蜕三日，令空壳记住「折返之声」 |
| 难度 | 低 |
| 成功率或风险 | 成功率较高；失败则蝉蜕碎裂，损失材料 |

# 【原创设定】余烬蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-002 |
| 名称 | 余烬蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 炎道 |
| 核心用途 | 资源（余火回收炼成可复用火种） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一撮永不熄灭的暗红灰烬，无固定形状，被微弱的火星托起悬浮。
- 大小：约一握之灰。
- 颜色：暗红为主，偶见金点闪灭。
- 形态特征：靠近尚有余温之物时，会自行聚拢成一小团火茧。
- 特殊视觉效果：吞食余火时，灰烬表面浮起细密火星，如星子自下而上攀爬。

### 二、核心能力

- 基础能力：吸收环境中的「余火」「余温」——篝火残烬、灶膛余炭、被炎道攻击灼烧后残留的余焰——将其凝练为可存蓄的「火种」。
- 作用机制：余烬蛊只回收「将熄未熄」的火，不主动引火；它把散逸的热力压成一点火种，封存在自身灰烬中，蛊师需要时再引燃。
- 作用对象：一切余温未散的炭、灰、残焰。
- 能力范围：贴身，约数尺。
- 效果强度：积满一握灰，可存约可维持一夜营火之热；火种可反复引燃、多次取用，但每取一次总量减。
- 使用限制：不能凭空生火，必须有「余温来源」；封存的火种会缓慢流失，最长存续七日；遇水即大损。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，炎道或兼修炎道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 需亲手以真元护住一次「自然熄灭的火」至最后一星 |
| 炼化风险 | 低；但若炼化失败，火星反扑可灼伤蛊师心窍 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 余温炭灰（以将熄的炭火喂食） |
| 辅助食物 | 无 |
| 频率 | 视取用情况；不取用时每七日喂一次即可 |
| 成本 | 低 |
| 特殊环境 | 最好喂「自己参与熄灭的火」，火种更纯 |
| 断食后果 | 火种彻底冷透，蛊成死灰，无法再醒 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 必须有「余温来源」，不能凭空生火 |
| 消耗 | 二转赤铁真元（回收时低耗），火种本身为存蓄资源 |
| 范围 | 贴身数尺 |
| 持续 | 火种最长存续七日，缓慢流失 |
| 缺陷 | 无直接攻击力；火种会自然流失；遇水、遇冰即毁；对「已经冷透」的炭灰无用 |
| 克制 | 被水道、冰雪道克制；能辅助炎道（作为火种后备） |
| 优势 | 把「必然浪费的余热」变作资源；无明火时是唯一稳定的火种来源；配合炎道杀招可省真元 |
| 适用场景 | 荒野、长夜、断粮断源时；炼蛊需稳定火候时 |
| 不适用场景 | 水域、雪原、无处取火之地 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一场「天火」（雷击起火）烧过的枯木所余之炭 |
| 辅助材料 | 夜露九滴、松脂一捻 |
| 过程 | 在无风之夜，以真元将炭灰中最后一星火「温养」至天明不灭 |
| 难度 | 中 |
| 成功率或风险 | 中；失败则炭灰散尽，且可能引火自灼 |
| 替代材料 | 可用常年不断火的炭窑余灰，但成品火种不纯、存续更短 |

- 大小：小指长。
- 颜色：灰绿，断口猩红。

- 能力范围：本人。
- 效果强度：可代偿一次「足以致死的直接打击」，本体存活，但被舍弃的部分永久失去（含其上道痕）。
- 使用限制：每只断尾蛊只能用一次；只对「有形的、可落到肉身上的直接伤害」有效，对魂魄、诅咒、灾劫、梦道侵蚀等无形伤害无效；舍弃的部分不可复原。

### 一、外观

- 外观：一颗圆润的鹅卵石，石上生着细如发丝的纹路。
- 大小：鸽卵大小。
- 颜色：青灰，纹路银白。
- 形态特征：走过之处，石纹会自行「长」出一条新的细线，对应走过的路。
- 特殊视觉效果：问路时，石上会亮起一条淡光，顺着该走的纹路流动。

### 二、核心能力

- 基础能力：自动记录蛊师走过的路径（以石纹刻画），问路时以微光指引回溯；也能「擦去」某段不想被记住的路。
- 作用机制：问路石以土道道痕「记住」大地的起伏与自身移动，形成一份只有蛊师能读的私密路图。
- 作用对象：本人走过的路（以自身足迹为限）。
- 能力范围：记录无上限，但只记「走过的」，不记「没走过的」。
- 效果强度：能精确回溯走过的路径；但只记录经过，不记录沿途变化后的现状。
- 使用限制：必须本人亲自走过；被外力抹去足迹（如水冲、翻土）不会影响石纹，但若蛊师刻意「忘路」，石纹也会淡去。

| 炼化风险 | 无 |

### 四、喂养条件

| 特殊环境 | 无 |

### 五、能力限制

| 项目 | 内容 |
|---|---|

- 特殊视觉效果：催动时，钟内会「记住」一次攻击的余音，并在数息后原样「还」出。

### 二、核心能力

- 基础能力：接下一次「有声之击」的余音，将其存于钟内，数息后朝来路方向原样返还一次「音之反击」。
- 作用机制：音道「以彼之余还彼之身」——不制造新的音，只延迟、定向返还既有之音。
- 作用对象：一次带声的直线攻击（音杀、含鸣啸的击打等）。
- 能力范围：数步内接音，返还方向为来路。
- 效果强度：返还之音威能与余音相当，不能放大，只能「迟还」。
- 使用限制：只能返还「有声」攻击；纯静默的攻击（暗器无声、魂道）无效；每存一音，钟内只能存一道，须先放空再存下一道。

- 使用限制：须事先在收信人身上或居处留标；一次一句、须蛊师亲口；途中被截则竹简碎、口信随散；不辨收信人死活，标在人亡亦照投。

| 所属流派 | 木道 |

| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一粒饱胀将裂的谷种，壳上凝着一层细密水珠。
- 大小：指甲盖大。
- 颜色：谷黄泛青，水珠澄亮。
- 形态特征：近了湿土，谷壳会微微一鼓，像要裂开。
- 特殊视觉效果：催动时，谷种周围浮起一层极淡的雨气，落地无声，却见土面针尖似的冒出嫩芽。

### 二、核心能力

- 基础能力：催动一方已播之田，令种子齐整抽芽、并按疏密匀苗，使一季出苗不稀不挤。

- 作用对象：一方已播种、且有水有肥的田畦。
- 能力范围：约一畦（数丈见方）。
- 效果强度：出苗齐整、疏密合度；但不增产、不改良种、不催「已死之种」、不代替后续生长。
- 使用限制：须应时令（谷雨前后最验，违时则芽弱）；须田已播种、水肥已备；一季对同一畦只验一次，重催反致苗挤根弱。

| 炼化风险 | 低；错过时令则谷种僵而不醒 |

| 所属流派 | 食道 |
| 核心用途 | 炼材生产：把废料沤渍发酵成可用炼材 / 肥 |
| 稀有程度 | 常见 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一只小口陶瓮，瓮沿总挂着一圈细密水沫，瓮身温热。
- 大小：拳头大。
- 颜色：陶褐，沫白。
- 形态特征：投料入瓮，瓮沿水沫便由白转微黄，示「沤到了火候」。
- 特殊视觉效果：开瓮时先冒一缕酸暖之气，瓮底废料已化成一团匀净的膏 / 肥，不见原样。

### 二、核心能力

- 基础能力：把秸秆、落叶、残渣、废料等「无用之物」投入瓮中，沤渍发酵，化成可入田的肥或可作低阶炼蛊辅材的「熟料」。
- 作用机制：食道「化废为用」——对应原著「食道＝回收与清算」的既有逻辑；它只「转化」已有之物，不凭空生材、不提质为仙材。
- 作用对象：一批可腐熟的有机废料。
- 能力范围：一瓮，约数升。
- 效果强度：数日成一瓮熟料，品质低、只作肥与低阶辅材；不能把凡材炼成仙材、不能去毒、不能化「不可腐」之物（金石、活蛊）。
- 使用限制：须「投得进瓮、且可腐」；须静置、避暴晒暴雨；一瓮沤成前不可开盖，开早则半熟、前功弃；遇剧毒废料则整瓮废。

### 一、外观

- 外观：一把微缩的抹子，刃上总沾着一点半干的灰泥，泥色温润。
- 大小：三指长。
- 颜色：木柄褐，泥灰白。
- 形态特征：近了裂缝，刃上灰泥会自行微微鼓起，像要往缝里填。
- 特殊视觉效果：抹过时，裂缝像被「抚平」般收拢，不留新痕，只余一道比周围略深的浅线。

### 二、核心能力

- 基础能力：把墙垣、田垄、沟渠、陶石器皿上的「裂 / 缺 / 缝」用灰泥弥合，恢复其「不漏、不塌、不断」的原状。

- 作用对象：一处既有之物的裂缝 / 缺损。
- 能力范围：单处，约一臂所见之缝。
- 效果强度：弥合后不漏不塌、外观只留浅线；但不加固、不新建、不补「整块已粉碎」者、不补含活跃道痕的仙材裂痕。
- 使用限制：须「原物尚在、只是裂了」；粉碎、朽透、被连根毁去者无效；须以同质灰泥 / 土作料；一处只补一次，反复抹反致凸疤。

- 特殊视觉效果：打磨时不见火星，只落下一层极细的粉末；粉落得匀，便知材质纯，粉忽粗忽细，便知内里夹了杂。

### 二、核心能力

- 基础能力：把器物表面的毛刺、糙口磨去、磨出合用的刃 / 面；磨时落粉的匀细，可顺带验出材质是否纯、有无夹层。
- 作用机制：金道「砥砺」——只「去余、显形」，不增材、不改形、不赋能力；「验材质」是打磨落粉的自然副产，并非第二能力。
- 作用对象：一件可磨的实物（器、料、刃、坯）。
- 能力范围：单件，手持可及。
- 效果强度：去毛刺、磨合用面、以落粉辨纯杂；但不能把凡铁磨成仙材、不能补裂（补裂属 O-G-018 弥缝蛊）、不能赋道痕。
- 使用限制：只磨「可磨」之物；过软（腐木、湿泥）、过脆（薄瓷）、含活跃道痕之仙材一概磨不得；一件磨到「形定」即止，过磨反损器。

- 颜色：牙白，绳褐。
- 形态特征：清点之物一多，算筹会自行在绳间挪位，筹头朝外者即「已点」。

- 能力范围：一批，数越大越耗心力。
- 效果强度：点数准、核价准、缺一件即「空磕」示警；但只核「数与价」，不核「质与真伪」。
- 使用限制：须「物已定价、且可逐件点数」；散装难计、活物乱窜、价目未定者核不了；一次只理一批，混批则乱；市集嘈杂、清点被打断则须从头再点。

# 【原创设定】结绳蛊

**基本资料**

| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一段旧麻绳，绳上打着疏密不一的结，结尾垂着一缕散穗。
- 大小：一尺长，可绕腕。
- 颜色：麻褐，结处磨得发白。
- 形态特征：记一件事，绳上便多一个结；结越大，所记越要紧。
- 特殊视觉效果：回放时，蛊师指尖捏住某结一捻，那段见闻便「按当时次序」在心头过一遍，不添不漏。

### 二、核心能力

- 基础能力：把一段亲眼所见 / 亲耳所闻的见闻、口供、契约条款「结」成绳结，日后按结回放，次序与细节不失真，可作记忆存档与推演底本。
- 作用机制：智道「结以存真」——只「录」不「解」：它保证「记下的不歪」，但不替蛊师推断、不补忘掉的部分、不辨所记真伪。原著书虫【原著蛊虫】是「喂什么记什么、永记不失」，本蛊与之同类而更重「次序」，二者可并用不悖。
- 作用对象：一段亲身经历 / 见闻 / 契约条款。
- 能力范围：绳长有限，结数有限（约十数结，结大者占得多）。
- 效果强度：回放次序、细节不失真；但不能推演未来、不能辨伪、不能记自己没留意到的细节。
- 使用限制：只记「亲身经见」；道听途说、事后脑补者结不牢；结满须「解结」（抹去旧记）方能再结；绳断则所记尽失。

| 炼化风险 | 低；结序打乱则成品回放错序 |

# 【原创设定】凝漏蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-108 |
| 名称 | 凝漏蛊 |
| 品阶 | 七转 |
| 凡蛊或仙蛊 | 仙蛊（同名天下唯一） |
| 所属流派 | 宙道 |
| 核心用途 | 时间相关：把小物「此刻状态」封存片刻 |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一枚凝住的漏刻，壶中水线停在半滴将落未落之处，箭尺不升不降。
- 大小：掌高。
- 颜色：铜青，水线澄白。
- 形态特征：只要「凝」着，浮尘落到刻面也会停在半空不动。
- 特殊视觉效果：解封那一瞬，半滴水才「补落」下去，箭尺轻轻一跳，像时间接着走。

### 二、核心能力

- 基础能力：把一件小物「此刻的状态」连同其极短一段时间冻结封存片刻——封存期间该物不受外界影响、也不自行变化（不腐、不枯、不继续发酵、不被催动）。
- 作用机制：宙道「凝刻」——不逆流、不回溯、不加速他人、不延寿，只把「这一刻」按住一小段。原著寸光阴【原著蛊虫】是「加速酝酿」，本蛊反其道「停住」，二者分用不相混。
- 作用对象：单件小物 / 一小片将成未成之状态。
- 能力范围：单件小物，数息至一刻。
- 效果强度：可让「熟地成型那一刻」「将枯之苗」「将凝之材」暂时定住以避外扰；但封存期间该物不可用、不可被催动、不可取出干预，解封后一切照旧继续。
- 使用限制：只封「小物」，不封活人、不封含活跃道痕之仙材（道痕会挣破凝刻）；封存期间物「不可用」；一次只凝一刻，解封后须隔一段时间方能再凝。

# 【原创设定】敛痕蛊

**基本资料**

| 核心用途 | 道痕相关：收拢游离道痕凝成痕砂 |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一枚极薄的空蚌壳，壳内不积物，只浮着一层会自己聚拢的细砂。
- 大小：两指长。
- 颜色：壳白泛青，砂灰。
- 形态特征：近了「有痕将散」之处，细砂会顺壳纹缓缓聚成一小撮。
- 特殊视觉效果：收痕时，壳内细砂会按流派泛出极淡的不同色泽，随即褪成一律的灰。

### 二、核心能力

- 基础能力：收拢「自然逸散的游离道痕」——杀招余波、炼蛊废渣、器物崩解时散出、道痕将散未散者——凝成一撮可辨、可封存的「痕砂」，供辨识佐证或作低阶炼材引子。
- 作用机制：炼道「敛屑」——只收「已散、无主、游离」之痕，不夺他人 / 他物身上「尚在生效」的道痕；不凭空生痕、不把痕炼成修为、不补全仙蛊道痕。
- 作用对象：一小片「痕场」内游离将散之痕。
- 能力范围：身边一小片痕场。
- 效果强度：痕砂可看出「属何流派、约何时散」，仅此；不能转化为蛊仙修为、不能反推完整杀招、不能当仙材使。
- 使用限制：只收游离将散之痕；活跃 / 有主道痕收不得（强收反被痕伤）；产出极淡、只堪佐证；一处痕场收一次即尽。

# 【原创设定】应候蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-202 |
| 名称 | 应候蛊 |

| 所属流派 | 宙道 |
| 核心用途 | 资质 / 记忆 / 推演（择时）：刻「候纹」提示宜否入定 / 推演 / 开炼 |

| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一节极短的葭灰管（古以葭灰候气之具），管内一撮灰，灰面随蛊师气息起伏而微微升降。
- 大小：寸许。
- 颜色：管竹青，灰素白。
- 形态特征：须依附于另一只蛊方可存在，离宿主则灰面一平、不升不降。
- 特殊视觉效果：气机顺时，灰面轻轻浮起一纹；气机浮时，灰面塌成一道浅沟——这一浮一塌便是「候纹」。

### 二、核心能力

- 基础能力：依附于一只宿主蛊，感知蛊师真元 / 心力的「节气般细微涨落」，把「此刻宜不宜入定、推演、开炼、开封」刻成一组「候纹」，供蛊师择时。
- 作用机制：宙道「候气」——只「报时宜」，不测资质高低、不预言结果、不改状态、不增修为；候纹是「提示」不是「保证」。
- 作用对象：宿主蛊所属之蛊师的当下气机。
- 能力范围：随宿主，只报「当下这一候」。
- 效果强度：能提示「真元正顺、宜入定」或「心力已浮、宜暂缓推演」；但不告诉「为何」、不替蛊师决断、次日候纹自换。
- 使用限制：须依附宿主蛊、同源炼化；宿主一灭应候蛊同灭（一次性）；一次只报一候、过时即换；对「被外力强行扰乱」的气机报不准。
