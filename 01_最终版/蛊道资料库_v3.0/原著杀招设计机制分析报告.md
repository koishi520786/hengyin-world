## 0. 结论摘要

1. **杀招的本体是「炼蛊残方」**——第三卷 543 节《巅峰盛景》一手正文：「任何杀招，不管是凡道还是仙道，都可以算是炼蛊的残方」「我要将杀招浓缩升华成蛊虫，就要删减蛊虫，增添蛊材，将其融汇成一体」。这一句是整个体系的地基：杀招与蛊虫不是两类事物，而是同一条链路的不同凝聚状态。【原著明确】
2. **「组成蛊虫流派 ≠ 杀招流派」是硬原则，且有一手正文实例**：我力「核心是力道，但也涉及魂道、气道」仍是力道杀招；百年好合「用宙道蛊虫，展现出信道威能」；万我「奴力合流」却是单一杀招。【原著明确】
3. **「杀招有解」接近原著普遍性铁律**：第七百零一节《前有古人》「这个世上，从未有无解的杀招」「任何的杀招，都有一个感应的过程」。此前资料库把「每条杀招都有缺陷」当作整理者归纳，本轮据正文段落**升级判定**。【原著明确】｜**证据等级注**：该两句来自 WebSearch 返回的 piaotia 正文段落，核验方**未对该页做 WebFetch 全文**，故按「搜索摘要旁证」登记，与 543 节／第 109 章的全文一手证据区别对待。
4. **仙元并非唯一驱动力**：态度蛊「不耗仙元但耗心力」、鬼官衣「不耗仙元但耗魂魄底蕴」、鬼不觉「不需要仙元灌输，就能运转不休」。「仙道杀招必耗仙元」不能当铁律。【原著明确】
5. **凡仙混编／越级催动有硬规则**：理论 1 颗青提仙元＝100 滴真元、仙元各级 100 倍；但低转仙元催高转蛊虫有额外损耗，**实际约 1:120～130**。第 109 章一手正文「六转青提仙元可催动不起似水流年蛊」即其例。【可靠资料佐证＋原著明确】
6. **本轮推翻／修正 8 处既有结论**（详见第 11 节）：天纲地常组件、五指拳心剑核心蛊、万剑鬼蛟与万一鬼蛟剑关系、鬼官衣章号、转数不可尽信的出处层级、仙蛊唯一性对杀招复用的限制、仙蛊屋是否固态杀招、浓缩成蛊利弊不完整。
7. **必须留白之处**：战场杀招的统一定义、蛊虫唯一性对「杀招复用」的专门限制、复合/图腾等分类术语是否原著定义——均【原著未明确】或【存在争议】，档案中不得写成定论。

## 1. 杀招的定义与本体

| 命题 | 判定 | 依据 |
|---|---|---|
| 杀招由多只蛊虫组合、同时催动 | 【原著明确】 | 543 节「删减蛊虫…融汇成一体」；巨灵变「三大四转蛊同时催动」；无极搜锁四老齐催 |
| 任何杀招都可视为一份炼蛊残方 | 【原著明确】 | 543 节逐字表述（5165.org 全文、piaotia 摘要双证） |
| 蛊方完善后，整套杀招可浓缩为单只蛊虫 | 【原著明确】 | 543 节「江山如故仙蛊…也可以看做是杀招江山如故在运作」；我力蛊、万我仙蛊 |
| 「炼蛊／养蛊／用蛊」三事在某些视角下同一 | 【原著明确】 | 543 节「这种搭配，不就是炼蛊吗？……不正是用蛊吗？」 |
| 杀招最原始的面目是道痕 | 【可靠资料佐证】 | 社区分类学归纳（S19）：荒兽荒植天赋本能即天然杀招 |

## 3. 流派与道痕：为什么蛊虫流派不等于杀招流派

### 3.1 一手依据

- 543 节：「**仙蛊是大道碎片，蛊材则是道痕累积，只要流派一致，它们就能相互取代**」「逆流护身印、井井有条，之所以能催成杀招，就是逆流河、市井的道痕太过丰富，**取代了蛊虫的作用**」「道痕之间还需要**搭配**……蛊虫之间相互配合，就是道痕的配合」。【原著明确】
- 「流派一致可相互取代」**只适用于同流派的仙蛊与蛊材互换**（炼蛊／浓缩原理），**不等于跨流派随意混合合法**。跨流派合法性应引「大宗师触类旁通」「井井有条让道痕不互斥」。【本轮精确化修正】
- 第 109 章一手：「百年好合……**用宙道蛊虫，展现出信道威能**」「年富力强：以年蛊为核心，却能赋予蛊仙巨大的力量」「年兽召来……宙道攻伐杀招（触类旁通显奴道）」。【原著明确】

### 3.2 典型例证

| 杀招 | 组成蛊虫流派 | 杀招流派 | 说明 |
|---|---|---|---|
| 我力 | 力道＋魂道＋气道 | 力道 | 543 节原文明载 |
| 万我 | 奴道＋力道（＋魂道、气道辅助） | 奴力合流；后期演进为人道 | 形态演进见第 8 节 |
| 百年好合 | 宙道（年蛊）＋信道凡蛊 | 宙道模拟信道 | 触类旁通 |
| 天纲地常 | 说法一：律道（纲＋正常）；说法二：律道＋信道＋天道 | 天道 | **组件两说并存且均待考**，见第 11 节 |
| 遗毒蚁祸 | 毒／奴／炼／木／食／天六道 | 复合 | 单招含多流派 |

> **建档口径**：按「主要运行机制或原著明确归属」定杀招流派，跨流派列主／辅；**禁止按核心蛊流派一键归类**。原文件依天纲地常确立的这条原则继续有效，不因该招组件存疑而推翻（任务书亦明定此原则）。

### 3.3 境界对杀招的影响

流派境界十阶：普通→准大师→大师→准宗师→宗师→准大宗师→大宗师→准无上大宗师→无上大宗师→道主。【可靠资料佐证】
- 宗师：可「以主修流派模拟其他流派威能」——解释年蛊系列跨流派表现。
- 大宗师：可「随意拆卸使用杀招，甚至直接利用自然界道痕」。
- 无上大宗师／道主「超脱仙元令杀招永存、自行运转」——**出处层级存疑**【存在争议】；543 节对「不耗仙元杀招」另给解释：**道痕搭配形成人造天地秘境**（「逆流河、市井……都是天地秘境，蕴藏道痕极丰」「道痕太过丰富，取代了蛊虫的作用」「鬼不觉……不需要仙元灌输就能运转不休，这也是一座人造的天地秘境」），两说并存。
- **不得把「道痕＝人造天地秘境」与「无上大宗师造无需仙元杀招」的境界说合并**：前者是 543 节正文的道痕机制解释，后者是出处层级不明的境界说，两者证据等级不同。【本轮收尾修订新增处置项】
- 逆流护身印的「律道」归类实为分类表／机制归类（逆流河为律道秘境），「八转」为威能层级，二者非同一维度，故两说**仍并列保留**但不必视作简单对立。

## 7. 缺陷与破解

**一手铁律**：第七百零一节《前有古人》「这个世上，**从未有无解的杀招**」「**任何的杀招，都有一个感应的过程**」。【原著明确】｜证据等级：搜索结果返回的正文段落（未做全文 WebFetch），与 543 节全文一手证据区别标注。

破解方式类型（均须在档案「七、优缺点」逐项记录）：

| 破解类型 | 实例 |
|---|---|
| 舍弃载体／切断锚点 | 无极搜锁：方源舍弃被种定星蛊的左臂；以神游蛊吞掉定星蛊，四老失去联系齐吐血 |
| 层级压制 | 无极搜锁「能封禁五转蛊，但禁不住六转仙蛊」 |
| 规则复位 | 天纲地常最克战场杀招（令天地恢复常态） |
| 消耗战／承受上限 | 逆流护身印受重击会变浅薄虚幻；巨灵变三倍消耗用久精神萎靡 |
| 针对感应机制 | 送友风感应秘密被智道蛊仙联手推算、「须接触身体」被针对防范 |
| 形态固有缺陷 | 二代冰刃风暴只能原地自转；自由残缺变三段各自短板（黄鸟不能飞、蓝豹吞一次鼓胀、绿鱼出手后须沉寂） |
| 推算／侦查反制 | 见面曾相识被「震运得距」等推算手段针对 |
| 环境反制 | 逆流河「落入不能动用九转以下蛊虫、攻势被逆反」 |

> 「每条杀招都有缺陷」此前仅作整理者归纳，本轮升级为**原著近似普遍性铁律**；但**具体某招的缺陷若无原文，仍须写【原著未明确】**，不得由铁律倒推填充。

## 8. 改良与演化

### 8.1 四条演化路径

1. **换蛊改版**：冰刃风暴初代（冰刃＋旋踵＋狂风）→ 二代（＋三转冰晶、龙卷、霜息、朝气蛊），并因化身冰晶解除了霜息蛊「只能间隔喷吐」的限制。【原著明确】
2. **浓缩成蛊**：杀招 → 单只仙蛊（我力蛊、万我仙蛊）。**完整利弊（543 节本轮补齐）**：利——催动简化、不易被推算拆解、省却多蛊同催；弊——整套招凝于唯一一蛊，被夺／被封则尽失，浓缩需消耗其他仙蛊作蛊材，拆分改良灵活性下降。【原著明确】
3. **融合升级**：万我由龙马精神、三头六臂、鼠疫、雷暴、豹突、马踏、三心合魂、兽影围杀、六臂天尸王等杀招融汇提升；万蛟＝万我＋上古剑蛟变；万剑鬼蛟为五招融合。【可靠资料佐证】
4. **形态演进**：万我六转「奴力合流」创制 → 经「我意」「集思广益」升格为「人道」杀招（有声书 2761 集「已经不再是单纯的奴力合流，而是更进一步的人道杀招」）。此说可**解释**六转／七转两说，但按项目纪律**不据此调和**，两说仍并列【存在争议】。
   - 补证：543 节一手全文明确「万我变式还有逆流护身印、阎帝、万蛟等，威力更胜从前……但论方便实用，还是万我仙蛊」，即**「万我第二式」体系有原著级依据**，逆流护身印不应仅视二手分类词。另 543 节「井井有条这个杀招，可以让道痕之间不互斥」为杀招跨流派合法性的一手依据。

### 8.2 改良带来的组件变化

方源在见面曾相识中加入血本仙蛊以伪装血脉；黑凡标注度日如年四招若得仙级日／月蛊则「无须耗费那么多凡级日蛊月蛊，且效果也会提升不少」——**同一杀招可因组件升级而减少辅助蛊数量**。【原著明确】

## 9. 蛊虫唯一性的边界

| 命题 | 判定 |
|---|---|
| 凡蛊可有多只同名、仙蛊天下仅一只；仿伪蛊为唯一例外 | 【可靠资料佐证】 |
| 本命蛊亡蛊师重伤但不会因炼蛊直接死亡；合炼无论成败本命蛊不死 | 【可靠资料佐证】 |
| 蛊虫唯一性对「他人能否复用同类杀招」构成专门限制 | **【原著未明确】**，属【合理推测】——原著只明载唯一性，未限制他人名下有同名凡蛊或同类杀招 |
| 「转数不可尽信，只取文中初次出现时的转数」 | **降级为【可靠资料佐证】**：实出自百科词条「转数之分」按语，非小说正文逐字；但另有正文级「转数≠威力」证据 |

> 原创设计须遵守「仙蛊唯一」，但**不得**把「因为仙蛊唯一所以某杀招天下只有一人能用」写成原著规则。
