# 衡垠世界 · 正式公开版

《衡垠世界》是一个以「现代都市 + 蛊道」为底盘的长期文字跑团世界，包含蛊虫、杀招、蛊方、妖兽、仙材、秘境、国家城市、社会组织、人物档案与完整 GM 规则。本仓库是它的**完整正式公开版本**，供人和 AI 直接读取、检索、引用与开局。

> 本仓库不提供网站。全部内容以 Markdown 正文和索引文件保存。

## 二、如何开始跑团

1. 打开 [`最终版/跑团提示词/衡垠世界_主提示词.md`](最终版/跑团提示词/衡垠世界_主提示词.md)。
2. 将这份启动提示词交给 AI；它只负责启动与指路，详细规则都在本仓库正文里。
3. AI 按提示词先读 [`AI_START_HERE.md`](AI_START_HERE.md)、[`最终版/MASTER_INDEX.md`](最终版/MASTER_INDEX.md) 与 [`最终版/FILE_CATALOG.md`](最终版/FILE_CATALOG.md)。
4. 按当前场景读取对应分卷与正文；不需要每轮加载全库。
5. 从垠历 738 年主角 11 岁生日当天、临江市北城区云栖花园开始。

仅凭本仓库中的启动提示词与正式资料，即可理解项目并开始跑团；不需要本地私有文件、旧版提示词或维护归档。

## 四、AI 应该怎样读

1. 先读 [`最终版/跑团提示词/衡垠世界_主提示词.md`](最终版/跑团提示词/衡垠世界_主提示词.md)，再读 [`AI_START_HERE.md`](AI_START_HERE.md) 与 [`最终版/MASTER_INDEX.md`](最终版/MASTER_INDEX.md)。
2. 按对象查 [`ENTITY_INDEX.md`](最终版/ENTITY_INDEX.md)，按关键词查 [`KEYWORD_INDEX.md`](最终版/KEYWORD_INDEX.md)，按文件查 [`FILE_CATALOG.md`](最终版/FILE_CATALOG.md)。
3. 进入对应目录的 `00_` 总索引，再按编号打开正文档案；索引摘要不等于完整正文。
4. 原著、原创、参考、待考证必须分开引用；`【原著未明确】`、`【待考证】`、`【原创设定】` 不得改写成确定事实。
5. 关系按语义使用：`携带 ≠ 拥有 ≠ 控制 ≠ 炼化`；`提及 ≠ 正式组成`；`对某妖兽有效 ≠ 组成杀招`。
6. 世界事实与 GM 规则分开：世界数值回 `04_世界`，运行流程回 `05_跑团规则`，启动顺序回 `跑团提示词`。

## 五、人类怎样使用

- **下载 ZIP**：在 GitHub 仓库页点击 `Code` → `Download ZIP`。
- **克隆**：`git clone https://github.com/koishi520786/hengyin-world.git`
- **开始跑团**：打开 `最终版/跑团提示词/衡垠世界_主提示词.md`，连同仓库一起交给 AI。
- **查蛊虫**：从 `最终版/01_蛊虫/00_蛊虫总索引.md` 进入，按 C-G／O-G 编号检索。
- **查杀招**：从 `最终版/01_蛊虫/11_原著杀招.md`／`12_原创杀招.md` 进入。
- **查妖兽**：从 `最终版/03_妖兽/00_妖兽总索引.md` 进入，按 C-B／O-B 编号检索。
- **查仙材**：从 `最终版/02_仙材/00_仙材总索引.md` 进入，按 SM 编号检索。
- **查世界**：从 `最终版/04_世界/00_世界总索引.md` 进入，按国家、城市、秘境、组织、历史条目检索。
- **查人物**：从 `最终版/04_世界/08_人物组织与重要地点.md` 进入，按 PER／HIS 编号检索；苏晞见 `04_世界/13_苏晞人物档案.md`，主角开局见 `04_世界/14_主角开局档案.md`。
- **查系统与开局**：从 `最终版/05_跑团规则/09_开局流程与初始状态.md`、`10_隐藏系统.md` 进入。

## 六、资料边界

- 部分 C-G 条目仍是简档：有名称与能力摘要，但炼制材料、真元消耗、反噬等字段未齐；不得把简档标成完整档案。
- 部分 C-K 条目仅名称待考：不强行补编号，不把提及蛊虫写成正式组成。
- O-G-110 界隙蛊只登记六转宇道、O-B-012 阈鹿体表被动寄生、未炼化、未封印、妖兽不可催动、自主护主存疑、宿主死亡后留存未知；具体能力／消耗／炼制／喂养／升炼均【待考证】。
- 妖兽没有空窍、真元、蛊师修炼体系，不能主动催动蛊虫；携带不等于控制。
- 启动提示词是运行入口，不是世界事实来源；具体事实以 `04_世界`、`01_蛊虫`、`02_仙材`、`03_妖兽` 正文为准。
