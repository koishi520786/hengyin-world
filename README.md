# 衡垠世界 · 数字图集与知识库

《衡垠世界》是一个现代都市蛊道跑团世界设定项目。本仓库同时保存世界图集网页、蛊虫/妖兽/杀招知识库、原始资料归档与迁入审计，供阅读、检索和 AI 资料读取使用。

## 快速入口

- 世界图集网页：`hengyin-world-atlas/衡垠世界图集.html`
- 知识库迁入说明：`衡垠知识库迁入/README.md`
- 全量迁入报告：`衡垠知识库迁入/Audit/IMPORT_REPORT.md`
- 蛊虫索引：`衡垠知识库迁入/Indexes/gu-index.json`
- 妖兽索引：`衡垠知识库迁入/Indexes/beast-index.json`
- 关系索引：`衡垠知识库迁入/Indexes/relationship-index.json`
- 网页 IA 对接说明：`衡垠知识库迁入/Stage2/WEB_IA_HANDOFF.md`

## 数据规模

| 项目 | 数量 |
|---|---:|
| 蛊虫记录 | 717（C-G 684 + O-G 33） |
| 妖兽记录 | 89（C-B 37 + R-B 40 + O-B 12） |
| 杀招 | 460（C-K 447 + O-K 13） |
| 实体档案 | 1,266 份 |
| 已登记关系 | 912 条 |

C-G 的 684 条记录中包含 3 条非实体注记（C-G-274、C-G-462、C-G-643）；有效候选为 681 条。另有 4 组疑似同物异号，保留原编号、未合并。R-B 为跨作品参考物种，不代表衡垠世界实存妖兽。

## 目录

- `01_最终版/`：当前生效的蛊道、妖兽与跑团提示词资料。
- `衡垠知识库迁入/`：独立实体档案、统一索引、关系网络、审计报告与第二阶段方案。
- `hengyin-world-atlas/`：世界图集网页与网页数据。
- `衡垠世界_世界地图集/`：世界地图集相关素材。
- `02_归档_历史版本/`、`03_归档_原始底稿与备份/`、`04_归档_拼装中间稿/`：只读归档，保留版本谱系。
- `00_工作区总导航.md`：项目目录与编号体系总览。

## 使用说明

网页为单文件 HTML，可直接在浏览器打开；Windows 下也可运行 `hengyin-world-atlas/启动网站.bat`。知识库档案为 Markdown，索引为 JSON，均可被脚本或 AI 直接读取。
