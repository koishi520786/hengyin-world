# 衡垠世界 · 正式知识库

《衡垠世界》是一个以「现代都市 + 蛊道」为底盘的开放世界设定库，包含蛊虫、杀招、蛊方、妖兽、秘境、国家城市、社会组织与跑团规则。本仓库是它的**正式公开版本**，供人和 AI 直接读取、检索与引用。

> **本仓库不再提供网站。** 没有 HTML 前端、没有部署配置、没有只为展示服务的数据副本；全部内容以 Markdown／TXT 正文和索引文件保存。删除网站是为了把精力放回设定、资料、索引和 AI 可读取性上。

---

└── 妖兽图鉴/             原著兽类、参考物种、原创妖兽、生态与战力判定

- 本地工作数据（不发布）：只供维护使用，不属于公开知识库。

本地回收区不是正式资料。任何 AI 不得从本地历史归档读取设定、恢复旧编号或把研究报告当作正式档案。

## 三、AI 应该怎样读

1. 先读根目录 [`AI_START_HERE.md`](AI_START_HERE.md)。
2. 再按任务读对应的 `00_` 总目录，不要一上来把全库塞进上下文：
   - 世界设定：`最终版/现代蛊道世界_v1.0/00_世界观总目录.md`
   - 国家／政治实体：`最终版/现代蛊道世界_v1.0/04_全球国家总览.md`（120 主权国家）＋`38_全球政治实体百国总表.md`（61 特殊实体；合计 181）；地图见 `40_全球地图与地理数据说明.md`
   - 人物／潜力人物：`最终版/现代蛊道世界_v1.0/37_全球重要人物与潜力档案.md`
   - 历史人物／古代蛊仙：`最终版/现代蛊道世界_v1.0/39_历代蛊师与古代蛊仙档案.md`
   - 蛊虫／杀招／蛊方：`最终版/蛊道资料库_v3.0/00_总目录.md`
   - 妖兽／生态／战力：`最终版/妖兽图鉴/00_妖兽图鉴总目录.md`
3. 查具体实体时，先定位编号，再打开正文档案；**索引摘要不等于完整正文**。
4. 原著、原创、参考、待考证必须分开引用；`【原著未明确】`、`【待考证】`、`【原创设定】` 不得被改写成确定事实。
5. 关系必须按语义使用：`携带 ≠ 拥有 ≠ 控制 ≠ 炼化`；`提及 ≠ 正式组成`；`对某妖兽有效 ≠ 组成杀招`。
6. 遇到世界底盘冲突，先看 `AI_START_HERE.md` 的「冲突处理」一节，不得自行合并两套数字。
7. 引用原著内容前，先看 `最终版/蛊道资料库_v3.0/版权与来源说明.md`：只做机制摘要与必要短引，不逐章复制。

## 四、人类怎样使用

- **下载 ZIP**：在 GitHub 仓库页点击 `Code` → `Download ZIP`。
- **克隆**：`git clone https://github.com/koishi520786/hengyin-world.git`
- 查蛊虫：从 `最终版/蛊道资料库_v3.0/00_总目录.md` 进入，按 C-G／O-G 编号检索。
- 查妖兽：从 `最终版/妖兽图鉴/00_妖兽图鉴总目录.md` 进入，按 C-B／R-B／O-B 编号检索。
- 查世界：从 `最终版/现代蛊道世界_v1.0/00_世界观总目录.md` 进入，按国家、城市、秘境、组织、历史条目检索。
- 查人物：从 `最终版/现代蛊道世界_v1.0/37_全球重要人物与潜力档案.md` 进入，按 PER 编号检索；先读“当前处境”和“缺点”，不要只取“天才”标签。
