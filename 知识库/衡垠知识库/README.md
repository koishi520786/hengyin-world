# 衡垠知识库

本目录是《衡垠世界》既有蛊虫、妖兽、杀招资料的统一迁入库。**只读原始资料，不修改原始档案，不覆盖、不删除任何原文。** 世界层数据另见同级目录 `../World/`；网站已移除。

## 结构
```

├── README.md
├── SOURCE_INVENTORY.md

│   ├── O-G/ 33 份正式原创蛊虫档案（32 完整 + O-G-110 登记）；另有 12 份未入索引候选
```

## 关键数字
- 蛊虫 717 条：C-G 684（含 3 条非实体注记、4 组疑似同物异号）、O-G 33。
- 妖兽 89 条：C-B 37、R-B 40、O-B 12。
- 杀招 460 条：C-K 447、O-K 13。
- 关系 912 条；外部临时键 45 条；秘境登记 64 条。
- 目录中另有 12 份 O-G 候选（O-G-022～033）与 7 份 O-K 候选（O-K-014～020），**未写入正式索引，不计入上述 717/460**。

## 使用顺序
1. 读 `Audit/IMPORT_REPORT.md` 看结论与缺口。
2. 读 `Indexes/gu-index.json`、`beast-index.json`、`move-index.json` 取结构化数据。
3. 需要关系图时读 `relationship-index.json`；每条关系都指向已登记实体。
4. 需要数据分区与 AI 读取建议时读 `Stage2/CLASSIFICATION_PLAN.md`；世界层数据见 `../World/`。
5. 交付前跑 `Tools/validate.py`，核对 `Audit/VALIDATION.md`。

## 边界
- C-G/O-G、C-B/R-B/O-B 严格分区。
- R-B 是参考物种，不是衡垠实存物种。
- 一条实体一份正式档案；分类目录只引用，不复制。
- 未知字段保留未知；没有正式编号的扩展条目不赋编号。
- 杀招、蛊方是关联实体，不是蛊虫。
