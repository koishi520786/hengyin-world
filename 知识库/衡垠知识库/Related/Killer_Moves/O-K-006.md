### 一、杀招简介

「画皮」是一式六转仙道伪装杀招。核心仙蛊 O-G-101 复刻蛊只复制「形」不复制「道」，产出一件外形一般无二、却不含任何道痕的「空形」；再以变形蛊赋予它预设动作、似有生命，以敛息蛊隐去本体气息，把一具死物空形在极短时间内冒充成蛊师本人或某件要物。画道供「形」、变化道供「活」、敛息供「真」，三者合一。它档次低于原著「见面曾相识」那类「改心」级伪装：替身无道痕、无能力、不能战斗，稍遇道痕探测 / 真伪辨类仙蛊即露；胜在成本低、可反复描形，是「形」级而非「心」级伪装。

### 三、运行原理

> 原文「二、杀招原理」照录）

复刻蛊只复制「形」不复制「道」（O-G-101），复制品空有其表。单独一件空形毫无价值，但若以变化道之「变形」赋予它动作、姿态，再以敛息蛊隐去本体气息，这空形便能在一段极短的时间里「冒充」蛊师本人或某件重要之物，骗过只凭肉眼或气息判断的对手。画道供「形」，变化道供「活」，敛息供「真」，三者合而为一具以假乱真的替身。

### 四、发动条件

> 原文「三、发动过程」照录）

- 发动步骤：① 复刻蛊描形产出空形；② 变形蛊赋予其预设动作；③ 敛息蛊隐本体，放出替身。
- 发动速度：中（描形需时间）。
- 是否需要蓄力：否。

- 发动失败的可能原因：描形未竟即催动；对手有道痕探测手段。

### 十一、设计理念

> 原文「七、设计说明」照录并补）

原著「见面曾相识」是变化道顶级的「改心」伪装（直接作用于对方心中印象），本招则是「画道空形 + 变化道假活」的「形」级伪装——档次低、易被道痕探测识破，胜在成本低、可反复。二者一高一低，正体现「高转不使低转失效」：高端手段有高端手段的代价，低端手段有低端手段的生存空间。本招严格遵守「不造无敌伪装」，替身无道痕、不能战斗是硬约束。本版补：把「无道痕」既是缺陷也是「不触碰仙蛊唯一性」的护身符——正因复制品不含道，它才不挑战「仙蛊唯一」这条原著红线。

### 十二、组合逻辑

- **核心 / 辅助**：核心 O-G-101 复刻蛊（定「画道空形」之性质），辅助变形蛊、敛息蛊【原著蛊虫】（赋活、隐息）。
- **协同类型**：按分析报告 3.2，属「条件型 + 载体型」混合——复刻蛊产出的「空形」是载体，变形蛊「赋动作」、敛息蛊「隐本体」是令载体得以冒充真身的条件；三者合而为一具替身，缺一即「死物 / 不动 / 真气外露」。
- **为何不是「多蛊同用」反例**：三蛊同赴「以假乱真替身」单一目标、各补一维，符合「每只蛊都要有作用」；且本招以仙蛊为核心、辅以凡蛊，正合原著仙道杀招之构成（分析报告 3.6）。

### 十三、与原著体系的兼容性

> 逐条分析）

1. **品阶规则**：六转仙道杀招，转数取「初次出现时标注」、非强度刻度；核心复刻蛊六转仙蛊、敛息蛊三转凡蛊、变形蛊待考，低转凡蛊靠「隐息」机制位参与，不靠数值，符合「高转不使低转失效 / 仙道杀招以仙蛊为核心辅以凡蛊」。
2. **真元仙元消耗**：耗六转青提仙元（中，三蛊同催，核心仙蛊每用必补），符合「六转以上用仙元」「仙道杀招用仙元（青提→黄杏），部分改耗心力 / 道痕」；本卷已把原文笼统的「真元或仙元」补足为仙元口径。
3. **道痕运行**：本招核心恰是「无道痕」——复刻蛊「写形不写真」，复制品**不含任何道痕**；故本招不凭空生痕、不增益修为、不补全仙蛊道痕，也不因「复刻仙蛊」而制造第二只同名仙蛊，严格守住道痕与唯一性红线。
4. **流派规律**：杀招流派为画道+变化道（复合），组成蛊虫含画道（复刻）、变化道（变形）、暗 / 草类（敛息）——「画道供形、变化道供活」在同一目标上协同；跨流派援引「大宗师触类旁通」，非无条件混合。
5. **蛊虫唯一性**：核心复刻蛊为仙蛊，同名天下唯一；本招只复刻「空形」、不复制真仙蛊之「道」，故不新增唯一性例外；原著「仿伪蛊」为唯一例外，本卷不借用、不新增。
6. **杀招组合规则**：3 只蛊同时催动、核心 1 + 辅助 2 分工明确、每只都有作用；发动条件、消耗、效果范围、缺陷与破解方式齐备，且「道痕探测 / 试探替身无能力 / 描形未竟」皆落到具体组件，符合检查表第 7、8 条。

### 十四、平衡性分析

- **强在何处**：以假乱真、成本相对低、可反复描形，适合诱敌、金蝉脱壳、布疑阵、谈判虚张声势，并可接 O-K-005「走马灯」形成「脱身→替身续惑」的连招。
- **代价与机制同源**：替身无道痕（复刻蛊本质）、无能力、不能战斗、维持时间短（变形蛊维持期间）、须当面描形（本体在场有暴露风险）、易被道痕探测 / 真伪辨类仙蛊识破——全从「只写形不写真」的机制里长出，非外加缺点。
- **破解链清晰**：道痕探测 / 真伪辨类仙蛊 → 直接看穿空形；试探替身「有无能力」 → 一试即露；描形未竟即催动 → 发动失败。
- **上限锁死**：档次明确低于「见面曾相识」、不造无敌伪装、不碰仙蛊唯一性、不涉无条件增益，故「高转不使低转失效」，低端伪装自有其生存空间。
