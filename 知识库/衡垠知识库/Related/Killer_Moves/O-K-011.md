### 一、杀招简介

「春耕图」是 v3.0 新增的一式三转凡道经营杀招，把「看天吃饭」的一季耕作拆成按农时铺开的六环：地力蛊【原著蛊虫】肥土、沤料蛊（O-G-016）把废料沤成熟料 / 肥、谷雨蛊（O-G-015）催芽匀苗、寸光阴【原著蛊虫】加速酝酿、拾穗蛊（O-G-017）采收归堆、弥缝蛊（O-G-018）修补田垄沟渠仓壁，天真蘑菇【原著蛊虫】顺带净化沤场浊气。它一次覆盖种植、炼材生产、资源采集、建筑修复四个非攻伐方向，却零战斗力、跨一季、极依赖时令水肥，任一环缺即当季减产——是一张按节气铺开的「图」，而非七蛊同时放大。

**分工说明**：谷雨蛊为**核心**，定「木道催芽 / 种植」之性质；沤料蛊司「产」（废料成肥 / 炼材）、拾穗蛊司「采」（收成归堆）、弥缝蛊司「修」（田垄仓壁）；地力蛊司「肥」、寸光阴司「速」、天真蘑菇司「净」。七蛊按「肥—沤—催—速—收—修」次第各补一环，缺一即当季减产，而非叠加多种无关能力。

### 三、运行原理

先以地力蛊肥土、沤料蛊把秸秆落叶残渣沤成熟料 / 肥（天真蘑菇吸收沤场浊气、净化空气），肥足之后谷雨蛊于谷雨前后催种子齐整抽芽、匀苗；寸光阴以「加速酝酿」把作物生长 / 沤料发酵的时间压缩——原著限定「不能对人施展，却可用于其他对象，广泛用于炼蛊」，用于作物与沤料属「其他对象」之延伸，本卷不改其限定。及至成熟，拾穗蛊把落穗与散料拾拢归堆；一季耕罢，弥缝蛊把被水冲裂的田垄沟渠、仓壁补回不漏，令来季可续。七蛊皆「小」、皆非战斗，按农时次第各补一环：地力 / 沤料是催芽之前置，田畦是承载一季之载体，寸光阴只压「酝酿」之时间、不增产，拾穗 / 弥缝是收尾。故名「春耕图」，对应分析报告第 6 节「非战斗用途（经营 / 生产 / 计时）」「资源转化与循环」「节奏控制」。

### 四、发动条件

- 发动条件：应时令（谷雨前后最验）、田已播种、水肥已备、有沤料之废料来源、沤场可置天真蘑菇、寸光阴为消耗类须逐次备。
- 发动步骤：① 地力蛊肥土 + 沤料蛊沤熟料（天真蘑菇净浊气）；② 谷雨蛊催芽匀苗；③ 寸光阴加速酝酿；④ 拾穗蛊采收归堆；⑤ 弥缝蛊修田垄沟渠仓壁。
- 发动速度：慢（按农时次第，跨一季；寸光阴只压「酝酿」，不压次第本身）。
- 是否需要蓄力：否（布设 / 经营型）。
- 是否能够连续发动：可（一季一轮，来季再起；但谷雨蛊一季对同一畦只验一次）。
- 发动失败的可能原因：违时令（芽弱）、无水无肥、沤瓮开早半熟、寸光阴误对人或断供、弥缝蛊遇暴雨暴晒、任一环缺当季减产。

### 五、消耗情况

- 真元仙元消耗：中（七蛊按环催动），耗一至三转真元（白银真元为主），不涉仙元。
- 心力：按农时调度多蛊、判火候耗心神。
- 蛊虫损耗：**寸光阴为消耗类**（加速一次耗一只，原著「消耗寸光阴蛊，迅速达到三天三夜的时间要求」）；其余无损。
- 材料成本：谷粒 / 雨水（谷雨）、废料 / 陈曲（沤料）、同质灰泥（弥缝）、本地旧土（地力）、可数之寸光阴。
- 使用限制：依赖时令水肥、一季一畦一次（谷雨）、寸光阴不能对人、天真蘑菇只净「粉尘浊气」不改肥、弥缝蛊只补「裂」不新建。
- 副作用：寸光阴加速使地力耗更甚（来季须加倍补肥）；整季铺开、田庄显眼无防备。
- 可被破解的方式：冰雪道冻土 / 炎道焦土、断水、毁沤瓮、夺寸光阴、暴雨暴晒坏弥缝、宙道乱候。

### 六、杀招效果

- 核心效果：一季「肥—沤—催—速—收—修」的可续耕作，稳出苗、稳收成、稳田垄。
- 作用范围：一方田（数畦至数亩）。
- 持续时间：一季（寸光阴只压其中酝酿段）。
- 攻击方式：非攻击型（种植 / 生产 / 经营）。
- 对目标的影响：无对敌效果；对己为「薄地成稳产、废料成肥、收成归堆、田垄不漏」。
- 特殊效果：同时覆盖种植、炼材生产、资源采集、建筑修复四个非攻伐方向；天真蘑菇顺带净化沤场空气。

### 七、优缺点

- 主要优势：把「看天吃饭」的一季耕作拆成可控次第，四维（种 / 产 / 采 / 修）一体，废料循环、来季可续。
- 主要缺陷：零战斗力、极依赖时令水肥、慢（跨一季）、寸光阴为消耗品、任一环缺当季减产、加速反耗地力。
- 附带副作用：寸光阴加速使来季须加倍补肥；整季铺开显眼无防备。
- 可被破解的方式：冻土 / 焦土、断水、毁沤瓮、夺寸光阴、暴雨坏弥缝、宙道乱候。

### 八、实战表现

- 对目标的实际影响：无对敌效果；对己「薄地成稳产、废料成肥、收成归堆、田垄不漏」。
- 作用范围 / 持续 / 方式：一方田 / 一季 / 非攻击型（种植 / 生产 / 经营）。
- 最适合的场景：福地药田、门派粮田、废园复耕、为 O-K-013「壶天造田」提供凡阶农时范本。
- 被哪些类型的能力克制：冰雪道 / 炎道 / 断水、宙道乱候、阵道封田、劫夺寸光阴 / 沤料。
- 与哪些杀招存在配合：O-K-010「一囊担山」（运肥运粮、收成归仓）、O-K-012「牙筹清账」（收成清点核价）、O-K-013「壶天造田」（凡阶农时 → 仙阶造田，理一脉相承）。

### 九、改良与进阶

- **换蛊改良**：可把「净浊气」一维由「另择净室沤料」替代而省下天真蘑菇；代价是沤场浊气外溢、邻近药田受扰，属取舍而非纯增强（援引分析报告 3.5「换掉狂风蛊」之改良逻辑）。
- **加环（不新增 O-G 引用）**：可在「收」与「修」之间加一道「按单清点」（沿用 O-K-012 之理，由蛊师自理，不另设蛊），令收成直接入账；代价是多一道人工、耗心力。
- **不宜单蛊化**：援引分析报告 1.5「合炼后新蛊通常只保留一只主蛊能力并强化、其余能力丧失」与「有的杀招只能收敛为数只仙蛊配合、无法单蛊化」，若硬收成一只「春耕蛊」，须择主蛊（谷雨蛊），则沤 / 速 / 收 / 修多维尽失，整张图塌成单环；故本招保留多蛊协同更合理。
- **进阶上限锁死**：不得设计成「违时令亦丰产 / 凭空造种造水 / 寸光阴对人 / 一季无限催」——谷雨蛊「应时令、须播种水肥、一季一畦一次」与寸光阴「不能对人施展」是硬约束，均不可突破。

### 十一、设计理念

对应分析报告第 6 节「非战斗用途（经营 / 生产 / 质检 / 计时）」「资源转化与循环（废弃物 → 可用资源）」「节奏控制（次第 / 蓄力）」。本招一次覆盖种植、炼材生产、资源采集、建筑修复四个扩充方向，却仍是「一张按农时铺开的图」而非「七只蛊一起放大」：每环各有前置、各有破法，缺一环即当季减产。名字「春耕图」取节气与田图之象，与全卷「时令 / 痕迹」取象一致，不落现代科技腔与西幻腔。

### 十二、组合逻辑

- **核心 / 辅助**：核心 O-G-015 谷雨蛊（定「木道催芽 / 种植」性质），辅助 O-G-016 沤料、O-G-017 拾穗、O-G-018 弥缝（产 / 采 / 修）+ 地力蛊 / 寸光阴 / 天真蘑菇【原著蛊虫】（肥 / 速 / 净）。
- **协同类型**：按分析报告 3.2，兼具「条件型 + 载体型 + 增幅型」——地力蛊肥土、沤料蛊沤肥是谷雨蛊催芽的「前置条件」，田畦是承载一季的「载体」，寸光阴「加速酝酿」是「增幅」（只压时间、不增产），拾穗 / 弥缝是收尾条件。
- **为何不是「多蛊同用」反例**：七蛊按农时次第各补一环、同赴「一季稳产」单一目标，符合「每只蛊都要有作用」；且严格不把「四味酒虫精炼真元」一类蛊虫自身能力当作杀招。

### 十三、与原著体系的兼容性

> 逐条分析）

1. **品阶规则**：三转凡道杀招，转数取「初次出现时标注」、非强度刻度；组成蛊虫一转（拾穗、天真蘑菇）、二转（沤料）、三转（谷雨、弥缝）、「一转到五转都有」（寸光阴，本招取低转者）、品阶未标（地力）混用，低转蛊靠「采收 / 净化 / 沤料」机制位参与，不靠数值，符合「高转不使低转失效」。
2. **真元仙元消耗**：耗一至三转真元（白银真元为主，中）+ 心力（调度多蛊、判火候）+ 消耗类寸光阴（用一次消一只），不涉仙元；符合「凡道杀招用真元」与「消耗类蛊用一次即消失」。
3. **道痕运行**：本招不新增、不消耗道痕层级设定；谷雨「催生」、沤料「化废」、弥缝「补形」、地力「肥土」皆凡蛊能力，寸光阴「加速酝酿」为宙道凡蛊之既有能力，不凭空生痕、不增益修为、不补全仙蛊道痕。
4. **流派规律**：杀招流派为木道（主）辅以食道 / 土道 / 宙道，组成蛊虫含木道（谷雨）、食道（沤料）、土道（拾穗 / 弥缝 / 地力）、宙道（寸光阴）、草蛊（天真蘑菇）——「肥—沤—催—速—收—修」在同一目标上协同；跨流派援引「大宗师触类旁通」，且皆低阶无道痕互斥之虞，非无条件混合。
5. **蛊虫唯一性**：七只组成蛊虫全为凡蛊，凡蛊可同名多只；本招不含仙蛊，不新增唯一性例外。
6. **杀招组合规则**：7 只蛊按农时次第同时 / 接续催动、核心 1 + 辅助 6 分工明确、每只都有作用；发动条件、消耗、效果范围、缺陷与破解方式齐备，且「断水 / 毁沤瓮 / 夺寸光阴 / 暴雨坏弥缝 / 乱候」皆落到具体组件，符合检查表第 7、8 条。

### 十四、平衡性分析

- **强在何处**：把一季耕作拆成可控次第，种植 / 炼材生产 / 资源采集 / 建筑修复四维一体，废料循环、来季可续，是田庄 / 福地的经营底子。
- **代价与机制同源**：极依赖时令水肥（谷雨本质）、慢（跨一季）、寸光阴为消耗品且加速反耗地力、任一环缺当季减产、整季铺开显眼无防备——全从「按农时铺开的多环协同」里长出；尤以「加速越快、来季越须补肥」为「增幅必伴代价」的具体化。
- **破解链清晰**：冻土 / 焦土 / 断水、毁沤瓮、夺寸光阴、暴雨暴晒坏弥缝、宙道乱候、阵道封田。
- **上限锁死**：非攻击型、无对敌伤害、不凭空造种造水、寸光阴不对人、不涉仙元与道痕增益，故只是「经营流程」而非「万能丰产」，不破坏平衡。
