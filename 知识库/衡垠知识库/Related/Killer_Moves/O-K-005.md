### 一、杀招简介

「走马灯」是一式五转凡道控制 / 掩护杀招，核心是把转灯蛊「显眼」这一缺点反转成「诱饵」：旋转光幕既偏折直线攻击，又因极亮而牵住对手的注意与火力；一旦光幕被击破，依附其上的熄烛蛊（伴生蛊）以自身为代价抽走最后一缕光、抹去「熄灭」的痕迹，蒙尘蛊再以灰烟遮蔽气息，蛊师便在对手「以为得手」的瞬间脱身。一明一暗、御敌与脱身一体。代价是熄烛蛊一次性、须与转灯蛊同源炼化、且整招成立的前提竟是「对手肯先攻光幕」——若对手无视光幕直取本体，此招即落空。

### 三、运行原理

> 原文「二、杀招原理」照录）

转灯蛊的光幕既能偏折攻击，又因「亮」而极显眼——这本是它的缺点，本招却「以亮为饵」：对手的注意与攻击都被光幕牵制，一旦转灯蛊被击破，熄烛蛊（O-G-201）以自身为代价把最后的光抽走、灭去痕迹，蒙尘蛊再遮蔽气息，蛊师得以在对手「以为得手」的瞬间脱身。暗道「灭迹」与光道「显眼」一明一暗，构成「明修栈道、暗度陈仓」的战术。

### 四、发动条件

> 原文「三、发动过程」照录）

- 发动条件：需要偏折远程攻击、并准备脱身的战斗。
- 发动步骤：① 催转灯蛊张光幕偏折；② 引诱对手攻光幕；③ 光幕受创即由熄烛蛊灭迹、蒙尘蛊遮蔽，脱身。
- 发动速度：快。
- 是否需要蓄力：否。
- 是否能够连续发动：否（熄烛蛊一次性）。
- 发动失败的可能原因：对手不攻光幕而直取本体；熄烛蛊未与转灯蛊同源炼化。

### 五、消耗情况

> 原文「五、消耗与限制」照录）

- 真元或仙元消耗：中（转灯蛊持续耗真元），耗五转紫晶真元，不涉仙元。
- 蛊虫损耗：熄烛蛊一次性（随转灯蛊受创而亡）。
- 材料成本：无额外。
- 使用限制：熄烛蛊不可再生（须重新炼化）；光幕显眼易暴露。
- 副作用：光幕被击破意味着转灯蛊已受损。
- 可被破解的方式：无视光幕直取本体；范围攻击绕开偏折；光道对轰压过光幕。

### 六、杀招效果

> 原文「四、杀招效果」照录）

- 作用范围：贴身光幕 + 脱身范围。
- 持续时间：光幕随真元维持；灭迹为一瞬。

### 九、改良与进阶

- **加蛊改良**：可加入 O-G-012 雁书蛊，脱身后递一句「已离」口信给接应者，补上「脱身→联络」的一环；代价是须预置收信标记、一次只递一句。
- **补路径维**：可加入 O-G-006 问路石蛊，预记脱身路线，令灭迹之后撤退不迷；代价是路图只记「走过的路」，对全新撤离线无益。
- **不宜单蛊化**：熄烛蛊是「宿主灭则灭迹」的一次性伴生蛊，若按「杀招＝炼蛊残方」硬浓缩为单蛊「走马灯蛊」，依「合炼只保留一只主蛊能力并强化、其余丧失」，「灭迹」一维必失，整招塌成单纯偏折；故援引分析报告 1.5「有的杀招只能收敛为数只仙蛊配合、无法单蛊化」，本招保留多蛊协同更合理。
- **进阶上限锁死**：不得设计成「光幕不可破 / 熄烛可再生 / 对手直取本体也无效」——「对手不攻光幕而直取本体」是本招与生俱来的破法，不可抹去。

### 十一、设计理念

> 原文「七、设计说明」照录并补）

本招把转灯蛊「显眼」这一缺点反转成「诱饵」，是「以缺点作机制」的设计。熄烛蛊（伴生蛊）提供了「宿主灭则灭迹」的暗道手段，与光道形成明暗对比。整招不追求更强攻击，而是「控制+掩护+脱身」的战术型杀招，符合原创方向中「改变战斗节奏」的追求。本版补：它强在「节奏」而非「数值」，且把胜负手交给对手的选择（攻不攻光幕），是少见的「以对手行为为发动条件」之设计，故天然可破。

### 十二、组合逻辑

- **核心 / 辅助**：核心 O-G-010 转灯蛊（定「光道偏折 + 显眼诱饵」之性质），辅助 O-G-201 熄烛蛊（灭迹）、蒙尘蛊【原著蛊虫】（蔽息）。
- **协同类型**：按分析报告 3.2，属「条件型 + 载体型」混合——转灯蛊「显眼的光幕」是诱饵载体，熄烛蛊「宿主灭则灭迹」须依附其上且同源炼化才成立；蒙尘蛊补「遮蔽气息」之条件。三者把「缺点（显眼）」直接写成机制的一环。
- **为何不是「多蛊同用」反例**：三蛊同赴「偏折御敌 + 受创脱身」单一战术，光幕缺则无饵、熄烛缺则无灭迹、蒙尘缺则气息露，缺一即崩，符合「每只蛊都要有作用」。

### 十三、与原著体系的兼容性

> 逐条分析）

1. **品阶规则**：五转凡道杀招，转数取「初次出现时标注」、非强度刻度；核心转灯蛊五转、熄烛蛊为无定转伴生蛊、蒙尘蛊品阶待考，低阶 / 无定转组件靠「灭迹 / 蔽息」的机制位参与，不靠数值，符合「高转不使低转失效」。
2. **真元仙元消耗**：耗五转紫晶真元（中，转灯蛊持续耗），不涉仙元；符合「凡道杀招用真元（青铜→紫晶）」，「光罩旋转越快、真元耗越多」亦合「效果提升必伴消耗上升」。
3. **道痕运行**：本招不新增、不消耗道痕层级设定；熄烛蛊「灭迹」为暗道凡蛊能力，抽走的是「光 / 热 / 声之迹」而非道痕，不凭空生痕、不增益修为。
4. **流派规律**：杀招流派为光道+暗道（复合），组成蛊虫含光道（转灯）、暗道（熄烛 / 蒙尘）——「一明一暗」在同一战术目标上协同；跨流派援引「大宗师触类旁通」，非无条件混合，三蛊皆凡阶无道痕互斥之虞。
5. **蛊虫唯一性**：三只组成蛊虫全为凡蛊 / 特殊伴生蛊，凡蛊可同名多只；本招不含仙蛊，不新增唯一性例外。
6. **杀招组合规则**：3 只蛊同时催动、核心 1 + 辅助 2 分工明确、每只都有作用；发动条件、消耗、效果范围、缺陷与破解方式齐备，且「无视光幕直取本体 / 范围攻击 / 熄烛未同源炼化」皆落到具体组件或条件，符合检查表第 7、8 条。

### 十四、平衡性分析

- **强在何处**：御敌与脱身一体、出其不意，把「显眼」变诱饵，能在被远程围攻时金蝉脱壳，并接 O-K-006「画皮」继续惑敌。
- **代价与机制同源**：依赖「对手先攻光幕」（把胜负手交给对手，天然可破）、熄烛蛊一次性且须同源炼化、光幕显眼易暴露、光幕被破即转灯蛊受损、耗真元——全从「以亮为饵 + 伴生灭迹」的机制里长出。
- **破解链清晰**：无视光幕直取本体 → 诱饵落空；范围攻击 → 绕开偏折；光道对轰 → 压过光幕；熄烛未同源 → 灭迹不发。
- **上限锁死**：非直接攻击、无范围杀伤、熄烛不可再生、不涉仙元与道痕增益，故是「战术脱身」而非「无敌护身」。
