### 一、外观

- 外观：一粒几不可见的微尘，寄于蛊仙指尖。
- 大小：微尘。
- 颜色：无色。
- 形态特征：附着于炼蛊炉鼎之上，几乎与器物融为一体。
- 特殊视觉效果：催动时，微尘「张开」成一只极小的眼，洞察入微。

### 二、核心能力

- 基础能力：以「尘眼」观测一次炼蛊过程中材料、道痕、温度的细微变化，把肉眼不可见的波动转译为蛊仙可读的征兆，辅助判断成败节点。
- 作用机制：炼道「观微」——道痕的变化会在极微处先现端倪，微尘蛊专察此端倪。
- 作用对象：一次炼蛊过程的器物内部。
- 能力范围：贴身观测。
- 效果强度：能提前片刻察觉「即将失败/即将成型的临界」，但只能观测、不能改变。
- 使用限制：只作观测，不能干涉炼蛊；对超出炼道理解的异变无能为力。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 六转蛊仙，炼道者更易 |
| 炼化难度 | 高 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 仙元（低频） |
| 辅助食物 | 炼蛊时散逸的废渣道痕 |
| 频率 | 每用必补；不用则每月一次 |
| 成本 | 中 |
| 特殊环境 | 无 |
| 断食后果 | 尘眼闭合，无法再观 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 须附着于一次炼蛊的器物内部 |
| 消耗 | 六转青提仙元，每用必补 |
| 范围 | 贴身观测单一次炼蛊过程 |
| 持续 | 该次炼蛊全程 |
| 缺陷 | 只观测不改命；对超纲异变无效；无战斗力 |
| 克制 | 无直接克制 |
| 优势 | 炼道势力梦寐以求的「预警眼」，能减少炼蛊失败损耗 |
| 适用场景 | 高阶炼蛊、炼仙蛊、复原残方 |
| 不适用场景 | 实战 |
