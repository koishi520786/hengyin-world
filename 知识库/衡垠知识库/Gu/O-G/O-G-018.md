| 所属流派 | 土道 |
| 核心用途 | 建筑修复：弥合墙垣、田垄、器皿裂缝 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一把微缩的抹子，刃上总沾着一点半干的灰泥，泥色温润。
- 大小：三指长。
- 颜色：木柄褐，泥灰白。
- 形态特征：近了裂缝，刃上灰泥会自行微微鼓起，像要往缝里填。
- 特殊视觉效果：抹过时，裂缝像被「抚平」般收拢，不留新痕，只余一道比周围略深的浅线。

### 二、核心能力

- 基础能力：把墙垣、田垄、沟渠、陶石器皿上的「裂 / 缺 / 缝」用灰泥弥合，恢复其「不漏、不塌、不断」的原状。
- 作用机制：土道「补形」——只补「本是一体、后来裂开」之处，把散开的土 / 石 / 陶重新拢回原形；不新建、不加固、不改形，补出的强度不超过原物完好时。
- 作用对象：一处既有之物的裂缝 / 缺损。
- 能力范围：单处，约一臂所见之缝。
- 效果强度：弥合后不漏不塌、外观只留浅线；但不加固、不新建、不补「整块已粉碎」者、不补含活跃道痕的仙材裂痕。
- 使用限制：须「原物尚在、只是裂了」；粉碎、朽透、被连根毁去者无效；须以同质灰泥 / 土作料；一处只补一次，反复抹反致凸疤。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 三转蛊师，土道或兼修土道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 须亲手抹平过一道「雨后不渗」的墙缝作引 |
| 炼化风险 | 低 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 一小撮同质灰泥 / 田土 |
| 辅助食物 | 无 |
| 频率 | 每补一处喂一次；闲时每半月一撮土 |
| 成本 | 低 |
| 特殊环境 | 须阴干、不可在暴雨 / 暴晒中补，否则泥未合先裂 |
| 断食后果 | 刃上灰泥干硬，补出的缝虚合，一遇水即再裂 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 原物尚在、只是裂缺；须同质灰泥；须阴干 |
| 消耗 | 三转白银真元，中耗（单处） |
| 范围 | 单处，约一臂所见 |
| 持续 | 补合后长期，留浅线 |
| 缺陷 | 不加固、不新建、不补粉碎朽透者、不补仙材道痕裂、一处一次、暴雨暴晒难成 |
| 克制 | 被炎道（烤裂）、冰雪道（冻胀）、力道「震裂」克制；与 O-G-102 归墟蛊（仙材道痕复原）分属凡 / 仙两层，互不替代 |
| 优势 | 低耗地把「坏了一道缝」就地修回，是田庄、据点、器物的常备维护蛊 |
| 适用场景 | 修田垄沟渠、补墙垣仓壁、合陶石器皿、震后小修 |
| 不适用场景 | 整屋重建、加固、仙材裂痕（宜归墟蛊）、粉碎之物 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一把抹过百年老墙、从未留过凸疤的旧抹子 |
| 辅助材料 | 老墙刮下的一撮陈灰泥、阴檐下一滴无风之水 |
| 过程 | 以真元把「拢回原形」之意炼入抹刃，令灰泥认得原物之形 |
| 难度 | 中 |
| 成功率或风险 | 中；若灰泥不同质，补处色差明显、遇水先裂 |
| 替代材料 | 可用竹抹板替代，但只补土、不补陶石 |
