# 【原创设定】守更蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-004 |
| 名称 | 守更蛊 |
| 品阶 | 三转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 律道 |
| 核心用途 | 辅助（固定节律内强化「守约」状态） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一枚古朴的更鼓，仅指尖大，鼓面紧绷。
- 大小：指尖大小。
- 颜色：木色鼓身，鼓面灰白。
- 形态特征：鼓身刻着均匀的刻线，恰如一夜的更次。
- 特殊视觉效果：每过一刻，鼓面会自行轻颤一下，发出几乎只有蛊师能听见的「笃」。

### 二、核心能力

- 基础能力：设定一个「更次节律」（如守一夜、候三更），在节律存续期间，使蛊师的「守约/戒备」状态获得律道加持——精神更清明、不易被催眠或惑乱，对违反既定节律的异动更敏锐。
- 作用机制：守更蛊把「时间」划成固定的更次，蛊师与其「定约」后，节律成为一道微弱的律道道痕，约束心神不散、不惰。
- 作用对象：蛊师自身（守约者）。
- 能力范围：本人。
- 效果强度：能抵御轻微的精神惑乱与困意；对「掐准更次发动」的异动有提前警觉。
- 使用限制：一次只能定一个节律；节律一破（如失约、睡着、被打断）加持即散，且当夜不可再定；只护「守约」不护「肉身」。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 三转蛊师，律道或兼修律道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 需一位从未失约者的一句「我必守此更」作炼化之引 |
| 炼化风险 | 低 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 以「准时」为食——蛊师每守约一次，鼓面便得一分滋养 |
| 辅助食物 | 夜露 |
| 频率 | 随守约频率；久不守约则需喂夜露维持 |
| 成本 | 低 |
| 特殊环境 | 无 |
| 断食后果 | 鼓面松弛、更次紊乱，最终无法定约，蛊亡 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 需与蛊师「定约」；一次只定一个节律 |
| 消耗 | 三转白银真元；定约后无需持续耗真元 |
| 范围 | 本人 |
| 持续 | 一个更次周期（整夜） |
| 缺陷 | 无攻击、无防御；节律被外力强断即失效；只对「守约」类情境有效，对正面强攻无用 |
| 克制 | 克制梦道/惑乱类轻微侵扰；被强行打断节律的手段克制 |
| 优势 | 守护心神、反制惑乱，是少数「非战斗却能在持久对峙中起决定性作用」的蛊；无需持续耗真元 |
| 适用场景 | 守夜、值守、伏击、候人、盯梢等需长期保持清醒与定力的场合 |
| 不适用场景 | 短促遭遇战；节律频繁被打断的混乱战场 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一块被更夫敲了十年、从未误时的更鼓鼓皮 |
| 辅助材料 | 更夫的一根白发 |
| 过程 | 在「子时交更」的刹那，以真元将鼓皮缩炼成蛊 |
| 难度 | 中 |
| 成功率或风险 | 中；错过交更之刻即失败，鼓皮作废 |
| 替代材料 | 可用更漏的刻度尺替代，但成品定约精度稍差 |
