# 【原创设定】记仇蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-009 |
| 名称 | 记仇蛊 |
| 品阶 | 三转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 魂道 |
| 核心用途 | 辅助（刻录一次「仇恨印记」，反哺战意） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一粒乌黑的、形如针尖的魂种，冷而沉重。
- 大小：针尖大。
- 颜色：乌黑，偶泛一丝暗红。
- 形态特征：被「记仇」者的气息一近，魂种会微微发烫。
- 特殊视觉效果：催动时，暗红顺着针尖爬升，像一道未干的血痕。

### 二、核心能力

- 基础能力：把对某人的「恨意」刻录为一道魂印。日后此人气息再近，蛊师心窍中的恨意被唤醒，战意、胆气为之暴增；恨印也可在关键时刻一次性「燃尽」，换来短促的爆发。
- 作用机制：魂道「情绪可存蓄」——把负面情绪炼成可调用的魂道道痕，需时反哺心神。
- 作用对象：本人（作用于自身情绪与战意）。
- 能力范围：本人；感知范围约百步。
- 效果强度：战意提振约三成（不增力、只提胆气与专注）；燃尽爆发可短暂顶住心神压制。
- 使用限制：只能记「确有深仇」之人，虚造的恨意种不下；恨印最多存三道；燃尽一次即耗一道，需重新刻录。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 三转蛊师，魂道或兼修魂道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 需蛊师确有一段刻骨之仇 |
| 炼化风险 | 中；若本无真仇而强炼，心神会被反噬 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 以「回想那仇」喂之（回想越真，恨印越牢） |
| 辅助食物 | 无 |
| 频率 | 不定期，仇念淡时须主动回想维系 |
| 成本 | 低（但耗心神） |
| 特殊环境 | 无 |
| 断食后果 | 恨印渐淡，最终消散 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 只能记「确有深仇」之人；恨印最多存三道 |
| 消耗 | 三转白银真元；喂养耗心神；燃尽耗一道恨印 |
| 范围 | 本人；感知约百步 |
| 持续 | 恨印长期留存，燃尽一次即消一道 |
| 缺陷 | 只提战意不增实力；会放大恨意、易使人偏执；依赖真实仇恨，不能凭空造 |
| 克制 | 克制惑乱、怯敌、心神压制；被梦道「消解情绪」、律道「释然」类手段克制 |
| 优势 | 非战斗却能决定战斗的心气；可作「反心神压制」的底牌；配合伏击（洄游蛊设伏）极契合 |
| 适用场景 | 复仇、对峙、被威压时 |
| 不适用场景 | 无仇可记的纯粹利益之争 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一滴在极恨之时流下的泪（或血） |
| 辅助材料 | 仇人的一缕气息（发、旧物、血皆可） |
| 过程 | 于深夜独处时，以真元将恨意「刻」入魂种 |
| 难度 | 中 |
| 成功率或风险 | 中；强炼伪仇则魂种自散、反噬心神 |
| 替代材料 | 无（仇恨不可替代） |
