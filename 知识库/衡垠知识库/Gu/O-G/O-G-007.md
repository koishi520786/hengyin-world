### 一、外观

- 外观：一团米粒大的淡灰气旋，常悬浮在半空微微打转。
- 大小：米粒大。
- 颜色：淡灰，中心微亮。
- 形态特征：周围空气中的浮尘会不自觉地朝它缓缓聚拢。
- 特殊视觉效果：聚满时，中心会凝出一颗极小的、半透明的「气晶」。

### 二、核心能力

- 基础能力：缓慢吸附周遭的粉尘、浊气与杂质，凝练成可存贮、可贩卖的「气晶」——一种低阶气道资源，可作炼蛊辅材或换取元石。
- 作用机制：气道「聚气成晶」，把散逸的无主之气归拢提纯。
- 作用对象：空气中的浮尘浊气。
- 能力范围：数尺内。
- 效果强度：日夜不停，约七日凝成一颗小气晶。
- 使用限制：空气越污浊效率越高，反之越慢；产出的气晶品质低，只作辅材；不能净化已黏附在物表、人体上的浊气。

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 需空气中有浮尘浊气 |
| 消耗 | 一转青铜真元，几乎为零（自给自足） |
| 范围 | 数尺内 |
| 持续 | 日夜不停，约七日凝成一晶 |
| 缺陷 | 无任何战斗、侦查能力；产率低、品质低；会被「无尘净室」环境废掉产出 |
| 克制 | 无 |
| 优势 | 零成本、可长期稳定产出气道辅材；是低阶蛊师「躺着攒资源」的入门之选 |
| 适用场景 | 城市、矿场、废墟、战场遗址等浊气重之地长期经营 |
| 不适用场景 | 战斗；洁净环境 |
