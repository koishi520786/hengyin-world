# 【原创设定】回声蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-001 |
| 名称 | 回声蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 音道 |
| 核心用途 | 侦查（回声标记与追踪） |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：形如一只干瘪的空蝉蜕，半透明，腹内无实。
- 大小：拇指盖大小。
- 颜色：通体灰白，边缘泛一层极淡的蓝。
- 形态特征：背上有三道环纹，环纹随最近一次「回响」的强弱或深或浅。
- 特殊视觉效果：催动时，空蝉蜕会轻轻震颤，发出人耳几乎听不见的嗡鸣；嗡鸣撞上障碍后会折返，在蛊师心窍中形成「第二重声响」。

### 二、核心能力

- 基础能力：向四周发出一次不可闻的低频回响，声波遇到障碍折返，蛊师据此在脑海中描出周围环境的粗糙轮廓。
- 作用机制：低频声穿透力强、衰减快，只适合近距；声波并非「看见」，而是「听见形状」，故无法分辨颜色、文字，只能勾勒凹凸、疏密与远近。
- 作用对象：半径约十五步内的实体障碍。
- 能力范围：十五步，越远越模糊。
- 效果强度：能辨明通路、门窗、沟壑与静止的大物；对贴地匍匐、柔软吸音之物几乎无效。
- 使用限制：每次催动需持续供真元；环境中噪声越大、杂响越多，轮廓越乱；对有音道修为者，这回响本身可被其察觉。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，音道或兼修音道者炼化更易 |
| 炼化难度 | 低；回声蛊意志微弱 |
| 特殊要求 | 无 |
| 炼化风险 | 几乎无 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 静水；每三日一碗 |
| 辅助食物 | 铜铃的锈屑（可让下次回响更清） |
| 频率 | 每三日一次 |
| 成本 | 低 |
| 特殊环境 | 若在「无声之室」（四面皆吸音软泥）中喂养一次，效果维持更久 |
| 断食后果 | 回响逐次变闷，最终无法勾勒轮廓，蜕壳硬化裂开、蛊亡 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 需持续供真元；环境偏静方可用 |
| 消耗 | 二转赤铁真元，低耗、可连发 |
| 范围 | 十五步内，越远越模糊 |
| 持续 | 单次回响一瞬，可连续催动 |
| 缺陷 | 无攻击力；无法辨字辨色；易受噪声干扰；对吸音软物、匍匐贴地之物近乎失明 |
| 克制 | 克制以视觉扰乱／迷幻为主的隐匿（因它不靠眼睛）；被音道反制（察觉并扰乱回响）、被水道「静水」环境削弱 |
| 优势 | 消耗低、可连发、不依赖光线，黑暗中亦可用；能识破视觉遮蔽但非实体隐藏 |
| 适用场景 | 洞穴、密道、浓雾、黑夜、废墟等目不能视之地 |
| 不适用场景 | 市集、战场、风口等嘈杂处；面对专精音道的对手 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一只自然老死的夏蝉蜕壳 |
| 辅助材料 | 三滴春雨后积于凹石的静水、一枚被敲响过九九八十一次的老铜铃碎屑 |
| 过程 | 在完全无声的静室内，以真元浸润蝉蜕三日，令空壳记住「折返之声」 |
| 难度 | 低 |
| 成功率或风险 | 成功率较高；失败则蝉蜕碎裂，损失材料 |
| 替代材料 | 可用秋蝉蜕替代，但成品回响偏短 |

### 七、搭配关系

| 项目 | 内容 |

| 可参与杀招 | O-K-003「静夜图」（核心：声之警戒）、O-K-007「空谷回音」（辅助：以低频回响锁定来音方位） |

| 进阶方向 | 可升炼为四转「广域回声蛊」：以回声蛊为主蛊，合炼一只抗噪类气道凡蛊，保留「声之轮廓」单一能力并强化范围与抗噪，代价是真元消耗与体积显著上升、辨形精度不再随距离提升（合炼只保留主蛊能力，符合原著升炼规律） |
