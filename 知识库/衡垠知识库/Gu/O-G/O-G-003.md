# 【原创设定】倒影蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-003 |
| 名称 | 倒影蛊 |
| 品阶 | 三转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 水道 |
| 核心用途 | 侦查/伪装（水面倒影成像、以假乱真） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一尾极扁的银鱼，游于水面时几乎与光融为一体。
- 大小：两指长。
- 颜色：银白，腹下泛青。
- 形态特征：静止时扁如刀片，可贴伏水面；游动时尾鳍搅起一圈不易察觉的细纹。
- 特殊视觉效果：潜入水中后，会「记住」最近一次映在水面的画面，并把它短暂地留在水面。

### 二、核心能力

- 基础能力：把一片水面当作「镜」，摄下此刻映于水面的影像，并将其凝固在水面数息，供蛊师读取；也可用其倒影覆盖真实水面，制造「假倒影」。
- 作用机制：倒影蛊吃的是「光的反射」，它在水面存下一层极薄的水膜，把已摄下的画面固定在水膜上；旁人看去，水面倒影与真实无异，却已是数息前的旧景。
- 作用对象：一片静水面（约一丈见方）。
- 能力范围：需目视水面；摄取与显影都限于同一片水。
- 效果强度：能清晰摄下并回放数息前的倒影；能造「假倒影」误导观察者，但假倒影是静态的，一经细看会露破绽。
- 使用限制：必须静水，流水、波涛皆不可；光照不足时影像极淡；只能作用于水面，不能凭空成像。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 三转蛊师，水道或兼修水道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 无 |
| 炼化风险 | 低 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 月华照射过的静水 |
| 辅助食物 | 银屑 |
| 频率 | 每五日一次 |
| 成本 | 低 |
| 特殊环境 | 满月之夜喂一次，可增强下次显影的清晰度 |
| 断食后果 | 水膜渐干，蛊僵死 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 必须静水、需目视水面、需一定光照 |
| 消耗 | 三转白银真元，低耗 |
| 范围 | 一丈见方的同一片静水面 |
| 持续 | 显影凝固数息 |
| 缺陷 | 无攻击力；极度依赖静水环境；假倒影静态、细节经不起推敲；被光道「强光」直接废掉水膜 |
| 克制 | 克制需要「持续目视」的侦察；被光道（强光破坏水膜）、冰雪道（冻结水面）克制 |
| 优势 | 不靠真元「看」，而是「借水面之镜」，隐蔽性强；可回放旧景、可伪造倒影；配合回声蛊可补足视觉 |
| 适用场景 | 湖畔、池塘、水井、雨后积水、蓄水陷阱旁 |
| 不适用场景 | 荒漠、无水面、大风浪、极寒结冰之地 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一尾在满月之夜浮头望月的银鱼 |
| 辅助材料 | 一面照过月亮的古铜镜的镜面水汽 |
| 过程 | 于静水之畔，以真元将银鱼与水膜「合」为一体，期间水纹不可破 |
| 难度 | 中 |
| 成功率或风险 | 中；失败则银鱼脱水而亡 |
| 替代材料 | 可用白鳞鱼替代，但成品只能显影、不能造假 |

### 七、搭配关系

| 项目 | 内容 |

| 可参与杀招 | O-K-003「静夜图」（辅助：影之警戒，回放/伪造水面倒影） |
| 蛊虫组合 | 与回声蛊、守更蛊、问路石蛊共织「声、影、时、地」四维警戒网（见 O-K-003）；与复刻蛊在「以假乱真」上同源 |
| 进阶方向 | 可升炼为五转「镜中月蛊」：以倒影蛊为主蛊，合炼一只光道折射类凡蛊，把倒影固定时间由数息延长至一炷香，并小范围折射光线；代价是水膜更惧强光、且每次造假倒影须耗一枚银屑辅材（效果提升伴随成本与破绽同步上升） |
| 其他关联资料 | 见《原创杀招图鉴.md》O-K-003 |
