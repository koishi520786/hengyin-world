# 【原创设定】谷雨蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-015 |
| 名称 | 谷雨蛊 |
| 品阶 | 三转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 木道 |
| 核心用途 | 种植：催种子抽芽、匀苗 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一粒饱胀将裂的谷种，壳上凝着一层细密水珠。
- 大小：指甲盖大。
- 颜色：谷黄泛青，水珠澄亮。
- 形态特征：近了湿土，谷壳会微微一鼓，像要裂开。
- 特殊视觉效果：催动时，谷种周围浮起一层极淡的雨气，落地无声，却见土面针尖似的冒出嫩芽。

### 二、核心能力

- 基础能力：催动一方已播之田，令种子齐整抽芽、并按疏密匀苗，使一季出苗不稀不挤。
- 作用机制：木道「催生」——它不凭空造种、不替代水肥，只把「本就要发」的芽催得齐、催得匀；土、水、种三者缺一，它催不动。
- 作用对象：一方已播种、且有水有肥的田畦。
- 能力范围：约一畦（数丈见方）。
- 效果强度：出苗齐整、疏密合度；但不增产、不改良种、不催「已死之种」、不代替后续生长。
- 使用限制：须应时令（谷雨前后最验，违时则芽弱）；须田已播种、水肥已备；一季对同一畦只验一次，重催反致苗挤根弱。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 三转蛊师，木道或兼修木道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 须在「春雨落、种子将破壳」的那一候炼化 |
| 炼化风险 | 低；错过时令则谷种僵而不醒 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 谷粒 / 一两撮新芽尖 |
| 辅助食物 | 雨水（非井水） |
| 频率 | 每催一畦喂一次；闲时每半月一粒谷 |
| 成本 | 低 |
| 特殊环境 | 须在应时节气、有雨露之地效力最验 |
| 断食后果 | 谷壳干瘪，催芽不齐，重催易出「老少苗」 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 应时令、田已播种、水肥已备、一季一畦一次 |
| 消耗 | 三转白银真元，中耗（一方田） |
| 范围 | 约一畦，数丈见方 |
| 持续 | 催芽为一候之力，苗齐后不再作用 |
| 缺陷 | 不增产、不改种、不催死种、不代水肥；违时令芽弱；重催伤苗 |
| 克制 | 被冰雪道（冻土）、炎道（焦土）、旱魃类「断水」手段克制；与原著地力蛊【原著蛊虫】（增长土地肥力、帮助栽培作物）互补 |
| 优势 | 把「看天吃饭」的出苗环节变成可控一步，是经营型势力的稳产底子 |
| 适用场景 | 春播、福地药田、门派粮田、苗圃匀苗 |
| 不适用场景 | 无种无水的荒地、隆冬、需即刻收成的场合（宜配寸光阴【原著蛊虫】加速酝酿） |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一捧在谷雨当日落地、当日齐出芽的谷种 |
| 辅助材料 | 谷雨雨水一盅、湿田黑土一撮 |
| 过程 | 以真元把「齐发」之意炼入谷种，令其记住那一候的雨气 |
| 难度 | 中 |
| 成功率或风险 | 中；若雨气不真，成品催芽虽齐却苗弱 |
| 替代材料 | 可用稻种替代，但只验水田、不验旱田 |

### 七、搭配关系
