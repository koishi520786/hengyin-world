### 一、外观

- 外观：一支无墨的笔，笔尖永远悬着一滴透明的「空墨」。
- 大小：寻常笔。
- 颜色：笔身素白，空墨无色。
- 形态特征：笔身刻满极细的刻度，如缩小的画作。
- 特殊视觉效果：落笔时，笔尖在虚空「画」出对象的轮廓，一笔不多、一笔不少。

### 二、核心能力

- 基础能力：对一件「有形之物」进行一次「形」的复刻，产出与该物外形、质地一般无二、但**不含任何道痕**的复制品。
- 作用机制：画道「写形不写真」——只复制「看得见的形」，不复制「内在的道」。复制品空有其表，无能力、无道痕。
- 作用对象：一件有形实体（蛊虫、器皿、材料皆可，但不能是活人）。
- 能力范围：单件，大小以笔能描尽为限。
- 效果强度：外形以假乱真；但内在全无，稍加检测（如仙蛊感应、道痕探测）即露。
- 使用限制：一次只能复刻一件，且须「当面」描形；复制品不能承载能力；复刻仙蛊时，其唯一性不受影响（因只是空形）。

| 项目 | 内容 |
|---|---|

| 成本 | 中 |
| 特殊环境 | 无 |
| 断食后果 | 笔尖空墨干涸，蛊僵 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 须「当面」描形；一次只复刻一件 |
| 消耗 | 六转青提仙元，每用必补 |
| 范围 | 单件，大小以笔能描尽为限 |
| 持续 | 复制品长期存形，但无道痕 |
| 缺陷 | 复制品无任何能力与道痕；易被道痕探测识破；只能描有形之物 |
| 克制 | 克制「看形不看真」者；被道痕探测、真伪辨类仙蛊克制 |
| 优势 | 唯一能量产「空形」的仙蛊，可作障眼、可作炼蛊试验替形、可作展示与震慑；不触动仙蛊唯一性 |
| 适用场景 | 欺敌、炼蛊前试形、布疑阵 |
| 不适用场景 | 需真材实料、真能力的场合 |

| 过程 | 以仙元将「空」炼入笔尖 |
