# 【原创设定】结绳蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-021 |
| 名称 | 结绳蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 智道 |
| 核心用途 | 资质 / 记忆 / 推演：把见闻结成绳结，回放不失真 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一段旧麻绳，绳上打着疏密不一的结，结尾垂着一缕散穗。
- 大小：一尺长，可绕腕。
- 颜色：麻褐，结处磨得发白。
- 形态特征：记一件事，绳上便多一个结；结越大，所记越要紧。
- 特殊视觉效果：回放时，蛊师指尖捏住某结一捻，那段见闻便「按当时次序」在心头过一遍，不添不漏。

### 二、核心能力

- 基础能力：把一段亲眼所见 / 亲耳所闻的见闻、口供、契约条款「结」成绳结，日后按结回放，次序与细节不失真，可作记忆存档与推演底本。
- 作用机制：智道「结以存真」——只「录」不「解」：它保证「记下的不歪」，但不替蛊师推断、不补忘掉的部分、不辨所记真伪。原著书虫【原著蛊虫】是「喂什么记什么、永记不失」，本蛊与之同类而更重「次序」，二者可并用不悖。
- 作用对象：一段亲身经历 / 见闻 / 契约条款。
- 能力范围：绳长有限，结数有限（约十数结，结大者占得多）。
- 效果强度：回放次序、细节不失真；但不能推演未来、不能辨伪、不能记自己没留意到的细节。
- 使用限制：只记「亲身经见」；道听途说、事后脑补者结不牢；结满须「解结」（抹去旧记）方能再结；绳断则所记尽失。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，智道或兼修智道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 须亲手按「事之先后」打过一串不错序的结作引 |
| 炼化风险 | 低；结序打乱则成品回放错序 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 一缕麻纤维 / 旧绳丝 |
| 辅助食物 | 无 |
| 频率 | 每结一记事喂一次；闲时每半月一缕 |
| 成本 | 低 |
| 特殊环境 | 须避潮避虫，麻绳受潮霉、被虫蛀则结散 |
| 断食后果 | 绳渐脆、结松，回放次序开始错漏 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 只记亲身经见；结满须解旧方能结新 |
| 消耗 | 二转赤铁真元 + 心力（结越密、回放越耗神） |
| 范围 | 约十数结 |
| 持续 | 长期存记，绳断即失 |
| 缺陷 | 只录不解、不辨伪、不推演、不记未留意之细节；结数有限、怕潮怕虫、绳断全失 |
| 克制 | 被梦道「改梦 / 消忆」、魂道「扰神」、律道「释然」类手段干扰回放心境；与书虫（永记不失）互补而不相替 |
| 优势 | 把「容易记岔、容易被事后脑补带偏」的见闻按次序钉住，是契约、口供、复盘推演的可信底本 |
| 适用场景 | 录契约、存口供、复盘战局、记路线见闻、为推演备料 |
| 不适用场景 | 辨伪（宜竹君子）、推演结论（宜智道推算蛊）、记未亲历之事、需无限存档 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一段记过一整季农事、结序从未错的旧麻绳 |
| 辅助材料 | 一缕新麻、一滴桐油（防潮） |
| 过程 | 以真元把「按序不歪」之意炼入绳结，令每结各系一段见闻 |
| 难度 | 中 |
| 成功率或风险 | 中；引绳若曾错序，成品回放必错一处 |
| 替代材料 | 可用丝绦替代，结更密但更怕虫 |

### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | O-G-020 牙筹蛊（录约存档）、O-G-012 雁书蛊（存口信要旨）、O-G-202 应候蛊（择推演时辰）、书虫·蛛丝马迹蛊【原著蛊虫】 |
| 可参与杀招 | O-K-012「牙筹清账」（辅助：把契约条款按序结绳存档，供核账时回放比对） |
| 蛊虫组合 | 与书虫（底本永记）、牙筹蛊（核数）、竹君子（测谎）、砥砺蛊（验质）串成交易链，结绳蛊专司「录约存档」（见 O-K-012）；与雁书蛊配合则「口信过耳即结绳留底」 |
| 进阶方向 | 可升炼为三转「谱牒蛊」：把「零散结」编成「可交叉检索的谱」，便于从多段见闻里比对同异；代价是每多一重关联便多耗一分心力、绳长却固定，谱越密可新结之事越少，且交叉比对只呈「同异」不代下结论，检索力以「容量与心力」为代价 |
| 其他关联资料 | 见《原创杀招图鉴.md》O-K-012；原著书虫「将要记的东西喂给书虫吃，从此只要书虫不失，蛊师就能永远清晰地记得」之设定本卷照录不改 |
