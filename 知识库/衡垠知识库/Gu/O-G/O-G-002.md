# 【原创设定】余烬蛊

**基本资料**

### 一、外观

- 外观：一撮永不熄灭的暗红灰烬，无固定形状，被微弱的火星托起悬浮。
- 大小：约一握之灰。
- 颜色：暗红为主，偶见金点闪灭。
- 形态特征：靠近尚有余温之物时，会自行聚拢成一小团火茧。
- 特殊视觉效果：吞食余火时，灰烬表面浮起细密火星，如星子自下而上攀爬。

### 二、核心能力

- 基础能力：吸收环境中的「余火」「余温」——篝火残烬、灶膛余炭、被炎道攻击灼烧后残留的余焰——将其凝练为可存蓄的「火种」。
- 作用机制：余烬蛊只回收「将熄未熄」的火，不主动引火；它把散逸的热力压成一点火种，封存在自身灰烬中，蛊师需要时再引燃。
- 作用对象：一切余温未散的炭、灰、残焰。
- 能力范围：贴身，约数尺。
- 效果强度：积满一握灰，可存约可维持一夜营火之热；火种可反复引燃、多次取用，但每取一次总量减。
- 使用限制：不能凭空生火，必须有「余温来源」；封存的火种会缓慢流失，最长存续七日；遇水即大损。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，炎道或兼修炎道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 需亲手以真元护住一次「自然熄灭的火」至最后一星 |
| 炼化风险 | 低；但若炼化失败，火星反扑可灼伤蛊师心窍 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 余温炭灰（以将熄的炭火喂食） |
| 辅助食物 | 无 |
| 频率 | 视取用情况；不取用时每七日喂一次即可 |
| 成本 | 低 |
| 特殊环境 | 最好喂「自己参与熄灭的火」，火种更纯 |
| 断食后果 | 火种彻底冷透，蛊成死灰，无法再醒 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 必须有「余温来源」，不能凭空生火 |
| 消耗 | 二转赤铁真元（回收时低耗），火种本身为存蓄资源 |
| 范围 | 贴身数尺 |
| 持续 | 火种最长存续七日，缓慢流失 |
| 缺陷 | 无直接攻击力；火种会自然流失；遇水、遇冰即毁；对「已经冷透」的炭灰无用 |
| 克制 | 被水道、冰雪道克制；能辅助炎道（作为火种后备） |
| 优势 | 把「必然浪费的余热」变作资源；无明火时是唯一稳定的火种来源；配合炎道杀招可省真元 |
| 适用场景 | 荒野、长夜、断粮断源时；炼蛊需稳定火候时 |
| 不适用场景 | 水域、雪原、无处取火之地 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一场「天火」（雷击起火）烧过的枯木所余之炭 |
| 辅助材料 | 夜露九滴、松脂一捻 |
| 过程 | 在无风之夜，以真元将炭灰中最后一星火「温养」至天明不灭 |
| 难度 | 中 |
| 成功率或风险 | 中；失败则炭灰散尽，且可能引火自灼 |
| 替代材料 | 可用常年不断火的炭窑余灰，但成品火种不纯、存续更短 |
