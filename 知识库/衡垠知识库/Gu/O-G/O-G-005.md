# 【原创设定】断尾蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-005 |
| 名称 | 断尾蛊 |
| 品阶 | 四转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 变化道 |
| 核心用途 | 保命（舍弃肢体分身，代偿一次致命伤） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一截蜷曲的蜥尾，断口处永远滴着不肯干涸的一滴血。
- 大小：小指长。
- 颜色：灰绿，断口猩红。
- 形态特征：遇危时会骤然绷直、微微跳动，似要自行断离。
- 特殊视觉效果：催动时，断口那滴血会化开，在蛊师身外映出一个「将要舍弃」的虚影。

### 二、核心能力

- 基础能力：在致命一击及身的瞬间，将「这一击」连同被击中的一部分身躯，一起割舍到断尾蛊化出的替身上，本体以残躯脱身。
- 作用机制：变化道「弃形求生」——断尾蛊吃的是「舍弃」本身。它在蛊师体内种下一道「可弃」的标记，命中时把伤害与道痕一起引向被舍弃的部分。
- 作用对象：本人（一次性替死）。
- 能力范围：本人。
- 效果强度：可代偿一次「足以致死的直接打击」，本体存活，但被舍弃的部分永久失去（含其上道痕）。
- 使用限制：每只断尾蛊只能用一次；只对「有形的、可落到肉身上的直接伤害」有效，对魂魄、诅咒、灾劫、梦道侵蚀等无形伤害无效；舍弃的部分不可复原。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 四转蛊师，变化道或兼修变化道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 需蛊师自愿「让出」身上一块肉作种蛊之引，此块肉日后即是最先被舍弃的部分 |
| 炼化风险 | 高；炼化失败会永久损失那块引肉及其道痕 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 蛊师自身的一滴血（低频） |
| 辅助食物 | 其他生灵「断尾求生」后新生的嫩尾 |
| 频率 | 每半月一次 |
| 成本 | 中（损耗自身气血，虽可回补） |
| 特殊环境 | 无 |
| 断食后果 | 断尾蛊与蛊师血肉联结渐松，替死时将「多舍」一截本不该舍的部分 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 致命一击及身的瞬间；每只仅一次 |
| 消耗 | 四转黄金真元；代价是永久丧失一部分肉身与其上道痕 |
| 范围 | 本人 |
| 持续 | 一瞬（一次性） |
| 缺陷 | 代价是永久丧失一部分肉身与道痕；只挡有形直接伤害；一次性、不可叠加多次替死；舍弃后的残躯需长时间休养 |
| 克制 | 克制单体强攻型的「一击必杀」；被魂道、诅咒、梦道、律道（限死）等无形手段克制，被「范围持续伤害」克制（仍只舍一次） |
| 优势 | 保命上限极高，能挡下必死之击，是稀缺的「多一条命」手段；只需一只、不占多个空窍位 |
| 适用场景 | 强敌单挑、被偷袭、突围保命 |
| 不适用场景 | 面对魂道/梦道/灾劫/群体围杀 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一尾真正断尾求生、且最终重生的石龙子（蜥蜴）的旧尾 |
| 辅助材料 | 蛊师自身一块自愿让出的血肉 |
| 过程 | 在蛊师命悬一线（重伤濒死）之时方成——炼成即种下 |
| 难度 | 高 |
| 成功率或风险 | 高；失败则引肉与材料皆损 |
| 替代材料 | 可用壁虎尾替代，但替死效果打折，会「多舍」更多本体 |

### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | 任何蛊皆可搭配；尤其配合 O-G-005 之后仍能行动的移动蛊（如 O-G-008 洄游蛊）更佳；O-G-009 记仇蛊（设伏→复仇→保命链末端） |
| 可参与杀招 | **不参与任何 O-K 编号杀招**（纯保命蛊，不与杀招同时催动，避免「杀招崩解时替死标记误触发」） |
| 蛊虫组合 | 与洄游蛊、记仇蛊构成「设伏→复仇→保命」的战术链，但断尾蛊本身只作兜底，不入杀招组成表 |
| 进阶方向 | 可升炼为六转仙蛊「壁虎尾」：保留「弃形替死」单一能力并强化为可多次替死，但每一次仍须逐次舍弃一部分本体（含其上道痕），且因仙蛊唯一，天下仅此一只；多次替死的代价是道痕层层剥落、修为随之缓降，绝不设计为无条件复活 |
| 其他关联资料 | 原著变化道「弃形求生」思路；检查表第 10 条禁「无条件复活／无限重生」 |
