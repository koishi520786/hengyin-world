# 【原创设定】壶天蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-105 |
| 名称 | 壶天蛊 |
| 品阶 | 六转 |
| 凡蛊或仙蛊 | 仙蛊（同名天下唯一） |
| 所属流派 | 宇道 |
| 核心用途 | 特殊空间：开一方壶中小空间 |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一枚扁圆小葫芦，葫芦口极细，内壁望之似有一线天光。
- 大小：拳头大，可系于腰。
- 颜色：葫芦皮赭黄，口沿泛一线幽蓝。
- 形态特征：壶口开时，细口里会浮出一圈极淡的涟漪，如门将启。
- 特殊视觉效果：纳物时物件不「缩」，而是被壶口那圈涟漪「让」进去，壶身不鼓不胀。

### 二、核心能力

- 基础能力：以仙元在葫芦腹内撑开一方「壶中小空间」，可纳死物、干材，亦可短时容一件「已封印沉眠」的活物；空间与外隔绝，内物不腐不潮、不与外物互扰。
- 作用机制：宇道「壶里乾坤」——只「容」，不生、不造、不加速、不产道痕；空间大小固定，撑开须持续供仙元维持壶口那道界门。
- 作用对象：一方静物 / 一件已沉眠封印之活物。
- 能力范围：数丈见方的一小方空间。
- 效果强度：可纳一方死物、隔绝外扰；但不能扩界、不能产资源、不能让内物「变好」。
- 使用限制：空间固定不可扩（扩须升炼）；须持续供仙元维持界门；含活跃道痕且未封印之物入内即与空间相冲；壶口一闭不可从内开；一次只开一口。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 六转蛊仙，宇道或兼修宇道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 须亲见「壶口开合一次」并记住那道界门之界 |
| 炼化风险 | 中；记界不清则成品界门不稳、易漏 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 仙元（低频，维持界门按月供） |
| 辅助食物 | 两地各一撮土（养界） |
| 频率 | 纳物期间每月一次；空置则每季一次 |
| 成本 | 中 |
| 特殊环境 | 壶口须避剧烈宇道震荡，震荡会晃散界门 |
| 断食后果 | 壶口合拢、内空间坍缩，所纳之物尽散 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 须持续供仙元、只开一口、只纳静物或已沉眠活物 |
| 消耗 | 六转青提仙元（维持型，持续耗）；纳物越多耗越甚 |
| 范围 | 数丈见方 |
| 持续 | 随仙元维持 |
| 缺陷 | 空间固定、须持续供仙元、不纳活跃道痕物、壶口一闭内不可开、壶体被夺则内物易失、无任何战斗力 |
| 克制 | 被宇道「破界」、阵道封印、更强空间类仙蛊克制 |
| 优势 | 唯一「可随身携带一方隔绝小天地」的经营底盘，不与外界互扰 |
| 适用场景 | 福地仓储、长途运仙材、隔离养材、为改土 / 封痕提供封闭场 |
| 不适用场景 | 实战、扩容、容纳活跃仙蛊、无仙元续供时 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一枚生于绝壁、腹内自成一洞、从未积过外物的老葫芦 |
| 辅助材料 | 仙材「洞天土」一撮、两地各取一撮土 |
| 过程 | 以仙元在葫芦腹内「撑」出一方与外隔绝的小空间，以壶口为唯一界门 |
| 难度 | 高 |
| 成功率或风险 | 中；撑界失败则葫芦内塌、材料尽毁 |
| 替代材料 | 无 |
