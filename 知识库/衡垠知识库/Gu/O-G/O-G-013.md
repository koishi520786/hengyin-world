# 【原创设定】束囊蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 编号 | O-G-013 |
| 名称 | 束囊蛊 |
| 品阶 | 二转 |
| 凡蛊或仙蛊 | 凡蛊（凡蛊可同名多只） |
| 所属流派 | 宇道 |
| 核心用途 | 储存：收纳干燥死物成一方囊内小空间 |
| 稀有程度 | 常见偏稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一只束口的小布袋，袋口以一根细麻绳收拢，袋内望不见底却极浅。
- 大小：巴掌大，可握。
- 颜色：靛青粗布，绳本色麻白。
- 形态特征：纳物时袋身不鼓不胀，仍瘪着；束绳一紧，物便「不在了」。
- 特殊视觉效果：开袋取物时，袋口会先浮起一层极淡的灰影，随即物件自影中被「吐」出。

### 二、核心能力

- 基础能力：把「干燥、无生命力、不自行变化」的死物收入袋内一方小空间，取时原样取出、不潮不腐。
- 作用机制：宇道「束而藏之」——只纳「静物」。活物、正在催动的蛊、含活跃道痕之物入囊会与囊内小空间相冲，撑破束绳。
- 作用对象：干燥死物（干粮、蛊材、账册、器件、元石皆可）。
- 能力范围：约一囊，数斗之量。
- 效果强度：原样存取、防潮防蛀；但不能保鲜活、不能减缓时间、不能让物「变多」。
- 使用限制：只纳干燥静物；活蛊须先交皓珠蛊一类封入沉眠方可入囊；含活跃道痕之物入囊即撑破；受潮则囊内结露、所纳受损。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 二转蛊师，宇道或兼修宇道者更易 |
| 炼化难度 | 中 |
| 特殊要求 | 须亲手把一只袋「装满又倒空」一遍，令其记住「满与空」 |
| 炼化风险 | 中；失败则袋底漏空，试纳之物尽失 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 一撮干燥谷壳 / 糠 |
| 辅助食物 | 无 |
| 频率 | 每开合数次喂一次；久不用则每半月一撮 |
| 成本 | 极低 |
| 特殊环境 | 须干燥处存放；受潮则囊内结露 |
| 断食后果 | 束绳渐松、囊口自开，所纳之物一件件「淡去」散失 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 只纳干燥静物；活物须先封印沉眠 |
| 消耗 | 二转赤铁真元，开合一次低耗 |
| 范围 | 数斗 |
| 持续 | 长期存放，久不喂则散 |
| 缺陷 | 不纳活物、不纳活跃道痕物、不保鲜、不减速；怕潮、怕宇道破囊；所纳若被外力「点名」可循标夺走 |
| 克制 | 被宇道「破囊」、水道浸潮、阵道封印克制；与原著皓珠蛊【原著蛊虫】（封印蛊虫使沉眠易保存）互补而非相替 |
| 优势 | 低耗、私密、随取随用；与扁担蛊配成「收纳—运输」对，是商队后勤的骨架 |
| 适用场景 | 商队带货、蛊材收纳、账册密存、长途迁徙 |
| 不适用场景 | 活蛊运输、鲜货、仙材、战场即时取用 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一只装过百家粮、从未破底的旧布袋 |
| 辅助材料 | 一撮干土、一根从未断过的细麻绳 |
| 过程 | 以真元在袋内「束」出一方小空间，再以麻绳收口，令「满」与「空」同系一绳 |
| 难度 | 中 |
| 成功率或风险 | 中；束绳若在成蛊前断过一次，成品囊口终会漏 |
| 替代材料 | 可用皮囊替代，容量更小但更耐潮 |
