# 【原创设定】归墟蛊

**基本资料**

| 项目 | 内容 |

| 所属流派 | 宇道 |
| 核心用途 | 经营/封存（收纳并缓慢复原一件仙材的道痕） |
| 稀有程度 | 唯一（仙蛊） |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一枚深不见底的漆黑螺壳，入口极小。
- 大小：拳大。
- 颜色：漆黑，壳缘泛一丝海蓝。
- 形态特征：螺壳内壁似有星点，望之如望深渊。
- 特殊视觉效果：吞入仙材时，螺口会缓缓旋开，如深渊张口。

### 二、核心能力

- 基础能力：把一件受损、道痕残缺的仙材收纳其中，以宇道「归」之力，缓慢温养，使其道痕缓慢复原（极慢，以年计）。
- 作用机制：宇道「有容乃大、损而能归」——以螺内一方小空间隔绝外扰，让道痕在封闭中缓慢自愈。
- 作用对象：一件仙材（道痕未彻底消散者）。
- 能力范围：单件，且限于道痕「尚存一线」者。
- 效果强度：极慢复原；道痕散尽者不可复原。
- 使用限制：一次只纳一件；复原期间螺壳不可再纳他物；道痕彻底消散即无法可救。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 七转蛊仙，宇道或兼修宇道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 无 |
| 炼化风险 | 中 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 仙元（低频） |
| 辅助食物 | 深海「归墟之水」 |
| 频率 | 纳物期间每月一次；空置则每季一次 |
| 成本 | 中 |
| 特殊环境 | 无 |
| 断食后果 | 螺内空间坍缩，所纳仙材道痕尽散 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 只纳「道痕尚存一线」的仙材；一次一件 |
| 消耗 | 七转红枣仙元，纳物期间按月供 |
| 范围 | 单件 |
| 持续 | 复原以年计；复原期间不可再纳他物 |
| 缺陷 | 极慢（年计）；只容一件；不能复活已散道痕；无任何战斗力 |
| 克制 | 无直接克制；但螺壳本体若被夺，所纳仙材易失 |
| 优势 | 唯一能「养伤材」的经营型仙蛊，是炼道势力的战略底牌 |
| 适用场景 | 门派/福地长期经营 |
| 不适用场景 | 实战 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一枚生于海底深渊、吸纳过无数沉船之物的老螺壳 |
| 辅助材料 | 仙材「归墟水」一掬 |
| 过程 | 以仙元在螺内「开」出一方与世隔绝的小空间 |
| 难度 | 高 |
| 成功率或风险 | 中 |
| 替代材料 | 无 |

### 七、搭配关系

| 项目 | 内容 |
|---|---|
| 可组合蛊虫 | O-G-103 微尘蛊（观测道痕复原进度）、O-G-109 敛痕蛊（收拢复原过程中逸散的游离道痕，避免螺内积散） |
| 可参与杀招 | **不参与任何 O-K 编号杀招**（纯经营仙蛊，复原周期以年计，与杀招「即时催动」性质相斥） |
| 蛊虫组合 | 与微尘蛊构成「养材—观材」的经营对；与敛痕蛊构成「复原—收逸」的道痕闭环，但三者分时使用、不组成杀招 |
| 进阶方向 | 可升炼为八转「归墟境蛊」：把「一方小空间」扩为「一方小天地」，可同时纳数件仙材；代价是道痕互斥风险陡增，须以「井井有条」类手段或宇道大宗师境界调和，否则小天地内不同道痕自发相冲、连带所纳仙材一并崩解（规模提升以「道痕互斥门槛」为代价，援引分析报告 2 节元规律第 3 条） |
| 其他关联资料 | 道痕互斥为原著硬约束；见分析报告第 6 节「资源转化与循环」 |
