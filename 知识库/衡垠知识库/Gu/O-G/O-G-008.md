# 【原创设定】洄游蛊

**基本资料**

| 项目 | 内容 |

| 编号 | O-G-008 |
| 名称 | 洄游蛊 |

| 所属流派 | 宇道 |
| 核心用途 | 移动（标记两点，成对往返通路） |
| 稀有程度 | 稀有 |
| 原创标识 | 【原创设定】 |

### 一、外观

- 外观：一对并生的鱼形石坠，一大一小，鱼首互衔，可拆作两半。
- 大小：拇指长。
- 颜色：青黑，衔口泛银。
- 形态特征：拆开后，两半会各自朝对方「游」去的方向微微倾斜。
- 特殊视觉效果：催动时，两半之间的虚空会荡起一圈极淡的涟漪。

### 二、核心能力

- 基础能力：拆作「母、子」两半，分别置于两地，可在二者之间架设一条仅蛊师可用的短距宇道往返通路。
- 作用机制：宇道「成对通路」——比原著洞地蛊弱化：只容本人或极小物件往返，且距离受限。
- 作用对象：本人及随身小物。
- 能力范围：两标记点相距约三里之内。
- 效果强度：可短时间内往返数次；距离越远、单次耗时越长、真元耗越多。
- 使用限制：两点须先由蛊师亲自到达并埋下；超过三里则失效；通路每次使用都会损耗两半的「游力」，需时间恢复。

### 三、炼化条件

| 项目 | 内容 |
|---|---|
| 炼化条件 | 四转蛊师，宇道或兼修宇道者更易 |
| 炼化难度 | 高 |
| 特殊要求 | 无 |
| 炼化风险 | 中；失败则两半皆裂 |

### 四、喂养条件

| 项目 | 内容 |
|---|---|
| 主食 | 元石（每次使用后以元石补游力） |
| 辅助食物 | 水流冲刷过的卵石 |
| 频率 | 每用必补；不用则每半月补一次 |
| 成本 | 中 |
| 特殊环境 | 无 |
| 断食后果 | 游力耗尽，两半失去联系，通路永断 |

### 五、能力限制

| 项目 | 内容 |
|---|---|
| 使用条件 | 两点须先由蛊师亲自到达并埋下标记 |
| 消耗 | 四转黄金真元 + 元石（每用必补游力） |
| 范围 | 两标记点相距约三里内 |
| 持续 | 数次往返或游力耗尽 |
| 缺陷 | 距离短（三里）、只容自身、依赖预置标记；每次用都耗元石；标记点若被毁则通路断 |
| 克制 | 被宇道封锁、阵道封印克制；标记点暴露即被针对 |
| 优势 | 往返机动、可藏匿、可设伏；比之瞬移类蛊，胜在「成对、可重复、私密」 |
| 适用场景 | 据点到战场、城内到城外、伏击后的撤离 |
| 不适用场景 | 长途；无预置标记的突发逃亡 |

### 六、炼制路线

| 项目 | 内容 |
|---|---|
| 核心材料 | 一条确曾洄游千里、又回到原处的鱼骨 |
| 辅助材料 | 两地各取一撮土（或各取一滴水） |
| 过程 | 将鱼骨断为两半，令其「互相牵挂」不散 |
| 难度 | 高 |
| 成功率或风险 | 中 |
| 替代材料 | 可用双生螺壳替代，成品距离更短 |
