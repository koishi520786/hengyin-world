### 2.1 酒虫系列（一转→四转，多条互斥路线）

```
酒虫 → 白虫茧 → 蒙汗蝶            （流传最广，花酒行者路线；失去精炼真元能力）
酒虫 → 邀月蛊 → 七香酒虫          （古月一族秘方）
酒虫 → 四味酒虫 → 七香酒虫 → 九眼酒虫   （方源记忆最优解，保留精炼真元）
九眼酒虫之上：无五转酒虫（秘方大师年少被杀，断代）
```

- 四味酒虫 = 两只一转酒虫 + 酸甜苦辣四味美酒（苦酒=艾家寨艾草绿苦酒）。
- 七香酒虫 = 两只四味酒虫 + 七种香料。
- 九眼酒虫 = 两只七香酒虫 + 九种百兽王眼珠。
- 逆炼：四味酒虫 + 浪子蛊 → 两只酒虫；四味酒虫 + 幡然蛊 → 一只酒虫。
- 八转仙蛊酒虫 = 三皇五帝酒（八种美酒合一），可令八转白荔仙元提炼为九转黄杏仙元（酒中帝皇毕生所炼）。

### 2.2 月光蛊系列（古月一族镇族蛊，多分支升炼）

月光蛊 + 两只小光蛊 → 月芒蛊 ─→ 黄金月
                              ├→ 霜霖月蛊

月光蛊 + 旋风蛊 → 月旋蛊        （直线改曲线）
月光蛊 + 玉皮蛊 → 月霓裳 → ??? → ??? → 宝月光王蛊   （中间两环待考）
```

### 2.3 皮蛊/防御系列

```
白豕蛊 + 玉皮蛊 + 野猪牙 → 白玉蛊 + 一只水行防御蛊虫 → 天蓬蛊
青丝蛊 + 黑豕蛊 → 黑鬃蛊 → 钢鬃蛊
玉皮蛊 / 铜皮蛊 / 石皮蛊 / 兽皮蛊   （同一系列，各有优缺点）

### 2.5 仙蛊炼制要点

- 定仙游 = 神游蛊 + 碧空蛊 + 定星蛊 + 太古荣耀之光（太光蛊催发），两只三更蛊、一只百战不殆蛊辅助；三息内抵脑海有印象之地，地点巨变则失败，食仙元。
- 至尊仙胎蛊：十绝仙僵无生大阵借浩劫万劫炼成；九转版需吞同转数仙窍供养（吞窍可跳灾劫得道痕）；完美十转以十绝体一次性炼就、不需食物。
- 第二空窍蛊 = 伪蛊胎盘主料 + 寿蛊（胎盘形态可存四十年）。
- 遁空蛊 = 盗天魔尊委托长毛老祖炼制，耗时二十一年，始终无法催入空门。

## 四、考据补全 · 通识规则

> 来源：03 文件「通识」节 + 01 文件「规则性说明」节。

1. **真元/仙元**：一转青铜、二转赤铁、三转白银、四转黄金、五转紫晶、六转青提、七转红枣、八转白荔、九转黄杏。
2. **凡蛊单一、仙蛊唯一**：仙蛊同名天下仅一只；仿伪蛊是唯一例外（仿品威能不及正品）。
3. **炼化**：以真元压制并绞杀蛊虫意志；位阶压制可降成本；本命蛊亡蛊师重伤。
4. **喂养**：等级越高食量/品质要求越高、进食间隔越长；缺食会退化。
5. **升炼**：合炼后只保留一只主蛊能力并强化；升炼方向是选择；秘方可断代。
6. **逆炼**：幡然蛊（拆回一只）、浪子蛊（拆回两只）。
7. **杀招=炼蛊残方**：可浓缩成蛊（万我→万我仙蛊）。
8. **开窍/希望蛊**：开窍时希望蛊聚于丹田，资质不同积累不同。
9. **升仙三气**：天气、地气、人气（人气蛊吸纳旁人人气，升仙时加持自身）。
10. **规矩二蛊／正常蛊**：律道仙蛊「正常」是「天纲地常」核心蛊之一；「规矩二蛊」与「天纲地常」无直接关联（03 文件已厘清）。
