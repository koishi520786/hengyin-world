# 【原创设定】以牙还牙

**基本资料**

| 项目 | 内容 |
|---|---|
| 杀招名称 | 以牙还牙 |
| 杀招编号 | O-K-001 |
| 杀招类型 | 凡道 |
| 对应品阶 | 三转 |
| 主要流派 | 魂道（辅以力道） |
| 功能分类 | 攻伐（复仇爆发） |
| 主要用途 | 在受压制、濒败时，以刻骨之仇激发短促爆发反击 |
| 设计者 | 原创 |

**一、杀招构成**

| 蛊虫名称 | 品阶 | 数量 | 在杀招中的作用 |
|---|---|---|---|
| 记仇蛊（O-G-009） | 三转 | 1 | 核心：刻录恨印，供给「仇」之力与战意 |
| 自力更生蛊【原著蛊虫】 | 三转 | 1 | 辅助：把积蓄的气力转化为瞬间爆发力 |
| 蛮力天牛蛊【原著蛊虫】 | 一转 | 1 | 辅助：提供一牛之力的临时爆发 |

**分工说明**：记仇蛊为**核心**，负责把「仇恨」这一魂道资源点燃为战意与爆发意志；自力更生蛊与蛮力天牛蛊为**辅助**，分别负责「把平日积蓄的力气一次性放出」与「临时力」，三蛊皆在「爆发」这一目标上协同，而非叠加多种无关能力。

**二、杀招原理**

记仇蛊把对仇人的恨意炼成魂道道痕（见 O-G-009），催动时这道恨印被一次性「燃尽」，反哺心神——这正是原著「情绪可存蓄、可调用」的魂道逻辑。战意被点燃后，蛊师不再畏战、不再手软，此时以自力更生蛊放出平日积蓄之气力、以蛮力天牛蛊再添一牛之力，将「心气」与「力气」汇于一击。三者皆属「平时积蓄、战时一次性释放」的消耗型机制，故能协同成招：魂道供「为何而战」，力道供「以何而战」。

**三、发动过程**

- 发动条件：目标须为被记仇蛊刻下恨印之人，且蛊师处于被压制、战意受挫或濒败之境。
- 发动步骤：① 催记仇蛊，燃尽一道恨印；② 战意暴起之刻，连催自力更生蛊与蛮力天牛蛊；③ 三力合一，挥出倾力一击。
- 发动速度：快（恨印点燃即发）。
- 是否需要蓄力：否（爆发型，反是一次性的）。
- 是否能够连续发动：否（每燃一道恨印少一道；蛮力天牛蛊有肌肉拉伤后遗症）。
- 发动失败的可能原因：恨印已尽、或目标并非所记仇人（恨印不燃）。

**四、杀招效果**

- 核心效果：短促的倾力反击，战意与力道双爆发。
- 作用范围：近身单体。
- 持续时间：一击之瞬。
- 攻击方式：近身重击。
- 对目标的影响：出其不意；对手若正以威压/惑乱压制蛊师，会因蛊师突然「不怕了」而失据。
- 特殊效果：附带「绝地反扑」的心理震慑。

**五、消耗与限制**

- 真元或仙元消耗：中（连催三蛊）。
- 蛊虫损耗：记仇蛊耗一道恨印；蛮力天牛蛊留拉伤后遗症。
- 材料成本：无额外材料，但恨印需提前刻录（成本已含在养蛊）。
- 使用限制：仅对刻有恨印者有效；恨印有限。
- 副作用：蛮力天牛蛊后遗症（肌肉拉伤）；爆发后短暂力竭。
- 可被破解的方式：让蛊师「释然」或「忘记」（梦道消解情绪、律道释然类手段，可令恨印失效）；或始终不给其近身机会。

**六、实战评价**

- 主要优势：绝境翻盘，反制心神压制，出其不意。
- 主要缺陷：一次性、依赖真实仇恨、事后力竭拉伤、只近身有效。
- 最适合的战斗场景：复仇战、被强敌威压濒败时。
- 被哪些类型的能力克制：梦道（消解情绪）、律道（释然）、远程风筝。
- 与哪些杀招存在配合：O-K-002「往复游」设伏后贴身爆发。

**七、设计说明**

复仇题材在蛊界天然契合「情绪即资源」的魂道设定。本招把「恨」做成可调用、可耗尽的一次性燃料，与原著「负面情绪可炼入道痕」的逻辑兼容；同时用原著已有的两只力道蛊承载爆发，不引入新机制，只做组合。短板（依赖真实仇恨、一次性）与能力机制同源，符合「缺陷须与机制相关」的原则。

# 【原创设定】往复游

**基本资料**

| 项目 | 内容 |
|---|---|
| 杀招名称 | 往复游 |
| 杀招编号 | O-K-002 |
| 杀招类型 | 凡道 |
| 对应品阶 | 四转 |
| 主要流派 | 宇道（辅以暗道） |
| 功能分类 | 移动/诱敌 |
| 主要用途 | 在两标记点间快速往返，制造真假动线诱敌 |
| 设计者 | 原创 |

**一、杀招构成**

| 蛊虫名称 | 品阶 | 数量 | 在杀招中的作用 |
|---|---|---|---|
| 洄游蛊（O-G-008） | 四转 | 1（成对） | 核心：架设两点往返通路 |
| 敛息蛊【原著蛊虫】 | 三转 | 1 | 辅助：隐藏气息，制造「真身不在」的错觉 |
| 悄步蛊【原著蛊虫】 | — | 1 | 辅助：掩藏脚步声，使往返不留痕 |

**分工说明**：洄游蛊为**核心**，负责「空间往返」；敛息蛊与悄步蛊为**辅助**，分别抹去「气息」与「脚步声」，令对手无法分辨蛊师此刻究竟在哪一点、是否已通过洄游蛊转移。

**二、杀招原理**

洄游蛊在 A、B 两点架起成对通路（O-G-008）。蛊师通过通路在两点间快速往返，配合敛息蛊隐去气息、悄步蛊掩去脚步，使对手眼中蛊师「忽在 A 忽在 B、又仿佛处处在」，无法锁定其真实位置与下一步动向。暗道的作用是「抹去转移痕迹」，宇道的作用是「提供转移本身」，二者协同构成「真假莫辨的机动」。

**三、发动过程**

- 发动条件：已提前在 A、B 两点埋下洄游蛊两半。
- 发动步骤：① 催洄游蛊通过通路；② 同时催敛息蛊、悄步蛊掩盖自身痕迹；③ 视需要往返数次。
- 发动速度：中（视两点距离）。
- 是否需要蓄力：否。
- 是否能够连续发动：可（但每次耗元石补游力，连续往返游力耗尽需恢复）。
- 发动失败的可能原因：标记点被毁、超距、游力耗尽。

**四、杀招效果**

- 核心效果：制造真假动线，诱敌扑空、掩护撤离或突进。
- 作用范围：A、B 两点之间（三里内）。
- 持续时间：数次往返或游力耗尽。
- 攻击方式：非攻击型（机动/诱敌）。
- 对目标的影响：让对手判断混乱、分散追击。
- 特殊效果：可配合设伏（往返后突然贴身，接 O-K-001）。

**五、消耗与限制**

- 真元或仙元消耗：中。
- 蛊虫损耗：洄游蛊每次往返耗游力，需元石补。
- 材料成本：元石。
- 使用限制：距离三里、标记点须预置、游力有限。
- 副作用：频繁往返暴露「有两点标记」这一事实，聪明对手会转而搜标记点。
- 可被破解的方式：毁标记点、宇道封锁、阵道封印、或以范围攻击覆盖两点之间。

**六、实战评价**

- 主要优势：机动性极强、真假难辨、可诱敌可设伏。
- 主要缺陷：距离短、依赖预置、耗元石、标记点暴露后即被针对。
- 最适合的战斗场景：阵地攻防、伏击、游击。
- 被哪些类型的能力克制：宇道封锁、阵道封印、范围覆盖。
- 与哪些杀招存在配合：O-K-001「以牙还牙」（设伏后爆发）、O-K-003「静夜图」（布防后用洄游蛊巡点）。

**七、设计说明**

原著有洞地蛊（成对宇道通路，但年耗二十万元石、距离远）与神游蛊、定仙游（瞬移但门槛高）。洄游蛊是「低配成对通路」的原创补位：距离短、只容自身、耗元石，换取低门槛与可重复。本招把「往返」与「隐藏痕迹」组合，做出「机动诱敌」的战术价值，短板（短距、预置、耗资源）与机制直接相关。

# 【原创设定】静夜图

**基本资料**

| 项目 | 内容 |
|---|---|
| 杀招名称 | 静夜图 |
| 杀招编号 | O-K-003 |
| 杀招类型 | 凡道 |
| 对应品阶 | 三转 |
| 主要流派 | 音道+水道+律道（复合） |
| 功能分类 | 侦查/布防 |
| 主要用途 | 守夜时构建一张「声、影、时」三重警戒网 |
| 设计者 | 原创 |

**一、杀招构成**

| 蛊虫名称 | 品阶 | 数量 | 在杀招中的作用 |
|---|---|---|---|
| 回声蛊（O-G-001） | 二转 | 1 | 核心：声之警戒，勾勒周边动静 |
| 倒影蛊（O-G-003） | 三转 | 1 | 辅助：影之警戒，回放/伪造水面倒影 |
| 守更蛊（O-G-004） | 三转 | 1 | 辅助：时之警戒，固定更次、反制惑乱 |
| 问路石蛊（O-G-006） | 二转 | 1 | 辅助：记录地形作底图 |

**分工说明**：回声蛊为**核心**，负责「听」；倒影蛊负责「看」水面倒影；守更蛊负责「守时」、定节律并抵御惑乱；问路石蛊负责「记地形」。四蛊分属音、水、律、土，各司一职，共同织成一张覆盖「动静、光影、时间、地形」的守夜警戒网。

**二、杀招原理**

守夜最大的破绽在于「某一刻的松懈」与「单一感官的盲区」。本招以守更蛊把守夜时段划成固定更次（律道「守约」加持），保证心神不散；回声蛊补足目不能视之处的「听」；倒影蛊借水面之镜补「看」；问路石蛊提供地形底图，令四者信息能落在同一张「图」上互参。四蛊皆低耗、皆非战斗蛊，却因「各补一维」而构成一张无死角的静夜警戒网——这正是「多蛊协同」的价值所在，而非堆砌。

**三、发动过程**

- 发动条件：守夜、伏击、盯梢等需长时间警戒且环境偏静的场景。
- 发动步骤：① 先以问路石蛊记录周边地形；② 以守更蛊定更次（与蛊师定约）；③ 以回声蛊周期性扫听；④ 有水面处，以倒影蛊摄影比对。
- 发动速度：慢（布设需时间）。
- 是否需要蓄力：否（布设型）。
- 是否能够连续发动：可（整夜维持）。
- 发动失败的可能原因：节律被外力强断（守更蛊失效，全招警戒心散）；环境噪声过大（回声蛊失效）。

**四、杀招效果**

- 核心效果：一张覆盖「声、影、时、地」的守夜警戒网，提前察觉异动、抵御轻度惑乱。
- 作用范围：周边（回声蛊十五步 + 倒影蛊一丈水面 + 守更蛊本人）。
- 持续时间：整夜（一个更次周期）。
- 攻击方式：非攻击型（警戒）。
- 对目标的影响：令潜入、偷袭、惑乱更难奏效。
- 特殊效果：倒影蛊可「伪造旧影」误导入侵者。

**五、消耗与限制**

- 真元或仙元消耗：低（各蛊低耗）。
- 蛊虫损耗：无（持续型）。
- 材料成本：无额外（各蛊日常喂养已含）。
- 使用限制：依赖静环境、静水面；节律被断即失效。
- 副作用：整夜维持耗心神。
- 可被破解的方式：制造持续噪声废回声蛊；冻住/搅动水面废倒影蛊；强行打断节律废守更蛊。

**六、实战评价**

- 主要优势：无死角、低耗、反潜行反惑乱。
- 主要缺陷：非战斗、依赖环境、单点被破则留盲区。
- 最适合的战斗场景：营地守夜、伏击设伏、秘密据点警戒。
- 被哪些类型的能力克制：音道（噪声）、冰雪道（冻水面）、强攻打断节律。
- 与哪些杀招存在配合：O-K-002「往复游」（布防后巡点）。

**七、设计说明**

原著有大量「非战斗却决定战局」的低阶蛊（书虫、地听肉耳草、蛛丝马迹蛊）。本招把这类蛊的「多维度补盲」价值显式化，用四只低阶蛊各补一维，织成警戒网。它不强、不无敌，每只蛊都有明确作用、也各有明确破法，符合「杀招必须能被拆解、每只蛊必须有作用」的规范。

# 【原创设定】星火燎原

**基本资料**

| 项目 | 内容 |
|---|---|
| 杀招名称 | 星火燎原 |
| 杀招编号 | O-K-004 |
| 杀招类型 | 凡道 |
| 对应品阶 | 三转 |
| 主要流派 | 炎道+气道（复合） |
| 功能分类 | 群攻起手 |
| 主要用途 | 以少量火种引动大片可燃环境，形成燎原之势 |
| 设计者 | 原创 |

**一、杀招构成**

| 蛊虫名称 | 品阶 | 数量 | 在杀招中的作用 |
|---|---|---|---|
| 余烬蛊（O-G-002） | 二转 | 1 | 核心：提供稳定火种 |
| 聚尘蛊（O-G-007） | 一转 | 1 | 辅助：聚拢浮尘浊气，制造可燃的「气尘」铺底 |
| 疾风蛊【原著蛊虫】 | 待考 | 1 | 辅助：引风助燃、催火蔓延 |

**分工说明**：余烬蛊为**核心**，负责「火种」；聚尘蛊负责「把空气里的粉尘浊气聚成一层可燃的气尘」；疾风蛊负责「把火借风势吹开」。三者构成「火种→燃料→风力」的燎原三要素，缺一不可。

**二、杀招原理**

余烬蛊的火种不能凭空生火，但一旦有可燃之物，火便能借势蔓延。聚尘蛊把环境里原本分散、不足以燃烧的浮尘浊气聚成一层可燃气尘，成为「燃料」；余烬蛊的火种点燃它；疾风蛊再借风势，把火舌推向大片区域。三蛊皆「小」，合起来却能把「一点星火」放大成「燎原之势」——这是资源与环境的协同，而非凭空造火。

**三、发动过程**

- 发动条件：环境中有可燃的尘、絮、草木或气尘，且有风可借。
- 发动步骤：① 催聚尘蛊聚气尘铺底；② 催余烬蛊取火种引燃；③ 催疾风蛊助燃蔓延。
- 发动速度：中（铺底需时间）。
- 是否需要蓄力：否。
- 是否能够连续发动：否（火种取一次少一次，气尘聚一次烧一次）。
- 发动失败的可能原因：环境无可燃物、无风、或火种已尽。

**四、杀招效果**

- 核心效果：以少引多，制造大范围火势。
- 作用范围：随风势，可延烧一大片。
- 持续时间：视可燃物多寡。
- 攻击方式：范围群攻（火势）。
- 对目标的影响：以燎原火势驱敌、封锁、清场。
- 特殊效果：火势一旦起来，蛊师本人亦难控，伤敌亦可自伤。

**五、消耗与限制**

- 真元或仙元消耗：中。
- 蛊虫损耗：余烬蛊火种耗尽（需重新养）。
- 材料成本：气尘、火种（均为养蛊产出）。
- 使用限制：依赖可燃环境与风力；火起难收。
- 副作用：**火势不可控，易伤及自身与同伴**；余烬蛊火种用尽后一段时期无火可用。
- 可被破解的方式：水道、冰雪道灭火；风道反吹；提前清除可燃物。

**六、实战评价**

- 主要优势：以极少资源制造极大声势与范围，是极佳的清场、封锁、打乱阵型手段。
- 主要缺陷：不可控、自伤风险、依赖环境、火种一次性。
- 最适合的战斗场景：草木丰茂的野外、堆放可燃物的据点、需要大火清场时。
- 被哪些类型的能力克制：水道、冰雪道、风道反吹。
- 与哪些杀招存在配合：与「静夜图」相反（一守一攻），可先守后攻。

**七、设计说明**

「星火燎原」取「资源与环境协同放大」的蛊道精髓，对应原著「弱者可借环境成势」的设定（如言而无信蛊、借力蛊等环境/资源依赖型）。本招不凭空造火、不无限放大，火种一次性、火势不可控、依赖可燃物与风力，代价与机制同源，符合平衡原则。

# 【原创设定】走马灯

**基本资料**

| 项目 | 内容 |
|---|---|
| 杀招名称 | 走马灯 |
| 杀招编号 | O-K-005 |
| 杀招类型 | 凡道 |
| 对应品阶 | 五转 |
| 主要流派 | 光道+暗道（复合） |
| 功能分类 | 控制/掩护 |
| 主要用途 | 以旋转光幕偏折攻击，并以「灭迹」掩护脱身 |
| 设计者 | 原创 |

**一、杀招构成**

| 蛊虫名称 | 品阶 | 数量 | 在杀招中的作用 |
|---|---|---|---|
| 转灯蛊（O-G-010） | 五转 | 1 | 核心：旋转光幕偏折直线攻击 |
| 熄烛蛊（O-G-201） | 伴生 | 1 | 辅助：宿主蛊受创时灭迹，掩护脱身 |
| 蒙尘蛊【原著蛊虫】 | 待考 | 1 | 辅助：以灰烟减弱气息，配合灭迹 |

**分工说明**：转灯蛊为**核心**，负责「偏折攻击」；熄烛蛊依附转灯蛊，负责「宿主受创时抽走最后一缕光、灭去痕迹」；蒙尘蛊负责「以灰烟遮蔽气息」。三者协同：光幕既御敌，又是「灭迹」的诱饵——对手被光幕吸引，转灯蛊一旦受创，熄烛蛊即刻灭迹，蛊师借蒙尘蛊遮蔽脱身。

**二、杀招原理**

转灯蛊的光幕既能偏折攻击，又因「亮」而极显眼——这本是它的缺点，本招却「以亮为饵」：对手的注意与攻击都被光幕牵制，一旦转灯蛊被击破，熄烛蛊（O-G-201）以自身为代价把最后的光抽走、灭去痕迹，蒙尘蛊再遮蔽气息，蛊师得以在对手「以为得手」的瞬间脱身。暗道「灭迹」与光道「显眼」一明一暗，构成「明修栈道、暗度陈仓」的战术。

**三、发动过程**

- 发动条件：需要偏折远程攻击、并准备脱身的战斗。
- 发动步骤：① 催转灯蛊张光幕偏折；② 引诱对手攻光幕；③ 光幕受创即由熄烛蛊灭迹、蒙尘蛊遮蔽，脱身。
- 发动速度：快。
- 是否需要蓄力：否。
- 是否能够连续发动：否（熄烛蛊一次性）。
- 发动失败的可能原因：对手不攻光幕而直取本体；熄烛蛊未与转灯蛊同源炼化。

**四、杀招效果**

- 核心效果：偏折直线攻击 + 受创瞬间灭迹脱身。
- 作用范围：贴身光幕 + 脱身范围。
- 持续时间：光幕随真元维持；灭迹为一瞬。
- 攻击方式：非直接攻击（控制/掩护）。
- 对目标的影响：牵制对手火力、制造「已击杀」的错觉。
- 特殊效果：灭迹后短时间对手难寻本体方位。

**五、消耗与限制**

- 真元或仙元消耗：中（转灯蛊持续耗真元）。
- 蛊虫损耗：熄烛蛊一次性（随转灯蛊受创而亡）。
- 材料成本：无额外。
- 使用限制：熄烛蛊不可再生（须重新炼化）；光幕显眼易暴露。
- 副作用：光幕被击破意味着转灯蛊已受损。
- 可被破解的方式：无视光幕直取本体；范围攻击绕开偏折；光道对轰压过光幕。

**六、实战评价**

- 主要优势：御敌与脱身一体，出其不意。
- 主要缺陷：依赖对手「先攻光幕」；熄烛蛊一次性；显眼。
- 最适合的战斗场景：被远程围攻、需金蝉脱壳时。
- 被哪些类型的能力克制：范围攻击、无视光幕的近身强攻。
- 与哪些杀招存在配合：O-K-006「画皮」（脱身后以假替身继续惑敌）。

**七、设计说明**

本招把转灯蛊「显眼」这一缺点反转成「诱饵」，是「以缺点作机制」的设计。熄烛蛊（伴生蛊）提供了「宿主灭则灭迹」的暗道手段，与光道形成明暗对比。整招不追求更强攻击，而是「控制+掩护+脱身」的战术型杀招，符合原创方向中「改变战斗节奏」的追求。

# 【原创设定】画皮

**基本资料**

| 项目 | 内容 |
|---|---|
| 杀招名称 | 画皮 |
| 杀招编号 | O-K-006 |
| 杀招类型 | 仙道 |
| 对应品阶 | 六转 |
| 主要流派 | 画道+变化道（复合） |
| 功能分类 | 伪装/替身 |
| 主要用途 | 复刻一件「空形」，配以变化道赋予其「活」的假象，制成以假乱真的替身 |
| 设计者 | 原创 |

**一、杀招构成**

| 蛊虫名称 | 品阶 | 数量 | 在杀招中的作用 |
|---|---|---|---|
| 复刻蛊（O-G-101） | 六转 | 1 | 核心：复刻一件无道痕的「空形」 |
| 变形蛊【原著蛊虫】 | 待考 | 1 | 辅助：赋予空形以「活动」的假象 |
| 敛息蛊【原著蛊虫】 | 三转 | 1 | 辅助：隐藏本体气息，令替身更像「真身」 |

**分工说明**：复刻蛊为**核心**，负责产出「外形一般无二、但无道痕」的空形；变形蛊负责让空形「动」起来、像有生命；敛息蛊负责压制本体气息、把注意力导向替身。三蛊协同，把一件「死物空形」伪装成「活物替身」。

**二、杀招原理**

复刻蛊只复制「形」不复制「道」（O-G-101），复制品空有其表。单独一件空形毫无价值，但若以变化道之「变形」赋予它动作、姿态，再以敛息蛊隐去本体气息，这空形便能在一段极短的时间里「冒充」蛊师本人或某件重要之物，骗过只凭肉眼或气息判断的对手。画道供「形」，变化道供「活」，敛息供「真」，三者合而为一具以假乱真的替身。

**三、发动过程**

- 发动条件：需先以复刻蛊「当面」描下要冒充之形。
- 发动步骤：① 复刻蛊描形产出空形；② 变形蛊赋予其预设动作；③ 敛息蛊隐本体，放出替身。
- 发动速度：中（描形需时间）。
- 是否需要蓄力：否。
- 是否能够连续发动：可（但每次须重新描形）。
- 发动失败的可能原因：描形未竟即催动；对手有道痕探测手段。

**四、杀招效果**

- 核心效果：制造一具「形似、似活、但无道痕」的替身，迷惑对手。
- 作用范围：替身所在处。
- 持续时间：变形蛊维持期间（短）。
- 攻击方式：非攻击型（伪装/诱敌）。
- 对目标的影响：误导目标判断，为己方争取时间或制造破绽。
- 特殊效果：替身被识破即露「空形」本质，无道痕、无能力。

**五、消耗与限制**

- 真元或仙元消耗：中（三蛊同催）。
- 蛊虫损耗：无（复刻蛊每描一次产一形）。
- 材料成本：颜料（复刻蛊喂养）。
- 使用限制：空形无道痕，稍加道痕探测即露；替身不能战斗。
- 副作用：描形期间本体须在场，有暴露风险。
- 可被破解的方式：道痕探测、真伪辨类仙蛊；试探替身是否「无能力」。

**六、实战评价**

- 主要优势：以假乱真、成本相对低、可反复使用。
- 主要缺陷：替身无道痕无能力、易被高端探测识破、维持时间短。
- 最适合的战斗场景：诱敌、金蝉脱壳、布疑阵、谈判中虚张声势。
- 被哪些类型的能力克制：道痕探测、真伪辨类仙蛊。
- 与哪些杀招存在配合：O-K-005「走马灯」（脱身后以替身继续惑敌）。

**七、设计说明**

原著「见面曾相识」是变化道顶级的「改心」伪装（直接作用于对方心中印象），本招则是「画道空形 + 变化道假活」的「形」级伪装——档次低、易被道痕探测识破，胜在成本低、可反复。二者一高一低，正体现「高转不使低转失效」：高端手段有高端手段的代价，低端手段有低端手段的生存空间。本招严格遵守「不造无敌伪装」，替身无道痕、不能战斗是硬约束。

# 【原创设定】空谷回音

**基本资料**

| 项目 | 内容 |
|---|---|
| 杀招名称 | 空谷回音 |
| 杀招编号 | O-K-007 |
| 杀招类型 | 仙道 |
| 对应品阶 | 七转 |
| 主要流派 | 音道 |
| 功能分类 | 攻伐（反制） |
| 主要用途 | 接下一次有声攻击的余音，延迟后原样返还，反制音杀 |
| 设计者 | 原创 |

**一、杀招构成**

| 蛊虫名称 | 品阶 | 数量 | 在杀招中的作用 |
|---|---|---|---|
| 回响蛊（O-G-104） | 七转 | 1 | 核心：存音、延迟、定向返还 |
| 回声蛊（O-G-001） | 二转 | 1 | 辅助：以低频回响「锁定」来音方位，辅助定向返还 |
| 音类凡蛊【原著蛊虫】 | 待考 | 若干 | 辅助：增强返还之音的清越与穿透 |

**分工说明**：回响蛊为**核心**，负责「存音与返还」；回声蛊负责「锁定来音方向」，使返还不至于打空；音类凡蛊负责「提纯返还之音」，使其更清越、更具穿透力。三者在「音」这一个维度上协同，不跨维度堆砌。

**二、杀招原理**

回响蛊接下一次「有声之击」的余音，存于钟内，数息后朝来路返还（O-G-104）。但它只「存一音、还一音」，返还方向若不准，便落空。故以回声蛊的低频回响先行「定位」来音，再以音类凡蛊提纯，令返还之音既准又利。整招的核心是「延迟返还」而非「放大」，故威能与来音相当，胜在「出其不意」与「以彼之道还施彼身」。

**三、发动过程**

- 发动条件：对手发动一次「有声」的直线攻击。
- 发动步骤：① 回声蛊定位来音；② 回响蛊接存余音；③ 数息后朝来路定向返还。
- 发动速度：中（有「存音→返还」的延迟）。
- 是否需要蓄力：否。
- 是否能够连续发动：否（钟内一音存满须先放空）。
- 发动失败的可能原因：来音无声、方向判定失误、钟内存音未放空。

**四、杀招效果**

- 核心效果：以彼之余音还彼之身，反制音杀。
- 作用范围：来路方向。
- 持续时间：一击之瞬。
- 攻击方式：定向音之反击。
- 对目标的影响：使音杀者自食其果，打乱其节奏。
- 特殊效果：返还之音与来音同源，对手难防「自己的音」。

**五、消耗与限制**

- 真元或仙元消耗：中（回响蛊耗仙元）。
- 蛊虫损耗：无（回响蛊可反复存返，但一次只一音）。
- 材料成本：无额外。
- 使用限制：只对有声攻击有效；存音槽单一；只能「迟还」不能「放大」。
- 副作用：延迟期间蛊师自身仍暴露于来音之下（须先硬接或闪避）。
- 可被破解的方式：改用无声音攻击；预判返还方向并闪避；以更强的音压垮钟壁。

**六、实战评价**

- 主要优势：反制音杀、出其不意、成本低。
- 主要缺陷：只对有声音有效、不能放大、单音槽、有延迟风险。
- 最适合的战斗场景：音道对轰、反制音杀。
- 被哪些类型的能力克制：无声音攻击、魂道、梦道。
- 与哪些杀招存在配合：与「静夜图」同源音道，可「以静制动、以音还音」。

**七、设计说明**

「空谷回音」取「余音绕梁」的自然现象，落成「延迟返还」的音道机制。它不放大威能、只「迟还」，故上限明确、不会破坏平衡；其短板（只对有声、单音槽、延迟期间自身暴露）皆与「存音返还」的机制同源。这是一条「反制型」仙道杀招，符合原创方向中「特殊防御、反制、控制」的追求。
