# 《原著蛊道体系分析报告》

> 阶段三交付物 · 生成于 2026-11-13
> 用途：在原创设计之前，归纳《蛊真人》原著体系的**运行逻辑**，并划定原创扩展的合法空间。
> 依据：本资料库第一卷、`.workbuddy/research/` 下 00～04 号考据文件、`蛊真人蛊虫合集.txt`（3815 行底稿）。
> **口径声明**：本报告只归纳原著中可核实的机制；凡属整理者推论、社区推测、原著未写明者，一律显式标注，不作既定事实。

---

## 0. 结论摘要

1. 蛊道体系的底层不是「等级越高越强」，而是**「能力唯一 + 代价守恒 + 资源门槛」**三件事。一只蛊只有一个能力，威力提升必然伴随消耗、条件、副作用或喂养成本上升。
2. 转数是**描述性标签**而非严格强度刻度：原著明确写「一切蛊虫皆可升级，所谓转数不可尽信，只取文中初次出现时的转数」。因此不存在「高转蛊自动淘汰低转蛊」的规则。
3. 杀招不是技能，而是**多蛊协同工程**：核心蛊定性质、辅助蛊补条件，任何一环缺失或失效都会导致整招崩解。原著更进一步把杀招定义为「炼蛊残方」，可反向浓缩成蛊。
4. 流派不是属性克制表，而是**对「道」的一种解释路径**；同一效果可由不同流派触类旁通达成（宙道杀招可展现力道、信道、奴道、运道威能），因此跨流派组合是常态而非例外。
5. 原创扩展最安全的空间在**机制缝隙**（触发条件、环境依赖、经营/生产/侦查用途、协同关系、失败后果），而不是「再造一只更强的攻击蛊」。

## 1. 蛊虫体系：设计规律

### 1.1 三条硬公理

| 公理 | 原著表述 | 对设计的约束 |
|---|---|---|
| 能力唯一 | 「任何一只蛊虫，都只有一个能力」「凡蛊单一，能力只有一个」 | 不得让一只蛊同时具备攻击、治疗、飞行、侦查等多种无关能力；「复合效果」必须由多蛊协同或升炼后单能力强化实现 |
| 仙蛊唯一 | 「仙蛊唯一，无论几转一种仙蛊只能有一个」 | 同名仙蛊天下仅一只；仿伪蛊是唯一定性明确的例外（且明言仿品威能不及正品） |
| 蛊不含杀招与蛊屋 | 词条明载「蛊不包括杀招与蛊屋（单独成蛊另算）」 | 分类时杀招、蛊屋、蛊阵必须独立编目，不能混进蛊虫表 |

### 1.2 转数与能力的关系（非幂次增长）

- 一转青铜真元、二转赤铁、三转白银、四转黄金、五转紫晶；六转青提仙元、七转红枣、八转白荔、九转黄杏。蛊虫催动消耗的是与使用者修为匹配的真元/仙元。
- **能力强度不由转数单独决定，而由「能力性质 × 使用条件 × 代价」决定**。实例：
  - 三转「月影蛊」能压制四转蛊师三成真元、五转一成半、三转六成——低转蛊靠**机制**（种入空窍）而非数值产生高转威胁。
  - 四转「水幕天华蛊」可挡五转攻伐，代价是**无法移动、无法停止、内外隔绝连蛊主也不能出入**。
  - 一转「酒虫」价值高于部分二转蛊，因为它精炼真元、无后遗症，是**修行资源型**而非战斗型价值。
- 由此得出设计规律：**低转蛊的生存空间在「独特机制」「低成本」「特定场景不可替代」**，高转蛊的优势在「规模」「范围」「道痕层级」，而不是「同类能力数值更大」。

### 1.3 喂养规律

- 等级越高，食量与食物品质要求越高，但**进食间隔越长**（二转多半个月以上，三转超过一个月）。
- 食料构成是蛊虫的**身份与弱点**：月光蛊食月兰花瓣（早晚各两片）、熊力蛊食蜂蜜、黑/白豕蛊每五天一整头成年猪、白玉蛊每二十天八两玉石、定仙游直接食仙元、坚持食逆流河水、智慧蛊食寿蛊、态度蛊**不耗仙元只耗心力**。
- 断粮后果有明确原著例证：花酒行者的蒙汗蝶因缺食**不断退化，最终还原成酒虫**。即「升炼可逆、状态会衰减」是体系内既有设定。
- 设计含义：喂养方案不是装饰字段，它同时定义了**持有成本、地理依赖、断供风险、可被针对的破绽**。

### 1.4 炼化规律

- 蛊虫有自身意志，炼化是「以真元压制并绞杀其意志」的过程，难度受蛊虫转数、意志强度、蛊师资质与真元储备影响。方源借春秋蝉（六转）气息镇压一转蛊意志，可令炼化从「消耗六块元石」降到「几乎不耗元石、五分钟完成」——**位阶压制能改变炼化成本**，但只是气息压制，不是能力借用。
- 本命蛊：蛊师第一只炼化的蛊；本命蛊灭亡蛊师也重伤，但不会因炼蛊直接死亡。
- 特殊炼化条件：竹君子只有「从小到大未说过一句谎言的至诚君子」才能炼化喂养；正气蛊需秉持正义方能催动；地听肉耳草需切掉一只耳朵与伤口黏合；骨肉团圆蛊需两个同心血亲合力炼成。
- 设计含义：**「能否炼化」与「能否催动」是两个独立门槛**，可以分别设置条件，这是原创蛊制造「稀有但非无敌」的有效手段。

### 1.5 炼制与升炼规律

- 合炼后新蛊通常只**保留一只主蛊的能力并强化**，其余能力丧失（白玉蛊保留玉皮蛊防御、丧失白豕蛊增力）。因此「升炼方向」是选择而非必然，选错方向等于浪费一只蛊的核心价值。
- 同一基础蛊可有多条互斥路线：酒虫可走「白虫茧→蒙汗蝶」（失去精炼真元）、「邀月蛊→七香酒虫」、「四味酒虫→七香酒虫→九眼酒虫」（保留精炼真元，方源记忆中的最优解）。
- **秘方会中断**：九眼酒虫之上没有五转酒虫，原因是创方秘方大师年少被杀。即体系允许「技术树断代」，不需要把每条链补齐到九转。
- 逆炼：幡然蛊、浪子蛊可把合炼蛊拆回低阶（四味酒虫→一只或两只酒虫）；力气蛊由风气蛊逆炼、气遁蛊由名声蛊逆炼。
- 仙蛊炼制需仙蛊方 + 仙材 + 道痕环境 + 炼道修为，成功率受仙蛊屋（四元方悔血炼池）与流派（毛民天地流 > 人族隔绝流）影响。第二空窍蛊的「伪蛊胎盘形态」说明主料可长期封存。
- **杀招 = 炼蛊残方**（第三卷 543 节）：任何杀招都可删减增添蛊材不断完善，最终炼成一只蛊（万我杀招→万我仙蛊）。好处是蛊数暴降、催动快、消耗与心智负担锐减；代价是可能要消耗其他仙蛊作蛊材，且有的杀招（紫血先河阵、燃念飞石）只能收敛为数只仙蛊配合，无法单蛊化。

### 1.6 相互克制与失效

原著中「克制」几乎都表现为**机制针对**而非数值压制：
- 逆流河：落入其中不能动用九转以下任何蛊虫，任何攻势被逆反过来——环境直接改写规则。
- 无极搜锁能封禁五转蛊，**禁不住六转仙蛊**——凡/仙之别是硬边界。
- 神游蛊吞掉定星蛊即破无极搜锁——破坏「定位组件」即可破招。
- 众生皆苦／吃亏是福分别反制幽魂的吃苦／吃亏。
- 天纲地常「最克制战场杀招」。
- 春秋蝉气息可反制月影蛊（月影蛊进入方源空窍反被瞬间炼化）。

设计含义：**破解方式应写在杀招档案里，且必须能落到「某个具体组件或条件」上**。

## 2. 流派体系：核心思想与短板

> 说明：下表只填考据可支持的字段；「原著未明确」处不推测。流派总数社区有 48／51 两说，本报告不裁定。

| 流派 | 核心理念／擅长 | 代表手段 | 明显短板 | 与其他流派关系 |
|---|---|---|---|---|
| 力道 | 以「力」为可积累、可借用、可外放的资源；分兽力虚影流／气象天地流／人力钧力流 | 兽力虚影、全力以赴蛊、借力蛊、我力/拔山/挽澜 | 单独使用时手段直白，缺侦查与远程；虚影需载体（力气蛊产生力之气） | 与奴道合流成「万我」；宙道可靠触类旁通展现力道（年富力强） |
| 奴道 | 以数量与调度替代单体强度 | 奴兽蛊、驭犬/驭狼蛊、军团蚁、魂兽令 | 依赖被奴役对象，遇魂道战场杀招（魂狩战场）会被反制 | 与力道、变化道复合（万我、万蛟） |
| 智道 | 推算、意志、念头；境界达宗师可触类旁通 | 智慧蛊、解谜、金刚念、天机蛊、特意蛊等意蛊 | 高强度推算常伴代价（天机蛊十次八败、失败损寿 10–70 年；说是道非每答一问耗 50 载寿元） | 魅道、情道为智道分支；与宙道、梦道、天道常复合 |
| 魂道 | 魂魄为可分割、可吞并、可外放的资源 | 分魂、魂穿、换魂、吞魂、鬼官衣、荡魂山/落魄谷 | 需魂魄底蕴支撑；鬼官衣持续消耗魂魄底蕴；碎魂手必须近身 | 与偷道（阎帝、大盗鬼手）、梦道（引魂入梦）、智道常复合 |
| 炼道 | 把「手段」炼成「物」，追求把杀招浓缩成蛊 | 升炼、水炼、悔蛊、四元方悔血炼池、炼海 | 依赖仙材、道痕环境与成功率；炼道本身不直接提供战斗力 | 与变化道（化炼蝶）、雷道/气道（雷韵丝流）、天道（残炼）复合 |
| 宙道 | 时间流速、灾劫调度、经营与重生 | 春秋蝉、年蛊、以后、似水流年、日/月蛊、江山如故 | 高阶核心蛊仙元门槛高（六转青提催不动似水流年）；时间类杀招常「催动久」或「触怒天意」 | 可靠触类旁通展现力道/信道/奴道/运道；与律道、风道复合（十里宙疾风） |
| 宇道 | 空间、挪移、通路 | 定仙游、神游蛊、碧空蛊、定星蛊、洞地蛊、镇宇、行空 | 常需「具体印象」「定位标记」「成对架设」等前置条件 | 与禁道（无极搜锁）、风炎光雷（风火光电轮）复合 |
| 变化道 | 以形态改变获得他物天赋 | 变形、变异、变通、态度、图腾杀招 | 变化道远程孱弱（靠图腾弥补）；三段同催失败可暴毙 | 与剑道（上古剑蛟变、万蛟）、炼道、奴道复合 |
| 剑道 | 攻强守弱，五大强攻流派之一 | 飞剑/浪剑/剑遁/慧剑、五指拳心剑、剑浪三叠 | 拘束擒拿不擅长；剑痕索命永久消耗仙蛊道痕会让仙蛊掉转 | 与刀道同源于刃蛊、恩怨极深；与人道/智道/刀道复合 |
| 天道 | 结算、推算反制、恢复常态 | 天机、天网、天纲地常、天地无情、天妒英才 | 原著未明确统一短板；多数手段依赖九转层级核心蛊 | 与律道、智道、宙道复合 |
| 律道 | 规则、界限、加减、常态 | 坚持、正常、加、限、锁、界、熟、防备 | 常需蓄力（防备仙蛊至少十息才发挥威能） | 禁道、虚道为律道分支；与宙道复合 |
| 运道 | 气运的链接、转嫁、采集与再分配 | 连运、好运、机运、镇运、察运、气运、狗屎运、招灾、排难 | 运道效果常「不可完全掌控」（年兽召来的年兽不真正受奴役、会索要更多年蛊） | 与智道（运算仙蛊）、阴阳道同源（巨阳） |
| 梦道 | 梦境推演、模拟、夺魂入梦 | 梦蝶、做梦、梦甲、如梦令、解梦、引魂入梦、纯梦求真变 | 需梦境载体；纯梦求真体只有九个时辰寿命且魂魄沉睡、记忆被消除 | 与魂道、智道、宙道复合 |
| 炎道／水道／冰雪道／毒道／木道／土道／金道／雷道／风道／光道／暗道／信道／音道／血道／食道／偷道／阵道／星道／人道／画道等 | 见第一卷流派总表（各流派核心理念、代表蛊、开创者、分支关系） | — | 原著未逐一流派给出统一短板，标【原著未明确】 | 见第六卷流派关联表 |

**流派设计的三条元规律**：
1. 流派**不是互斥分类**，一只蛊可跨流派（运算仙蛊横跨智道、运道），一个杀招可含六七个流派。
2. 大宗师境界可「以主修流派模拟其他流派威能」——这是原著给出的**跨流派合法性依据**，原创复合杀招应援引此条而非自造规则。
3. 道痕互斥是硬约束：至尊仙体之所以特殊，正在于道痕不互斥；四元方悔血炼池离开至尊仙窍就会因道痕互斥自发崩溃。「井井有条」是让道痕不互斥的具体杀招。原创设定不得默认「随便什么都能混」。

## 3. 杀招体系：设计规律

### 3.1 基本构成

```
核心蛊（1 只或数只，决定杀招性质与流派）
  + 辅助蛊（少则数只，多则数万只，补足条件／规模／载体／防护）
  + 发动条件（姿势、站位、环境、前置状态、蓄力时间）
  + 消耗（真元/仙元、心力、魂魄底蕴、寿命、道痕、蛊虫本身）
  → 效果（作用范围、持续时间、作用对象）
  + 缺陷／失效／破解（写在同一档案内）
```

典型配比实例：
- **万我**：核心仙蛊 我力/拔山/挽澜/净魂（4 只）+ 辅助蛊 十余类 + 魂道凡蛊；由八九个旧杀招融汇提升。
- **剑浪三叠**：核心 七转浪剑 + 一些水道仙蛊 + **500 只凡蛊**。
- **丰年**：核心 仙级年蛊 + **数万只分门别类凡蛊**，黑凡亲催也需两三天。
- **巨灵变**：核心 巨灵心/身/意三大四转蛊**同时催动**，身心意合一。
- **无极搜锁**：定星蛊+疑似搜锁蛊，另需**四名蛊师分占四方**并事先种入定星蛊。
- **五指拳心剑**：特定姿势（低头闭目、双手合十、握拳举过头顶），五指依次出剑，一剑强过一剑；七转只能催三到四指。

### 3.2 协同逻辑的三类

1. **载体型**：一只蛊产生「场/气/载体」，另一只蛊的效果附着其上才成立。例：力气蛊产生无形力之气，兽力虚影附其上才具备直接攻击能力，力之气消散虚影自回。
2. **条件型**：一只蛊负责满足前置条件，另一只蛊才能生效。例：定星蛊定位 → 无极搜锁破空拘拿；神游蛊吞掉定星蛊即整招失效；朝气蛊保住生机 → 白凝冰才敢化身冰晶持续喷吐霜息。
3. **增幅型**：一只蛊放大另一只蛊的规模或层级。例：小光蛊使月刃体积与攻击力翻倍（但增幅不可叠加）；八转慧剑仙蛊使五指拳心剑从七转层级升到八转。

> 反例（原著明确否定）：月光蛊 + 两只小光蛊**不是杀招**，幅度也不叠加；四味酒虫精炼真元是蛊虫自身能力，不是杀招。分类时不能把「多蛊同用」一律当作杀招。

### 3.3 发动条件与消耗的常见形态

| 类型 | 原著实例 |
|---|---|
| 真元/仙元 | 青丝蛊一次性耗三成青铜真元；一气金光虫持续耗真元；丰年仙元消耗极多 |
| 心力 | 操纵蛊虫需心力，用久精神萎靡；态度蛊不耗仙元只耗心力；巨灵变心力三倍增长也三倍消耗 |
| 魂魄底蕴 | 鬼官衣不耗仙元但耗魂魄底蕴 |
| 寿命 | 说是道非每答一问耗五十载；炼蛇寿元花折损寿命；天机蛊失败损寿 10–70 年 |
| 道痕 | 剑痕索命永久消耗剑道仙蛊道痕；燃魂爆运永久消耗魂道道痕；血魔解体消耗肉身血道道痕 |
| 蛊虫损耗 | 消耗类蛊用一次即消失（舍利蛊、寿蛊、石窍蛊、生机叶）；丰年对年蛊消耗大需先平炼 |
| 时间／蓄力 | 丰年需两三天；防备仙蛊至少十息；三十三天光催动期间不能移动分毫 |
| 环境／站位 | 逆流河、四老分居四方、需在月光充足之夜露天合炼、定仙游需地点未巨变 |

### 3.4 缺陷与破解（**每条杀招档案必填**）

原著杀招几乎都有明确弱点，且弱点与机制相关，不是随手加的：
- 冰刃风暴二代「缺乏前进动力，只能原地自转」——形态机制导致。
- 年兽召来「召来的并非奴役，遇强敌不迎战，中途还会索要更多年蛊」——奴道威能由宙道模拟，控制力天然不足。
- 三十三天光「动弹分毫即戛然而止，且中止时按已闪次数反噬」——持续型杀招的通病。
- 后患无穷「触怒天意使下次灾劫威力翻倍」——代价递延而非消失。
- 定仙游「地点须有具体印象且未发生巨变」——信息前置条件。
- 无极搜锁「禁不住六转仙蛊；舍弃被种蛊的肢体即破」——组件依赖。

### 3.5 改良与演化

- 见面曾相识 → 方源加入血本仙蛊后可伪装血脉。
- 万我 → 加入自爱/爱意的「我意」与集思广益，使虚影具备念头与思考能力。
- 万蛟 = 万我 + 上古剑蛟变；阎帝 = 鬼不觉 + 鬼官衣 + 魂兽令 + 万我。
- 冰刃风暴初代 → 二代（换掉狂风蛊，改用冰晶蛊/龙卷蛊/霜息蛊 + 朝气蛊护生机）。
- 终极演化：杀招浓缩成蛊（见 1.5）。

### 3.6 凡道杀招 vs 仙道杀招

| 维度 | 凡道杀招 | 仙道杀招 |
|---|---|---|
| 组成 | 凡蛊组合，数量从三只到四五十只（我力） | 以仙蛊为核心，辅以凡蛊（可数百至数万只） |
| 能量 | 真元（青铜→紫晶） | 仙元（青提→黄杏），部分改耗心力/魂魄底蕴/寿命/道痕 |
| 规模 | 单体或小范围，受真元总量限制，战斗通常不长久 | 可覆盖百里、跨天数、作用于仙窍与灾劫 |
| 门槛 | 蛊师修为与心力 | 核心仙蛊转数（六转青提仙元催不动八转似水流年）、道痕、流派境界 |
| 失败 | 真元枯竭、反噬、蛊虫损毁 | 催动失败可重伤或暴毙（自由残缺变）、折损仙蛊道痕、触怒天意 |
| 上限 | 五转封顶 | 可至九转尊者级，甚至「超脱仙元令杀招永存」（道主） |

## 4. 炼蛊与资源体系

### 4.1 资源层级

- **元石**：凡蛊世界通用货币与真元补给（青茅山、商队、赌石坊）。一年喂养洞地蛊需二十万块元石。
- **仙元石**：只在天庭出产，可兑换仙元。
- **蛊材**：月兰花瓣、蜂蜜、玉石、参须、野猪牙、痕石、九宫花、问鼎石、金乌流精、寒冰草、九种百兽王眼珠、七种香料、酸甜苦辣四味美酒、三皇五帝酒、雪柳叶片、太古星屑、八荒剑叶树叶片、正反狙神针等。
- **仙材**：碧空玉竹、太光蛊催发的荣耀之光、太古荣耀之光、仙材上的道痕（图腾杀招直接吞食吸收）、炼水（炼海产出）。
- **特殊环境**：月光充足之夜露天合炼（提高月痕蛊成功率）、九重天青天竹林/蓝天夜晚/清晨朝阳（定仙游采料）、逆流河、荡魂山／落魄谷／迷魂湖、市井、书山、光阴长河、炼海、四元方悔血炼池。
- **辅助蛊**：寸光阴（加速酝酿）、三更蛊（时间加速三倍，代价寿命缩至三分之一）、百战不殆蛊、幡然蛊/浪子蛊、地藏花蛊/皓珠蛊（封印休眠）。

### 4.2 成本、风险与失败后果

| 环节 | 已知风险 |
|---|---|
| 合炼 | 成功率受秘法、材料、环境、炼道造诣影响；失败可能损失主蛊；走错升炼方向会永久丧失原蛊核心能力 |
| 逆炼 | 结果为「一只」还是「两只」取决于用幡然蛊还是浪子蛊，产出数量有差别 |
| 升炼 | 九眼酒虫之上无五转形态（秘方断代）；年蛊需先平炼否则降为凡蛊很亏 |
| 仙蛊炼制 | 需仙蛊方 + 仙材 + 道痕环境；道痕互斥可致仙蛊屋自发崩溃；遁空蛊耗时二十一年炼成却始终无法催入空门 |
| 一次性消耗蛊 | 用后即消失（舍利蛊、寿蛊、三更蛊、妇人心、鸿运齐天蛊）；部分有后遗症（人药蛊延寿但后遗症很大） |
| 喂养断供 | 蒙汗蝶退化回酒虫；高阶蛊饥饿后果原著多未写明，标【原著未明确】 |
| 杀招催动 | 失败可重伤/暴毙（自由残缺变）、反噬（斗志昂扬、天机蛊）、折损寿命（炼蛇寿元花）、触怒天意（后患无穷） |

### 4.3 资源与修炼的关系

蛊师修为决定真元质与量 → 决定能同时催动多少蛊、催多久 → 决定能承载多大规模杀招；喂养成本决定能长期养多少蛊（方源一次炼化两百只骨枪蛊仍选择毁掉其余，理由是「养不活」）。**「能炼化」≠「能养活」≠「能同时催动」**，这是三个独立门槛，也是原著反复用来约束主角资源爆发的机制。

## 5. 原著体系中必须遵守的规则（原创设计检查表）

> 阶段五将逐条据此校验。任何一条不满足即判为不合格。

1. 一只蛊**只有一个能力**。
2. 凡蛊单一、仙蛊唯一（仿伪蛊为原著唯一例外，原创不得新增例外）。
3. 蛊虫、杀招、蛊屋、蛊阵**分别编目**。
4. 转数取「初次出现时的标注」，不得把转数当作强度线性刻度。
5. 效果提升必须伴随**消耗、条件、限制、风险、成本**中至少一项同步上升。
6. 高转不使低转失效；低转蛊须有不可替代的机制位。
7. 杀招必须有明确的核心蛊/辅助蛊分工，**每只蛊都要有作用**，不得堆名字。
8. 杀招必须写明**发动条件、消耗、效果范围、缺陷与破解方式**，且缺陷要与机制相关。
9. 复合杀招的跨流派合法性援引「大宗师触类旁通」或「道痕不互斥」相关设定，不得默认无条件混合。
10. 不得设计「无条件克制所有能力」「无任何代价的全能蛊」「无条件复活／无条件无限重生」类设定。
11. 炼制信息须含主材/辅材/成功条件/失败风险；喂养信息须含食物/频率/成本/断供后果。
12. 原创内容**不得改写、覆盖、合并**任何原著蛊虫、杀招、品阶、食料、炼化条件；使用原著蛊虫须标【原著蛊虫】并保持原设定。
13. 原著未写明的机制标【原著未明确】，社区推测标【待考证】，不同来源冲突标【存在争议】，不自行调和。
14. 出处尽量可追溯；无可靠出处者进待考区，不进正式定论表。

## 6. 适合原创扩展的空间

| 空间 | 说明 | 为什么安全 |
|---|---|---|
| **非战斗用途** | 经营、生产、质检、档案、运输、储存、清算、通风、照明、计时 | 原著已有大量后勤类蛊（元老蛊、皓珠蛊、兜率花、书虫、阵图蛊、寸光阴），属成熟类别 |
| **特殊触发条件** | 需特定时辰、天气、声音、气味、伤口、契约、回声、连续催动次数 | 原著已有先例（竹君子、正气蛊、地听肉耳草、月痕蛊合炼时辰、三十三天光中止条件） |
| **环境依赖** | 只在水中／雾中／地下／人群／废墟／逆流类环境发挥优势 | 原著已有水幕天华蛊、水乳交融、逆流河、市井等环境绑定案例 |
| **资源转化与循环** | 把废弃物、余烬、残方、断蛊、失效蛊转化为可用资源 | 符合「食道=回收与清算」「炼道=残方完善」的既有逻辑，且不新增攻击上限 |
| **协同关系** | 两只蛊互为载体／互为条件／互为增幅，单独使用价值很低 | 直接继承 3.2 三类协同逻辑，最能体现蛊道特色 |
| **成长／分化／状态衰减** | 会随喂养或催动次数改变形态、分裂、退化 | 蒙汗蝶退化、剑痕索命道痕递减、九眼酒虫断代均给出合法性 |
| **节奏控制** | 延迟、蓄力、冷却、打断、交换行动次序 | 原著有大量「三息」「十息」「两三天」「五个呼吸」「出手一次后需沉寂」等时间机制 |
| **信息不对称** | 误导侦查、标记真伪、假气息、假道痕 | 敛息蛊、蒙尘蛊、宝珠蒙尘、不灭星标、见面曾相识均属此域 |
| **失败后果设计** | 把「代价」写进机制而非附加缺点 | 与 3.3 消耗形态表完全对齐 |

**禁区**（不建议原创触碰）：再造「唯一性例外」、改写宿命蛊/春秋蝉/至尊仙胎蛊等核心叙事装置、设定无条件克制、让原创蛊解释原著未写明的世界观空白（只能标【原著未明确】）。
