# 第一卷 · 原著蛊道体系

> 本卷为《蛊真人》原著体系的**规则层**归纳，供原创设计对照。
> 详细推导与出处见《原著蛊道体系分析报告》（同目录），本卷为精炼版。
> 凡标注【原著未明确】【存在争议】【待考证】者，均不视作既定事实。

## 一、蛊道基础规则

1. **能力唯一**：任何一只蛊虫只有一个能力；凡蛊单一、仙蛊唯一（同一名称无论几转，天下只能有一只）。
2. **蛊不含杀招与蛊屋**：杀招、蛊屋、蛊阵单独成类，不并入蛊虫。
3. **转数非强度刻度**：「一切蛊虫皆可升级，所谓转数不可尽信，只取文中初次出现时的转数」。
4. **凡蛊与仙蛊**：一至五转为凡蛊，六至九转为仙蛊；蛊是道，凡蛊是道的碎片，仙蛊是完整的道。
5. **升炼可逆、状态会衰减**：合炼后新蛊通常只保留一只主蛊的能力并强化；缺食会退化（蒙汗蝶→酒虫）。
6. **蛊虫有意志**：炼化是以真元压制并绞杀其意志的过程；位阶压制（如春秋蝉气息）可大幅降低炼化成本。

## 二、修炼体系

- **境界**：一至九转，每转分初阶／中阶／高阶／巅峰。五转皆凡、六转成仙、九转为尊。
- **真元**：一转青铜、二转赤铁、三转白银、四转黄金、五转紫晶；**仙元**：六转青提、七转红枣、八转白荔、九转黄杏。
- **灾劫**：六转十年一地灾、百年一天劫（三次天劫成七转）；七转十年一地灾、五十年一天劫、百年一浩劫；八转十年一天劫、五十年一浩劫、百年一万劫（三次万劫成九转）；九转十年一浩劫、五十年一万劫、百年一混沌大难。成尊另需主修流派达无上大宗师并突破天道封锁（灾劫、寿蛊、宿命）。
- **资质**：十绝体（十成）、甲等（八至九成）、乙等（六至七成）、丙等（四至五成）、丁等（两至三成）。已知十绝体：太日阳莽、古月阴荒、北冥冰魄、森海轮回、炎煌雷泽、万金妙华、大力真武、逍遥智心；第十一绝体纯梦求真体。
- **本命蛊**：蛊师第一只炼化的蛊；本命蛊亡蛊师重伤，但不会因炼蛊直接死亡。
- **蛊虫三用**：炼、养、用。

## 三、流派体系

### 3.1 流派分期与开创者

- 太古（人祖时代）：宇、宙、人。
- 远古：气、奴、智、星、阵、炼、炎。
- 上古：律、变化、力、风、光、暗、食。
- 中古：木、画、偷、水、运、阴阳、金、冰雪、云、土、雷、信、音。
- 近古：骨、虚、禁、魂。
- 近代：剑、丹；现代：兵；未来：梦。
- 时代不明：血、毒、魅、幻、刀、情、影、月等。

| 流派 | 开创者 | 流派 | 开创者 |
|---|---|---|---|
| 人道 | 人祖 | 气道、奴道 | 元始仙尊 |
| 智道、星道 | 星宿仙尊 | 律道 | 无极魔尊 |
| 力道、变化道 | 狂蛮魔尊 | 木道、画道 | 元莲仙尊 |
| 偷道 | 盗天魔尊 | 运道、阴阳道 | 巨阳仙尊 |
| 魂道 | 幽魂魔尊 | 血道 | 血海老祖（巨阳分身） |
| 剑道 | 薄青（幽魂分魂） | 食道 | 龙鳄兽人蛊仙 |
| 水道 | 水尼 | 虚道 | 虚无邪 |
| 丹道 | 青玉鹤·阮丹 | 兵道 | 车尾 |
| 影道 | 顾影仙君 | — | — |

- **分支关系**：力道分兽力虚影流／气象天地流／人力钧力流（霸仙楚度开）；炼道源自毛民，分毛民天地流／人族隔绝流；魅道、情道为智道分支；禁道、虚道为律道分支；雪道为冰道分支（合称冰雪道）；刀道与剑道同源于刃蛊。
- **流派境界十阶**：普通→准大师→大师（产生直觉）→准宗师→宗师（触类旁通，以主修流派模拟其他流派）→准大宗师→大宗师（随意拆卸使用杀招、直接利用自然界道痕）→准无上大宗师→无上大宗师→道主（唯尊者，可炼化天地间本流派全部道痕，超脱仙元令杀招永存）。

### 3.2 关键流派特性（可核实者）

| 流派 | 擅长 | 明显短板 |
|---|---|---|
| 力道 | 力之积累、借用、外放 | 手段直白、缺侦查远程、虚影需载体 |
| 奴道 | 数量调度替代单体 | 依赖被奴役对象，被魂道战场杀招反制 |
| 智道 | 推算、意志、念头 | 高强度推算常伴代价（天机蛊失败损寿） |
| 魂道 | 魂魄分割、吞并、外放 | 需魂魄底蕴；部分杀招须近身 |
| 炼道 | 把手段炼成物，杀招浓缩成蛊 | 依赖仙材、道痕、成功率 |
| 宙道 | 时间流速、灾劫调度、经营、重生 | 高阶核心蛊仙元门槛高；时间杀招催动久或触天意 |
| 宇道 | 空间、挪移、通路 | 需前置条件（印象、标记、成对架设） |
| 变化道 | 形态改变获得他物天赋 | 远程孱弱（靠图腾补）；多段同催可暴毙 |
| 剑道 | 攻强守弱（五大强攻流派） | 拘束擒拿不擅长 |
| 律道 | 规则、界限、加减 | 常需蓄力（防备仙蛊十息） |
| 运道 | 气运链接、转嫁、采集 | 效果不可完全掌控 |
| 梦道 | 梦境推演、模拟、夺魂入梦 | 需梦境载体；纯梦求真体短命、记忆被消除 |

## 四、炼蛊体系

- **合炼通则**：① 一只蛊只有一个能力；② 合炼后新蛊通常只保留一只主蛊能力并强化，其余丧失；③ 升炼方向是选择，选错浪费核心能力；④ 秘方可断代（九眼酒虫之上无五转酒虫）；⑤ 逆炼用幡然蛊（拆回一只）、浪子蛊（拆回两只）。
- **仙蛊炼制**：需仙蛊方 + 仙材 + 道痕环境 + 炼道修为；毛民天地流成功率高于人族隔绝流；四元方悔血炼池可提成功率降成本，但只能存于至尊仙窍（否则道痕互斥崩溃）。
- **杀招 = 炼蛊残方**：杀招可删减增添蛊材，完善后炼成一只蛊（万我杀招→万我仙蛊），好处是蛊数暴降、催动快、消耗与心智负担锐减；代价是可能消耗其他仙蛊作蛊材，部分杀招（紫血先河阵、燃念飞石）无法单蛊化。
- 详细配方见第二卷、`.workbuddy/research/01_炼蛊合成路径.md`。

## 五、资源体系

- **元石**：凡蛊世界通用货币与真元补给。**仙元石**：只在天庭出产。
- **蛊材／仙材／特殊环境**：见第二卷炼蛊条目与《体系分析报告》§4。
- **辅助蛊**：寸光阴（加速酝酿）、三更蛊（时间加速三倍，代价寿命缩至三分之一）、幡然蛊／浪子蛊（逆炼）、地藏花蛊／皓珠蛊（封印休眠）。
- **三门槛**：能炼化 ≠ 能养活 ≠ 能同时催动，是约束资源爆发的核心机制。

## 六、杀招体系

### 6.1 基本构成

核心蛊（定性质流派）+ 辅助蛊（补条件/规模/载体/防护）+ 发动条件 + 消耗 → 效果 + 缺陷/破解。

### 6.2 协同三类

1. **载体型**：一蛊产「场/气/载体」，另一蛊效果附其上（力气蛊产力之气，兽力虚影附上）。
2. **条件型**：一蛊满足前置，另一蛊生效（定星蛊定位→无极搜锁；毁定位即破）。
3. **增幅型**：一蛊放大另一蛊规模/层级（小光蛊使月刃翻倍但不叠加；慧剑使五指拳心剑升八转）。

> 反例：多蛊同用 ≠ 杀招（月光蛊+小光蛊不是杀招，增幅不叠加）。

### 6.3 消耗形态

真元/仙元、心力（操纵蛊虫，态度蛊只耗心力）、魂魄底蕴（鬼官衣）、寿命（说是道非、炼蛇寿元花）、道痕（剑痕索命、燃魂爆运）、蛊虫损耗（消耗蛊用一次即消失）、时间/蓄力（丰年两三天、防备十息、三十三天光不可移动）、环境/站位（四老分四方、定仙游需地点未巨变）。

### 6.4 凡道 vs 仙道

| 维度 | 凡道 | 仙道 |
|---|---|---|
| 组成 | 凡蛊（三至四五十只） | 仙蛊核心 + 凡蛊辅助（数百至数万） |
| 能量 | 真元 | 仙元（或心力/魂魄/寿命/道痕） |
| 规模 | 单体或小范围，战斗不长久 | 可跨百里、跨天、作用仙窍灾劫 |
| 失败 | 真元枯竭、反噬、蛊损 | 可重伤/暴毙、折损道痕、触怒天意 |
