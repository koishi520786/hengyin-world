# 【原创设定】回声蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 蛊虫名称 | 回声蛊 |
| 品阶 | 二转 |
| 所属流派 | 音道 |
| 蛊虫类别 | 凡蛊 |
| 核心用途 | 侦查（回声标记与追踪） |
| 稀有程度 | 常见偏稀有 |
| 原创编号 | O-G-001 |

**一、外形描述**

- 外观：形如一只干瘪的空蝉蜕，半透明，腹内无实。
- 大小：拇指盖大小。
- 颜色：通体灰白，边缘泛一层极淡的蓝。
- 形态特征：背上有三道环纹，环纹随最近一次「回响」的强弱或深或浅。
- 特殊视觉效果：催动时，空蝉蜕会轻轻震颤，发出人耳几乎听不见的嗡鸣；嗡鸣撞上障碍后会折返，在蛊师心窍中形成「第二重声响」。

**二、核心能力**

- 基础能力：向四周发出一次不可闻的低频回响，声波遇到障碍折返，蛊师据此在脑海中描出周围环境的粗糙轮廓。
- 作用机制：低频声穿透力强、衰减快，只适合近距；声波并非「看见」，而是「听见形状」，故无法分辨颜色、文字，只能勾勒凹凸、疏密与远近。
- 作用对象：半径约十五步内的实体障碍。
- 能力范围：十五步，越远越模糊。
- 效果强度：能辨明通路、门窗、沟壑与静止的大物；对贴地匍匐、柔软吸音之物几乎无效。
- 使用限制：每次催动需持续供真元；环境中噪声越大、杂响越多，轮廓越乱；对有音道修为者，这回响本身可被其察觉。

**三、炼化信息**

- 炼化条件：二转蛊师，音道或兼修音道者炼化更易。
- 炼化难度：低；回声蛊意志微弱。
- 是否存在特殊要求：无。
- 是否有炼化风险：几乎无。

**四、喂养信息**

- 主要食物：静水；每三日一碗。
- 辅助食物：铜铃的锈屑（可让下次回响更清）。
- 喂养频率：每三日一次。
- 喂养成本：低。
- 特殊喂养条件：若在「无声之室」（四面皆吸音软泥）中喂养一次，效果维持更久。
- 长期不喂养的后果：回响逐次变闷，最终无法勾勒轮廓，蜕壳硬化裂开、蛊亡。

**五、优缺点**

- 优势：消耗低、可连发、不依赖光线，黑暗中亦可用；能识破视觉遮蔽但非实体隐藏。
- 劣势：无攻击力；无法辨字辨色；易受噪声干扰；对吸音软物、匍匐贴地之物近乎失明。
- 克制关系：克制以视觉扰乱／迷幻为主的隐匿（因它不靠眼睛）；被音道反制（察觉并扰乱回响）、被水道「静水」环境削弱。
- 适用场景：洞穴、密道、浓雾、黑夜、废墟等目不能视之地。
- 不适用场景：市集、战场、风口等嘈杂处；面对专精音道的对手。

**六、炼制信息**

- 主要材料：一只自然老死的夏蝉蜕壳。
- 辅助材料：三滴春雨后积于凹石的静水、一枚被敲响过九九八十一次的老铜铃碎屑。
- 炼制难度：低。
- 成功条件：在完全无声的静室内，以真元浸润蝉蜕三日。
- 失败风险：低；失败则蝉蜕碎裂，损失材料。
- 是否存在替代材料：可用秋蝉蜕替代，但成品回响偏短。

**七、相关联内容**

- 可以参与的杀招：O-K-003「静夜图」（与倒影蛊、守更蛊协同）。
- 可以搭配的蛊虫：O-G-003 倒影蛊（声像互补）、O-G-004 守更蛊（守夜警戒）。
- 存在的进阶方向：待完善——或可升炼为四转「广域回声蛊」，以扩大范围与抗噪为代价提高消耗（尚未设计）。
- 其他关联资料：见第六卷关联索引。

# 【原创设定】余烬蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 蛊虫名称 | 余烬蛊 |
| 品阶 | 二转 |
| 所属流派 | 炎道 |
| 蛊虫类别 | 凡蛊 |
| 核心用途 | 资源（余火回收炼成可复用火种） |
| 稀有程度 | 稀有 |
| 原创编号 | O-G-002 |

**一、外形描述**

- 外观：一撮永不熄灭的暗红灰烬，无固定形状，被微弱的火星托起悬浮。
- 大小：约一握之灰。
- 颜色：暗红为主，偶见金点闪灭。
- 形态特征：靠近尚有余温之物时，会自行聚拢成一小团火茧。
- 特殊视觉效果：吞食余火时，灰烬表面浮起细密火星，如星子自下而上攀爬。

**二、核心能力**

- 基础能力：吸收环境中的「余火」「余温」——篝火残烬、灶膛余炭、被炎道攻击灼烧后残留的余焰——将其凝练为可存蓄的「火种」。
- 作用机制：余烬蛊只回收「将熄未熄」的火，不主动引火；它把散逸的热力压成一点火种，封存在自身灰烬中，蛊师需要时再引燃。
- 作用对象：一切余温未散的炭、灰、残焰。
- 能力范围：贴身，约数尺。
- 效果强度：积满一握灰，可存约可维持一夜营火之热；火种可反复引燃、多次取用，但每取一次总量减。
- 使用限制：不能凭空生火，必须有「余温来源」；封存的火种会缓慢流失，最长存续七日；遇水即大损。

**三、炼化信息**

- 炼化条件：二转蛊师，炎道或兼修炎道者更易。
- 炼化难度：中。
- 是否存在特殊要求：需亲手以真元护住一次「自然熄灭的火」至最后一星。
- 是否有炼化风险：低；但若炼化失败，火星反扑可灼伤蛊师心窍。

**四、喂养信息**

- 主要食物：余温炭灰（以将熄的炭火喂食）。
- 辅助食物：无。
- 喂养频率：视取用情况；不取用时每七日喂一次即可。
- 喂养成本：低。
- 特殊喂养条件：最好喂「自己参与熄灭的火」，火种更纯。
- 长期不喂养的后果：火种彻底冷透，蛊成死灰，无法再醒。

**五、优缺点**

- 优势：把「必然浪费的余热」变作资源；无明火时是唯一稳定的火种来源；配合炎道杀招可省真元。
- 劣势：无直接攻击力；火种会自然流失；遇水、遇冰即毁；对「已经冷透」的炭灰无用。
- 克制关系：被水道、冰雪道克制；能辅助炎道（作为火种后备）。
- 适用场景：荒野、长夜、断粮断源时；炼蛊需稳定火候时。
- 不适用场景：水域、雪原、无处取火之地。

**六、炼制信息**

- 主要材料：一场「天火」（雷击起火）烧过的枯木所余之炭。
- 辅助材料：夜露九滴、松脂一捻。
- 炼制难度：中。
- 成功条件：在无风之夜，以真元将炭灰中最后一星火「温养」至天明不灭。
- 失败风险：中；失败则炭灰散尽，且可能引火自灼。
- 是否存在替代材料：可用常年不断火的炭窑余灰，但成品火种不纯、存续更短。

**七、相关联内容**

- 可以参与的杀招：O-K-004「星火燎原」（余烬蛊作火种，供炎道群攻起手）。
- 可以搭配的蛊虫：O-G-007 聚尘蛊（聚气，余烬存火）。
- 存在的进阶方向：或可升炼为四转「不熄蛊」，火种存续延长至年计（尚未设计）。
- 其他关联资料：见第六卷。

# 【原创设定】倒影蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 蛊虫名称 | 倒影蛊 |
| 品阶 | 三转 |
| 所属流派 | 水道 |
| 蛊虫类别 | 凡蛊 |
| 核心用途 | 侦查/伪装（水面倒影成像、以假乱真） |
| 稀有程度 | 稀有 |
| 原创编号 | O-G-003 |

**一、外形描述**

- 外观：一尾极扁的银鱼，游于水面时几乎与光融为一体。
- 大小：两指长。
- 颜色：银白，腹下泛青。
- 形态特征：静止时扁如刀片，可贴伏水面；游动时尾鳍搅起一圈不易察觉的细纹。
- 特殊视觉效果：潜入水中后，会「记住」最近一次映在水面的画面，并把它短暂地留在水面。

**二、核心能力**

- 基础能力：把一片水面当作「镜」，摄下此刻映于水面的影像，并将其凝固在水面数息，供蛊师读取；也可用其倒影覆盖真实水面，制造「假倒影」。
- 作用机制：倒影蛊吃的是「光的反射」，它在水面存下一层极薄的水膜，把已摄下的画面固定在水膜上；旁人看去，水面倒影与真实无异，却已是数息前的旧景。
- 作用对象：一片静水面（约一丈见方）。
- 能力范围：需目视水面；摄取与显影都限于同一片水。
- 效果强度：能清晰摄下并回放数息前的倒影；能造「假倒影」误导观察者，但假倒影是静态的，一经细看会露破绽。
- 使用限制：必须静水，流水、波涛皆不可；光照不足时影像极淡；只能作用于水面，不能凭空成像。

**三、炼化信息**

- 炼化条件：三转蛊师，水道或兼修水道者更易。
- 炼化难度：中。
- 是否存在特殊要求：无。
- 是否有炼化风险：低。

**四、喂养信息**

- 主要食物：月华照射过的静水。
- 辅助食物：银屑。
- 喂养频率：每五日一次。
- 喂养成本：低。
- 特殊喂养条件：满月之夜喂一次，可增强下次显影的清晰度。
- 长期不喂养的后果：水膜渐干，蛊僵死。

**五、优缺点**

- 优势：不靠真元「看」，而是「借水面之镜」，隐蔽性强；可回放旧景、可伪造倒影；配合回声蛊可补足视觉。
- 劣势：无攻击力；极度依赖静水环境；假倒影静态、细节经不起推敲；被光道「强光」直接废掉水膜。
- 克制关系：克制需要「持续目视」的侦察；被光道（强光破坏水膜）、冰雪道（冻结水面）克制。
- 适用场景：湖畔、池塘、水井、雨后积水、蓄水陷阱旁。
- 不适用场景：荒漠、无水面、大风浪、极寒结冰之地。

**六、炼制信息**

- 主要材料：一尾在满月之夜浮头望月的银鱼。
- 辅助材料：一面照过月亮的古铜镜的镜面水汽。
- 炼制难度：中。
- 成功条件：于静水之畔，以真元将银鱼与水膜「合」为一体，期间水纹不可破。
- 失败风险：中；失败则银鱼脱水而亡。
- 是否存在替代材料：可用白鳞鱼替代，但成品只能显影、不能造假。

**七、相关联内容**

- 可以参与的杀招：O-K-003「静夜图」。
- 可以搭配的蛊虫：O-G-001 回声蛊、O-G-004 守更蛊。
- 存在的进阶方向：或可升炼为五转「镜中月蛊」，可把倒影固定更久、并小范围折射光线（尚未设计）。
- 其他关联资料：见第六卷。

# 【原创设定】守更蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 蛊虫名称 | 守更蛊 |
| 品阶 | 三转 |
| 所属流派 | 律道 |
| 蛊虫类别 | 凡蛊 |
| 核心用途 | 辅助（固定节律内强化「守约」状态） |
| 稀有程度 | 稀有 |
| 原创编号 | O-G-004 |

**一、外形描述**

- 外观：一枚古朴的更鼓，仅指尖大，鼓面紧绷。
- 大小：指尖大小。
- 颜色：木色鼓身，鼓面灰白。
- 形态特征：鼓身刻着均匀的刻线，恰如一夜的更次。
- 特殊视觉效果：每过一刻，鼓面会自行轻颤一下，发出几乎只有蛊师能听见的「笃」。

**二、核心能力**

- 基础能力：设定一个「更次节律」（如守一夜、候三更），在节律存续期间，使蛊师的「守约/戒备」状态获得律道加持——精神更清明、不易被催眠或惑乱，对违反既定节律的异动更敏锐。
- 作用机制：守更蛊把「时间」划成固定的更次，蛊师与其「定约」后，节律成为一道微弱的律道道痕，约束心神不散、不惰。
- 作用对象：蛊师自身（守约者）。
- 能力范围：本人。
- 效果强度：能抵御轻微的精神惑乱与困意；对「掐准更次发动」的异动有提前警觉。
- 使用限制：一次只能定一个节律；节律一破（如失约、睡着、被打断）加持即散，且当夜不可再定；只护「守约」不护「肉身」。

**三、炼化信息**

- 炼化条件：三转蛊师，律道或兼修律道者更易。
- 炼化难度：中。
- 是否存在特殊要求：需一位从未失约者的一句「我必守此更」作炼化之引。
- 是否有炼化风险：低。

**四、喂养信息**

- 主要食物：以「准时」为食——蛊师每守约一次，鼓面便得一分滋养。
- 辅助食物：夜露。
- 喂养频率：随守约频率；久不守约则需喂夜露维持。
- 喂养成本：低。
- 特殊喂养条件：无。
- 长期不喂养的后果：鼓面松弛、更次紊乱，最终无法定约，蛊亡。

**五、优缺点**

- 优势：守护心神、反制惑乱，是少数「非战斗却能在持久对峙中起决定性作用」的蛊；无需持续耗真元。
- 劣势：无攻击、无防御；节律被外力强断即失效；只对「守约」类情境有效，对正面强攻无用。
- 克制关系：克制梦道/惑乱类轻微侵扰；被强行打断节律的手段克制。
- 适用场景：守夜、值守、伏击、候人、盯梢等需长期保持清醒与定力的场合。
- 不适用场景：短促遭遇战；节律频繁被打断的混乱战场。

**六、炼制信息**

- 主要材料：一块被更夫敲了十年、从未误时的更鼓鼓皮。
- 辅助材料：更夫的一根白发。

**七、相关联内容**

# 【原创设定】断尾蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 蛊虫名称 | 断尾蛊 |
| 品阶 | 四转 |
| 所属流派 | 变化道 |
| 蛊虫类别 | 凡蛊 |
| 核心用途 | 保命（舍弃肢体分身，代偿一次致命伤） |
| 稀有程度 | 稀有 |
| 原创编号 | O-G-005 |

**一、外形描述**

- 外观：一截蜷曲的蜥尾，断口处永远滴着不肯干涸的一滴血。
- 大小：小指长。
- 颜色：灰绿，断口猩红。
- 形态特征：遇危时会骤然绷直、微微跳动，似要自行断离。
- 特殊视觉效果：催动时，断口那滴血会化开，在蛊师身外映出一个「将要舍弃」的虚影。

**二、核心能力**

- 基础能力：在致命一击及身的瞬间，将「这一击」连同被击中的一部分身躯，一起割舍到断尾蛊化出的替身上，本体以残躯脱身。
- 作用机制：变化道「弃形求生」——断尾蛊吃的是「舍弃」本身。它在蛊师体内种下一道「可弃」的标记，命中时把伤害与道痕一起引向被舍弃的部分。
- 作用对象：本人（一次性替死）。
- 能力范围：本人。
- 效果强度：可代偿一次「足以致死的直接打击」，本体存活，但被舍弃的部分永久失去（含其上道痕）。
- 使用限制：每只断尾蛊只能用一次；只对「有形的、可落到肉身上的直接伤害」有效，对魂魄、诅咒、灾劫、梦道侵蚀等无形伤害无效；舍弃的部分不可复原。

**三、炼化信息**

- 炼化条件：四转蛊师，变化道或兼修变化道者更易。
- 炼化难度：高。
- 是否存在特殊要求：需蛊师自愿「让出」身上一块肉作种蛊之引，此块肉日后即是最先被舍弃的部分。
- 是否有炼化风险：高；炼化失败会永久损失那块引肉及其道痕。

**四、喂养信息**

- 主要食物：蛊师自身的一滴血（低频）。
- 辅助食物：其他生灵「断尾求生」后新生的嫩尾。
- 喂养频率：每半月一次。
- 喂养成本：中（损耗自身气血，虽可回补）。
- 特殊喂养条件：无。
- 长期不喂养的后果：断尾蛊与蛊师血肉联结渐松，替死时将「多舍」一截本不该舍的部分。

**五、优缺点**

- 优势：保命上限极高，能挡下必死之击，是稀缺的「多一条命」手段；只需一只、不占多个空窍位。
- 劣势：代价是永久丧失一部分肉身与道痕；只挡有形直接伤害；一次性、不可叠加多次替死；舍弃后的残躯需长时间休养。
- 克制关系：克制单体强攻型的「一击必杀」；被魂道、诅咒、梦道、律道（限死）等无形手段克制，被「范围持续伤害」克制（仍只舍一次）。
- 适用场景：强敌单挑、被偷袭、突围保命。
- 不适用场景：面对魂道/梦道/灾劫/群体围杀。

**六、炼制信息**

- 主要材料：一尾真正断尾求生、且最终重生的石龙子（蜥蜴）的旧尾。
- 辅助材料：蛊师自身一块自愿让出的血肉。
- 炼制难度：高。
- 成功条件：在蛊师命悬一线（重伤濒死）之时方成——炼成即种下。
- 失败风险：高；失败则引肉与材料皆损。
- 是否存在替代材料：可用壁虎尾替代，但替死效果打折，会「多舍」更多本体。

**七、相关联内容**

- 可以参与的杀招：不参与杀招（纯保命蛊）。
- 可以搭配的蛊虫：任何蛊皆可搭配；尤其配合 O-G-005 之后仍能行动的移动蛊更佳。
- 存在的进阶方向：或可升炼为六转仙蛊「壁虎尾」，可多次替死但仍需逐次舍弃（尚未设计）。
- 其他关联资料：见第六卷。

# 【原创设定】问路石蛊

| 核心用途 | 移动/侦查（记录并指引用走过的路径） |
| 稀有程度 | 常见偏稀有 |
| 原创编号 | O-G-006 |

**一、外形描述**

- 外观：一颗圆润的鹅卵石，石上生着细如发丝的纹路。
- 大小：鸽卵大小。
- 颜色：青灰，纹路银白。
- 形态特征：走过之处，石纹会自行「长」出一条新的细线，对应走过的路。
- 特殊视觉效果：问路时，石上会亮起一条淡光，顺着该走的纹路流动。

**二、核心能力**

- 基础能力：自动记录蛊师走过的路径（以石纹刻画），问路时以微光指引回溯；也能「擦去」某段不想被记住的路。
- 作用机制：问路石以土道道痕「记住」大地的起伏与自身移动，形成一份只有蛊师能读的私密路图。
- 作用对象：本人走过的路（以自身足迹为限）。
- 能力范围：记录无上限，但只记「走过的」，不记「没走过的」。
- 效果强度：能精确回溯走过的路径；但只记录经过，不记录沿途变化后的现状。
- 使用限制：必须本人亲自走过；被外力抹去足迹（如水冲、翻土）不会影响石纹，但若蛊师刻意「忘路」，石纹也会淡去。

**三、炼化信息**

- 炼化条件：二转蛊师，土道或兼修土道者更易。
- 炼化难度：低。
- 是否存在特殊要求：无。
- 是否有炼化风险：无。

**四、喂养信息**

- 主要食物：路上的一撮浮土。
- 辅助食物：无。
- 喂养频率：每行一段路可顺带喂一次。
- 喂养成本：极低。
- 特殊喂养条件：无。
- 长期不喂养的后果：石纹渐淡，路图渐失。

**五、优缺点**

- 优势：低成本、无需持续耗真元；在迷宫、密林、雾中、沙丘等易迷路之处极实用；路图私密，他人夺石也读不懂。
- 劣势：只记走过之路，不探未知；无战斗能力；记录的是「过去的路」，不反映实时变化。
- 克制关系：几乎无直接克制；被「夺走蛊虫」可读石无用（私密性）。
- 适用场景：探险、追踪回撤、送货、勘探。
- 不适用场景：正面战斗；完全未知、需即时探测之地（应配合回声蛊）。

**六、炼制信息**

- 主要材料：一块在岔路口被无数人踩过、磨得圆润的鹅卵石。
- 辅助材料：一位老向导的一句指路之言（声入石中）。
- 炼制难度：低。
- 成功条件：以真元将石纹「刻」入，全程不可离手。
- 失败风险：低。
- 是否存在替代材料：可用河滩卵石替代，但成品路图更易散。

**七、相关联内容**

- 可以参与的杀招：O-K-003「静夜图」（作路径底图）。
- 可以搭配的蛊虫：O-G-001 回声蛊、O-G-003 倒影蛊。
- 存在的进阶方向：或可升炼为四转「旧路重走蛊」，可重演一次走过的路径上的情景（尚未设计）。
- 其他关联资料：见第六卷。

# 【原创设定】洄游蛊

| 项目 | 内容 |
|---|---|

| 品阶 | 四转 |
| 所属流派 | 宇道 |
| 蛊虫类别 | 凡蛊 |
| 核心用途 | 移动（标记两点，成对往返通路） |
| 稀有程度 | 稀有 |
| 原创编号 | O-G-008 |

**一、外形描述**

- 外观：一对并生的鱼形石坠，一大一小，鱼首互衔，可拆作两半。
- 大小：拇指长。
- 颜色：青黑，衔口泛银。
- 形态特征：拆开后，两半会各自朝对方「游」去的方向微微倾斜。
- 特殊视觉效果：催动时，两半之间的虚空会荡起一圈极淡的涟漪。

**二、核心能力**

- 基础能力：拆作「母、子」两半，分别置于两地，可在二者之间架设一条仅蛊师可用的短距宇道往返通路。
- 作用机制：宇道「成对通路」——比原著洞地蛊弱化：只容本人或极小物件往返，且距离受限。

- 辅助食物：水流冲刷过的卵石。
- 喂养频率：每用必补；不用则每半月补一次。
- 喂养成本：中。
- 特殊喂养条件：无。
- 长期不喂养的后果：游力耗尽，两半失去联系，通路永断。

**五、优缺点**

- 优势：往返机动、可藏匿、可设伏；比之瞬移类蛊，胜在「成对、可重复、私密」。

- 克制关系：被宇道封锁、阵道封印克制；标记点暴露即被针对。
- 适用场景：据点到战场、城内到城外、伏击后的撤离。
- 不适用场景：长途；无预置标记的突发逃亡。

**六、炼制信息**

- 辅助材料：两地各取一撮土（或各取一滴水）。
- 炼制难度：高。

- 失败风险：中。

**七、相关联内容**

- 可以搭配的蛊虫：O-G-009 记仇蛊（设伏后反击）。
- 存在的进阶方向：或可升炼为六转仙蛊「归途蛊」，距离与容量大增（尚未设计）。
- 其他关联资料：见第六卷。

- 颜色：乌黑，偶泛一丝暗红。

- 能力范围：本人；感知范围约百步。

- 使用限制：只能记「确有深仇」之人，虚造的恨意种不下；恨印最多存三道；燃尽一次即耗一道，需重新刻录。

**三、炼化信息**

**一、外形描述**

- 外观：一支无墨的笔，笔尖永远悬着一滴透明的「空墨」。
- 大小：寻常笔。
- 颜色：笔身素白，空墨无色。
- 形态特征：笔身刻满极细的刻度，如缩小的画作。

- 使用限制：一次只能复刻一件，且须「当面」描形；复制品不能承载能力；复刻仙蛊时，其唯一性不受影响（因只是空形）。

- 炼化难度：高。

- 是否有炼化风险：中。

**四、喂养信息**

- 主要食物：仙元（低频）。
- 辅助食物：各色颜料（增描形之精）。
- 喂养频率：每用必补仙元；不用则每月一次。

**五、优缺点**

- 适用场景：欺敌、炼蛊前试形、布疑阵。
- 不适用场景：需真材实料、真能力的场合。

**六、炼制信息**

- 炼化难度：高。

**四、喂养信息**

- 主要食物：仙元（低频）。
- 辅助食物：清越钟声。
- 喂养频率：每用必补；不用则每月一次。
- 喂养成本：中。
- 特殊喂养条件：无。
- 长期不喂养的后果：钟壁渐哑，无法存音。

**五、优缺点**

- 优势：以彼之道还施彼身，出其不意；可反制音杀、可打乱对手节奏。
- 劣势：只能延迟不能放大；只对有声音攻击有效；存音槽单一、易被预判。
- 克制关系：克制音道直线攻击；被无声音、魂道、梦道克制。
- 适用场景：反制音杀、音道对轰。
- 不适用场景：静默战斗。

**六、炼制信息**

- 主要材料：一座被敲响后余音绕梁三日不绝的古钟。
- 辅助材料：仙材「余音」一缕。
- 炼制难度：高。
- 成功条件：以仙元将「余音」炼入钟内，令其可存可返。
- 失败风险：中。
- 是否存在替代材料：无。

**七、相关联内容**

- 可以参与的杀招：O-K-007「空谷回音」（回响蛊作核心）。
- 可以搭配的蛊虫：O-G-001 回声蛊（凡蛊，与回响蛊同源）。
- 存在的进阶方向：或可升炼为八转「回响境蛊」，可成片返还、多音同存（尚未设计）。
- 其他关联资料：见第六卷。

## 三、原创特殊蛊虫

---

# 【原创设定】熄烛蛊

**基本资料**

| 项目 | 内容 |
|---|---|
| 蛊虫名称 | 熄烛蛊 |
| 品阶 | 无定转（伴生蛊，随宿主而定） |
| 所属流派 | 暗道 |
| 蛊虫类别 | 特殊蛊（伴生蛊） |
| 核心用途 | 依附宿主蛊，宿主「熄灭」时带走一缕光/热/声 |
| 稀有程度 | 稀有 |
| 原创编号 | O-G-201 |

**一、外形描述**

- 外观：一截极短的白蜡，无芯，却自行发着幽光。
- 大小：米粒长。
- 颜色：蜡白，光幽蓝。
- 形态特征：须依附于另一只蛊方可存在，离开宿主即暗淡。
- 特殊视觉效果：宿主蛊消亡的瞬间，熄烛蛊会骤然一明，随即「带走」一样东西。

**二、核心能力**

- 基础能力：依附于一只宿主蛊（多为光道、炎道、音道等「有光/热/声」之蛊）。当宿主蛊被毁、被夺、或被强行熄灭时，熄烛蛊以自身为代价，把宿主最后一缕「光/热/声」抽走并封存，使现场不露其熄灭的痕迹。
- 作用机制：暗道「灭迹」——它不是保命，而是「善后」：令对手无法从「光灭/火熄/声止」的瞬间判断宿主蛊死因与方位。
- 作用对象：宿主蛊的最后一缕光/热/声。
- 能力范围：随宿主。
- 效果强度：可抹去宿主蛊消亡瞬间的「动静」，制造「它还在」或「它本就没有」的假象。
- 使用限制：自身无法独立存在；宿主一灭，熄烛蛊随即同灭（一次性）；只能灭「迹」，不能救「命」。

**三、炼化信息**

- 炼化条件：随宿主蛊一同炼化。
- 炼化难度：中。
- 是否存在特殊要求：须与宿主蛊同源炼化。
- 是否有炼化风险：低。

**四、喂养信息**

- 主要食物：随宿主蛊同喂，无需单独喂养。
- 辅助食物：无。
- 喂养频率：随宿主。
- 喂养成本：无额外。
- 特殊喂养条件：无。
- 长期不喂养的后果：随宿主蛊衰亡。

**五、优缺点**

- 优势：极隐蔽的「灭迹」手段，是刺客、间谍类蛊师的利器。
- 劣势：不能独立存在、不能救宿主、一次性；只灭「迹」，不造成任何伤害。
- 克制关系：克制「观光/火/声判断」的侦查；被更高明的「观道痕」侦查识破。
- 适用场景：暗杀、潜入、销毁证据、伪装蛊虫仍在。
- 不适用场景：正面对抗。

**六、炼制信息**

- 主要材料：一根在无风之夜「无端熄灭」的蜡烛。
- 辅助材料：宿主蛊的一缕气息。
- 炼制难度：中。
- 成功条件：以真元将蜡烛「并」入宿主蛊，使其同生共灭。
- 失败风险：低。
- 是否存在替代材料：无。

**七、相关联内容**

- 可以参与的杀招：O-K-005「走马灯」（作灭迹组件）。
- 可以搭配的蛊虫：O-G-010 转灯蛊、O-G-002 余烬蛊。
- 存在的进阶方向：或可升炼为「灭灯蛊」，可成片灭迹（尚未设计）。
- 其他关联资料：见第六卷。
