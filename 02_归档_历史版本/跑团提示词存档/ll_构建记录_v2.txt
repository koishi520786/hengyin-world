## 5. 结构决策（v3 定稿采用）

**双层文档，单文件自包含**：
- 【常驻指令层】零～六、十二～十九：精简规则内核，正向条件句 + 编号，首尾各一次硬约束。
- 【资料层】七～十一：前史编年、体系数值、制度条款、地下城表、索引规则。显式标注「查表用；永不进入叙事文本；不得照抄其措辞；前史细节须经可见载体 + 能读懂的人 + 三条独立线索转译」。

**语域三色词表**（替代「不得写成古风」）：
- 允许：台账、复审、保单、配额、入闸、层级、资质评级、执照编号、作业票、事务所、稽查、监理、承保、核销、归属、转数、蛊性、执业方向。

**每轮输出顺序**：内部复述硬前缀 → 重建状态块 → 定结果档位 → 写「可见变化 → 人物言行（含代价宣告） → 交还行动权」→ 执行卡自检 → 输出。

## 7. v4 · 本轮追加记录（2026-11-11）

### 7.1 本轮要解决的问题

用户原话的核心不是「设定全不全」，而是：**几百上千种蛊虫 AI 记不住又会不会自己乱命名、自己说秘境里有什么**；以及流派（食道／奴道／力道／气道／语道／天道／人道）、杀招怎么诞生与怎么克制（送友风这类超标招）、擂台与外界压力、任务驱动。并指定工作流：**先把提示词交给自己跑几轮，逐轮自问哪里玩不下去，再改**。

### 7.2 自跑复盘：8 个卡点

| 2 | 「嗯。」 | 含混短句谁听见、算不算承诺无规则 | 铁律补 1e：逐人判听者，无人解释成承诺／同意／拒绝／态度 |

### 7.3 四路考据的关键纠错（不顺着错）

- **语道不存在**：原著与百科流派清单均无「语道」/「言道」；信息契约名号归**信道**，声音频率归**音道**。易混项「一言仙」是智道蛊仙人名。
- **原著无流派相克表**，只有道痕互斥；硬对抗轴为「天道反制智道推演」「变化道反破律道封锁」。

## 10. v7 · 反思与精简重构（2026-11-12 晨）

### 10.1 用户实测反馈（比此前所有考据都重要）

> 「我实测发现，一段简短的提示词反而比你之前用的一大段提示词效果更好。请反思这一点：不要再拘泥于繁琐的规则式写法，而应该总结提示词写作的核心原则（简洁、明确、直击目标），并在后续生成提示词时优先采用精炼、聚焦的表达方式。」

### 10.2 反思：我此前做错了什么

一整晚把文件从 558 行堆到 **1368 行 / 179.8 KB**，方向是错的。具体错因：

1. **把「防模型犯错的补丁」当成质量**。每次发现一个失败模式就加一条禁令、加一张裁决表、加一项执行卡；92 处禁令、24 行硬前缀、37 项执行卡、九类输出形态例外表——这些本身成了新的冲突源，逼得模型「无论怎么做都违反一条」，后面几轮全在修自己制造的死锁。
2. **长上下文衰减被我用「重注入」硬扛**，而不是减少长度。首尾效应、lost-in-the-middle 的研究结论我查过，却选择加更多首尾声明，等于给已经过重的提示词再加压。
3. **把数值表、考据纠错、误写清单、物价、流派谱系全塞进系统提示词**。这些是「按需查阅的资料」，不是「每轮生效的指令」；混在一起后，模型和玩家都分不清哪些是规则、哪些是背景。
4. **否定了自己早先的正确判断**。用户说过「提示词是次要的，主要看扮演的人」，我也写过「条文能压住三四成，压不住骨子里的语气」——但随后仍按工程思维不停加条文。
5. **篇幅被当成完成度**。每一次汇报都报行数与条目数，实际交付质量与体量负相关。

结论：**提示词的作用只是划场地、立边界；演得好不好主要靠模型语感。边界越少越清楚，模型越有余力去演。**

### 10.3 提示词写作核心原则（写入用户级与项目级 MEMORY，长期生效）

**简洁、明确、直击目标。**

1. 只保留五件：一句话身份与目标／3 条以内不可绕过的红线（正向短句）／会改变当轮判断的关键世界事实／输出形态一句话／5–7 问简短自检。
2. 不复述优先级、不堆执行卡与硬前缀、不把数值表与考据塞进系统提示词；详细设定外置为按需备查文件。
3. 不靠「再加一条禁令」修模型毛病；长提示词中部规则会被忽略，补丁之间会互相打架。
4. 少用抽象形容词，改用可判定的短句。
5. 用户明确锁定的硬约束必须保留，其余交给模型语感。
6. 交付时给「精简版 vs 长版」体量对比，不把篇幅当质量。

## 11. 深层人口与血料底层（2026-11-12 · 用户补充世界观）

### 11.1 考据结论（四处硬依据）

1. **上亿人**：第一百四十二节「屠杀亿民」——火原洞天「生活了上亿的纯正人族」，方源令「全都杀了，用来铸造人海」，骨、血肉、内脏、人魂分类整理成蛊材。至尊仙窍超五亿亩、分十层。
2. **时间流速**：第三卷 96 节——灾劫按仙窍自身时间计，「每个仙窍引入的光阴支流规模不同」；狐仙福地约 5 倍，黑楼兰特等福地 **1:38**；第 1024 章方源至尊仙窍 **1:60**（外界一天＝仙窍两个月）。
3. **人口快速再生产**：第 3600 集「天道梦境」——「送生庙」人道仙蛊屋（怀胎／三胎／死胎／多胎／安胎蛊），三胞胎中两胎炼骨肉团圆蛊、一胎受保护，宙道辅助使「整个怀胎到出生不超过 7 天」，原文「各族人口就能迅速增长」；方源的循环是「多生育 → 血颅蛊海量屠杀 → 人海复活 → 再循环」。
4. **人可买卖**：第三卷 36 节北原奴隶市场公开叫卖（「五个男奴才卖半块元石」）；宝黄天「甚至异人、人族亦可在其中交易贩卖」；第三卷 455 节正道蛊仙石忠拿人当蛊材炼财富蛊，奴隶「直接在宝黄天中收购」，自忖「只要秘而不宣，就没有人知道」。

### 11.2 两处纠错（不顺着错说）

- **「随机刷新」不准确**：原著不是天地凭空刷人，而是**主动经营**出来的——仙窍空间＋人道蛊屋＋宙道加速＋人海循环。人口是「养」出来的，需要资源、有人经营、承担灾劫，因此有产能上限与成本。
- **「不是明面上买卖」不准确**：前史是**公开买卖**（北原集市、宝黄天挂牌），隐蔽的是**用途**（拿人炼蛊／当血料）；石忠那句「秘而不宣」秘的是用途不是交易。现代层「明面禁止、暗地按批次流转」是本团法理化改写，不是原著口径。
- 另：把这套机制推为「专门供血道」属**本团推导**；原著中它主要用于人道领悟、资质堆料与寿蛊产出。但「稳定人口供给 → 致死型血方也用得起」的推论成立。

### 11.3 落地位置（遵守短提示词优先）

- **主提示词只加一句**（第二节人口条）：册内 1.2 亿有籍有照有配给；深层孕育区还有不进统计、无人籍、按批次流转的册外人口，是黑市高活性血料与炼材用度的来源，明面册籍不可转让、暗地按批次计价。
- **考据与转写全进 `ll_设定备查.txt` 附节**：原著事实表、两处口径纠正、现代层转写、扮演约束。不进每轮叙事。

### 11.4 与现有框架为何不打架（关键平衡）

- 1.2 亿是**册内**统计，册外不进统计、不受保单保护；册外入册内走「回册」。两套数字不冲突。

### 12.6 叙述者介入（2026-11-12 上午续二）

用户指出一类更隐蔽、也更伤阅读的毛病，并给了它的正式名字：**叙述者介入**（作者／旁白跳出来解释），又叫解说式旁白、作者乱入；网文语境里被骂「出戏」「上帝视角」「AI 味」「解释癖」。他举的具体形态是「不像十九岁该有的」——**对照式说明 ＋ 旁白替读者下判断**：正文本来在写茧，忽然插一句年龄对照，等于叙述者停下来解释，把读者该自己感到的「不对劲」直接说破。

**为什么这类毛病比设定错更值得写进提示词**：设定错玩家能容忍（当成另一条世界线），但叙述者介入直接毁掉代入感——它把玩家从「在场」推到「被讲解」。而且它极难被自检发现，因为句子本身通顺、信息也正确，只是位置错了：本该由读者完成的推理，被旁白抢答了。

**完整谱系（写进条款时按类不按例）**：

| 类型 | 形态 | 本质 |
|---|---|---|
| 对照式说明 | 拿年龄、身份、性别、常理作参照比较 | 旁白拿两个信息做比较，替读者完成推理 |
| 替读者定性 | 直接宣布「不正常」「没那么简单」「显然在撒谎」 | 读者本可从细节得出，旁白抢答 |
| 情绪翻译 | 动作后面挂情绪名词 | 等于给读者划重点，动作失去留白 |
| 动机注解 | 给动作补一个旁白推断的原因 | 把可观察行为降级为结论注脚 |
| 意义升华 | 段末拔高、「这一刻他明白了」 | 强行替读者完成情感结算 |
| 预告悬念 | 「他还不知道，更大的麻烦在等着」 | 元叙述，暴露「这是个故事」 |
| 设定解说 | 借旁白讲世界规则 | 资料层入侵叙事层 |
| 程度代偿 | 极其、无比、难以置信 | 用副词代替具体描写 |
| 叙述者的惊讶 | 竟然、居然、原来 | 替读者表演反应 |

**判据（写进提示词的核心）**：**只写镜头能拍到的东西**——在场者的动作、说出口的话、器物与账目的状态、环境的变化。比较、定性、因果、动机、意义、预告，全都拍不到，因此全都属于旁白介入。辅助判据是**删句测试**：删掉这句，读者还能从已有细节推出同样的意思吗？能，就是解释，删。

**正向替代（比禁令更有效）**：要让人感到异常，就写产生异常的那处实物——位置、厚薄、裂口、力道、时机，以及谁因此停了半拍。异常由细节自己显出来，不由旁白宣布。这一条解决了「只禁不导」的老问题：模型被禁止解释之后，如果没被告知该写什么，就会转向更空的形容词。

**一处取舍**：条款里**没有放例句**。之前已吃过负向例句污染的亏——提示词里写一句「这茧不像十九岁该有的」，模型会在输出时照抄。所以只写类别名与维度（年龄、身份、性别、常理），不给句式。同时点出这类句子的语法标志「像／不像／仿佛／似乎／显然／竟然／原来」——这些词后面往往就是旁白在下结论。

**落地**：`ll.txt` 第七节加两条（判据＋正向替代），默查第 5 问加「有没有一句是旁白在替读者解释或下判断」；`ll_极简版.txt` 输出段与默查同步各加一句。主提示词增至 88 行 / 14.3 KB，仍属短版。

## 13. 长版重建（2026-11-12 上午 · 用户判定极简版不可用）

### 13.1 用户反馈

### 13.2 为什么极简版会「垃圾」

短版把「防模型犯错的规则」压到极少，读起来顺，但**把可演的内容一起删了**：物价、食宿、课表、层级、制度链、人物档案、杀招数值、名录调阅全在备查里，系统提示词里只剩语感与红线。模型于是只能靠通用语感编——不违规，但空。上一轮「短更好」的结论只对**规则密度**成立，对**设定密度**不成立。这两件事被我在 10.2 里混成了一条。

## 15. 第三招换血：送友风 → 自由残缺变（2026-11-12 上午）

## 16. 人物卷：示例对话与排版前置（2026-11-12 上午 · 用户：扮演能力还是差，去网上学）
